# V-0747: レイヴンの持続ダメージの tick の位相のずれは、残り時間の止まりと同じ時刻・大きさか（録画 0122 の読み直し）

- 問い: レイヴン単騎の 0122 の f2136 のまとまりの起点の位相 φ 0.12〜0.17（V-0317）は、まとまりの途中のフレームの途中の大きさの残り時間の止まり（C-0262）で説明がつくか（V-0744 の見立ての再現）
- 話題: スキル・キャラ固有
- 日付: 2026-11-12
- 録画: `0122`
- 結論: `C-0454`
- 状態: 完了

## 条件

- C-0454（仮説）: 持続ダメージの k 回目の tick は、起点 + ceil(φ + k × 間隔 ÷ 0.017)。起点は付いた発のフレームで、始まりの φ は 0 付近（0.01〜0.05）。V-0744（クルミの 058〜060）で、まとまりの途中で φ が 0.3〜0.7 に変わった 3 か所は、同じ時刻の残り時間の止まり（C-0262。フレームの途中の大きさを持つ）と変わった量が合った。この見立ては 058〜060 を見てから立てたもの。
- V-0317（レイヴン単騎の 0122・`0122-25`）: まとまりは 3 つ（起点 f842・2136・5195）。f842 と f5195 は φ 0 付近で、f5195 は k 43 から 1 段上がる。f2136 のまとまり（51 tick）は、6 tick に 1 回ほど 1 tick だけ +1 になり、φ 0.12〜0.17 で 49/51 が一致した。+1 の最初は k = 6（f2490 付近）。
- 0122 の残り時間（`timer.ts`）の止まりは、この記録ではまだ読んでいない。
- 最小構成: 単騎・AUTO。tick の時刻に効くのは、刻み方と止まりだけ。

- f842 のまとまりの k 17 の段は、k × 58.8235 がちょうど整数（1000）になる tick が 1f 後に出る形（V-0744）で、止まりは要らない（予測に使わない）。

## 読み方

1. `timer.ts --mode stalls` と `--mode runs` で、0122 の止まりの区切りと大きさ（前後の共通部分の差の両端と真ん中）を取る。
2. 止まりを、V-0317 の 3 つのまとまりの tick（`0122-25`）の時刻に当て、まとまりごとに、止まりの前後の区間で φ（起点からの ceil(φ + k × 58.8235)）を当てはめ直す（V-0744 と同じ）。
3. 読んだ値は観測値にする（`source` に `V-0747`）。

## 分かったこと・分からないこと

- **まとまりの途中の大きな止まりの後で、tick も止まりと同じだけずれることは、別のキャラ（レイヴン）の録画でも 1 か所で合った**（V-0744 の見立ての再現。和 1.24 の止まりと φ の 1 のずれ）。
- **始まりの φ は、止まりでは説明がつかないぶれを持つ**。f2136 のまとまりは始まりから 0.12〜0.17 で、止まりは無い。クルミの 2 つのまとまり（−0.11〜−0.06。V-0744）と合わせ、始まりの φ は −0.11〜0.17 の幅でまとまりごとに違う。出どころは分からない（V-0317 は、ゲーム内の時刻を 0.017 秒ずつ浮動小数で積み上げる誤差とみたが、確かめていない）。
- **残り時間の止まりのうち、tick がずれないものがある**: 0122 の 4753（0.29。戦闘開始から約 68 秒）と 9519（0.21。約 149 秒）。V-0744 の、3 本に共通の時刻（約 62・114・155 秒）の 0.18〜0.24 と同じく、的のジャンプの頃の止まり。残り時間の表示だけの止まりか、ゲーム内の時計の止まりかは分からない。
- C-0454 は仮説のまま。始まりの φ のぶれの出どころが分からないため。モデル（`dot.ts`。φ = 0）は変えない（ぶれは ±0.17 の幅で、四捨五入（φ = 0.5）より φ = 0 に近い）。

## 次に撮るもの

- 撮影は要らない。始まりの φ のぶれを確かめるなら、付いた発の前後の止まりを細かく読む（`timer.ts --mode runs` の a の幅は 0.06 で、0.1 前後のぶれは区切りとして出ない）か、別の録画のまとまりの始まりの φ を集めて、戦闘開始からの時刻と比べる（浮動小数の積み上げの誤差なら、時刻とともに広がる）。

## 0. 要約

- I・II の遅れの定数（C-0219 ニヒリスター・C-0220 フラワー・C-0230 ユニ・C-0479 アドミ）は、右のバースト欄の六角形の替わり目から数えた値。モデルはこれを本当の発動（満タンから 23f。C-0285）に足しているので、満タンから数えたヒットが実機より 4〜5f 早い。V-0382 で、新しく読んだ 2 本（223・081）と後付けの 2 本（077・134）がどれもそうだった（いまのモデルで 4 件とも許容外）。
- 推す直し方（3.1 節の A）: 定数はそのまま、I・II の遅れを足す起点を「替わり目」（本当の発動の 5f 後。3.2 節）にする。チェーン・CT・フルバーストの窓は本当の発動のまま。
- 手元の試しで、許容外は **36 → 26**（減る 10・増える 0）。V-0382 の 4 件と、クラウンの効果の付き始め（`302-14`〜`302-22`）が許容内に入る。ほかの観測値は動かない（5 節）。

## 2. 遅れの表に無い I・II のキャラ

- 遅れの表に無いキャラ（遅れ 0。未測定）のヒット・効果は、いまどおり本当の発動に置く（A でも変えない）。
- 裏付け: 測った I・II の効果の付き始めは、どれも替わり目より前だった。クラウン（II）は替わり目の 3〜6f 前（C-0499）、リター・クルミ・エマ：TU（I）は替わり目の 1〜2f 前の発に▲が乗る回がある（V-0370・V-0371・V-0376）。本当の発動は替わり目の 6f 前なので、「遅れの無い効果は本当の発動の頃に付く」と読める。A では、クラウンのモデルの効果（本当の発動）が替わり目の 5f 前になり、`302-14`〜`302-22` が許容内に入る（5 節）。
- C-0499 の文（「モデルは発動より前に効果を置けないので、遅れ 0 がいちばん近い」）は、A では「モデルの発動（本当の発動）は替わり目の 5f 前なので、遅れ 0 で合う」になる。`model` 欄だけを直し、状態は仮説（単独実測）のまま。

- A を推す理由:
  1. 遅れの定数は動画で替わり目から読んだ値そのままで、これからほかのキャラの遅れを読むときも、読んだ値を表に書けばよい。B は表に書くたびに 5 を足すことになる。
  2. B は確定の結論 C-0219・C-0220・C-0230 の文（「替わり目から N f」）を訂正（棄却して置き換え）することになる。A は文を変えない（design-activation-stall-video.md 3.2 節の A と同じ考え方）。
  3. 「替わり目は本当の発動の 5f 後」を 1 か所（定数 1 つ）に置ける。III の起点（4 節）を同じ形で扱うときも、`hexagonFrameOf` に足せばよい。
- A でも B でも、チェーン・CT・フルバーストの窓・与ダメージの計算の順は変わらない（動くのは I・II の遅れの行のヒットと効果のフレームだけ）。

### 3.2 5f の値

- 5 = 満タン → 替わり目 29f（C-0220）− 満タン → 本当の発動 23f（C-0285。モデルの `BURST_READY_DELAY_FRAMES`）− 発動の止まり 1f（C-0289。`ACTIVATION_STOP_VIDEO_FRAMES`）。確定の結論とモデルの定数から出る値で、V-0382 の観測値に合わせた値ではない。
- V-0382 の 4 件の差は、5 なら 0〜+1、4 なら −1〜0 で、どちらも許容（±2f）の中。C-0285 の 23f は 22.6〜23.9f の幅を持つので、観測値からは 4 と 5 を分けられない。推奨は 5（合わせ込みをしない。モデルのほかの定数と同じ出どころ）。

### 3.3 結論

- 新しい結論（話題「バーストの段階とフルバースト」）: 「I・II の発動の次の段の六角形の替わり目は、本当の発動のゲーム内 5f 後（動画では発動の止まりを含めて 6f 後）。I・II の遅れの定数はそこから数えるので、遅れて出るヒットは満タンから I は 29f + 定数、II は 58f + 定数（動画のフレーム）」。根拠は V-0382 の観測値。値を決めた録画（134。C-0220）と別の録画（223・081）で再現し、予測を読む前に固定したので、道具の等級の候補は反復実測の見込み（077・134 は後付けで、根拠に数えない）。確定にするかは、道具の候補と最小構成の検査を見てから決める。
- C-0219・C-0220・C-0230・C-0479 の `model` 欄に、起点が `hexagonFrameOf`（本当の発動の 5f 後）であることを書く。文は変えない。
- C-0499 は 2 節のとおり `model` 欄だけ。

### 3.4 派生: III の起点（起票するか）

- III の遅れの定数（イサベル C-0165・ヘルム・ノワール・ラピ・ドレイク・クイーン・レイヴン・マナ・モダニア・ソルジャーE.G.・雪子）は、フルバーストのタイマーが 00.00 になるフレームから数えた値で、モデルはフルバーストの入り（III の本当の発動）に足している。00.00 が III の本当の発動の何 f 後かは確かめていない（C-0258 の「次の段の表示は本当の発動の数 f 後」が III でも同じなら、III の遅れも絶対の時刻がずれている）。

### 8.3 33f の値（論点 2）

- 33 = 満タン → 00.00 の 87f（C-0220 の満タン → I の替わり目 29f + C-0285 の I → II・II → III の 29f × 2）− I・II の発動の止まり 2f（C-0289）− モデルの II の本当の発動 52f（23 + 29）。確定の結論とモデルの定数から出る値で、V-0391 の観測値に合わせた値ではない。
- II の替わり目（モデルでは本当の発動の 5f 後。C-0503）から 29f と数えると 34f（満タン → 00.00 が 88f）になる。モデルの II の替わり目は 59f で、実機（58f）より 1f 遅い（モデルの I → II が動画で 30f。C-0285 の 28〜30f の中）。V-0391 の観測値は 33 でも 34 でも全部許容内（33 は差 −1〜+2、34 は −2〜+1。どちらも端は 258）。推奨は 33（満タンからの絶対の時刻を、確定の値の和で決める）。

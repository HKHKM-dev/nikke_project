## 条件

- C-0043（仮説）の再現。根拠は凍結の verification.md Stage 18-B2「的の見かけの大きさ」（録画 057 の 1 本。60f ごとの色を区間ごとに数えた: 中近 白 3 / 水色 26・近 33 / 0・遠 35 / 0・中遠 0 / 33・近 28 / 0）。057 は仮説の出どころ。
- 結論は「十字・リング」だが、根拠は AR の十字だけ。リングの再現も含めるため、撮影 C（SMG）・D（MG）でも読む。
- オートバースト OFF なので、フルバーストの黄色は出ない。
- backlog 2-33（既存の確定の点検で仮説にした結論）。2026-10-10〜11 の点検（plan/design-investigation-review.md 1.4.3 節）で、反復実測の再現が仮説・値・読み方を決めるのに使った録画（結論の `decidedOn`）の中にしか無かったので仮説にした。確定に戻すには、決めるのに使っていない録画の再現を足す。過去の録画の読み直しはしない（2026-10-11 のオーナーの決定）ので、新しく撮る。
- 新しい録画は 2026-10-08 のゲームの更新（plan/captures/index.md「ゲームの更新の境目」。境目は録画 344 / 345）の後になる。根拠の録画は更新の前なので、合わなかったときは結論の誤りか更新の影響かを、この録画だけでは分けられない（design-investigation-review.md 1.2 節）。そのときは係数で合わせず、更新の後と書いて残差として残す。
- 撮影は backlog 2-33 の 12 件でまとめて計画した（束ねた撮影の記号 A〜I は V-0416「次に撮るもの」の表）。
- 共通の条件: 的は灼熱タブの BigArms・3 分モード（range-3min）・スペック固定 ON・ゲージ表示は右。撮影プロトコル（plan/captures/index.md）のとおり、出撃画面と戦闘履歴（キャラ名）を写す。

## 読み方

1. `aim.ts` の `aim_color` 列（white / cyan / yellow）で、60f ごとに照準の色を取る。
2. 距離ボーナスの有無は、HUD の増分の格子で決める（V-0421・V-0423 と同じ分け方）。
3. 区間ごとに白・水色を数える。
4. 判定の目安: どの区間でも色の多数派が距離ボーナスの有無と合い、外れたサンプルはジャンプの直後・区間の替わり目で説明がつけば再現。

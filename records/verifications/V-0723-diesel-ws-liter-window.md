# V-0723: ディーゼル：ウィンタースイーツの 2 回目のフルバーストの S2 の tick の 1.4〜1.7% の増し分の出どころ（リターのバーストの窓の中の持続ダメージ・倍率ダメージ）

- 問い: V-0703 の撮影 A・B の 2 回目のフルバーストの最初の数回の S2 の tick がモデルより 1.4〜1.7% 大きいのは、ディーゼルに固有か、リターのバーストの攻撃力▲の窓の中で一般に出るのか

- 日付: 2026-11-11
- 録画: `1007`、`1008`、`1009`、`1010`、`0039`、`0116`、`0117`、`0788`、`0789`、`0902`、`0903`、`0906`、`0907`
- 結論: `C-1017`
- 状態: 完了

- 訂正: `V-0703`

## 条件

- 型: 読み直し（撮り足さない）。
- V-0703 の 4 本（撮影 A: `1007`・`1008`、撮影 B: `1009`・`1010`）の HUD の総ダメージを全部読み直し（`tools/captures/hud.ts --mode jumps`）、フルバーストごとに、S2 のフルバーストの持続ダメージ（63.33%）の 9 回の tick の増分をモデルの tick（非会心・会心）に当てた。時刻は V-0703 と同じずれ（S2 は −2f）で当てた。
- 増分がモデルと合わない tick は、前後のフレームに単独で出る味方の 1 ヒットの値と、モデルの味方の 1 ヒットの格子（指標 `hitDamage`）を見た。
- ほかの録画は、リターのバーストを使った多人数の録画のうち、リターの攻撃力▲の窓の中のほかの味方の倍率ダメージ・持続ダメージの 1 ヒットが観測値に既にあるものを、`npm run records:residual` で見た（新しくは読んでいない）。

## 予測

なし

## 読み方

- V-0703 が 1.4〜1.7% 大きいと読んだ tick の増分から、モデルの tick の値を引いた残りは、撮影 A の 2 回目のフルバーストで 35,418、撮影 B の 2 回目で 32,586。どちらも、その窓の中に単独の増分で 2〜3f おきに並ぶリターの通常攻撃の 1 ヒット（胴体・非会心・距離ボーナスあり）の値で、モデルの `hitDamage` とも ±1 で合う（`1007-13`・`1009-18`）。tick の増分のフレームは、その並びの 1 つの上にある。
- そこで、増分からリターの 1 ヒットを引いた値をモデルの tick と比べた（`1007-12`・`1009-17`）。I-DOLL・サンの 1 ヒットが重なった tick も同じに扱った（`1009-19`・`1009-20`）。引く値は、前後のフレームに単独で出る増分（同じ窓の中で同じ値）から決めた。

## 結果

- 引いた値は、どれもモデルの tick と ±1 で合った（`1007-12`・`1009-17`・`1009-19`）。引いた 1 ヒットも、モデルのリター・I-DOLL・サンの 1 ヒットと ±1（`1007-13`・`1009-18`・`1009-20`）。
- 窓の中でも、リターが撃っていないフレームの tick は増分そのままでモデルと合う: `1007` の 2 回目のフルバーストの 3 回目の tick（+197f）は、リターが +184f で撃ち止んだ後で 2,046,353（モデルと同じ）。`1007` の 3〜5 回目のフルバーストの窓の中の tick（リターの▲は 2 回目と同じ使用 3 回目以上の段）も、増分そのままでモデルの非会心か会心と合った。
- `1007` の 2〜4 回目のフルバーストの 4 回目の tick（+256f）は、モデルでは窓の切れた後（窓の終わりの 4f 後）の値なのに、録画では窓の中の値（2,046,353）だった。tick がモデルより 2〜3f 早く出ること（C-1017）と、リターの▲の付き始めがモデルより 3〜4f 遅く窓もその分遅く切れうること（C-0493。直さない端の差）で説明がつく端の差で、この問いのずれとは別。
- 窓の後でも、リターの 1 ヒットと同じフレームに重なった tick は、同じ比で大きく読める: `1007` の 1 回目のフルバーストの 7・8 回目の tick（`1007-14`。▲の無いリターの 1 ヒット 19,622 との和）、`1009` の 2 回目のフルバーストの 5 回目の tick（+314f。同じく 19,622 との和。`1009-17` の読み方）。
- バーストの敵全体の持続ダメージ（18.43%）の tick にも、同じフレームの同じ値が足されていた（`1007` の 2 回目のフルバーストの +81f・+140f の 630,938 = モデル 595,520 + 35,418）。6f 後に出るターゲットの持続ダメージ（181.2%）の tick（+87f・+146f）は増分そのままでモデルと合う。
- V-0703 が「持続ダメージ▲と攻撃ダメージ▲の群の和に、撮影 A・B のどちらも同じ 0.13785 を足すと合う」とした形は、リターの 1 ヒットとディーゼルの tick が同じリターの攻撃力▲で伸び、同じ受けるダメージ▲・フルバースト補正が乗るので、1 ヒットを tick の群の 1 あたりの値で割った比が撮影 A・B で同じになったことによる（35,418 ÷ (2,046,353 ÷ 7.9647) と 32,586 ÷ (2,296,016 ÷ 9.7131) がどちらも 0.13785）。「最初の 3〜4 回」と「窓の中だけ」に見えたのは、リターが窓の中で途切れずに撃ち続け、tick がその並びに乗りやすかったため（`1009` の 2 回目は窓の終わりの +255f まで撃ち続け、4 回とも乗った）。
- ほかの録画のリターの窓の中の倍率ダメージ・持続ダメージの 1 ヒットは、どれもモデルと許容内（±1〜3）: ドレイクの S2（`0039-16`・`0039-17`。使用 1 回目と 3 回目以上の段）、ラピ：レッドフードのバーストの追加ダメージと起爆・付着（`0116-15`・`0117-15`・`0116-26`・`0117-26`）、エイダの S2（`0788-10`・`0789-10`）、アークレンジャー・ブラックの S2 とバーストの持続ダメージの tick（`0902-08`・`0902-09`・`0903-08`・`0903-09`）、ギルティの追加ダメージ（`0906-03`・`0907-02`）。このうち `0039-16` は、同じフレームのリターの 1 ヒットを引いて合わせた値で、同じ重なりが前から読まれていた。

## 分かったこと・分からないこと

- V-0703 の「分からないこと」の 1.4〜1.7% のずれは、ディーゼルにもリターの攻撃力▲の窓にも固有でなく、HUD の 1 つの増分に、同じフレームのリター（`1009` の 4 回目のフルバーストでは I-DOLL・サン）の通常攻撃の 1 ヒットが乗った和だった。引けば、窓の中の S2 の tick もモデルと ±1 で合う（C-1017 の根拠に足した）。モデルは直さない。
- リターの窓の中で、ほかの味方の倍率ダメージ・持続ダメージの 1 ヒットにずれは無い（ほかの録画の既存の観測値）。
- 連射の味方がいる録画では、tick がモデルより一定の割合で大きく見えても、群に定数を足した形で合うことを根拠にしない。味方の 1 ヒットと tick は同じ攻撃力▲で伸びるので、和の比も窓の中で一定になる（[captures/guide.md](../../plan/captures/guide.md) に 1 行足した）。
- 分からないことは残っていない。

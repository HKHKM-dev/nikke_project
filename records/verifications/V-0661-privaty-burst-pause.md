# V-0661: プリバティのバーストの後の撃たない間（0938・0939 の読み直し）

- 問い: プリバティは自分のバーストの発動の後、いつまで撃たないか。モデルに入れると、最後の弾丸の時刻と V-0660 で合わなかった S2 の増分は合うか
- 話題: スキル・キャラ固有
- 日付: 2026-11-03
- 状態: 調査中
- 録画: `0938`、`0939`（対照 `0469`）
- 派生元: `V-0660`

## 条件

- 型: 読み直し。V-0660 の録画 0938・0939（リター・デルタ・プリバティ（III・操作）。宝物版）を、新しく撮らずに読み直す。
- V-0660 の読みで、プリバティの最後の弾丸（S2 の追加ダメージ）の時刻が、フルバーストの入りからモデルとずれていた（1 回目のフルバーストの最初の最後の弾丸は、モデルが III のタイマーの 00.00 の +89f、録画は +195f）。
- 対照は、同じ III・操作で、バーストの倍率ダメージが 3 ヒットのミハラ（録画 0469。ラム・デルタ・ミハラ）。
- 語彙の追加の案は [design-privaty-burst-pause.md](../../plan/design-privaty-burst-pause.md)。

## 予測

なし（読み直し）。

## 読み方

1. HUD の増分は、レシピ `hud-jumps` のキャッシュ（0938・0939 は V-0660 で作ったもの、0469 はこの検証で作った）。
2. III のタイマーの 00.00 は、レシピ `burst-panel` の観測値（0938-05・0939-05）。0469 は 0469-08 の説明の f1424。
3. プリバティの発は、5f おきに出る増分（AR）。リターの発（2〜3f おき）とデルタの発（約 80f おき）は、V-0660 の格子の値で分けた。
   - V-0660 で「誰の発か決めていない」とした 00.00 の +66〜+67f の 693,454 は、デルタの 1 発 654,118 とリターの 1 発 39,336 の和（654,118 は約 80f ごとに出る）。プリバティの発ではない。

## 結果（途中）

- プリバティの最初の発の、00.00 からの動画のフレーム（どの回も、00.00 の前の最後の発は −3〜−8f）:
  - 0938: +125・+126・+126・+126（4 回）
  - 0939: +125・+125・+126・+128・+130（5 回）
- どの回も、バーストの 3 ヒット目（+117〜+118f）の約 8〜12f 後に撃ち始める。00.00 から 3 ヒット目までの間（止まりの明けの +22f から）は撃たない。
- 1 回目のフルバーストでは、撃ち始めてから 15 発目（0938 の f1639・0939 の f1633）が最後の弾丸で、00.00 の前のマガジンの残りを撃ち切っている。V-0660 のモデルとのずれは、この撃たない間で説明できる。
- 対照のミハラ（0469 の 1 回目）は、+27f から 5f おきに撃ち、バーストのヒット（+39・+49・+61f）の間も撃つ。

# V-0372: スペック固定 OFF の SG の近のコア命中率は、ON と同じか

- 問い: スペック固定 OFF のノワール単騎の近のコア命中率（`109-09` で ON より高く見えた）は、ON の的の表（C-0158）と同じか、スペック固定 OFF で高くなるか
- 話題: 命中率・距離
- 日付: 2026-10-09
- 状態: 保留
- 待ち: 撮影（ノワール単騎・スペック固定 OFF・キューブなしを 2 本。オーナーの撮影の機会。backlog 4-6）
- 派生元: `V-0105`

## 条件

- V-0105 の候補 F の続き。スペック固定 OFF の 4 本（`109`〜`112`）の近を合わせたコア命中率（`109-09`）は、スペック固定 ON の 3 体 5 本（C-0158 の根拠。数えて分けた値）より 2.6 SE 高かった。読みの約束・撮った日・キューブの命中率▲では説明しきれず、既存の録画では偶然と見分けられない（V-0105「結果」の 2）。
- 撮るもの: ノワール単騎・AUTO 射撃 ON・オートバースト OFF・**スペック固定 OFF・キューブなし**（`109` と同じ条件）・射撃場の灼熱の的（BigArms）・3 分モード・180 秒・戦闘中は触らない。**2 本**（2026-10-08 のオーナーの判断）。
- 最小構成: 単騎で、未確定の要素はスペック固定 OFF で変わるもの（ステータス・装備）だけ。キューブは外す（命中率▲がコア命中率を変えうる。C-0036。SG のペレットでは確かめていない）。オートバースト OFF なので、ノワールのバースト（SG の味方に命中率▲）は出ない。
- モデルの的の表の SG の近のコア命中率は 0.042（C-0158）。近の着地点 A・B では分けない（スペック固定 ON の 5 本で差は 0.8 SE。V-0076）。会心率は CDN の 0.15（C-0159。スペック固定 OFF の 4 本でも CDN どおり）。
- スペック固定 OFF の録画はオーナーの育成で 1 ヒットの値が決まるので、与ダメージはモデルと照合しない（`109-01` と同じ）。比べるのは割合（コア命中率・会心率）だけ。

## 予測（撮る前に書く）

数値は予測ファイル（records/predictions/V-0372.json）。判定に使うのは指標 `near-core`（近のコア命中率）だけ。`near-crit`（近の会心率）は読みの確かめ。

**F1. 偶然**（`109` の 1 本が高かった）

- スペック固定 OFF でも、近のコア命中率は的の表と同じ。2 本の近 4 区間を合わせた値は 0.042 の近く。いまのモデル。

**F2. スペック固定 OFF で変わる**（機構は未知）

- 2 本の値は、同じ条件の `109` の近（0.060。`109-08` の近 2 区間）の近く。モデルには無いので、予測ファイルでは手入力の条件でコア命中率を置いた。

**見分け方と許容幅**（撮る前に決める）

- 観測値は、2 本の近 4 区間（2 区間目と 5 区間目 × 2 本）を合わせた 1 つの値: コアに当たったペレット ÷ 当たったペレット。幅は、ペレットを独立とみた二項の 95% 区間（p̂ ± 1.96 √(p̂(1 − p̂) / n)。`109-09` と同じ。トリガーを単位にした SE とほぼ同じことは V-0073 で分かっている）。予測ファイルの `near-core` に `observations` で結び付け、区間に入る仮説を `npm run records:check` が「許容内」と出す。
- 2 本で当たったペレットは約 1,700 個（`109` の近は 849 個）。n = 1,700 なら、区間に入るのは F1 が p̂ ≈ 0.034〜0.052、F2 が p̂ ≈ 0.050〜0.072。
  - F1 だけが入る（p̂ ≈ 0.034〜0.050）→ F1。
  - F2 だけが入る（p̂ ≈ 0.052〜0.072）→ F2。
  - 両方入る（p̂ ≈ 0.050〜0.052）→ 未決。
  - どちらも入らない → 未決。下に外れた（p̂ < 約 0.034）なら F2 は棄却、上に外れた（p̂ > 約 0.072）なら F1 は棄却と書く。
- 見込み（n = 1,700）: F1 が正しいとき、F2 と出るのは約 2%、両方入るのは約 3%、下に外れるのは約 4%。F2 が正しいとき、F1 と出るのは約 4%、両方入るのは約 5%、上に外れるのは約 2%。
- 判定は新しい 2 本だけで行う。`109`〜`112` は足さない（`109` は F2 の値の出どころで、`110`〜`112` はキューブの命中率▲が付く）。
- 読みの確かめ: 2 本の近の会心率が、CDN の 0.15 の二項の 95% 区間（約 0.133〜0.167）から外れたら、判定の前に分解（レシピの発ごとの分解とほかの候補の数）を見直す。

**止め方**（撮る前に決める）

- 2 本で判定する。結果を見てから本数を足したり、録画を外したりしない。
- 未決なら、この検証は未決のまま閉じる（近の与ダメージへの効きは 180 秒で約 0.25〜0.4% で、照合の許容よりずっと小さい。V-0105）。撮り足すかはオーナーが決め、撮るなら新しい検証で本数と判定を撮る前に決め直す。
- 録画の条件が崩れたもの（キューブが付いていた・途中で触った・オートバーストが ON だった・スペック固定が ON だった）は、読む前に外し、その本は撮り直す（判定の本数は 2 本のまま）。外す理由は読む前に検証記録に書く。

**外れたときの効き**

- F2 なら、スペック固定 OFF の SG の近の与ダメージは、モデルより約 0.8% 多い（近の 1 ペレットの値は 1.3 + 0.5 × 会心率 + 1.0 × コア命中率。V-0071）。近は SG 単騎の与ダメージの約半分なので、180 秒で約 0.4%。スペック固定 ON の照合（C-0158 の根拠）には効かない。

**それぞれの後**

- F1: スペック固定は SG の近のコア命中率を変えない、という結論を作り（2 本で反復実測の候補）、C-0158 の根拠にこの検証を足す。`109-09` の差は偶然とみる。backlog 4-6 を閉じる。
- F2: 「スペック固定 OFF で SG の近のコア命中率が高い」を結論にし（機構は未知なので、モデルは変えない）、何が違うのか（ステータス・装備）を調べる検証と、的の表のコア命中率をスペック固定で分けるかの設計を、別に起こす（オーナーの判断）。

## 読み方

1. 録画の先頭と末尾で条件を確かめる（下の「次に撮るもの」の映すもの）。崩れていれば、読む前に外す（止め方）。
2. 取り込み: `node tools/captures/intake.ts <元ファイル> --id NNN --name SG_noir_spec-off --rid 271 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec off --auto-fire on --auto-burst off`。台帳の `conditionNote` にキューブなし・出撃画面で確かめたことを書き、検証記録の冒頭の「録画」に 2 本を挙げる。
3. 1 ペレットの値（胴体・会心・コア。距離ボーナスなし）を、的の上の数値と CORE HIT の出たトリガーの増分から読み、`hit` の観測値にする（`109-02` と同じ読み方）。スペック固定 OFF のレシピはこの値を使う。
4. `npm run records:read -- <録画 id> --recipe sg-pellets --source V-0372 --write`（`--opt debug=1` で発ごとの分解とほかの候補の数を見る）。近の会心・コアは増分から一意に出る（V-0105「結果」の 2）。
5. `npm run records:read -- <録画 id> --recipe near-landing --source V-0372 --write` で、近の 2 区間の着地点（A・B）を読む（判定には使わない。`109` との比べの注記）。
6. 2 本の近 4 区間を合わせたコア命中率と会心率を、1 つの観測値（`recordings` に 2 本。幅は ci95）にして、予測ファイルの `near-core` に `observations` で結び付ける。会心率は `near-crit` に結び付ける。録画ごとの値は、それぞれの録画の割合の観測値に残る（判定には使わない）。
7. `npm run records:check` で予測との比べを出し、見分け方の規則で決める。

# V-0405: 鈴原サクラ単騎・操作で外れを減らした 1 回目の満タン（物の分と S2 の見分け）

- 問い: 外れの少ない鈴原サクラ単騎の 1 回目の満タンは、的への 500 ヒット目か（物の分）、499 ヒット目以前か（S2 の発火が 2,000 以上溜める）
- 話題: バーストゲージ
- 日付: 2026-10-10
- 録画: `405`、`406`
- 結論: `C-0321`、`C-0518`
- 状態: 完了
- 派生元: `V-0400`

## 条件

- V-0400 の「次に撮るもの」の案。オーナーが 2026-10-10 に撮った 2 本（鈴原サクラ単騎・操作（AUTO 射撃 OFF）・射撃場の灼熱の BigArms・3 分モード。1 回目の満タンの少し後まで、約 67 秒）。スペック固定 ON は 1 ヒットの値で確かめた（距離ボーナスの胴体 9,162 は `243-02` の 1.3 倍）。オートバーストは画で決められなかったが、満タンの後は読まない。
- 出どころ: 録画 243（AUTO）の 1 回目の満タンは 499 ヒット目（`243-08`）で、ヒットのほかの出どころの合計 E は 2,000 以上 4,000 未満。被弾は単独の原因でない（C-0518）。残る候補は、外れた発が的以外の物に当たった分（1 発 1,000。C-0139）と、S2 の発火（60 発ごと・120 発ごと）の溜め（C-0321）。
- 操作で的の中央を狙い続け、外れを 0 に近づける。外れが 0 なら物の分は 0 になる。

## 予測（撮る前に書く）

手計算（予測ファイルは作らない。ゲージの効果を足していない語彙の仮説なので、予測ファイルの範囲外）。録画を読む前に commit する。

指標: 戦闘開始から 1 回目に BURST バーが消えたヒットまでの、的へのヒットの数 N と、それまでの外れ m（撃った発 − 当たった数）。満タンまでの S2 の発火は、243 と同じく 60 発ごと 8 回・120 発ごと 4 回の見込み（撃つ発が約 500 発のため）。

| 仮説                                                                    | 外れ m = 0 のときの N | 外れ m > 0 のときの N                 |
| ----------------------------------------------------------------------- | --------------------- | ------------------------------------- |
| H-obj: S2 の溜めは合計 2,000 未満。243 の 1 ヒット早いのは物の分        | 500                   | 500 − ⌊m / 2⌋ 以上 500 以下           |
| H-S2: S2 の溜めが合計 2,000 以上 4,000 未満（243 を S2 だけで説明する） | 499                   | 499 以下（物の分が足されれば 498 も） |

- 見分け方: m = 0（か、m が小さく H-obj の幅が 500 だけになる m = 1）の本で、N が 500 なら H-obj、499 なら H-S2。m ≧ 2 の本は、N = 500 なら H-S2 を外せるが、N = 499 は両方と合う。
- 被弾: C-0518 の上限（3 回で 2,000 未満）があり、H-obj の 500 と矛盾しない。鈴原サクラの被弾がミサトより多く溜めるなら、H-S2 と同じ見え方になる（見分けられない）。満タンまでの赤い画面の回数と時刻も読み、243 と同じ時刻表かを書く。
- 外れたときの影響: H-S2 なら、鈴原サクラの定義の S2 にゲージの効果を足す語彙を検討し、C-0321 を棄却する。H-obj なら C-0321（S2 は溜めない）の根拠に足し、1 ヒット早いのは物の分とする（C-0139 のモデルへの取り込みは別の話）。

## 読み方

1. `hud.ts --mode jumps`（レシピ `hud-jumps`）で総ダメージの増分を読み、鈴原サクラの 1 ヒットの格子（`243-02`・`243-03` と同じ基。操作なので距離ボーナスとコアの組は録画で確かめる）で、満タンまでのヒットを 1 つずつ数える。読めない区間の和は格子のヒットの組に分ける。
2. `gauge.ts --mode events`（バー消失）で満タンのフレームを取る。
3. 照準の横の残弾（`reticle-ammo.ts`）とリロードで撃った発の数を数え、外れ m を出す。
4. 被弾の赤い画面は V-0400 と同じ方法で拾う。

## 分かったこと・分からないこと

**分かったこと**

- **鈴原サクラの S2 の発火は、バーストゲージを溜めない**（12 回で合わせて 2,000 未満）→ C-0321 を確定にした（等級は厳密一致。撮る前の予測と合い、2 本で繰り返した）。スキル定義の S2 の notes にも結び付けた。
- 鈴原サクラ自身でも、満タンまでの 3 回の被弾は（S2 と合わせて）2,000 未満しか溜めない → C-0518 の根拠に足した（ミサトと同じ量とみる推論が要らなくなった。C-0518 は探索の観測値が主なので仮説のまま）。
- 録画 243 の 1 ヒット早い満タン（`243-08`。ヒットのほかの出どころが 2,000 以上）は、S2 と被弾（合わせて 2,000 未満）では足りないので、外れた 6 発のうち少なくとも 1 発が的以外の物に当たった分（1 発 1,000。C-0139）による。S2 と被弾が 0 なら 2〜3 発（推論。243 で物に当たったところは画で見ていない）。
- モデルは変えない（S2 にゲージの効果なし。的以外の物のゲージは入れていない。C-0139 のモデルへの取り込みは別の課題）。

**分からないこと**

- 243 で外れた発が何に当たったか（遮蔽物・コンテナ・敵の弾）。物に当たった分のモデルへの取り込みは、この検証の範囲の外。

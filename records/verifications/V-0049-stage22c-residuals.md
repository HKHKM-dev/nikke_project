# V-0049: 22-C（チャージの無い武器の構え）を入れた後の残差

- 問い: チャージの無い武器（AR・SMG・SG・MG）の戦闘開始・窓の明けの 1 発目を構え 12f の後にした（Stage 22-C）後、残差の一覧は V-0044 の試算どおりに動いたか。戦闘開始の最初の発は実測と合うか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-09-29
- Stage: [design-stage22.md](../../plan/design-stage22.md) 8 節の 22-C
- 録画: `018`〜`022`、`037`〜`039`、`044`、`054`、`056`、`072`〜`074`、`078`、`L-AD`、`L-AI`、`L-AN`
- 結論: `C-0114`
- 状態: 完了
- 派生元: `V-0044`

## 条件

- 撮影も録画の読み直しもしていない。22-C を入れたモデル（design-stage22.md 8.6 節）で `npm run records:check` を回し、残差の一覧を入れる前（#101 の後の main）と比べた。
- 入れたもの: `weapons.ts` の `aimInFrames` = 12。`cadence.ts` の `firstShotFrames` はチャージの無い武器（MG を含む）で 12f、MG の `reloadFirstShotFrames` は `spinUpFirstShotFrames`（20f）。`frame/shooter.ts` の `unhideShooter` は、撃てる状態なら 12f、込め終えて 1 発目を待っている枠は残りの待ちと 12f の長いほう。SG も含める（オーナー、2026-09-29）。
- 使用武器の変更（モダニアの殲滅モード）で持ち替えた武器の 1 発目には構えを入れない（`weaponChangeShooter`。持ち替えはハイドではなく、根拠が無い）。

## 予測（撮る前に書く）

- 残差の一覧は、V-0044 の表の「12f」の列と同じになる（V-0044 は同じ変更を手元で回した値。違うのは使用武器の変更を分けたことだけで、殲滅モードの発は残差の観測値に効かない見込み）。
- 戦闘開始の最初の発は、チャージの無い武器ではモデルが 12f。実測（`054-05`・`054-09`・`072-06`・`073-05`・`074-02`・`074-05`・`L-AD-05`・`L-AN-03`・`L-AI-02`）は 11〜13f なので、±1f で合う。

## 読み方

1. 22-C を入れて `npm run records:check` を回し、`plan/residuals.md` の差を取る。
2. 動いた観測値を V-0044 の表と突き合わせる。
3. `npm test` の落ちたテストを、新しい規則で出る値に直す（手で数えた値と比べる）。

## 結果

- 残差の一覧で動いたのは 13 件で、どれも V-0044 の表の「12f」の列と同じ値になった。
  - 1 回目の満タン: `018-11`・`019-10`・`021-08`・`037-01`・`038-06`・`039-05`・`044-08`。操作キャラが SG の `019-10`・`037-01`・`039-05` は 0f。`038-06` は許容の外に出た。`021-08` は縮んだが許容の外のまま。
  - 単騎の合計: `054-02`・`L-AI-01`（SMG）は離れた（許容の中）。`L-AD-01`（AR）は許容の中に入った。`056-02`・`L-AN-01`（MG）はほとんど動かない。`078-08`（ユニ + アスカ）は許容の中で下がった。
- 確定の結論にひもづく観測値は、どれも許容の中に残った。
- 戦闘開始の最初の発は、モデルが AR・SMG・SG・MG とも 12f で、実測の 11〜13f と ±1f で合う（073 の 11f は録画のフレーム落ち。V-0046）。
- テストは 7 本の 15 件と、残差の一覧の一致のテストが落ち、新しい規則の値に直した。直した値は手で数えた値と同じだった（例: AR 単騎の 180 秒は、1 発目が 12f なので 29 マガジン目が 12 + 28 × 372 = 10428f から始まり、33 発で 1,713 発）。
- モダニアの録画 44 は、1 回目のフルバーストが 8f 早くなった（MG の戦闘開始が 20f → 12f）。殲滅モードは今までどおり持ち替えの次のフレームから毎フレーム撃つ。

## 分かったこと・分からないこと

- 22-C を入れた後の残差は、V-0044 の試算と同じ。戦闘開始の最初の発は、すべての武器種で実測と ±1f で合う。
- C-0114 は仮説のまま。戦闘開始は反復実測で合うが、AR・SMG の窓の明けは、実機の明けのフレームが読めていない（V-0043。起き上がりからの 10〜20f）。確定にするかはオーナーの判断（design-stage22.md 8.6 節）。
- 分からないこと（V-0044 から続く）: `038-06`（イサベルの操作）でモデルが遅い理由。SMG の単騎でモデルが少ない理由。

## 次に撮るもの

撮影は要らない。AR・SMG の窓の明けを確かめるなら、窓の終わり（的が着地して狙えるようになったフレーム）を画面で決められる録画で、明けから最初の発までを読む。

## 3. バフ・デバフ（stat の▲▼）

### 3.1 stat

- **語彙あり（直接）**: 与ダメージの stat（攻撃力・攻撃ダメージ・クリティカル確率・クリティカルダメージ・チャージダメージ（倍率）・分配ダメージ・持続ダメージ・防御力無視ダメージ・有利コードの攻撃ダメージ・コアダメージ・発射体爆発ダメージ・通常攻撃ダメージ倍率・通常攻撃のクリティカル確率）、射撃の stat（最大装弾数・リロード速度・チャージ速度・チャージ時間（秒）・装弾数無限）、命中率（味方）、バーストゲージのチャージ速度（`passive` だけ）、敵の受けるダメージ▲（`damageTaken`）。
- **語彙なし（直接）**: 敵の防御力▼（注記だけの `enemyDefenseDown`。式の中の置き場所が要る）、攻撃速度・マシンガン立ち上げ速度、適正射程距離（距離ボーナスの乗る範囲を広げる。T6）、貫通ダメージ（貫通特化の発に乗る。T2。6.7 節）、発射体付着ダメージ・順番攻撃ダメージ、対象の書き方で絞ったバーストスキルダメージ▲、別の状態の維持時間▲・中身の値▲。
- **間接に効く（6 節）**: 防御力▲（味方。防御力の比べ・順位の対象）、最大HP▲・最大HP のみ▲・自分の現在のHP▼（HP の経路）、受けるHP回復量・与えるHP回復量（HP が満タンでない時の回復量）、ペレット数（1 発の総ダメージは変わらず、当たったペレットを数えるきっかけを早める。T3）。
- **被弾で効く**: 受けるダメージ▼・〈コード〉の敵から受けるダメージ▼（味方）、敵の攻撃力▼・命中率▼、次のバリアの HP▲（6.6 節）。
- **前提の外（構造）**: パーツダメージ・阻止部位の攻撃ダメージ・バリアに与えるダメージ（敵のバリア）・敵の発射体へのダメージ・貫通範囲。
- **要確認**: 爆発範囲・味方の受けるダメージ▲（効く道があるかの判断が先）。爆発範囲は、ダメージの式に無いが、コアに当たる割合を変えるかは確かめていない（既存の notes の読み）。

### 3.2 値の算出

| 算出                                           | 区分       | 語彙                               |
| ---------------------------------------------- | ---------- | ---------------------------------- |
| 対象自身の値の X%                              | 語彙あり   | `ratio`                            |
| スキル発動者基準の攻撃力・チャージ速度         | 語彙あり   | `casterAttack`・`casterChargeTime` |
| スキル発動者基準の防御力・最大HP               | 間接に効く | 発動者の値を読む（6 節）           |
| 実数（発・個）・秒                             | 語彙あり   | `flat`                             |
| 発動者の最大HP の X% 分の攻撃力▲               | 語彙なし   | HP の経路の読む側（6.2 節）        |
| X% × 〈状態〉のスタック数・最大装弾数 N 発ごと | 語彙なし   | なし                               |
| 失った HP N% ごと                              | 間接に効く | HP の経路の読む側（6.2 節）        |

### 3.3 持続の形

- **語彙あり**: N 秒間維持（`durationRef`）・持続（`durationUntil: 'battleEnd'`。常時なら `passive`）・N 発間維持（`durationShots`）・フルバーストタイムの間（`durationUntil: 'fullBurstEnd'`）・N スタック（`maxStacks`）・使用回数別／開始回数別の効果（回数の段）・攻撃回数別の効果（`cycle`）・下位効果のスタック適用（`sequential`）。
- **語彙なし**: 外れ方の多く（4.5 節）、回数 × N 秒・戦闘中 N 回発動・最低 N を維持、維持の付いたクールタイムの増減（その間スキル自体のクールタイムを変える。維持の無い増減だけが `cooldownReduction`。T4）、同一効果は重複不可（同じ効果をほかの出どころと足さない。K の S2）。
- **要確認**: N 秒間隔（持続回復・状態の中の周期）、最大 N（固有のカウンタの上限）、段階別の効果。
- **解除不可**: 持続の長さを変えない（4.5 節）。

## 4. 状態

### 4.1 名前の付いた状態と、効果の呼び名

- 説明文の「〈名前〉：…」には、ほかの行から名前で参照されるもの（**状態**）と、参照されないもの（**効果の呼び名**）がある。分類の一覧では、名前がどこかの行の頭（きっかけ・条件・対象）に出るかで分けた。
- 参照されない名前（効果の呼び名）も目録（`skills/states.ts`）に入れ、画面に名前を出す（本体の論点 4。2026-10-15 の決定）。目録に足すのは、そのキャラを定義する時（使い手のいない id を先に入れない。[design-named-state.md](design-named-state.md) 3.6 節）。参照の有無は、見る側の語彙が要るかの目安として一覧に残す。
- 1 つのキャラの中だけで参照される状態も、目録に入れる（キャラの定義の中だけの名前は作らない）。名前は 1 か所の目録で持つ決定（[design-named-state.md](design-named-state.md) 4.2 節・同 10 節の論点 1）のとおりで、ステージパート：ボーカルのように別のキャラと共有する状態もある（本体 11 節の 3.11）。
- 持ち主は味方（自分・味方）と敵がある。敵の状態は 1 体の前提で、条件 `enemyState` で見る。
- 静的な状態と時間で変わる状態の分け方は、[design-named-state.md](design-named-state.md) 3.4 節のまま。
- バリア・デコイも、付いている間だけ「バリア適用状態」「デコイが存在する時」として見られる状態として扱う（6.4・6.5 節）。

### 4.2 状態の一生

| 段     | 説明文の形                                                | 区分                                                                                       |
| ------ | --------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 付く   | きっかけ＋「〈名前〉：中身」「〈名前〉」                  | 語彙あり（付与 `kind: 'state'`）                                                           |
| 中身   | stat の▲▼                                                 | 語彙あり（`contents`）                                                                     |
|        | ダメージ・回復・使用武器変更・バリアなど                  | 語彙なし（後の拡張: 中身の `kind`。[design-named-state.md](design-named-state.md) 8.4 節） |
|        | 名前だけ（中身は「機能：…」のまとまりや、ほかの行が見る） | 要確認（状態か、キャラ固有の仕組みか）                                                     |
| 重なる | N スタック                                                | 語彙あり（`maxStacks`）                                                                    |
|        | スタック量の増減・スタックのコピー                        | 語彙なし                                                                                   |
| 段階   | 〈名前〉I・II・III、段階別の効果                          | 要確認（回数の段で書けるものがある。イサベルのターゲットマーキング）                       |
| 変わる | 「A が B に変化」、A と B の切り替え                      | 語彙なし（後の拡張: 目録の `group`。同 8.2 節）                                            |
| 切れる | 4.5 節の外れ方                                            | 時間・フルバースト終了・戦闘の終わりは語彙あり。ほかは語彙なし                             |

- **キャラ固有のカウンタ**（勇者レベル・乗車券・MP・弾倉など）: 「〈名前〉N 枚発券：最大 N 枚まで」「〈名前〉：最大 N レベルまで成長」のように、上限と増減を持ち、時間では外れず、値が「X% × 枚数」のように数で決まる。分類の一覧では状態に数えず「キャラ固有のカウンタ」に置いた。スタックの状態（上限・スタックの増減・スタック数の値）として書くか、カウンタの語彙を分けるかは要確認で、使うキャラを撮る段で決める（使い手のいない語彙は入れない。本体 11 節の 3.2）。
- 中身の「持続」は、親の状態の間と読む。鉄・拳・制・裁！の中身（有利コードの攻撃ダメージ▲。「持続」「解除不可」）は、親の解除条件（フルバースト終了）のフレームで外れる（C-0307）。

### 4.3 状態を見る側

| 見る形                                             | 区分                                                         | 語彙                                               |
| -------------------------------------------------- | ------------------------------------------------------------ | -------------------------------------------------- |
| 条件: 自分が〈状態〉なら                           | 語彙なし                                                     | 後の拡張 `selfState`（同 8.1 節）                  |
| 条件: 自分が〈状態〉のフルスタックなら・でなければ | 語彙なし                                                     | 後の拡張 `selfState` の `stacks`・`present`        |
| 条件: 自分に〈状態〉適用中（他人の状態の間）       | 語彙なし                                                     | 後の拡張 `while`（同 8.4 節）                      |
| 条件: 対象（敵）が〈状態〉なら                     | `damage` だけ語彙あり                                        | `enemyState`                                       |
| きっかけ: 〈状態〉が適用された時                   | `damage` だけ語彙あり                                        | `{ applied }`（`timed` などは後の拡張。同 8.1 節） |
| きっかけ: 〈状態〉が終了した時                     | 語彙なし                                                     | 後の拡張 `{ ended }`                               |
| きっかけ: フルスタックでスタック解除後             | 数えるだけのスタックは語彙あり、効果のあるスタックは語彙なし | `stacksRef`（クラウン S2 のリラックス）            |
| 対象: 〈状態〉状態の味方                           | 静的な状態だけ語彙あり                                       | `targetState`（時間で変わる状態は後の拡張）        |

- 「自分が〈stat〉増加状態なら」は名前の付いた状態ではなく、語彙あり（`selfBuffed`）。

### 4.4 いまの定義の近似

状態の語彙が無いため、いまの定義は次のように近似している。書き直す候補で、書き直すかと順は 2 段目で決める（値が変わらないことを退化で確かめる）。

- マナ S2: 「マターシグマ状態なら」「マターシグマ解除」を `assumes` で書く（毎サイクル自分がバーストするので付き直す。[design-named-state.md](design-named-state.md) 7.2 節）。
- エマ：TU S2・ウンファ：TU S2: 「自分にフォーメーション AS / LT 適用中」を `withCharacter` で書く（相手がいれば適用中。C-0306）。
- アニス：スター S1・S2・バースト: 私だけの星・みんなの星を `burstStepMix` で書く（編成で決まる静的な状態）。S2 の「自分より最終防御力が低い味方」は全員とみなす（C-0210。防御力の経路。6.3 節）。
- クラウン S2: リラックスのフルスタックでのスタック解除を `stacksRef` で書く（数えるだけのスタック）。
- アスカ S2: 「自分がバリア適用状態なら」を notes の前提の外にしている。バリアの経路（6.4 節）では、アスカの前にバリアを張る味方がいれば起きうる。
- 編成の条件 `burstStepMix`・対象 `targetBurstStep`: 基本バースト段階を `CharacterData.burstStep` だけで数え、同じ段階に再突入するキャラ（ティアなど）も数える。ツールチップでは数えない（T1。本体の論点 11）。

### 4.5 外れ方と「解除不可」

説明文で効果・状態が外れる書き方は次のとおり（英語版の言い回しを添える）。

| 外れ方           | 説明文（英語版）                                               | 解除不可の効果                   | 語彙                                       |
| ---------------- | -------------------------------------------------------------- | -------------------------------- | ------------------------------------------ |
| 時間切れ         | 「N 秒間維持」（for N sec）                                    | 外れる（読み）                   | 語彙あり                                   |
| 出来事まで       | 「解除条件：〈出来事〉」（Deactivation condition）             | 外れる（C-0307）                 | フルバースト終了は語彙あり。ほかは語彙なし |
| 同じスキルの消去 | 「〈名前〉消去」（Cancels）                                    | 外れる（ツールチップ「消去」）   | 語彙なし（解除とは別の語彙。本体の論点 8） |
| 同じスキルの解除 | 「〈名前〉解除」（Removes）                                    | 例が無い（相手は解除不可でない） | 語彙なし（後の拡張 `removeOn`）            |
| 出来事で外れる   | 「〜時に解除」「〈名前〉解除まで」（Removed upon …）           | —                                | 語彙なし                                   |
| 切り替え         | 「条件に合う〈グループ〉のみ適用」（Initiates a new … mode）   | 解除不可どうしで切り替わる       | 語彙なし（後の拡張 `group`）               |
| スタックの消費   | 「スタック解除後」（Removes stacks）                           | —                                | 数えるだけのスタックは `stacksRef`         |
| 被弾             | 「直接攻撃を受けると解除」（removed upon taking a direct hit） | —                                | 被弾で効く                                 |
| 効果解除         | 「バフ・デバフ効果解除 N 個」（Removes N buff(s) / debuff(s)） | **外れない**（解除不可の意味）   | 語彙なし                                   |
| 発動不可         | 「〈名前〉発動不可」                                           | 先に発動していれば止まらない     | 語彙なし                                   |

「解除不可」（英語版: This effect cannot be removed）の整理:

1. **意味**: 効果解除（「バフ効果解除 N 個」「デバフ効果解除 N 個」）で外れず、先に発動していれば後から付いた発動不可でも止まらない（ツールチップ「発動不可」）。効果の長さ・条件・同じスキルの外し方は変えない。
2. **持続時間が終わった時**: 解除不可でも外れる。
   - 「N 秒間維持」「解除不可」の効果（ネオン：ビジョン・アイの火力チャージ、プリカのパフォーマンス、ブレッディの味、ミハラ：ボンディングチェーンのプリング・チェーン）は N 秒で終わる（読み。確かめた結論は無い）。
   - 「持続」「解除不可」は戦闘の終わりまで続く（ペルソナ。C-0354）。ただし解除条件・同じスキルの消去・切り替え・親の状態の終わりでは外れる（鉄・拳・制・裁！の中身は親の解除条件で外れる。C-0307）。
3. **条件を満たさなくなった時**: 解除不可とは別の問題で、条件の書き方（4.6 節）で決まる。発火の瞬間の条件なら、付いた後に条件が外れても続く。続いている間の条件なら、条件の間だけ効く。解除不可の「持続」効果が続いている間の条件で書かれた例（ギルティ：マイティバニー・シン：スウィフトバニーのバニーモードごとの効果、千束の超感覚の段階ごとの効果）は、条件が外れたら効かなくなる読みが自然だが、外れてから戻った時の扱いは説明文で決まらない（要確認）。
4. **「消去」との関係**: スキル自身が状態を外す行には、「〈名前〉消去」（Cancels）と「〈名前〉解除」（Removes）の 2 つの言葉がある。全キャラの説明文で、消去の相手はどれも解除不可で付く状態（戦闘補助・私だけの星・みんなの星・チェーンバインド・オススメの味・やみつきの味・ステージパート）で、解除の相手はどれも解除不可でない状態だった。解除不可の状態は効果解除では外れないので、同じスキルが外す時に別の言葉を使っている、と読む。ツールチップ「消去」もこの読みと合う（残りの時間に関係なくすぐ消え、解除不可の効果も消え、消された効果はまた条件を満たせば発動できる）。モデルでは消去と解除を別に実装する（本体の論点 8。2026-10-15 の決定）。消去は解除不可の状態も外し、解除は外さない。この違いを持つため、解除不可は付与の印として持つ見込み。
5. **解除不可が計算に効く場面**: モデルに効果解除が無いので、いまは計算を変えない。効くのは、編成に「デバフ効果解除」（ココア・ソラ・クレア・ミカ：スノーバディ・クラスト）か「デバフ効果免疫」（エード・クレイ）を持つ味方がいて、自分に付く▼（最大装弾数▼・命中率▼・チャージ速度▼など）を持つ味方がいる時だけ。外せる数より多ければ先に付いたデバフから外す（ツールチップ「デバフ効果解除」）が、どの効果がデバフに数えられるかは決まらない（要確認）。敵のバフを外す「バフ効果解除」（ロザンナ）は、射撃場の的にバフが無いので効かない。

### 4.6 条件の判定のタイミング

- **発火の瞬間の条件**（「〜した時、〜なら」）: 発火の瞬間だけ見る。付いた後は、条件が外れても維持の終わりまで続く。マナ S2 は、同じ発火でマターシグマを解除しても、攻撃ダメージ▲・攻撃力▲が 10 秒続く（C-0281）。語彙は `condition`（`selfBuffed`・`inFullBurst`）と編成の条件。
- **続いている間の条件**（「〜の時に限り」「〜の時のみ」「〜である限り」）: 条件の間だけ効く。ウンファ：TU の「カモフラージュ状態である限り」の効果は、カモフラージュの窓の間だけ効く（C-0311。状態の中身で書いた）。自分の状態なら中身（`contents`）で書ける。他人の状態・HP などは語彙なし。
- **きっかけの無い条件**（「〜なら、自分に…持続」）: 続いている間の条件と同じに読む。ノワール S1（HP 以上）は、HP がいつも満タンとみなして `assumes` で書いた（HP は減りうるので、6.2 節で見直す）。
- 説明文が前の状態を明示的に消している形（アニス：スターの私だけの星・みんなの星、ラピ：レッドフードの戦闘補助、マナのマターシグマ）は、条件が変わっても自動では外れないことを示唆する（だから消去・解除を書いている）。
- 「生存している限り」は前提で成り立つ。「HP が X% 以上の時のみ」は HP の経路の読む側（6.2 節）。「フォーカス状態の時に限り」は操作キャラかで決まる（ツールチップ「フォーカス」。編成で決まる）。

## 5. 回復

### 5.1 回復の形

| 形                                                               | 区分             | 語彙                                                                                                                                        |
| ---------------------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 回の回復（発動者の最大HP の X%）                               | 語彙あり         | `heal`                                                                                                                                      |
| 吸収回復（攻撃ダメージの X%・N 秒間維持）                        | 語彙あり         | `heal` + 維持（C-0082）                                                                                                                     |
| 持続回復・「N 秒間隔」「N 秒間維持」の付いた回復                 | 語彙あり（読み） | 付いた時に 1 回だけ `healed`（ツールチップ「回復効果が適用された時」。[design-heal-vocabulary.md](design-heal-vocabulary.md) 3.1 節の D-a） |
| 蓄積した回復の放出                                               | 語彙なし         | 回復効果と判定される（ツールチップ「蓄積量に応じた回復」）。蓄積の量は被弾で決まる                                                          |
| バリアの HP 回復・デコイの回復・超過回復量の保存・回復の均等分配 | 被弾で効く       | HP・バリアが減った時に効く。回復の均等分配は `healed` を起こさない（同ツールチップ）                                                        |
| 復活                                                             | 前提の外（構造） | —                                                                                                                                           |

### 5.2 回復の対象

- 語彙あり: 味方全体・自分・自分を除く・武器／コード／部隊で絞る（`heal` には順位の対象を書けない。足すときは対象の語彙と合わせて確かめる）。
- 要確認: 残りの HP の割合（数値）が最も低い味方 N 機（HP の経路の読む側。6.2 節）。射撃場では的の攻撃を受けた操作キャラが選ばれる見込みで、全員が満タンで並んだ時（最初の被弾の前）の選び方だけが残る（E-a〜E-d。同 3.2 節）。ランダムな味方（乱数を起点にする効果。[design-stage16.md](design-stage16.md) 10.0.2 節）。
- 語彙なし: 両隣・最大HP 順・防御力順（防御力の経路。6.3 節）・クラスで絞る。

### 5.3 回復が与ダメージに届く道

- **回復を受けた時のきっかけ**: 「回復効果が適用された時」の効果を持つ味方（クラウン・ネロ・シラツル・アスカ）がいる編成でだけ届く（C-0180・C-0254）。HP が満タンでも適用とみなす（C-0345）。
- **HP の経路**: 回復は HP を動かす側でもある（6.2 節）。HP が満タンでない時（被弾・自分の現在のHP▼・最大HP のみ▲の後）に、HP の条件を変える。回復量の stat（受けるHP回復量・与えるHP回復量）もこの経路で間接に効く。

## 6. 間接に効く経路（HP・防御力・バリア）

### 6.1 考え方

- 間接に効く効果は、**動かす側**（HP・防御力・バリアなどを変える効果）と、**読む側**（その値・有無で、値・対象・条件・きっかけが決まる効果）の組で効く。読む側が編成にいなければ与ダメージは変わらない。回復と受け手の関係（5.3 節）と同じ形。
- 前提の中で動くもの（最大HP▲・自分の現在のHP▼・回復・防御力▲・バリアの付与）は、この節の経路で間接に効く。被弾を通す分（被ダメージを減らす・バリアや遮蔽物が壊れる）は被弾で効くに分ける（6.6 節）。
- いまのモデルは、枠ごとの HP・最終防御力・バリアを持たない。どの経路も、読む側を定義するときに、動かす側と合わせて語彙が要る（語彙なし）。
- **読む値の基準と、いつの値を読むか**: 「最終」の付く値は戦闘中の効果を含み、付かない値は基礎と装備の値（ツールチップ「最終」）。発動者基準の攻撃力▲（`casterAttack`）は付かない値（バフ前）なので戦闘中に変わらないが、「発動者の最終最大HP の X% 分の攻撃力▲」などは戦闘中に変わる値を読む。発火の瞬間の値で固定するか、続いている間に読み直すかは、語彙を足す段で確かめる（要確認）。読み直すと循環しうる形がある（メアリー：ベイゴッデスのバースト: 発動者の最終最大HP 基準で、発動者を含む味方全体の最大HP▲）。基礎値を読むと決めて循環を避けるのは、説明文の「最終」と食い違うので取らない（本体 11 節の 3.3）。

### 6.2 HP の経路

- **動かす側**:
  - 最大HP▲（自分・味方。スキル発動者基準を含む）。現在の HP も増えるかは説明文に無い（要確認）。
  - 最大HP のみ▲。英語版は「Max HP ▲ (without restoring HP)」で、現在の HP は増えない（データ明記）。HP の割合が下がる。
  - 自分の現在のHP▼（ギロチン・紅蓮・ラプンツェル：ピュアグレイス・アビスタ・グレイブ・A2）。
  - 回復（1 回・持続・吸収）と、受ける・与える HP 回復量。
  - 最大HP のコピー（最大HP が最も高い味方の最大HP の X%）。
  - 被弾。射撃場でも的の攻撃でわずかに減る（オーナーの指摘）。3 分モードの的は操作キャラを攻撃する（C-0551。単騎の録画からの仮説で、操作キャラ以外が撃たれるかは分からない）。
- **読む側**:
  - 最大HP 基準の値: 発動者の最大HP の X% 分の攻撃力▲、最大HP を攻撃力に足したダメージ（ラプラス：アルティメットヒーロー・メイデン：アイスローズ・シンデレラ・2B など）。最大HP▲ を持つキャラ自身に多い。
  - 失った HP ごとの▲（ギロチンの攻撃力▲など）。
  - HP の割合の条件（「HP が X% 以上／以下」「HP が最大の時のみ」）と、閾値のきっかけ（「HP が X% 以下になった時」「HP が最大になった時」）。
  - HP 順の対象（残りの HP の割合・数値が最も低い味方。5.2 節）。
- **HP は減りうる**（オーナーの指摘で、前提で決めるのをやめた）: HP の条件は、被弾と HP を動かす効果で変わる。射撃場の被弾はわずかなので、「X% 以上」は多くの時間で成り立つが、「最大の時のみ」は 1 回の被弾で外れて回復まで戻らず、「X% 以下」は届きにくく、失った HP は 0 にならない。いまの `assumes`（ノワール S1 の HP 70% 以上）と notes（アリス S2 の HP 80% 未満の回復など）は、満タンとみなした読みなので見直す。モデルは被弾の時刻を持たないので、HP の条件を書くには HP の模型か、利用者が選ぶ想定が要る（本体の論点 12）。
- **連鎖の例**: シンデレラ S2 の「デコイが存在する時」の美しさ（最大HP▲）→ S1 の最大HP 基準の攻撃力▲。ルージュの最大HP のみ▲（味方全体）→ 味方の HP の割合が下がり、「HP が最大の時のみ」の▲（ソリン S2 など）が外れうる。

### 6.3 防御力の経路

- **動かす側**: 防御力▲（自分・味方。スキル発動者基準を含む）、失った HP ごとの防御力▲（モラン）、発動者の防御力に比例する防御力▲（マルチャーナ。「最終」の付かない発動者の防御力を読むので、読む側にはならない）。
- **読む側**:
  - 防御力の比べで決まる対象: アニス：スター S2 の「自分と、自分より最終防御力が低い味方」（定義では全員とみなす。C-0210）。
  - 防御力の順位で決まる対象: パスカル S1 の「最終防御力が最も高い味方」への回復（回復の受け手がいれば、5.3 節の道で届く）。
- **前提での読み**: 対象の比べに使う最終防御力は、基礎の防御力と防御力▲の和で決まり、被弾に依らない。いまのモデルは最終防御力を持たない。
- 防御力が被ダメージを減らす分は被弾で効く（HP の減りを変える）。

### 6.4 バリアの経路

- **動かす側**: バリアの付与（個別のバリア・共用バリア・名前の付いたバリア（ナノコーティング・妄想・必死の抵抗・ポリスバッジ・ブルーハーブ））。バリアは効果解除では外れない（ツールチップ「バリア」）。バリアの HP（量・バリアの HP 回復・次のバリアの HP▲・バリアへの無敵付与）は、壊れるまでの長さだけを変えるので被弾で効く。
- **読む側**:
  - 条件: 「自分がバリア適用状態なら」（アスカ S2・ナガのバースト）、「自分がバリア適用状態の時に限り」（ラプンツェル：ピュアグレイス S1・S2）。
  - きっかけ: 「バリア適用時」（ナガ S1・フローラの宝物版 S2）。
  - 名前の付いたバリアの状態: 「ナノコーティング状態でなければ」（キロ）、「妄想状態の時に限り」「妄想が終了した時」（レーベル）、「必死の抵抗状態なら」（モリー）。
- **バリア適用の範囲**: 「バリア適用」は自分の前に張られたバリアで、共用バリアは設置の基準が自分のときだけ数える（ツールチップ「バリア適用」）。共用バリアは、張った本人（「自分に…共用バリア」なら発動者）だけをバリア適用状態にし、守られるほかの味方はバリア適用状態にならない。
- **読み**: バリアは、付与の窓を状態の窓とする名前の付いた状態として書ける見込み（4.3 節の `selfState`・`{ applied }` と同じ語彙で見る）。窓の終わりは維持の終わりか、被弾でバリアの HP が尽きた時（被弾で効く）。射撃場の被弾はわずかなので、多くは維持の終わりまで続くと読む（要確認: 3 分モードの的の攻撃でバリアが壊れるか）。
- 敵のバリアへの効果（バリアに与えるダメージ▲）は前提の外（構造）のまま。

### 6.5 デコイ・遮蔽物

- **デコイ**: バリアと同じく、付与の窓の間「デコイが存在する時」として読まれる（シンデレラ S2・ライ）。判定は自分が展開したデコイだけ（ツールチップ「デコイが存在する時」）。窓の終わりは維持の終わりか、被弾で壊れた時。
- **遮蔽物**: 「自分の遮蔽物が破壊されていない限り」（シュガーの宝物版 S1）・「遮蔽物が破壊された味方がいない場合」（リリーのバースト）は、被弾で遮蔽物が壊れなければ成り立つ（射撃場の被弾はわずか）。「遮蔽物の HP を回復した時」（ティア S1）は、壊れていない遮蔽物に回復が適用されれば起きる（ツールチップ「遮蔽物の HP を回復した時」「遮蔽物 HP 回復」。回復を受けた時と同じ形の出来事。語彙なし）。

### 6.6 被弾の経路

- 受けるダメージ▼・防御力（被ダメージを減らす分）・敵の攻撃力▼／命中率▼・挑発・ヘイト・無敵・不屈・隠れ身（単一攻撃の対象から除外）・ダメージ分配・気絶（敵）・バリアや遮蔽物の HP は、被弾の量・誰が撃たれるかを変え、HP・バリア・遮蔽物を通して間接の経路の読む側に届く。
- 射撃場でも被弾はわずかにあり、HP は減りうる（オーナーの指摘。C-0551）。モデルは被弾の時刻を持たない（[design-range-enemy-attacks.md](design-range-enemy-attacks.md) の案 A）。敵の構造が無いもの（前提の外（構造））とは分けておく（本体の論点 9）。

### 6.7 貫通特化と貫通ダメージ

- 貫通ダメージは、貫通特化の状態のニケが敵を攻撃するときのダメージ（ツールチップ「貫通ダメージ」。T2）。貫通特化は、自分の発を貫通ダメージ▲の乗る発にする状態で、貫通ダメージ▲（自分・味方。ツバイ・エード：エージェントバニーなど）が読む側になる。
- いまの notes（アリス S2・ニヒリスター S1・スノーホワイト：ヘビーアームズ S2・アスカのバースト）は、貫通特化を「敵 1 体ではダメージに関係しない」と前提の外にしている。編成に貫通ダメージ▲が無ければその読みのままでよいが、あれば効きうる。敵 1 体の的で貫通ダメージ▲が乗るかは撮って確かめる（要確認）。

## 7. 条件・きっかけ・対象

### 7.1 条件

- **語彙あり**: 編成（同じ部隊・基本バースト段階・特定のキャラ。`squad`・`burstStepMix`・`withCharacter`）・敵の属性（`enemyElement`）・フルバーストタイム中なら（`inFullBurst`）・自分が〈stat〉増加状態なら（`selfBuffed`）。対象（敵）が〈状態〉なら（`enemyState`）は `damage` だけ。
- **語彙なし**: 自分が〈状態〉なら・フルスタックなら・でなければ・適用中（4.3 節）、直前に自分がバーストを使用していれば・武器変更状態なら・固有のカウンタの値、フォーカス状態なら（操作キャラかで決まる。4.6 節）。
- **間接に効く**: 自分がバリア適用状態なら・の時に限り（6.4 節）、自分・味方の HP が X% 以上／以下・最大（6.2 節。HP は減りうるので前提で決めない）。
- **前提で決まる**: 生存している限り・ラプチャーなら（成り立つ。`assumes`）、敵が N 機以上（N ≥ 2 は起きない）。
- **要確認**: 対象がターゲットなら（射撃場の的をターゲットとみなす読み）、適正射程距離内なら（距離の帯）。
- 判定のタイミング（発火の瞬間か、続いている間か）は 4.6 節。

### 7.2 きっかけ

- **語彙あり**: 戦闘開始時・バーストスキル使用時（回数の段を含む）・フルバーストタイム発動時／終了時・バースト N 段階突入時、通常攻撃で N 回攻撃した時・N 回命中した時・コアに命中・ペレットが命中・フルチャージ（攻撃・命中。フルチャージ攻撃の命中は、フルチャージの発が当たるとみなして書く）・最後の弾丸、N 秒ごと・回復効果が適用された時・確率（撃った・命中した時）。スキルのスロットで、きっかけが書かれず維持やダメージを持つもの（CT ごとのアクティブ）も、周期のトリガー（`everySeconds`）で書ける。周期は説明文に無いので、キャラごとに録画で読む（C-0453・C-0496・C-0502 の形。分類の一覧では語彙の残りと別に数える。本体 11 節の 3.9）。
- **要確認**: 〈状態〉が適用された時（`damage` だけ）。
- **間接に効く**: バリア適用時（6.4 節）、デコイが存在する時（6.5 節）、HP が閾値を越えた時（6.2 節）。
- **語彙なし**: 〈状態〉が終了した時・フルスタックで解除後（効果のあるスタック）、クリティカル命中した時・フルチャージを N 秒以上維持した時・フルチャージでない通常攻撃・リロード完了時、ほかのスキルの発動・命中・味方の消費した弾の合計・固有のカウンタの出来事、遮蔽物の HP を回復した時（6.5 節）。ミハラ：ボンディングチェーンの「特定のタイミング」は周期ではなく、フルバースト終了・バースト 3 段階突入・敵の出現（T5）。
- **被弾で効く**: 攻撃を受けた時（射撃場でも起きる。C-0551）。
- **前提の外（構造）**: 敵を倒した時・戦闘不能時・パーツ・敵の出現・N 機以上に同時に命中。

### 7.3 対象

- **語彙あり**: 自分・味方全体・自分を除く味方全体・武器／コード／部隊／基本バースト段階で絞る・最終攻撃力順・基本チャージ時間順・直前にバーストした味方、敵（敵全体・攻撃範囲内・命中した敵・条件で選ぶ N 機。敵 1 体）。
- **要確認**: 残りの HP の割合順（HP の経路の読む側。5.2 節）・ランダムな味方・時間で変わる状態で絞る・デバフのかかった味方のうちランダムな N 機（ココア S1 の「デバフ効果がかけられている味方のうち、ランダムに N 機に」。条件ではなく対象の絞り込み。自分に付く▼のある味方から選ぶが、どの効果がデバフに数えられるかは決まらない。4.5 節の 5。本体 11 節の 3.10）。
- **語彙なし**: クラスで絞る・両隣（編成の枠の左右。ツールチップ「両隣」）・最大HP 順・防御力順（防御力の経路）・特定のキャラ（チャイムの「自分の王」はクラウン、アビスタの「自分のアイドル」はアニス：スター）。
- **被弾で効く**: 遮蔽物。

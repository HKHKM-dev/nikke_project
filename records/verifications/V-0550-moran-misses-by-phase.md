# V-0550: 射撃場の単騎の AR の、ジャンプの外の外れを相ごとに数える（モラン単騎の 0719・0720）

- 問い: 0719・0720 の窓の外（ジャンプの外）の外れは、どの相（距離）に出るか。的の表の AR の弾丸命中率と合うか
- 話題: 命中率・距離
- 日付: 2026-10-31
- 録画: `0719`、`0720`
- 結論: `C-0756`
- 状態: 完了
- 派生元: `V-0539`

## 条件

- 型: 読み直し。V-0530・V-0539 の 2 本（モラン（宝物版・段階 3）単騎・操作・AUTO 射撃・オートバースト ON・スペック固定 ON・BigArms の 3 分モード）。
- 出どころ: V-0539「分からないこと」（backlog.md 2-39）。窓の間の変更前の武器の発に外れがある（`0719-17`・`0720-17` と命中の数の差）。V-0530 の比べる指定は手入力の条件（`condition` を書かない。弾丸命中率 1）なので、モデルは外れを持たない。
- 見るもの: 外れが特定の相に偏るか。偏りと大きさが、自動の条件のモデルが使う的の表（`data/enemies.json` の `range-bigarms` の AR の `bulletHitRate`。C-0543・C-0643・C-0644）と合うか。
- 変更後の武器の窓の中の発も、同じ数え方で相ごとに数える（表の AR の値と比べる）。
- 最小構成: 単騎で、見るのは通常攻撃の発の当たり外れだけ。モランのスキルは外れの有無に効かない（S1 の追加ダメージは命中の数で出る。C-0705）。

## 予測

なし（読み直し）。

## 読み方

1. 録画をクラウドで Drive から取り寄せ、`hud.ts --mode jumps` で総ダメージの増分を読んだ（V-0539 と同じ）。
2. 着地点はレシピ `midfar-landing`（`0719-18`・`0720-18`）と `far-landing`（3 区間目は 30f ごと、6 区間目は 10f ごと。`0719-19`・`0719-20`・`0720-19`・`0720-20`）で読んだ。
3. 区間（相）の切れ目はジャンプの前の最後の増分（`0719-01`・`0720-01` の note）、変更後の武器の窓は最初の増分（`0719-09`・`0720-09` の note）から 580f（V-0539 と同じ）。
4. 発の当たり外れは使い捨てのスクリプトで数えた（`buff-edge`・`ar-cores` は、変更後の武器の窓と S1 の追加ダメージの乗った増分を分けない）。数え方は `0719-21`・`0719-22` の note。
   - 撃ち続けた連ごとに、増分に発の番号を振る。変更前の武器は前の増分からの空きの丸め（4〜6f と 9〜11f で分かれる）、変更後の武器は連の全部に当てた 2.451f の格子（2〜3f の揺れを吸う）。
   - 1 発の格子に乗り、前のフレームも読めた増分は 1 命中。前の命中との間の番号の空きは、確かな外れ。
   - HUD が止まって合わさった増分は、命中を下限と上限で挟む（V-0539「読み方」4 と同じ）。連の端の合わさった増分は撃った発の数も決まらないので、外れの下限に数えない。
   - 連の頭・最後の発の外れは見えない。外れの上限は少なめに出うる。
5. 表との比べ: 相ごとに、撃った発 × (1 − 表の値) を外れの期待値とし、2 項分布の 2σ と比べた。中遠・遠は読んだ着地点の値（中遠 A は帯の値、中遠 C は `midFarC`。遠は A・B とも帯の値）。

## 結果

読んだ日: 2026-10-31。観測値は `0719-18`〜`0719-22`・`0720-18`〜`0720-22`。

- 着地点: 0719 は中遠 A・遠 B（3 区間目）・遠 A（6 区間目）、0720 は中遠 C・遠 A・遠 A。
- **外れは遠の相に集まる**。
  - 変更前の武器（窓の外。`0719-21`・`0720-21`）: 外れの下限の和は、遠の 2 区間で 7（0719）・13（0720）、ほかの 4 区間で 2・2。遠の発は全体の約 4 分の 1。
  - 変更後の武器（窓の中。`0719-22`・`0720-22`）でも同じ。遠で 7・12、ほかで 3・3。
  - 変更前の武器の近・中近の確かな外れは、0719 の 1 回目の窓の前の 1 発（f1609。中近）だけ。
- **大きさは、表の AR の値と 2σ の中で合う**（下の表の行（録画 × 武器 × 相）にも、区間ごとの観測値にも、外れの下限が期待値 + 2σ を超えるものは無い）。

- 区間ごとの値は観測値。ほかの相の期待値は、中遠 C の 0720（`midFarC` 0.984）で大きい。
- 0720 の遠は表より多い側にある。2 つの武器を合わせると、外れの下限 25（574 発）が期待値 16.6 + 2σ（8.0）をわずかに超える。2 本・2 つの武器を合わせると、下限 39（1,146 発）は 33.1 ± 11.4 の中。
- 合わさった増分の中の外れを 1 つに決められないので、相ごとの率は幅でしか言えない。

**モデルとの比べ（記録）**

- V-0530 の比べる指定を自動の条件（`condition: auto`。表の弾丸命中率）に替えて照合を回すと、`0719-07`・`0720-07`（S1 の最初の 3 回の発）が 1 発ずれて許容外になる（205・210・215 → 206・211・216）。ほかの比べる観測値は許容内のまま。
  - モデルは外れを期待値（`normalHit` の命中の重みが表の値）で数える。1 回目の窓の前の約 201 発で、中近の外れの期待値 0.75 発ぶん命中の累計が遅れ、5 の倍数に届く発が 1 つ後ろになる。
  - 録画の外れは 1 発ずつ（0719 は窓の前に 1 発、0720 は 0 発）で、どちらも命中で 205 発目に届く。
- 比べる指定はこの検証では替えていない。

## 分かったこと・分からないこと

- 分かったこと:
  - 0719・0720 の窓の外の外れは、遠の相に集まる（C-0756。仮説）。大きさは、射撃場の的の表の AR の弾丸命中率（C-0543・C-0643・C-0644）と、相ごと・録画ごとに 2σ の中で合う。外れの原因は、表で持っている射撃場の外れ（自動の条件でモデルが使う）と見てよい。表を変える根拠は無い。
  - V-0539 の「条件では弾丸命中率 1」は、V-0530 の比べる指定が手入力の条件だったことによる。録画の条件（操作・AUTO 射撃の射撃場）には、表の外れがある。
  - 変更後の武器の窓の中の外れも、同じく遠に集まり、表の AR の値と合う。
  - `0719-11`・`0720-11` のモデルとのずれは、比べる指定を自動の条件にしても直らない。期待値で数えるモデルは、1 発ずつの外れで決まる S1 の発の位置を言い当てられない（上の「モデルとの比べ」）。
  - `0719-07` の note の「外れは無い」は誤り。1 回目の窓の前に 1 発の外れ（f1609）がある。増分（命中）は 201 で、C-0705 の判定（命中を数える H1）は変わらない。
- 分からないこと:
  - 0720 の遠の外れが表より多い側にあるのが、録画ごとの散らばりか、モランの撃ち方（720rpm の AR）による違いか。2 本では分けられない。

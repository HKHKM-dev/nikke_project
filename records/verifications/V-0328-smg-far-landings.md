## 条件

**V-0215 で遠の判定が付かなかったわけ**（この検証の仮説の出どころ。既に値を見た観測値の読み直しなので、結論にはしない）

- 遠の着地点は 2 か所ある（C-0333。仮説。V-0228）。遠 A（足元 540〜542）と遠 B（足元 534 前後）で、遠 B の的は高さ・幅が約 8% 小さい。単騎の 109 本で遠 A 61・遠 B 48。モデルと的の表の遠は 1 か所（`far`）のまま（2026-10-06 のオーナーの判断。V-0228 論点 1 の案 A）。
- V-0200 の 25 本と V-0215 の 16 本の遠の観測値（レシピ `smg-mags`。`098-14` など）を、V-0228 で読んだ遠の足元（`213-06` など）で分けると、次のようになる（2026-10-07 にこの検証を起こす前に集計した）:

| 遠の着地点       | 録画の数（V-0200 / V-0215） | 当たった数 ÷ 撃った数     | 録画ごとの標準偏差（V-0200 / 全部） |

- 着地点で分けると、録画ごとの標準偏差は、1 録画（約 480 発）の二項分布の幅（遠 A 0.018、遠 B 0.019）とほぼ同じになる。分けない遠の録画ごとの標準偏差（V-0200 0.0265、V-0215 0.0358）が二項分布より大きいのは、2 か所の値が混ざっているためと読める。
- 分けない値は、撮った録画の遠 A・遠 B の割合で動く（V-0200 は A 13・B 12 で 0.7887、V-0215 は A 7・B 8・間 1 で 0.7769）。V-0215 の「表（0.760）と候補（0.7887）の間」は、1 か所の値どうしを比べる問いの立て方が合っていなかったためとみる。
- 遠 B の値（0.7608）は、的の表の遠（0.760。C-0320）とほぼ同じ。

**編成**（最小構成。2026-10-07 のオーナーの判断）: リター（SMG）単騎。射撃場 BigArms・灼熱・3 分モード・スペック固定 ON・AUTO 射撃・**オートバースト OFF**（V-0200 と同じ条件。バーストの効果の窓のマガジンが入らない）。リターは命中率▲を持たない。遠の着地点はキャラによらない場面の性質とみる（V-0228）。

**本数**（2026-10-07 のオーナーの判断。撮る前に決めて変えない）: 遠 A・遠 B の録画がそれぞれ **6 本以上**になるまで撮る。止めるかは遠の着地点の数だけで決め、弾丸命中率は見ない。上限は 20 本。上限で片方が 6 本に満たないときも、撮れた本数で判定する（σ は実際の本数で出す）。

## 予測（撮る前に書く）

撮る前に `npm run records:predict -- V-0328` を回し、予測ファイル（`records/predictions/V-0328.json`）を commit した。値は予測ファイルを指す。

- 指標は `bulletHitRate`（V-0215 と同じ。遠は 3 区間目の中のフレーム）。モデルの遠は 1 か所なので、予測ファイルの指標 `far-a`・`far-b` はどちらも同じ遠の値を出す。H2 は指標ごとに仮説を分け（`H2-farA`・`H2-farB`）、**H2-x は指標 x だけで比べる**（V-0215 の H1-x と同じ書き方）。観測値は読んだ後に、予測ファイルの指標の `observations` で着地点ごとに結び付ける。
- 仮説:
  - **H0**: 遠は着地点によらず、的の表のとおり 0.760（C-0320）。
  - **H1**: 遠は着地点によらず、V-0200 の 25 本の値 0.7887。
  - **H2**: 遠は着地点で違い、遠 A 0.8068・遠 B 0.7608（上の 40 本）。
- **判定の指標**:
  - 録画ごとの、3 区間目の完全なマガジンの弾丸命中率（6 区間目は使わない。着地点を読むのは 3 区間目なので）を、遠の着地点ごとに平均した p̄_A・p̄_B。
  - **主な指標**は差 d = p̄_A − p̄_B。H0・H1 なら 0、H2 なら 0.0460。
- σ（録画の数 kA・kB は撮った後に決まる）:
  - σ_A = max(0.0142 ÷ √kA, √(0.8068 × 0.1932 ÷ nA))、σ_B = max(0.0189 ÷ √kB, √(0.7608 × 0.2392 ÷ nB))。0.0142・0.0189 は V-0200（同じ条件）の着地点ごとの録画ごとの標準偏差、n はその着地点の撃った数の合計。
  - σ_d = √(σ_A² + σ_B²)。
- **判定の目安**（撮る前に固定する）:
  - 主な指標 d:
    - **着地点で違う（H2）**: |d − 0.0460| < 2σ_d かつ |d| ≥ 3σ_d。
    - **着地点で違わない（H0・H1）**: |d| < 2σ_d かつ |d − 0.0460| ≥ 3σ_d。
    - どちらでもなければ判定なし。
  - 着地点ごとの値（d で H2 のときだけ）: p̄_A が 0.8068 から、p̄_B が 0.7608 から、それぞれ 2σ 未満なら、H2 の値が再現した。
  - d で「違わない」のとき: 着地点を分けない平均 p̄（全部の録画）を、V-0215 と同じ目安（σ は max(0.0265 ÷ √k, 二項分布)）で H0・H1 と比べる。
- 見込み（kA = kB = 6、1 本 480 発のとき）:
  - σ_A 0.0074、σ_B 0.0080（どちらも二項分布のほうが大きい）、σ_d 0.0108。H2 の d は σ_d の 4.2 倍。
  - H2 が正しいとき、d で判定が付く見込みは約 87%（d が 0.0325 未満か 0.0677 以上に落ちると判定なし）。H0・H1 が正しいときも同じく約 87%（d が 0.0135 を超えるか −0.0217 以下に落ちると判定なし）。
  - 着地点ごとの値では、遠 A は H2 と H0 の差が 6.4σ_A・H1 との差が 2.5σ_A、遠 B は H2 と H1 の差が 3.5σ_B。遠 B の H2 と H0 は 0.0008 しか違わず見分けない（予測の表で `far-b` に H0 と H2-farB の両方が合うのは見込みどおり）。
- 外れたときの影響:
  - **H2**: 遠を `farA`・`farB` の 2 か所に分ける案（V-0228 論点 1 の案 B。遠の配分は C-0333 の 0.56 : 0.44 か 1 : 1。設計が要る）と、表の SMG の遠を着地点ごとの値にする案をオーナーに諮る。C-0333 の状態（仮説）を確定にするかも合わせて諮る。遠の区間の期待値は、配分 0.56 : 0.44 なら 0.760 → 0.7866 になる。
  - **違わない**: 遠は 1 か所のまま。C-0333 は着地点で命中率が違うとは言っていないので変えない。H0・H1 の比べで表を変えるかを諮る。
  - **判定なし**: 表を変えず、結果と次の手をオーナーに諮る。

## 読み方

1. 取り込み: `tools/captures/intake.ts`（`--rid 82 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec on`。オートバースト OFF を素性に書く。録画は撮った後で冒頭の「録画」に足す）。
2. 遠の着地点（命中率より先に読む）: V-0228「読み方」の 2〜4 と同じ（`node tools/captures/aim.ts <動画> --from 4300 --to 7800 --step 35 --bg-step 240 --csv <scratch>`、同じコマの選び方）。足元の y の中央値が 540 以上なら遠 A、536 以下なら遠 B、537〜539 は使わない。使えるコマが 8 未満の録画も使わない。観測値は `kind: "position"`（`source: V-0328`）。ここで本数を数え、止めるかを決める。
3. 弾丸命中率: `npm run records:read -- <録画 id> --recipe smg-mags --source V-0328 --opt body=8714.7 --write`（区間の切れ目はレシピが決める。切れ目が 5 つでなければ止めて見る）。オートバースト OFF なので窓は無い（窓が見つかったら止めて見る）。
4. 3 区間目のマガジンの当たった数（観測値の説明）から、着地点ごとの p̄_A・p̄_B と d を出し、判定の指標の観測値（`rate`・`use: compare`・指標 `bulletHitRate`）を着地点ごとに 1 つ書く。d と判定は、遠 A の観測値の説明に書く。

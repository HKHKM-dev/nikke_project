# キャラの画像のコスチューム違いを取り込む

- 何のための文書か: キャラの画像（顔のアイコンと縦長の絵）に、コスチューム違いの絵を足す変更の、案・決定と経過。
- 関連: [design-modern-ui.md](design-modern-ui.md) 1 節 3（画像の同梱）・「スロットの縦長の絵」、`packages/core/scripts/fetch-images.ts`。

## 1. 調べたこと

- 画像を取っている Blablalink の公開 CDN の名前は `/character/{si|mi}/{si|mi}_c{resourceId 3 桁}_{番号 2 桁}_s.webp`。これまでは番号 `00` だけを取っていた。
- 番号を `01`・`02` … にすると、同じキャラの服違いの絵が返る（ラピの `00`〜`02`、アリスの `01` を見て確かめた）。si と mi は同じ番号でそろっている。
- 番号は飛ぶことがある（ディーゼルは `03` が無く `04` がある）。全キャラで、取った最後の番号の次から 8 つ先まで調べ、飛びはこの 1 か所だけだった。
- 大きい版（`_m`・`_l`）は無い。
- コスチュームの名前は、取り込んでいるデータ（キャラの一覧・roledata）に無い。手に入るのは番号だけ。

## 2. 決定

- ファイル名は `{resourceId}_{番号 2 桁}.webp`（オーナーの承認）。番号は CDN の番号そのもので、`00` が初期の絵。初期の絵も `{resourceId}.webp` から `{resourceId}_00.webp` に名前を変え、決まりを 1 つにした。名前の組み立ては `packages/core/src/characterImage.ts` の 1 か所。
- `npm run fetch-images` は、キャラ × 種類ごとに `00` から順に取り、CDN に無い番号が 3 つ続いたら止める。`00` が無いキャラは、コスチュームも探さない。
- 画面は初期の絵（`00`）だけを出す。コスチュームを選ぶ画面は未実装。

**理由**

- 名前が取れないので、番号のほかに確かな手がかりが無い。CDN と同じ番号なら、対応の表を持たずに取り直せる。
- 初期の絵だけ番号を付けない形は、「番号が無ければ初期の絵」という例外が、取るスクリプトと画面の両方に残る。
- 止める条件を 1 つの欠けにすると、ディーゼルの `04` を取りこぼす。
- 番号は si と mi で別々に探す。今はそろっているが、そろうことを前提にすると、片方だけにある絵を取りこぼす。CDN に無い番号を聞く回数は倍になるが、手で回すスクリプトなので構わない。

## 3. 経過

- 2026-11-12: オーナーの依頼（立ち絵のコスチューム差分は手に入るか、ファイル名をどうするか）で調べ、取り込んだ。

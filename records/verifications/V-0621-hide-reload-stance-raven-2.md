# V-0621: 射撃姿勢維持型のハイド中のリロードの始まり（レイヴン単騎の再現）

- 問い: 射撃姿勢維持型のハイド中のリロードは、D と前の発の射撃姿勢の終わり（撃ってから ⌈S⌉ − H）の遅い方から始まるか（C-0842 の再現）
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-01
- 録画: `0886`、`0887`、`0888`、`0889`、`0122`
- 結論: `C-0842`
- 状態: 完了
- 派生元: `V-0615`

## 条件

- 型: 撮る。C-0842（仮説）は、レイヴンの既存の録画 `0122` で再現したが、ハイド中のリロードの始まり（バーの 0 の点）をモデルと比べる指標が無いので確定にできない。レイヴンはリロード 2 秒で、どの仮説でもジャンプの間に終えないので、発の数では見分けられない。
- 読むときに、モデルのハイド中のリロードの始まりのフレームを記録し、録画のバーの 0 の点と比べる指標を足す（その PR で）。指標ができたら、`0122`（D を決めるのに使っていない）も比べる観測値にする。
- キャラと最小構成は V-0615 と同じ（レイヴン単騎・操作・オートバースト OFF。⌈S⌉ 49f・H 16f）。
- 見分けの要: マガジンの途中のジャンプ。(a) チャージの途中で窓に入る（部分チャージの発あり。約 6 割）、(b) 前の発の約 44f 以内に窓に入る（部分チャージの発なし。約 4 割）。1 本で 2〜3 回を見込む。

- 撮った後・読む前に足した予測（紅蓮：ブラックシャドウ。⌈S⌉ 14f・H 1f。オーナーが追加で撮った）: C-0842 では、部分チャージの発 → バーの 0 の点が約 13f、0 の点 → 明けが約 96f。D からの形では約 −1f・約 110f、前の発の約 19f 後からの形では約 19f・約 90f。

## 読み方

1. `node tools/captures/hud.ts <動画> --mode jumps`、`node tools/captures/reload.ts <動画> --mode fit`、撃ったフレームは `node tools/captures/reticle-ammo.ts <動画> --mode series`（替わり目の前後のフレームが続けて読めた回だけ）。
2. 録画の窓は V-0615 と同じ決め方（明けの後の 1 発目の 85f 前を終わり、その 2 秒前を始まり）。
3. ジャンプごとに (a)・(b) に分け、撃ったフレーム・バーの 0 の点・消えたフレームを読む。

## 結果

- 撮影は計画どおり（レイヴン単騎 2 本・紅蓮：ブラックシャドウ単騎 2 本。灼熱・3 分モード・スペック固定 ON・オート射撃 ON・オートバースト OFF を、出撃画面・左上のボタン・戦闘履歴で確かめた）。
- 比べる指標 `hideReloadToWindowEnd`（窓の中のハイド中のリロードの始まりから窓の終わりまで）を足し、モデルの 1 パス目がハイド中のリロードの始まりを記録するようにした（`ShotLog.hideReloadStarts`）。録画の窓（`0886-01`・`0887-01`・`0888-01`・`0889-01`）は、ハイド中のリロードのバーが消えたフレームを明けにした。
- 比べる観測値（バーの 0 の点 → 消えた。モデルと 0〜1.1f の差）:
  - 部分チャージの発の回: `0886-04`・`0887-04`（レイヴン。約 62f）・`0888-02`・`0889-02`（紅蓮：ブラックシャドウ。約 96f）・`0122-33`。C-0842 の予測（61f・96f）どおりで、D からの形（110f）・前の発の約 19f 後からの形（75f・90f）とは合わない。
  - 窓の前のフルチャージの発の姿勢の終わりからの回: `0886-03`・`0887-03`。
  - 姿勢が窓の前に終わっていて D からの回: `0886-05`・`0887-05`・`0888-03`（約 110f）。
- 比べていない回（記録の観測値）: `0886-02`・`0887-02`・`0889-03`・`0122-32`。どれも窓の直前のフルチャージの発の姿勢の終わりから始まる回で、モデルの発は増分（撃ったフレームより飛ぶ時間だけ遅い）にそろえてあるので、飛ぶ時間（約 4〜8f）や窓の終わりのずれがそのまま差になる（0889 の 5 回目は、モデルの発が数 f ずれてチャージの途中で窓に入る）。

## 分かったこと・分からないこと

- 分かったこと: D と式を決めた後に撮る前に予測を固定して撮った録画で、射撃姿勢維持型のハイド中のリロードが、D と前の発の姿勢の終わりの遅い方から始まる形（C-0842）が、レイヴンと紅蓮：ブラックシャドウで再現した。C-0842 を確定にした。
- 分からないこと: 窓の直前のフルチャージの発の回を比べるには、RL の飛ぶ時間（直進弾。モデルに無い）か、撃ったフレームにそろえた戦闘開始が要る。H の長い射撃姿勢維持型の部分チャージの発の値（C-0843）は読んでいない。

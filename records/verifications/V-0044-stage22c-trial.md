- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-09-29
- Stage: [design-stage22.md](../../plan/design-stage22.md) 8 節の 22-C（案・オーナーの判断待ち）
- 録画: `018`〜`022`、`037`〜`040`、`042`〜`044`、`047`、`054`、`056`、`078`、`L-AD`、`L-AI`、`L-AN`
- 結論: `C-0114`

## 条件

- 撮影も録画の読み直しもしていない。モデルを手元でだけ変えて（リポジトリのモデルは変えていない）、`npm run records:check` の残差の一覧を変更の前（#92 の後の main）と比べた。
- 試した変更（設計書 8.3 節の案のとおり）:
  - `weapons.ts` の `WeaponModel` に構えのフレーム `aimInFrames` を足す。
  - `cadence.ts` の `firstShotFrames`（戦闘開始・窓の明け）を、チャージの無い武器では `aimInFrames` にする（AR・SMG・SG は 0f → 12f、MG は 20f → 12f）。MG のリロードの後（`reloadFirstShotFrames`）は 20f（C-0002）のまま。
  - `frame/shooter.ts` の `unhideShooter`（窓の明け）で、チャージの無い武器は、撃てる状態なら待ちを `aimInFrames` にし、込め終えて 1 発目を待っている状態（窓の中でリロードが終わった AR・SMG・SG）なら、残りの待ちと `aimInFrames` の長いほうにする。チャージ武器は Stage 22-A のまま。
- 構えの長さは 12f（C-0114 の 11〜13f の中ほど）。11f・13f でも回した。
- 録画ごとのジャンプの時刻で回すときは、`range-3min-jump` の最初の時刻と間隔を、その録画の観測値（`056-06`・`056-07`、`L-AN-02`、`L-AD-02`）に書き換えた。窓と一緒に、着地点の時間割り（窓の終わりで区間を切る。Stage 18-C）も動く。

## 予測（撮る前に書く）

回す前に、V-0043 の「分かったこと」から見込んだ。

- AR・SMG は、戦闘開始と窓の明けごとに約 2 発少なくなる。単騎の合計は 3 分モードで 1% 足らず下がる。
- MG は戦闘開始で 8f 早く、明けで 12f 遅くなるので、合計はほとんど動かない。
- 1 回目の満タンの時刻は、チャージの無い武器の発で満タンになる編成で約 12f 遅くなる。チャージ武器の発で満タンになる編成は動かない。

## 読み方

1. `aimInFrames` を 0・11・12・13 にして、それぞれ `npm run records:check` を回し、残差の一覧の差を取る。
2. 単騎の合計（`056-02`・`L-AN-01`・`L-AD-01`）は、代表値のジャンプの時刻と、録画ごとのジャンプの時刻の両方で、構えの 0f と 12f を回す（`buildTeamInput` と `runSimulation` をその場で呼ぶ使い捨てのスクリプト）。
3. `npm test` を回し、落ちるテストを数える。

**テスト**（構え 12f）: 16 件が落ちる。どれも発の時刻・数を固定したテスト（`shooter.test.ts`・`cadence.test.ts`・`stage10Shooter.test.ts`・`stage16Events.test.ts`・`engine.test.ts`・`burstRegression.test.ts`・`stage11ModerniaTeam.test.ts`）と、残差の一覧の一致のテスト。sim と calc の整合のテストは変えずに通る。確定の結論にひもづく観測値は、どれも許容の中に残る。

## 分かったこと・分からないこと

- 構えの遅れを入れると、1 回目の満タンは 7 本のうち 5 本で実測に近づき（019・037・039 は 0f）、038 だけが許容の外に出る。単騎の合計は、AR が近づき、SMG は離れ（許容の中）、MG は動かない。
- 操作キャラが SG の 3 本がそろって 0f になったので、SG も戦闘開始に約 12f の構えがあるとみられる → C-0114 の根拠に足した（間接。モデルを通した値なので、C-0114 は仮説のまま）。
- V-0036 の L-AD の「録画ごとの時刻で +3.83%」は、着地点の時間割りを動かさなかった組み方によるもので、動かすと +1.84%。
- 分からないこと: 038（イサベル）でモデルが遅い理由。SMG の単騎でモデルが少ない理由（構えを入れると 1〜1.7% 少ない）。SMG の明けの遅れ（`054-06` の 20・10f）は起き上がりから数えたもので、窓の終わりから数えた長さは読めていない。

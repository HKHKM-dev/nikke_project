# 残差の一覧

- 関連: [design-stage19.md](design-stage19.md) 2.5 節、[verification.md](verification.md)、`records/observations/`
- **このファイルは生成する（手で書かない）**。観測値（`records/observations/<録画 id>.json`）を直したら `npm run records:check` で作り直す。
- 載せるのは、件数（判定ごと・話題ごと）と、見る行（許容外・比べられない・失効）だけ。許容内の行とモデルと比べない観測値は `npm run records:residual -- <観測値 ID|録画 id|V-NNNN>` で引く（同じ列で出す。[design-workflow-simplification-3.md](design-workflow-simplification-3.md) 2 節）。
- 1 行が 1 観測値。実測（録画から読んだ値）と、録画の条件と観測値の `compare.setup` から組んだモデルの予測を並べる。差は、許容幅が比（±%）なら (予測 − 実測) ÷ 実測、差（±値）なら 予測 − 実測。
- 「許容外」はモデルの誤りとは限らない。まずは読み取りと条件を疑い、機構の話にするのは、未確定の要素を 1 つにした編成（最小構成）で切り分けてから（AGENTS.md「事実と記録」）。

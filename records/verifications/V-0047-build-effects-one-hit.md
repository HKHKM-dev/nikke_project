# V-0047: スペック固定 OFF の 1 ヒットに、OL・キューブ・コレクションの効果はどう乗るか

- 問い: スペック固定 OFF の射撃場で、OL の行（攻撃力・有利コードダメージ・クリティカルダメージ・チャージダメージ）、キューブ（命中率・アンチコード）、コレクション（通常攻撃ダメージ倍率・チャージダメージ倍率）の効果は、1 ヒットの式のどこにどう入るか
- 話題: 1 発の式・バフの掛かり方
- 日付: 2026-09-29
- Stage: [design-stage12.md](../../plan/design-stage12.md) 3.5 節・11 節の (c)・13.2 節の 8・9
- 録画: `086`〜`090`
- 結論: `C-0118`、`C-0119`、`C-0120`、`C-0121`、`C-0122`、`C-0123`、`C-0124`、`C-0125`
- 状態: 完了

- OL の行の名前は、どれも装備画面の表示が「チャージダメージ**増加**」で、「倍率」の字は無い。「倍率」が付くのはコレクション（SR・RL）の「チャージダメージ倍率▲」と、SMG・SG の「通常攻撃ダメージ倍率▲」。
- 単騎では、リター・ヘルム・アリス・モダニアとも、1 ヒットに効くスキルは次のものしか出ない: リターのバースト（攻撃力 66%。`086` だけ）、ヘルムの S2 の追加ダメージ（フルチャージの発ごと）、モダニアの S1 の追加ダメージと S2 の攻撃力▲（200 ヒットごと）。スキルの値は、どれも Lv10 の値で合った。
- モダニアは撮影の直前にキューブを付けた（キャラ画面の攻撃力は 469,944 から 470,854 に、キューブの攻撃力 910 だけ増えた）。
- 宝物の段階はオーナーの確認。

## 予測（撮る前に書く）

撮る前にオーナーに示した仮説（2026-09-29）。どの組も、1 ヒットの値が 0.9% 以上離れる。

| 問い                                        | 仮説（いまのモデル）                            | 別の仮説                                      |
| ------------------------------------------- | ----------------------------------------------- | --------------------------------------------- |
| OL の攻撃力増加の位置                       | スキルの攻撃力▲と同じ足し算の群: (1 + OL + B)   | 別枠: (1 + OL)(1 + B)。乗らない               |
| OL の有利コードダメージ増加                 | 有利の敵にだけ 1.1 に足す                       | 乗らない                                      |
| OL のクリティカルダメージ増加               | 1.5 に足す                                      | 乗らない                                      |
| コレクションの通常攻撃ダメージ倍率          | 1 + 9.46% を掛ける                              | 武器倍率 0.0873 に足す（約 2.1 倍）。乗らない |
| OL のチャージダメージ増加（`088`）          | フルチャージ倍率に足す（2.5 + 0.1111）          | 掛ける（2.5 × 1.1111）                        |
| コレクションのチャージダメージ倍率（`089`） | フルチャージ倍率に足す（3.5 + 0.1181 + 0.0947） | 掛ける（(3.5 + 0.1181) × 1.0947）             |
| キューブの命中率▲と「命中率増加状態」       | 数える（200 ヒット目の後に攻撃力▲が乗る）       | 数えない（段差が出ない）                      |

ヘルムは宝物を持つので、コレクションのスキルは乗らない（モデルの扱い）とみて、OL だけを読む録画にした。

## 読み方

- `hud.ts --mode jumps` で HUD の総ダメージの増分を全フレーム読んだ。単騎なので、1 フレームの増分は 1 発ぶん。
- 1 ヒットの予測は、攻撃力 = 丸め(キャラ画面 × (1 + 攻撃力▲の合計)) − 防御 100、に武器倍率・フルチャージ倍率・倍率グループ（1 + コア + 会心 + 距離）・属性を掛けた値（使い捨てのスクリプト）。会心の数やヒット数は数えていない。
- ヘルムとモダニアは、通常攻撃と追加ダメージが同じフレームに乗る。ヘルムは、増分の 4 つの値の差（会心の 0.8386 の分）から、通常攻撃と追加ダメージを分けた（`088-01`）。

- **攻撃力**: OL の攻撃力増加は、スキルの攻撃力▲と同じ足し算の群に入る（C-0118）。キャラ画面の攻撃力をそのまま素の攻撃力にしてよい（Stage 12 の (c)）。
- **属性**: 有利コードダメージ（OL）とアンチコード（キューブ）は、有利の敵にだけ 1.1 に足す。スキルの追加ダメージにも乗る（C-0119）。
- **会心**: OL のクリティカルダメージ増加は 1.5 に足す（C-0120）。
- **通常攻撃ダメージ倍率（コレクション）**: 武器倍率の整数（873）に掛けて丸めた 956 で合う（C-0121）。丸めないと 0.044% 小さく、1 ヒットの値が 25 ずれる。
- **チャージダメージ（コレクションと OL）**: 丸め(素のフルチャージ倍率 × (1 + コレクション)) + OL で合う（C-0122）。アリス・ヘルムとも、丸める前の端数がちょうど 0.5（38,314.5・27,367.5）で、どちらも切り上がった。
- **宝物**: ヘルムにもコレクション SR Lv15 の 9.47% が乗っていた（C-0123）。スペック固定 ON のヘルム（V-0033）では乗っていない（C-0125）。
- **命中率増加状態**: モダニアの S2 は、キューブの命中率▲だけで 200 ヒット目に攻撃力▲を得て、201 ヒット目から乗った（C-0124）。

## 分かったこと・分からないこと

- 分かったこと: 上の 8 件（C-0118〜C-0125）。どれも 1 ヒットの値が端数まで合った（厳密一致）。
- いまのモデルとずれるのは 3 点で、どれも未反映:
  1. コレクションの「チャージダメージ倍率▲」を足し算の `chargeDamage` に写し、OL の「チャージダメージ増加」と足してから倍率を掛けていない（アリスで 6.0% 小さい）。
  2. 宝物を持つ枠のコレクションのスキルを読まない（ヘルムで 5.7% 小さい）。
  3. 通常攻撃ダメージ倍率とチャージダメージ倍率の丸め（0.3% 以下）。
- 分からないこと:
  - 丸めが四捨五入か切り上げか（端数 0.5 の 2 件と 0.59 の 1 件では決まらない）。
  - スキルの「チャージダメージ▲」（C-0020。足し算）も、OL と同じく倍率を掛けた後に足すか。
  - スキルの「チャージダメージ倍率▲」（C-0099）とコレクションの倍率が両方付いたときの順（足してから掛けるか、掛け合わせるか）。スペック固定 OFF のヘルムのバーストの後の 10 発で見分けられる。
  - SG のコレクションの通常攻撃ダメージ倍率（SMG と同じ説明文。ペレットの武器倍率で丸めるか）。
  - AR のコレクションのコアダメージ▲（design-stage12.md 3.5 節の 5）と、キューブのリロード速度（同 6）。

## 次に撮るもの

- スペック固定 OFF のヘルムで、オートバースト ON（バーストの後の 10 発）: スキルの倍率▲とコレクションの倍率▲が両方付いたときの順。
- 丸めを決める録画: 素の倍率 × (1 + 値) の端数が 0.5 より小さくなる組（例: コレクション SR Lv5 の 6.31% を付けた SR か RL）。

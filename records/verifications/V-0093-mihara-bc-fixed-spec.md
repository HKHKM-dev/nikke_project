## 条件

**何を確かめるか**

- C-0166（仮説・反復実測）は、スペック固定 ON の好感度の上限を、所属ではなく CDN の roledata の `corporation_sub_type` が `OVERSPEC` かで決める（`fixedSpec.ts` の `fixedSpecAffectionRank`）。根拠はラピ：レッドフード（16）の 1 ヒット（録画 116・117。V-0081・V-0083）だけで、ピルグリムでない残りの OVERSPEC 3 体（ミハラ：ボンディングチェーン（162）・ネオン：ビジョンアイ（18）・アニス：スター（17））はデータの印からの推し量りのまま（plan/backlog.md 2-11）。
- 2026-10-02 に所持を確かめた: 3 体とも所持あり。この記録はミハラ：ボンディングチェーン、ネオン：ビジョンアイは `V-0094`。
- ミハラ：ボンディングチェーンは MISSILIS・Attacker・MG。通常攻撃の武器倍率と `computeFixedSpecAttack` の値（rank40・rank30 とも）はラピ：レッドフードと同じなので、1 ヒットの値もラピ：レッドフードと同じになる見込み（予測ファイル）。
- 単騎で未確定の要素は好感度の 1 つだけ。S1 は戦闘開始時にキャプチャーチェーンをチャージする（攻撃力に効かない）。特定のタイミングで出るスキルダメージ（最終攻撃力の割合）とチェーンバインドの持続ダメージは通常攻撃の 1 ヒットとは別の数値で、増分に混ざるフレームは読まない。S2 のトリガー（フルバースト中・戦闘不能・敵の撃破・バースト 3 段階突入）はバーストを使わなければ起きない。スキル定義は無い（モデルは通常攻撃だけ）。
- アニス：スター（17）は単騎だと S1 の「私だけの星」（基本バースト段階 1 の味方がいないとき、自分に攻撃力▲・持続）が乗り、未確定の要素が 2 つになるので、この 2 本には入れない（「次に撮るもの」）。

**編成**（未確定の要素は好感度の 1 つだけ）

- ミハラ：ボンディングチェーン（162）単騎・操作。射撃場の炎の BigArms（3 分モードでなくてよい）。スペック固定 ON。自動バースト OFF（バーストは使わない）。

1. `tools/captures/intake.ts` で取り込む（`--rid 162 --controlled 1 --target BigArms --element Fire --fixed-spec on`。plan/skills-guide.md 1.7 節）。台帳の `records/recordings/<録画 id>.json` を埋めて `npm run records:table`。
2. `npm run records:read -- <録画 id> --recipe hud-jumps --source V-0093 --write` で、撃ち始めから最初のリロードまでの増分を読む。116・117 と同じく、胴体・会心・コア・コア + 会心の 4 つの値に 1 未満の差で一致する増分を拾う（MG は撃ち始めの数発が胴体で、そこからコアに移る。`117-06`）。

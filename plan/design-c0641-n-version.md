# C-0641 の撮り方（命中率▲の N が宝物版の値か）

- 出どころ: [backlog.md](backlog.md) 2-33・1.2 節。C-0641（仮説。フルバースト開始時に配られる持続の命中率▲の N は、ドレイクの宝物版 S1 の値 20.09% で効く）は、V-0492 の撮影（A 631〜636・B 637〜642）で、宝物版の N（H1。K = 1.566）と基礎版の N（H2。K = 1.287）を分けられなかった（`0631-02`。σ 0.167）。
- 目的: 同じ編成のまま、H1 と H2 を分けられる読み方と本数を、撮る前に固定する。▲で上がること（C-0640。確定）は確かめ直さない。
- 検証記録: V-0542（条件・読み方・撮影の依頼）。この文書には、選んだわけと見込みと論点を置く。
- 状態: 2026-10-28 に起案し、2026-10-29 にいまの手順（検証記録に読み方と撮影の依頼を置く。[verification-guide.md](verification-guide.md) 3・4 節）に合わせて組み直した。オーナーの承認待ち。

## 1. V-0492 で分けられなかったわけ

631〜642 の着地点ごとの数（`0631-01`〜`0642-01`）を読み直した（計算はスクラッチのスクリプトで、`fb-window-k-lib.ts` の `ratio`・`estimate` をそのまま使った）。

1. **σ を大きくしたのは中遠 A**: B の窓の中の中遠 A は 642 の 22 ヒット（コア 0）だけで、A の窓の中の中遠 A の 316 ヒットの期待値がほぼ 0 になり、642 を抜くかどうかで K が動いた（V-0492「結果」）。中遠 A を除くと jackknife は 0.167 から 0.079 に下がり、2 項分布（0.078）と同じ大きさになる。
2. **対照が 0 に近い着地点は K を上に偏らせる**: 対照の率が 0 の着地点では、A のコアは分子に入り、期待値は分母に入らない。中遠 A を含めた K（1.577）は、除いた K（V-0492「結果」の参考の 1.483）より高い。揺れだけでなく、値もずれる。
3. **H1 と H2 を分ける力は中近・近 A・近 B にある**: 1 ヒットあたりの見分ける力は、▲の無いコア命中率 p が大きいほど大きい（H1 と H2 の率の差は 0.279p で、2 項分布の揺れは √p ほどでしか増えない）。鈴原サクラの p は近 B（約 0.26）・近 A（約 0.21）・中近（約 0.10）で大きく、遠（約 0.03）・中遠（約 0.06）では小さい（631〜642 の窓の外）。
4. **中近・近 A・近 B は、どの録画でも窓に入る**: 帯の順は中近・近・遠・中遠・近・遠で、1 回目のフルバーストの窓は中近に、2 回目と 5 回目はたいてい近（A か B）に落ちる（631〜642 の 12 本とも、窓の中の近のヒットが 95 以上）。遠と中遠は、3 回目・4 回目の窓に落ちるかどうかが録画で違う（ジャンプの間隔が録画で縮む。C-0553）。

## 2. 推す案: 同じ編成で、中近・近 A・近 B だけを使い、H1 と H2 を比べて 10 本ずつ撮る

### 2.1 何を変えるか

| 項目             | V-0492                              | この案                                                                          |
| ---------------- | ----------------------------------- | ------------------------------------------------------------------------------- |
| 編成・条件       | 鈴原サクラ・デルタ・サン / ドレイク | 同じ（受け手と対照を替えない。未確定の要素を足さない）                          |
| K に使う着地点   | 6 つ全部                            | **中近・近 A・近 B の 3 つだけ**（撮る前に固定）。遠・中遠は参考に出すだけ      |
| 判定の目安       | 1 から 3σ・H1 と H2 から 2σ         | **H1 と H2 だけを比べる**（▲で上がることは C-0640 で確定。下の 2.3）            |

### 2.2 本数と見込み

撮影を引き直して、撮る前に決めた取り方の σ と判定の目安（2.3）をそのまま当て、当たり方を数えた（1000 回。スクラッチのスクリプト）。

- 引き方: 録画ごとの着地点ごとの窓の中・外のヒットの数は、631〜642 の 12 本から 1 本ずつ引く（窓がどの着地点に落ちるかの揺れが入る）。率は着地点ごとの 631〜642 の窓の外の合計で、A の窓の中だけ K 倍にする。コアは 50 ヒット（マガジンほど）ごとに率を揺らして引く。揺れの大きさは、2 項分布のまま（下の表の左の値）と、分散が 2 項分布の約 1.5 倍（右の値）の 2 通り。V-0492 の「読み直し」の 5 では着地点の中のマガジンの単位で 0.9〜2.4 倍だったが、631〜642 の 12 本の jackknife は 2 項分布とほぼ同じだった（1 節の 1）ので、その間に置いた。
- 見込みは、2.3 の 4（両方と合えば 2 本ずつ足して 1 回だけ見直す）まで入れた値。

| 本数（A・B ずつ） | σ（中央値） | H1 が正しいとき H1 に当たる | H2 が正しいとき H2 に当たる | 逆の仮説に当たる |
| ----------------- | ----------- | --------------------------- | --------------------------- | ---------------- |
| 6                 | 0.10〜0.12  | 約 52〜71%（足す前）        | 約 62〜74%（足す前）        | 約 1〜3%         |
| 8                 | 0.08〜0.10  | 約 83〜91%                  | 約 84〜89%                  | 約 2〜4%         |
| 10                | 0.08〜0.09  | 約 86〜92%                  | 約 89〜93%                  | 約 1〜3%         |
| 12                | 0.07〜0.08  | 約 91〜94%                  | 約 89〜93%                  | 約 0〜2%         |

- 残りは、K_out が 1 と合わない（約 3〜5%。2σ の目安なので、条件が正しくても 20 回に 1 回ほど外れる）か、どちらの仮説からも 2σ 以上離れる（約 2〜3%）。
- 10 本ずつを推す: 8 本ずつより揺れが大きいときの見込みが上がり、12 本ずつとの差は小さい。
- 6 本ずつ（V-0492 と同じ本数）では足りない。V-0492 の見込み（σ 約 0.070〜0.080。H1 に当たる見込み 91〜95%）は、本数で割り戻しただけで、窓がどの着地点に落ちるかの揺れと、jackknife の σ が揺れることを見込んでいなかった。
- 前の起案（2026-10-28）の見込み（10 本ずつで約 95%）は、σ の中央値を固定して正規分布で数えた値で、σ の揺れを入れたこの表より高く出ていた。

### 2.3 判定の目安（撮る前に固定する）

1. K_out（窓の外。同じ 3 つの着地点）が 1 と 2σ の中で合うことを先に見る。合わなければ K から結論を作らない。
2. K が H1（1.566）と 2σ の中で合い、H2（1.287）から 2σ 以上離れていれば **H1**（C-0641 の再現）。
3. K が H2 と 2σ の中で合い、H1 から 2σ 以上離れていれば **H2**（C-0641 を棄却し、N は基礎版の値とする結論を作る）。
4. K が H1 と H2 の両方と 2σ の中で合えば、A・B を 2 本ずつだけ足し、全部を合わせて同じ目安で 1 回だけ見直す。それでも決まらなければ、この撮り方では足さない。
5. K が H1 と H2 の両方から 2σ 以上離れていれば、どちらとも合わない。結論は作らず、オーナーと次を決める（式の形 p ÷ (1 − N)² は C-0640 で確定しているので、N がどちらの値でもないことになる）。

- V-0492 の目安の「1 から 3σ 以上」は外す。▲で上がることは C-0640 で確定していて、この撮影の問いは N の版だけ。残すと、H2 が正しいときに K が 1 から 3σ 離れず、判定なしになりやすい（10 本ずつで H2 に当たる見込みが約 63〜83% に下がる）。
- 係数は動かさない（どの結果でも）。H2 に当たったら、ドレイクの宝物版 S1 の effects[3] を基礎版の値にする（モデルの変更）。

### 2.4 撮る順

- B（サン）を先に、A（ドレイク）を後に、まとめて撮る（V-0492 と同じ順。順で偏る根拠は無く、K_out で確かめてから K を見る）。
- 1 日で撮り切れないときは、日ごとに A と B を同じ本数ずつ撮る（例: 1 日目に B 5 本・A 5 本、2 日目に B 5 本・A 5 本）。日による違いが A と B に同じく入れば、K で割り消える。

### 2.5 撮る前の準備

- `tools/captures/fb-window-k.ts` に、K・K_out に使う着地点を選ぶオプション（`--landings 中近,近A,近B`）を足す。省くと 6 つ全部で、V-0492 の値（`0631-02` など）がそのまま出ることをテストで確かめる。承認の後に足し、撮る前に 631〜642 で 3 つの着地点の値（2.6 節）が出ることを確かめる。
- 読み方は V-0542「読み方」に書いて、撮る前に固定する。

### 2.6 再現に数える録画

- 354〜361・434〜439・631〜642 の 26 本は、どれも数えない（C-0641 の `decidedOn` に「読み方を合わせた」）。3 つの着地点に絞ることは、631〜642 を読んだ後に決めた（1 節）。
- H1 は合わせ込みの定数を持たない（N は CDN のデータの宝物版 S1 の値、式は C-0640）ので、結論に `parameterFree` を書ける。ただ、`parameterFree` で再現に数えられるのは `仮説の出どころ` の録画だけで、`読み方を合わせた` の録画は数えない（[design-grade-runs.md](design-grade-runs.md) 3 節）。26 本はどれも後者なので、再現に数えるのは新しく撮る録画だけのまま。
- 参考（判定に使わない）: 3 つの着地点だけの K は、631〜642 で 1.491 ± 0.083（H1 から −0.9σ、H2 から +2.5σ）、K_out は 0.987 ± 0.044。

## 3. 選ばなかった撮り方

| 案                                                                              | 選ばないわけ                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 6 つの着地点のまま、本数だけ増やす                                              | 中遠 A は対照のヒットが 0 に近い録画があり、K が揺れるだけでなく上に偏る（1 節の 1・2）。本数を増やしても、窓に中遠 A が入るかどうかで K が飛ぶ                                                                                                                                           |
| 中遠の 3 か所を 1 つにまとめる（SMG のコア命中率は中遠で共通。C-0543）          | 見込みは推す案とほぼ同じ（引き直しで σ の差は 0.005 ほど）。ただ、中遠の窓は録画によって入らず、対照の少なさは残る。見分ける力の小さい遠・中遠を入れる得が無い                                                                                                                            |
| 対照のヒットが一定より少ない着地点を除く（例: 両方の窓に 150 ヒット以上）       | 見込みは推す案とほぼ同じ。除く着地点が撮った後に決まり、K の中身（どの着地点の平均か）が録画で変わる                                                                                                                                                                                      |

| ▲の無いコア命中率が高い受け手にする（AR の AI。射撃場の近で約 0.42）            | 1 ヒットの見分ける力は大きい（H1 で約 0.66、H2 で約 0.55）。ただ、配られる▲が受け手のコア命中率を上げる式は SMG の受け手でしか確かめていない（C-0640）。受け手を替えると、式が AR にも当てはまるかが未確定の要素として混ざり、K が H2 に寄ったときに N の版と式の当てはまりを分けられない |

## 4. オーナーに決めてほしいこと

1. 推す案（同じ編成・中近・近 A・近 B だけ・H1 と H2 だけを比べる目安）でよいか。
2. 本数は 10 本ずつ（推す）か、8 本ずつか、12 本ずつか（2.2 節）。
3. 1 日で撮り切れないときは、日ごとに A と B を同じ本数ずつ撮る（2.4 節）でよいか。

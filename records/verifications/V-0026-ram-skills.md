# V-0026: ラムのスキルの定義は既存の録画と合うか

- 問い: ラム（822）の S1 の「フルバースト終了時、同じ部隊の味方がいれば自分のバーストスキルクールタイム 20.16 秒▼」を条件なしで効かせると読んで、モデルは既存の録画と合うか
- 話題: スキル・キャラ固有
- 日付: 2026-09-28
- Stage: キャラの定義（plan/skills-guide.md 2 節。撮影が先に済んでいるとき）
- 録画: `038`、`040`、`047`
- 結論: `C-0080`
- 状態: 完了

## 条件

- 説明文（`data/characters/822.json`）を 1 行ずつ分けた（skills-guide.md 1.2 節）。
  - S1「通常攻撃 5 回命中で対象に攻撃力▼」: 敵の攻撃力を下げるだけで、ダメージに関係しない。
  - S1「フルバースト終了時、同じ部隊の味方がいれば自分のバーストスキルクールタイム 20.16 秒▼」: 語彙にある（`cooldownReduction`・`fullBurstEnd`・`self`）。ただし「同じ部隊の味方がいれば」の条件は語彙に無い。
  - S2「自分に最大HPのみ▲」「残りの HP が最も低い味方 2 機に防御力▲」: ダメージに関係しない。
  - バースト「味方全体にバリア」: ダメージに関係しない。
- ダメージに効きうるのは S1 の CT 短縮だけ。ラムの CT は 40 秒なので、効けばバーストの周期が変わる。
- ラムが写る既存の録画: 単騎の `075`・`076`（フルバーストなし）、I として `037`・`038`・`040`・`047`。どれもラムと同じ部隊の味方はいない。オーナーの所持キャラに、ラムと同じ部隊の味方はいない（撮れない）。
- `047` はオートバースト ON（録画の台帳、V-0001）。`038`・`040` は台帳にオートバーストの有無が無い。
- オートバーストは、II が明けていなくても I を撃ち、チェーンを約 600f で切らす（録画 22・39。C-0009）。

## 予測（撮る前に書く）

録画は撮ってあり、`047-01`（フルバーストの回数）・`038-03`・`040-02`（フルバーストをまたいだ回ごとの位相のずれ）は前から観測値にある。予測は、仮の定義を入れたモデルと、効果なしのモデルを、それぞれの録画の条件（敵 `range-bigarms-fire`・出来事 `range-3min-jump`・スペック固定・台帳の操作枠）で回して出した（2026-09-28）。仮の定義を入れて `npm test` を回したところで `047-01` が許容外になって気づいたので、`047-01` の値を見る前の予測ではない。

| 仮説                                                      | 047（ラム + デルタ + 紅蓮BS）           | 038（ラム + デルタ + イサベル） | 040（アドミ + ユニ + ラム + クイーン（真）） |
| --------------------------------------------------------- | --------------------------------------- | ------------------------------- | -------------------------------------------- |
| H1: 条件なしで、フルバースト終了のたびに CT 20.16 秒▼     | 3 回（約 60 秒おき。チェーン切れ 3 回） | 3 回（チェーン切れ 3 回）       | 3 回（チェーン切れ 3 回）                    |
| H2: 同じ部隊の味方がいるときだけ（この 3 本では起きない） | 5 回（約 40 秒おき。チェーン切れ 0 回） | 5 回                            | 5 回                                         |

- H1 では、フルバーストの終わりにラムの CT が約 9 秒まで縮み、デルタ（II・CT 40 秒）より約 20 秒早く明ける。オートバーストがすぐ I を撃ち、II を待つチェーンが切れて、ラムの CT が 40 秒から数え直しになる。
- 見分けられる。フルバーストの回数が 3 回か 5 回か。ただし `038`・`040` は、手動でバーストを撃っていれば H1 でも 5 回になりうる（I を II が明けるまで撃たなければよい）ので、見分けに使えるのはオートバースト ON の `047` だけ。
- 参考: ラムが唯一の I で III が 2 体の編成（ラム + ユニ + クイーン（真）+ 紅蓮BS）では、H1 で 180 秒に 9 回（20 秒周期）、H2 で 5 回。

## 読み方

- 新しく読んだ値は無い。既存の観測値（`047-01`・`038-03`・`040-02`）と、両方の仮説のモデルを `npm run records:check` と sim の CLI で比べた。

## 結果

- `047-01` はフルバースト 5 回で、H2 と一致し、H1（3 回）と合わない。
- `038-03`・`040-02` も、フルバーストを 4 回以上またいでおり、H1 の 3 回と合わない（手動の可能性があるので補強にとどめる）。
- H1 の仮の定義を入れると、`047-01`（確定の C-0022 の根拠）が許容外になり、録画 38 の回帰テスト（`stage8Team.test.ts`、4 回目のバースト）も崩れた。

## 分かったこと・分からないこと

- **C-0080 は確定（厳密一致）**: 同じ部隊の味方がいない編成では、S1 の CT 短縮は起きない。説明文の条件（英語版は "an ally from the same squad"）どおりで、「同じ部隊」はゲーム内の部隊と読む。
- 定義は、全スロットを `unsupported` にして notes だけを書いた（`data/skills/822.json`）。CT 短縮は、部隊のデータを持たないので未対応にした。ダメージに効く効果が無い定義を置けるように、`definitions.test.ts` の「効果が 1 つ以上ある」の検査を、全スロットが `unsupported` の定義では外した。
- **分からないこと**: 同じ部隊の味方がいるときに、CT がどう縮むか（撮れない）。部隊の情報は CDN のデータから取り込んでおらず、どのキャラがラムと同じ部隊かもリポジトリに無い。
- **分からないこと**: `047-03` の戦闘履歴のラムの与ダメージは、効果なしのモデルより約 6% 大きい（デルタは約 0.4%）。ラムのスキルにダメージに効く効果は無いので、AI のコア命中率など射撃場の条件の差とみられるが、確かめていない。

## 次に撮るもの

- なし。同じ部隊の味方（所持していない）がそろったときに、ラムの CT の表示を、フルバーストの終わりの前後で読む。

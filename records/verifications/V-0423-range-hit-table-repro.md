- 話題: 命中率・距離
- 日付: 2026-10-11
- 状態: 調査中

## 条件

- C-0508（仮説）の再現。根拠は凍結の verification.md Stage 18-A（旧の録画 L-AD・L-AI・L-AN の読み直しと、録画 054・056・057〜062）で、L-AD・L-AI・L-AN は値を合わせた録画。表の値は `data/enemies.json` の `range-bigarms`。
- 対象: AR と MG はコア命中率と弾丸命中率、SMG はコア命中率だけ（SMG の弾丸命中率は C-0287・C-0465・C-0467・C-0507・C-0476 に分けてある）。
- 編成は武器種ごとに命中率▲の出どころが無い、機構の確定したキャラの単騎: AR は I-DOLL・サン、SMG は I-DOLL・オーシャン（効果は回復だけ）、MG はクラウン。キューブは付けない。
- MG のコア命中率は撃ち始めの外れ（C-0035）を含めた平均なので、表と同じ数え方にする。
- クラウン単騎は更新の前の 056 と同じ形なので、合わなかったときの更新の切り分けにも使う（056 は読み直さない。既にある観測値と比べるだけ）。
- backlog 2-33（既存の確定の点検で仮説にした結論）。2026-10-10〜11 の点検（plan/design-investigation-review.md 1.4.3 節）で、反復実測の再現が仮説・値・読み方を決めるのに使った録画（結論の `decidedOn`）の中にしか無かったので仮説にした。確定に戻すには、決めるのに使っていない録画の再現を足す。過去の録画の読み直しはしない（2026-10-11 のオーナーの決定）ので、新しく撮る。
- 新しい録画は 2026-10-08 のゲームの更新（plan/captures/index.md「ゲームの更新の境目」。境目は録画 344 / 345）の後になる。根拠の録画は更新の前なので、合わなかったときは結論の誤りか更新の影響かを、この録画だけでは分けられない（design-investigation-review.md 1.2 節）。そのときは係数で合わせず、更新の後と書いて残差として残す。
- 撮影は backlog 2-33 の 12 件でまとめて計画した（束ねた撮影の記号 A〜I は V-0416「次に撮るもの」の表）。
- 共通の条件: 的は灼熱タブの BigArms・3 分モード（range-3min）・スペック固定 ON・ゲージ表示は右。撮影プロトコル（plan/captures/index.md）のとおり、出撃画面と戦闘履歴（キャラ名）を写す。

## 予測

なし。見分け: AR 1 本 180 秒で約 1,630 ヒット、近の σ は約 0.02・遠は約 0.013（見積もり）。帯ごとの揺れ（SMG の近。Stage 18-A の 4）があるので、武器種ごとに 2 本以上。

## 読み方

1. SMG のコア命中率は `npm run records:read -- <録画> --recipe smg-cores --source V-0423 --write`。AR・MG は hud-jumps の増分を格子で分ける使い捨てのスクリプト（V-0421 と共用）。
2. 弾丸命中率は、AR が完全なマガジンの当たり数 ÷ 装弾数、MG が 1 クリップの当たり数（Stage 18-A と同じ数え方）。
3. 近（2 か所。C-0155）・中遠（3 か所。C-0044）・遠（2 か所。C-0477）の着地点を録画ごとに読み、帯を着地点で分けて記録する（`near-landing` レシピほか）。
4. 判定の目安（撮る前に決める）: 帯ごとに、全本数を合わせた率が表の値と 2σ の中で合えば再現。σ は 2 項分布と録画ごとのばらつきの大きいほう。

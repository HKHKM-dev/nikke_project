## 条件

**何を確かめるか**

- 射撃場の的（`data/enemies.json` の `range-bigarms`）の RL のコア命中率 1 は、紅蓮：ブラックシャドウ（225）で測った値（C-0028。`055-01`）で、表ではキャラによらない値として RL 全体に使っている。紅蓮BS 単騎の 180 秒でコアを外した発は数発（`046-06`・`055-06`）で、着地直後の 1 発（V-0091 で調べている）の分と見ている。
- I-DOLL・フラワー（304）単騎の `077` では、通常攻撃のうちコアを外した発が多く、遠の区間に集まる（`077-15`。V-0090 の副次）。
- CDN の `shot_detail` では RL だけが飛ぶ弾で、ほかの武器は即着弾（`Instant`）。キャラデータの `shot.fireType` と `shot.projectile`（`speed`・`homing`・`radius`・`explosionRange`。CDN の生値で、単位は分からない）で弾の種類を引ける（2026-10-02 に足した。計算にはまだ使わない）。RL の弾の種類は、直進弾（`ProjectileDirect`。弾速 400・300・100）、誘導弾（`HomingProjectile`。弾速 100。RL の大半）、曲射（`ProjectileCurve`。弾速 1500。damage.ts は未対応）に分かれ、爆発の範囲も 50・500・750 に分かれる。紅蓮BS は直進弾・弾速 400・爆発の範囲 50 で、フラワーは誘導弾・弾速 100・爆発の範囲 500。紅蓮BS とフラワーは、弾速・誘導・爆発の範囲の 3 つが同時に違う。

**仮説の出どころ**

- H1a（飛ぶ時間。オーナーの知見）: 弾が飛ぶ間に、ゆっくり横に動く的のコアからずれる。遠いほど、弾速が遅いほど飛ぶ時間が長い。
- H1b（誘導の向かう先）: 誘導弾は、コアではなく的の中心（胴体）へ向かう。
- H1c（爆発の範囲）: コアに当たったかの判定が爆発の範囲で変わる。紅蓮BS だけ爆発の範囲が 50 と小さいので、この見込みも外せない。

**最小構成**: 単騎（観測したい事象は通常攻撃のコアの当たり外れだけ）。AUTO 射撃・3 分モード（180 秒）・スペック固定 ON・自動バースト OFF・BigArms（灼熱タブ）。紅蓮BS の `046`・`055` と同じ組み方。どのキャラもスキルは弾の行き先を変えない（持続ダメージ・追加ダメージは HUD の増分の分け方に効くだけ。各記録の「条件」）。

**記録の分け方**: 予測ファイルは 1 本に 1 つの編成なので、新しく撮るキャラごとに記録を分けた（`V-0098`〜`V-0101`）。それぞれの記録は、そのキャラの区間ごとの「撃った発・コアを外した発」を観測値にするまで。弾の種類どうしの比べ・仮説の判定・結論はこの記録で行う。紅蓮BS とフラワーの読み直しもこの記録で行う。

**V-0091 との分担**: V-0091（着地直後の 1 発はコアを外すか）は同じ紅蓮BS・フラワーの録画で胴体の発を数える。この記録では、胴体の発のうち着地の後の 1 発目のものを分けて数え、区間ごとの割合を「着地の後の 1 発目を含む・除く」の両方で出す。読みは片方が先に観測値にしたら、もう片方は ID で指す。

## 予測（撮る前に書く）

モデルはコア命中率を弾の種類で分けない（表の RL は 1）ので、H1a〜H1c はモデルの入力で表せない（予測ファイルの範囲外。下に手で書く）。予測ファイル `records/predictions/V-0097.json` には、いまのモデル（H0）のフラワーの 1 ヒット（胴体・コア。読み直しで増分を分ける鍵。後から書いた形の確かめ）と、`077` の組み方の与ダメージ（コアを外さないときの値。実測 `077-06` との差が、コアの外れでどれだけ説明できるかの目安）を固定した。新しく撮るキャラの 1 ヒットの値と射撃の数は、それぞれの記録の予測ファイル。

各仮説で見えるはずのもの（割合は、区間ごとの「コアを外した発 ÷ 撃った発（部分チャージの発を除く）」。着地の後の 1 発目の外れ（V-0091）は除いて比べる。区間は C-0031 の並びで、遠は 3 区間目）:

| H1a: 飛ぶ時間（弾速と距離で決まる。誘導・爆発によらない）            | ほぼ 0                 | 紅蓮BS と同じ（ほぼ 0）   | 紅蓮BS とフラワーの間。遠で出る         | フラワーと同じ程度。遠に集まる | `077-15` のとおり遠に集まる | ラプラスUH がフラワーと同じ程度か         |

- 見分けられるか: 1 キャラ 180 秒で撃つ発は 100 前後（予測ファイルの `shots`。区間ごとに 20 前後、遠は 3 区間目の 20 前後）。フラワーの遠の外れの数（`077-15` の注記）と、紅蓮BS の 180 秒全体の外れの数（`046-06`・`055-06`）は大きく違うので、遠の区間の数で「フラワーと同じ程度」と「ほぼ 0」は 1 本ずつで分かれる。「間」（H1a の A2）は 1 本では幅が広いので、向き（遠に出るか）だけを見る。
- 組み合わせ（H1a と H1b が両方効く）なら、ラプラスUH は A2 より多く、フラワーより少ない。
- シンデレラ（曲射・弾速 1500・爆発の範囲 50）は、曲射の弾の飛ぶ時間が分からないので予測しない（探索。`V-0101`）。H1a で弾速だけが効くならほぼ 0 になる。
- 外れたときの影響: H1a・H1b・H1c のどれかなら、表の RL のコア命中率 1 は紅蓮BS（とそれに近い弾の種類）にだけ当てはまる。表の持ち方（武器種ごとか、弾の種類か弾速ごとの距離帯の値か）をオーナーが決める（roadmap「今後の課題」）。誘導弾は RL の大半なので、RL の通常攻撃の与ダメージは遠の区間でモデルより下がる。大きさの目安はフラワーの `total-077`（予測ファイル）と `077-06` の差。モデルの変更は根拠の結論を作ってから行い、係数で合わせない。

## 読み方

1. 紅蓮BS の 4 本（`046`・`055`・`070`・`071`）: V-0090「読み方」と同じく、`npm run records:read -- <録画> --recipe hud-jumps` の増分の列を、1 発の値（コア・胴体 × 会心、部分チャージ）と S1 の段の値の和に分け、胴体の発（コアを外した発）のフレームを取る。区間の切れ目は V-0090 の観測値の注記（`046-22`・`055-13`・`070-04`・`071-06`）の窓を使い、区間ごとの撃った発（母数）もその観測値を使う。部分チャージの発は母数から外す（`046-06`・`055-06` の内訳）。
2. フラワーの `077`: `077-15` の注記の区間ごとの胴体の発の数を、区間ごとの配列の観測値にする（母数は `077-12` から部分チャージの発を除いた数）。バーストのヒットは数えない（`077-07`）。1 ヒットの値は予測ファイルの `hit-body-304`・`hit-core-304`。
3. どの録画でも、胴体の発が着地の後の 1 発目（窓の終わりの発。V-0090 の注記の窓の終わりのフレーム）かを付ける。区間ごとに「コアを外した発（着地の後の 1 発目を含む）」と「そのうち着地の後の 1 発目」の 2 つの配列を観測値（`use: "record"`、`source: V-0097`）にする。V-0091 が先に同じものを観測値にしていれば、その ID を指す。
4. 新しく撮った 4 キャラは、それぞれの記録（`V-0098`〜`V-0101`）で同じ形の観測値を作る（読み方はこの節の 1 と 3。1 ヒットの値はそれぞれの予測ファイル）。
5. 弾の種類 × 区間の表（割合と発の数）をこの記録の「結果」に並べ、「予測」の表のどの行に合うかを見る。紅蓮BS は 4 本の合計と 1 本ごとの両方。
6. 結論: 合う仮説を `npm run records:new -- claim --from V-0097` で起こす。新しく撮るキャラは 1 本ずつなので、判定がつくのは大きな違い（「フラワーと同じ程度」か「ほぼ 0」か）だけで、等級は機械の候補に従う。見分けがつかないときは、見分けの要のキャラ（ラプラスUH かレイヴン）をもう 1 本撮る。C-0028 と表の RL の値は、結論の後にオーナーが表の持ち方を決めてから変える（この記録では変えない）。

## 分かったこと・分からないこと

（起票時）

- 分かっていること: 「条件」のとおり。紅蓮BS（直進弾・弾速 400・爆発の範囲 50）はコアをほとんど外さず、フラワー（誘導弾・弾速 100・爆発の範囲 500）は遠の区間で多く外す。
- 分からないこと: どの違い（弾速・誘導・爆発の範囲）が効くか。

（2026-10-02。`V-0100` を読んだ）

- ラプラス：アルティメットヒーロー（直進弾・弾速 100・爆発の範囲 500）の変わる前の武器も、近では外さず、遠で多く外す（`121-03`・`121-04`）。フラワー（誘導弾・弾速 100・爆発の範囲 500）と同じ形なので、H1b（誘導弾だけが外す）とは合わない向き。H1a（飛ぶ時間）と H1c（爆発の範囲）は、どちらもラプラスUH とフラワーが同じになるので、この 1 本では分かれない。次の見分けの要はレイヴン（`V-0098`）。結論は残りの読みの後に作る。曲射の弾でどうなるか。外れが区間の中のどの時刻（的の横の動きの向き）に寄るか。

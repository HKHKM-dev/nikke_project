- 問い: 中遠の着地点を録画から読んで 1 か所に固定すると、距離ボーナスの帯は武器種ごとにどう変わり、単騎の与ダメージと録画 48〜50 の予測はどう動くか

- Stage: plan/design-stage18.md 12.1 節の 1・12.9 節の 1（中遠の配分）。V-0065「次の候補」の 3

## 条件

- 撮影はしない。録画 48〜50 の 4 区間目（中遠。V-0065 の「次に撮るもの」の 2 行目。約 106〜140 秒）の足元の y を `tools/captures/aim.ts` で読み、着地点（A・B・C）を決める。読むのは録画のある環境（クラウドでは plan/captures/index.md「クラウド環境での取り寄せ」）。
- 固定の入力はある: `compare.setup.midFarLanding`（観測値・予測ファイル）と `sim-run.ts` の `--mid-far`。録画 48〜50 を回すには実ビルドが要るので、その部分はメインのチェックアウトで回す（V-0065 の CLI に `--mid-far` を足す）。
- **結論は作らない見込み**。着地点の読みは録画ごとの条件（観測値）で、仕組み（C-0044）は確定済み。録画 48〜50 は未確定の要素が複数混ざるので、予測の列を足すだけ（AGENTS.md「事実と記録」）。

**いま分かっていること**

- 中遠の着地点は 3 か所（足元の y で見分ける。C-0044 確定。verification.md「実距離への換算」、plan/captures/guide.md）。A だけが 35 未満で、SMG に距離ボーナスが乗り MG に乗らない。B・C は 35 以上で MG に乗る。表のコア命中率・弾丸命中率は中遠の 3 か所で同じ帯の値（design-stage18.md 12.9 節の 2）なので、**固定で動くのは距離ボーナスだけ**。
- 固定していない録画はモデルが配分（0.3 : 0.3 : 0.4。`data/enemies.json` の `range-bigarms`）で期待値を取る。固定してある単騎は `054-02`（A）・`056-02`（A）・`L-AN-01`（B）。旧 L-AD・L-HC と録画 48〜50 は未読で配分のまま。
- 録画 48〜50 の 5 体の帯（V-0065 の「自動の条件で sim が使った値」）: SMG のリター・SR のアリスは中遠 A で距離ボーナスが乗り、MG のクラウン・モダニアは B・C で乗る。RL の紅蓮BS は距離ボーナスが無い（`bonusRange` なし）。固定すると、A なら SMG・SR が上がり MG が下がる、B・C ならその逆（V-0065 の「AR・SMG・SR と MG で逆向き」）。
- 足元の y の読み方は verification.md「実距離への換算」の「足元の高さ」（的の外接矩形の下端の区間ごとの中央値。ジャンプの前後と爆発のフレームを除く）。多人数の録画ではフルバーストの演出・スキルのエフェクトで的が隠れるフレームが増える（`aim.ts` の `fx` の列で除く）。

## 読み方

1. 録画 48〜50 の 4 区間目を `node tools/captures/aim.ts <動画> --from <f> --to <f> --step 60 --csv out.csv` で読む。区間の範囲は、4 回目のジャンプの着地（`048-01`・`049-05`・`050-03` の 4 回目 + 2 秒）から 5 回目のジャンプの始まり（`049-04`・`050-02`。録画 48 の 5 回目は未読なので代表値 C-0057 の目安で切る）まで。フルバーストの入りの止まり（C-0070）を動画のフレームに直すのは `videoFrameOf`（V-0019）。
2. `tgt_*` の下端の中央値を出す。`fx` が大きいフレーム（的が隠れている）と、ジャンプの前後を除く。
3. 読んだ y と着地点を、録画ごとの観測値（`use: "record"`、`source` は `V-0089`）に書く。
4. メインのチェックアウトで、V-0065 の CLI に `--mid-far <A|B|C>` を足して回し、V-0065 の表に列を足した新しい記録（V-0087 の次）に書く。この記録には、単騎（`056-02`）の A・B・C の試算と、48〜50 の読んだ着地点だけを書く。

- **`aim.ts` の的の検出は使えなかった**（多人数の録画で初めて試した）。照準が取れる枚が少なく、取れた枚も的の下端が散らばる（数は観測値の注記）。操作枠のアリス（SR）のスコープが的を覆い、フルバーストの金色のエフェクトで背景が作れないため。足元の y 561〜584 の高さには、アリスの体力バー・アイコンと頭も重なる。

## 分かったこと・分からないこと

- 録画 48〜50 の中遠の着地点を読んだ: 048 A・049 C・050 A（`048-13`・`049-13`・`050-11`）。`sim-run.ts` の `--mid-far` で録画ごとに固定して回せる。固定して回した値は V-0117（合計への効きは 0.1〜0.4 ポイント）。
- 同じ編成・同じジャンプの時刻の 049 と 050 で着地点が違った（H1）。
- 多人数の録画（操作枠が SR）では `aim.ts` の的の検出は使えない。操作枠のリロードの間に、脚の先を画素で読めば見分けられた（plan/captures/guide.md に 1 行足した）。
- 固定で動くのは距離ボーナスだけで、動くのは SMG（`bonusRange` 15〜35。A だけ乗る）と MG（35〜55。B・C だけ乗る）。AR（25〜45）は 3 か所とも乗り、SG（0〜25）・SR（45〜100）は 3 か所とも乗らず、RL は距離ボーナスが無いので、どれも動かない（`data/characters/` の `bonusRange`。V-0065 の「AR・SMG・SR と MG で逆向き」の AR・SR も誤り）。B と C はモデルでは区別が無いので、読むときは A かどうかだけ分かればよい。
- 結論は作らない。着地点の読みは録画ごとの条件（観測値）で、仕組み（C-0044）は確定済み。録画 48〜50 は未確定の要素が複数混ざるので、記録にとどめる指示（2026-10-03）に沿い、「打ち切り」で閉じた。
- 分からないこと: 画素の読み方の物差しが `aim.ts` とどこまで同じか（単騎の参照 3 本で合わせたが、C の参照はしきい値を揃えられなかった）。中遠の着地点が何で決まるか。

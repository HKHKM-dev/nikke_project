# 設計書: チャージしない武器から替えたチャージ武器の、的のジャンプの始まりの部分チャージの発

- 何のための文書か: 使用武器の変更で、チャージしない基礎の武器からチャージ武器に替えた枠（`chargeInput`）が、敵のジャンプの始まりにチャージの途中だと部分チャージで撃つこと（V-0840）を、モデルに入れる
- 関連: V-0840（課題 2-68 の読み直し）・V-0815（スノーホワイト）・V-0718（ツバイ）、C-1001（ジャンプの始まりの部分チャージ。押下チャージ型は撃たない）・C-0843（部分チャージの発の値）、[design-hide-reload-detect.md](design-hide-reload-detect.md)（D と H の形）、[design-nayuta.md](design-nayuta.md) 2.6 節（`chargeInput` を押下チャージ型にした理由）、[design-snow-white.md](design-snow-white.md) 8.1 節の論点 6
- 起案: 2026-11-21
- 状態: 起案（4 節の論点はオーナーの判断待ち）

## 1. 分かったこと（V-0840）

- 課題 2-68 の「戦闘の終わりの 1 発」（スノーホワイトの 5 回目のバースト。録画 1279・1291）は、戦闘の終わりの発ではなく、敵の 5 回目のジャンプの始まりの発だった。発の後に的が跳び、スノーホワイトは AR に戻って構え直し、約 2 秒後に戦闘が終わった。発の 1〜6f 前に、ココア（SR・入力 UP）もジャンプの始まりの部分チャージの発を撃った。
- ツバイの変更後の武器も、的のジャンプにかかった回（1056 の 6 回目。V-0718 で比べなかった回）に、満ちる前の値で撃ち、その後に的が跳んだ。
- 基礎の武器が入力 UP の SR・RL は、チャージの途中で戦闘が終わっても撃たない（5 本）。モデルも撃たない（戦闘の最後のフレームの後に発を作らない）ので、戦闘の終わりの扱いは変えない。

## 2. いまのモデル

- `skills/resolve.ts` の `chargeInput` は、変更後の武器の入力を押下チャージ型（`DOWN_Charge`）にする。押下チャージ型には 3 つの扱いがある。
  1. 発と発の間はチャージ時間だけ（解放を足さない。C-0222）。ナユタの記憶燃焼の発の間隔で確かめた（V-0666）。
  2. リロードの始まりの待ちが 0（`cadence.ts`）。
  3. 敵のジャンプの始まりに部分チャージで撃たない（`frame/shooter.ts` の `partialChargeProgress` が null。C-1001。根拠はアニス：スターなど基礎の武器が押下チャージ型のキャラ）。
- 3 は、基礎の武器が押下チャージ型のキャラで確かめた形を、変更後の武器にもそのまま当てている。変更後の武器で確かめた根拠は無かった。
- 当たるキャラ: `chargeInput` を使うスノーホワイト（220）・ツバイ（390）・ナユタ（223）・E.H.（113）・ドレイク：グレイトヴィラン（104）。基礎の武器が入力 UP の SR のマクスウェル（102）・ウンファ：タクティカル・アップ（95）は、変更後の武器も入力 UP のままで、いまもジャンプの始まりに部分チャージで撃つ。

## 3. 案

- **案 A（推奨）**: `chargeInput` の変更後の武器は、1・2 はそのままにし、3 だけを入力 UP のチャージ武器と同じにする（C-1001 の形: 窓の始まりの D に満ちたことにして、H（1f）の後に部分チャージで撃つ。値は D の時点の進み。C-0843）。
  - 形: `ShotParams` か `FiringParams` に「ジャンプの始まりに部分チャージで撃つ押下チャージ型」の印を足し（例: `chargeInput` を `inputType` と別に持つ）、`partialChargeProgress` はこの印のある武器で null を返さない。進みは入力 UP と同じ式（次の発までの待ち k から p = (C + H − k) / C）。変更の後の最初の発の待ち（`firstShotDelayFrames`）の間は、満ちた発の時刻から C + H 戻した所から溜めているとみる（いまの `chargeProgressFrames` と同じ見え方）。
  - 理由: 2 キャラ・3 回とも、入力 UP の部分チャージの発と同じく、窓の始まりに撃って、その後に的が跳んだ。押下チャージ型として撃たない根拠は、変更後の武器には無い。1・2 は、ナユタの発の間隔の根拠があり、この読みでは何も見ていないので変えない。
  - 値: ツバイは、着地点の区間が近の外なら、モデルの D の進み（0.493）と読んだ進み（0.496）が合う。スノーホワイトは、読んだ進みが 2 回とも約 14f 分大きい（0.517・0.480 に対しモデル 0.468・0.434）。差の原因は分からない（チャージ 5 秒の溜めの始まりか、満ちてから撃つまでの間か）。差を係数で埋めず、値は C-0843 の式のまま入れ、差は `assumes` と結論に未解明として書く。
- 案 B: 入れずに、課題 2-68 を「変更後の武器の、ジャンプの始まりの部分チャージの発」に書き直して残す。モデルは、スノーホワイト・ツバイがジャンプにかかった回の発を落とす（5 秒のチャージのスノーホワイトは、5 回のバーストのうちジャンプにかかる回が出やすい）。

## 4. 決めてほしいこと

1. **案 A で入れるか**（推奨: 案 A）。入れたら、課題 2-68 は閉じる。値の約 14f の差は、新しい課題に起こさず、結論と `assumes` に未解明として書く（撮り足しで見分ける道が今は無いため）。
2. **ナユタ・E.H.・ドレイク：グレイトヴィランにも同じ扱いを当てるか**（推奨: 当てる）。3 体の変更後の武器がジャンプの始まりに撃つかは読んでいない。理由: どれも同じ `chargeInput` の武器で、分ける根拠が無い。ドレイク：グレイトヴィランは、別のセッションがスキル定義を進めているので、マージの順で残差の変わりを知らせる。
   - 代わりの案: スノーホワイトとツバイだけに当て、ほかの 3 体は、ジャンプにかかった回を読んでから決める（`chargeInput` とは別の印を、キャラごとに書く）。

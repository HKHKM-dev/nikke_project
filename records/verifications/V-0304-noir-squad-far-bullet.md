## 条件

**なぜ確かめるか**

- `data/skills/271.json` の burst の notes[1]（未対応）: 「同じ部隊の味方がいれば味方全体の命中率▲（30 秒間維持）」。V-0219（サクラのコア命中率の、▲の窓の中と外の比べ）と V-0234（命中率▲の無い対照）では決められず、打ち切った。backlog 6 節は「命中率▲の効きの大きい受け手と、指標の設計が要る」とした。
- 決まらなかった理由は 3 つ:
  1. 指標がコア命中率で、▲の効きが小さかった。C-0170 の式はコア命中率を 1.28 倍にするだけで、SMG のコア命中率は近で 0.26、遠・中遠ではほぼ 0。増えるコアは 1 本あたり約 80 だった。
  2. 窓の中と外の比べに、時刻による偏りがあった。▲がどこにも無い編成でも、帯によって 3σ を超える差が出た（V-0234）。窓の中は「フルバーストの直後から 30 秒」、窓の外は「戦闘開始の直後と、次のフルバーストの直前」で、戦闘の中の違う時刻を見ている。
  3. A（部隊あり）と B（部隊なし）を直に比べた R = K_A ÷ K_B（`246-11`）でも、K の基準に窓の外（ヒットが少ない）を使ったので揺れが大きく、10 本で 1 と H1 の間に落ちた。
- この記録では、受け手と指標を替える:
  - **受け手**: AI のサクラ（SMG）の**遠の弾丸命中率**。的の表の弾丸命中率は 0.76 で、SG を除く武器種 × 距離帯の中で最も低い（AR・MG はどの帯も 0.97 以上、SMG の中遠は 0.92）。命中率▲が弾丸命中率に効く式は C-0192（確定。SMG の遠）。SG は式が決まっていない（C-0157・C-0396）ので受け手にしない。
  - **効きの大きさ**: N = 0.1161（説明文の値 6。Lv10）で、外れの割合は m ^ 1.280 になる。m = 0.24 なら 0.161 で、外れの数が約 3 分の 1 減る。コア命中率の 1.28 倍より、数の差が大きく出る。
  - **指標**: 窓の中と外の比べはやめ、**同じ時刻（遠の帯のうち▲の窓の中）の外れの割合を、A と B で直に比べる**。A と B は、ブランとユニ（どちらも撃たない操作枠）が違うだけで、フルバーストの時刻が揃う（V-0219 で、最初のヒットから 1 回目の III の発動までが A・B とも平均 398f）。窓が両方で同じ時刻に落ちるので、時刻による当たり方の違いは A と B に同じだけ乗り、比べると打ち消し合う。

**説明文**（`data/characters/271.json`）: バースト「同じ部隊の味方がいれば味方全体に 命中率 {値 6}%▲（{値 7} 秒）」（Lv10 で 11.61%・30 秒）。同じバーストの「ショットガンを所持する味方全体に命中率 {値 2}%▲（{値 3} 秒）」（effects[1]。C-0396 は仮説）は SG にだけ付き、サクラ（SMG）には付かない。

## 予測（撮る前に書く）

撮る前に書いた（2026-10-07）。モデルの値は予測ファイル `records/predictions/V-0304.json` の `predicted`（A の遠の弾丸命中率。窓の中は H0 で表の値のまま、H1 で C-0192 の形で上がる。窓の外はどちらも表の値）。

**判定の指標 q**（撮る前に固定する）

- 遠の帯のうち▲の窓の中にある完全なマガジン（読み方の 3）で、撃った数 S と当たったヒットの数 h を数え、外れの割合 m = 1 − h ÷ S を出す。A の 4 本を合わせた m_A と、B の 4 本を合わせた m_B から、**q = m_A ÷ m_B**。
- σ は、(a) m_A・m_B の 2 項分布の σ から出した q の σ（相対の σ の 2 乗和の平方根 × q）と、(b) A の 1 本ずつと B を合わせた値の q のばらつき（参考）の大きいほう（V-0219 と同じ取り方）。

| 仮説                                                                   | q                                                                  |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **H1**: 部隊がいれば▲が付き、C-0192 の形で弾丸命中率に効く（N 0.1161） | m_B ^ 0.2800（m_B が表の 0.24 なら 0.671。予測ファイルの H1 から） |
| **H0**: ▲は付かない（いまの定義）                                      | 1                                                                  |

| H3（手で書く）: ▲は付くが、AI の SMG の弾丸命中率には効かない          | 1（q では H0 と分けない）                                          |

- H1 の q は、指数 1 ÷ (1 − N)² − 1 = 0.2800 を、B で測った m_B に当てて出す（m_B の揺れは σ に入れる）。表の値（0.76）を使わないのは、AI のサクラの弾丸命中率が表とずれうるため。

**判定の目安**（A・B 4 本ずつを合わせた q で見る）

- q が 1 から 3σ 以上離れ、H1 の q と 2σ の中で合えば **H1**（部隊の味方がいるときだけ▲が付き、C-0192 の形で効く）。ブランが未確定なので、結論は仮説にとどめる。
- q が 1 から 3σ 以上離れ、H1 の q からも 2σ 以上離れていれば、**部隊ありでだけ上がるが、大きさは C-0192 の形と合わない**（大きさは決めない）。
- q が 1 と 2σ の中で合い、H1 の q から 3σ 以上離れていれば、**部隊の有無で差は無い**（H0・H2・H3 のどれかは決めない）。
- どれでもなければ結論にしない。
- **下限と上限**: 1 通りに分けられない増分（読み方の 4）を、サクラのヒットの数の下限と上限の両方で数え、どちらでも同じ目安に当たるときだけ結論にする。分かれたら結論にしない。
- **陰性の対照**（遠の窓の外）: 同じ読み方で窓の外の q_out を出す。▲はどちらにも無いので 1 のはず。1 から 2σ を超えて離れたら、A と B の当たり方が▲のほかでも違うと書き、上の判定を保留にする。
- **前提**: A と B の 1 回目の III の発動（最初のヒットから）の平均の差が 60f を超えたら、そのことを書く（判定は変えない。V-0219 と同じ）。
- `records:check` の機械の照合は、予測ファイルの指標（A の遠の弾丸命中率の絶対値）と観測値を比べる。判定は上の目安で人が書く。

**本数の見込み**

- サクラは装弾数 120・毎分 1,440 発（1 発 2.5f）・リロード 1 秒なので、120 発のマガジンは約 300f、リロードを入れて約 6 秒ごと。遠の帯の窓の中（III の発動から遠の帯の終わりまでの約 21 秒と、前の窓の終わりの数秒）で、読み方の 3 の条件を満たすマガジンは 1 本あたり 2〜3 個（約 250 発）の見込み。
- 外れは 1 本あたり B が約 60、A が約 40（H1・m_B = 0.24 のとき）。4 本ずつで q の 2 項分布の σ は約 0.068 で、H1（0.671）と 1 は約 4.8σ 離れる。録画ごとのばらつきが 2 項分布より大きくても、約 4σ の見込み。
- 窓の外のマガジンは 1 本あたり約 1 個なので、q_out の σ は約 0.13 の見込み（陰性の対照には足りる）。

**外れたときの影響**

- H1 なら、ノワールの定義の notes[1] を効果（`squad` つきの持続の `hitRate`）に替え、結論を仮説で作る（ブランが未確定）。コア命中率への効き（C-0170 の形）は、この記録では確かめていない。
- ▲は付くが大きさが合わないときは、効果を入れるかどうかをオーナーに聞く（C-0192 は単騎の AUTO で確かめた式で、AI の受け手には確かめていない）。係数で埋めない。
- 差が無ければ、notes[1] は未対応のまま、根拠に「部隊の有無で、AI のサクラの遠の弾丸命中率に差は無かった（H0・H2・H3 は分けていない）」と書く。H3 を分けるには、命中率▲を確かに配るキャラで AI の SMG の遠を見る陽性の対照が要る（この記録では撮らない）。

## 読み方

1. 取り込み（plan/skills-guide.md 1.7 節）。戦闘履歴のパネルで枠順と、ブラン・ユニの与ダメージが 0 であることを確かめる。台帳の枠に `fires`・`bursts` を書く（ブラン・ユニは撃たない・バーストを使わない）。
2. 戦闘開始・的のジャンプ（`hud-jumps`）・ノワールのバースト使用（III の発動。右のバースト欄の平均色で拾い、目で確かめる。V-0219 の足し撮りと同じ）を読む。帯は増分が 100f 以上途切れた所で区切る。▲の窓は III の発動から 30 秒とし、窓の始まりの後 59f と、1,706〜1,859f は窓の中にも外にも数えない（V-0219 と同じ）。
3. **完全なマガジン**: サクラのヒットが 40f 以上途切れた所をリロードとし、前後をリロードで区切られたマガジンだけを使う。撃った数 S は装弾数で、ノワール S2 の窓（フルバーストの始まり（III の発動）から 611f。C-0395）の中で始まって中で終わるマガジンは 125、窓に重ならないマガジンは 120。次のマガジンは使わない: S2 の窓の始まり（弾丸チャージが入る）か終わり（装弾数が戻る）にかかるもの、的のジャンプにかかるもの、▲の窓の境（数えない範囲を含む）にかかるもの。
4. **サクラのヒットの数**: HUD の増分（`hud.ts --mode jumps`）を、サクラの 1 ヒットの格子（基は `sakura-body-hit` に、コア（+1）・会心（+0.5）・距離ボーナス（+0.3）・フルバースト補正（+0.5）を足した倍率と、サクラ S1 の受けるダメージ▲（×1.1718）。V-0219 と同じ）で読む。2 ヒットの和、ノワールのトリガー（ペレットの和）・デルタの 1 発・バーストの倍率ダメージとの和も、格子の和で分ける。1 通りに分けられない増分は、その中のサクラのヒットを下限（含まれうる最少）と上限（最多）の両方で数える。前のフレームが読めていない増分（gap > 1）も同じく下限・上限で数える。A と B で同じ扱い。
5. 録画ごと・窓の中と外ごとに S と h（下限・上限）を観測値に置き、A・B を合わせた m と q、σ をこの記録に書く。観測値は、予測ファイルの `sakura-far-bullet-in`・`sakura-far-bullet-out` と同じ `metric`・`args`・`setup` の `bulletHitRate`（A の録画）にする。
6. 参考（判定に使わない）: 判定の後で、既存の V-0219 の 10 本（246〜249・267〜272）を同じ読み方で読み直し、q の再現を確かめる。中遠の帯の窓の中の q も参考に書く（着地点が録画ごとに違いうるので判定に入れない）。

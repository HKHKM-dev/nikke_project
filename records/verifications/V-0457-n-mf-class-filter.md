# V-0457: エヌ：ミラクルフェアリーのバーストの攻撃力▲は火力型の味方にだけ付くか（撮影）

- 問い: エヌ：ミラクルフェアリーのバーストの「火力型の味方全体に攻撃力 X%▲（10 秒）」は、火力型の味方にだけ付き（防御型・支援型の味方と自分には付かない）、付いた味方の 1 ヒットを攻撃力の比率で上げるか
- 話題: スキル・キャラ固有
- 日付: 2026-10-18
- Stage: plan/design-skill-stage9.md 2.1 節（2 段目の段 9 の PR 1）
- 状態: 調査中

## 条件

- 撮るもの: 1 枠目 I-DOLL・フラワー（304・防御型・I）、2 枠目エヌ：ミラクルフェアリー（121・支援型・II）、3 枠目ソルジャーE.G.（300・火力型・III・**操作**・AUTO 射撃 ON）。オートバースト ON。射撃場・灼熱のタブ（BigArms。風圧のフラワー・エヌ：ミラクルフェアリー、電撃のソルジャーE.G. に有利なし）・3 分モード・スペック固定 ON。2 本。出撃画面と戦闘履歴（キャラ名）、右のバースト欄（各段の発動の時刻）も映す。
- 仮説は説明文の読み（「火力型の味方全体に」）で、録画からは決めていないので、どの録画も再現に数えられる。エヌ：ミラクルフェアリーのバーストの CT は 60 秒なので、フルバーストは 3 分で 3 回ほど（モデル）。どの回も I はフラワー、II はエヌ：ミラクルフェアリー、III はソルジャーE.G.。
- 最小構成にするための選び方:
  - 比べる量は、攻撃力▲の窓（エヌ：ミラクルフェアリーの II の発動から 10 秒）の中の、ソルジャーE.G.（火力型）の 1 ヒットと、フラワー（防御型）・エヌ：ミラクルフェアリー（支援型）自身の 1 ヒット。
  - フラワーとソルジャーE.G. は、機構が確定したキャラ（plan/skills.md の根拠がすべて確定）。フラワーは味方の与ダメージに効く効果が無い（C-0072・C-0178）。ソルジャーE.G. の S1 の命中時の攻撃力▲（C-0372）は自分にだけ付き、モデルに入っている。
  - エヌ：ミラクルフェアリーのほかの定義: S1 とバーストの回復は、回復を受けた時の効果を持つ味方がいないので値に効かない。S2 は間接（HP）と計算に無関係の notes。通常攻撃の条件（射撃場の表）は、1 ヒットの値を格子で読むので効かない。
  - 回復を受けた時の効果を持つアスカ・クラウンは入れない（回復の確かめは副次。下の「予測」）。
- 説明文の値（スキル Lv10）: バーストの攻撃力▲ 77.22%（10 秒）と、スキル発動者の最終最大HP の 38.61% の回復。S1 は通常攻撃 3 回ごとに、攻撃ダメージの 6.07% の吸収回復（5 秒）。

## 0. 範囲

- 足す語彙は 2 つ:
  - 「現在のHP X%▼」「1 秒間隔」を、状態の間だけ周期で発火させる形（2.1）。

### 0.1 コードで確かめた、いまのモデル（2026-11-11）

- 即時効果 `currentHpDown`（紅蓮編）は、発火のたびに自分の HP の割合に 1 − X を掛ける（C-1044）。`skills/holders.ts` の `lowerCurrentHp` が発火を記録し、`selfHpRatioAt` が次のフレームから読む。きっかけは即時効果の共通のもの（回数・出来事）だけで、時間の周期は受けない（`parse/instant.ts` の `parseTrigger` は heal にだけ周期を許す）。
- 時間の周期 `{ everySeconds }` の `since: { applied: 状態 }`（段 19）は、その状態が自分に付いた最後のフレームから k × everySeconds 秒に、状態が付いている間だけ発火する。いまは `counterChange` にだけ書ける（`parse/state.ts`。発火は `holders.ts` の `sinceFires`）。
- HP の割合を読むのは、きっかけ `{ selfHpAtMostRef }`（下がったフレームに発火）と、その維持 `durationUntil: "selfHpAbove"`（閾値を**上回る**まで）、timed の条件 `selfHp.atMost`。「閾値**以下**になったら終わる」維持は無い。
- 状態の付与の維持の終わりを時間の途中で決める形は、`durationUntil: { counterEmpty }`（カウンタが 0 に届いたフレームの次で件を閉じる。`holders.ts` の `closeTrack`）がある。状態の中身にはチャージ速度（1 パス目で窓を追う stat）も書ける（103・840 の定義）。
- A2 の録画（0123・0864・0865・0940〜0945）はどれも単騎で、バースト III を使わない。B モードの語彙を足しても、いまある録画のモデルの値は変わらない見込み（4 節）。

## 2. 語彙

### 2.1 周期の現在の HP▼（論点 1・2）

- `currentHpDown` のきっかけに、時間の周期の `since` の形 `{ "everySeconds": N, "since": { "applied": 状態 } }` を書けるようにする。周期の `since` の意味は段 19 のまま（状態の付いた最後のフレームから k × N 秒。状態が付いている間だけ。外れたら止まり、次に付いた時は数え直す）。
  - 見る状態は、同じ定義の、自分に付ける付与のあるもの（段 19 の `validateOwnStateTriggers` と同じ検査）。
  - 発火は 1 パス目の即時効果の流れ（`frame/firstPass.ts` の `instantTracker`）で、`lists.stateStartedAt`・`stateHeldAt` を読んで決める（`counterChange` の `sinceFires` と同じ数え方）。
- 1 回目の時刻の読み（撮影で選ぶ）:
  - **T1（本命）**: 付いた 1 秒後が 1 回目（`since` のいまの数え方。持続ダメージの `afterInterval` と同じ形）。
  - **T0**: 付いたフレームに 1 回目、その後 1 秒ごと。T0 なら `since` に「付いたフレームにも発火する」印（`atStart` に相当）を足す。足すのは選ばれた時だけ。
- 「持続」「N 秒間維持」は、周期そのものには書かず、見る状態の維持で決まる（B モードは 2.2 の解除まで、グレイブは完全計算の 10 秒）。周期の側に維持の欄を持たせない（代案は論点 1）。
- 下げ方は紅蓮と同じ掛け算（C-1044 の H1）を本命にし、撮影で最大HP の X% を引く読み（H2）と見分ける。A2 は 40% で解除されるので、どちらの読みでも HP は 0 に届かない（H1 は 23 回で 39.2%、H2 は 16 回で 36.2%）。

### 2.2 HP の割合による状態の解除（論点 3・4）

- 状態の付与の維持に `durationUntil: { "selfHpAtMostRef": N }` を足す（`{ counterEmpty }` と同じオブジェクトの形。解いた後は閾値の割合）。
  - 意味: 持ち主（自分）の HP の割合が閾値以下と読めたフレーム g の次のフレームで、件を閉じる（g の判定には付いている。解除 `removeState` の f + 1 と同じ）。それまでは戦闘の終わりまで。
  - HP の割合は `selfHpRatioAt`（現在の HP▼ は発火の次のフレームから読む）。現在の HP▼ が t に起きたら、g = t + 1 で読み、t + 2 で閉じる。循環しない（状態の窓の終わりが HP▼ の発火より後のフレームにしか来ない）。
  - 付いたフレームですでに閾値以下なら、そのフレームだけで閉じる（R1）。
  - 書けるのは、対象が自分で、スタックしない付与だけ（A2 の形。広げるのは使い手が出た時）。
- 既存の `selfHpAbove` は使わない。`selfHpAbove` は「閾値を上回るまで」（下がって付いたものが戻ったら切れる）で、B モードは逆向き（付いていたものが下がったら切れる）。きっかけ `{ selfHpAtMostRef }` と解除 `removeState` を組む形（論点 3 の代案）は、下がった瞬間にしか発火しないので、すでに 40% 以下の時に付いた B モードが外れない（R2 の形）。
- 2 回目以降のバーストの読み（撮影で選ぶ）:
  - **R1（本命）**: 付いた時に 40% 以下なら、すぐに解除される（攻撃力▲・チャージ速度▲は実質付かず、HP▼ も起きない）。
  - **R2**: 下がった瞬間にだけ解除される。2 回目以降の B モードは戦闘の終わりまで続く（HP▼ も続き、HP は掛け算で 0 に近づく）。R2 が選ばれたら、維持の形をやめて、`{ selfHpAtMostRef }` のきっかけの `removeState` で書く。
- 解除の後は、中身（攻撃力▲・チャージ速度▲）と HP▼ の周期（`since` が見る状態が外れる）が全部止まる。

### 2.3 足さないもの

- ラプンツェル：ピュアグレイスの S2 の「フルチャージ状態を 1 秒以上維持した場合」は、オートの射撃では起きない（C-0839 で確定）。同じきっかけの S1 の攻撃ダメージ▲は前提の外の notes（C-0839）にしてあるので、S2 の現在の HP▼ とバリアHP 回復も同じにする。「バリア適用状態の時に限り」の条件も書かない。
- 「フルチャージ状態を N 秒以上維持」のきっかけ・「バリア適用状態」の条件: 上のとおり要らない。
- グレイブの S1・S2（完全計算・放熱・過熱）: キャラを定義しないので、このタスクでは扱わない。

## 7. 論点（オーナーに決めてもらうこと）

1. **周期の形**（2.1 節）
   - 推奨: `currentHpDown` に、時間の周期の `since: { applied }`（状態の付いた時から数え、状態の間だけ）を書けるようにする。「持続」「N 秒間維持」は見る状態の維持で決まる。
   - 代わりの案: 持続ダメージ（dot）のように、`currentHpDown` に `intervalSeconds`・維持（`durationRef`・`durationUntil`）・`firstTick` の欄を足す。A2 では B モードの解除と HP▼ の止まりを別々に書くことになり、2 つの終わりがずれうる。
2. **1 回目の時刻**（2.1 節）
   - 推奨: T1（付いた 1 秒後）を本命に、T0 も予測に書いて撮影で選ぶ。T0 が選ばれたら、`since` に付いたフレームの発火の印を足す。
3. **HP での解除の形**（2.2 節）
   - 推奨: 状態の付与の維持 `durationUntil: { selfHpAtMostRef }`（閾値以下と読めたら閉じる。付いた時にすでに以下なら、すぐ閉じる）。
   - 代わりの案: きっかけ `{ selfHpAtMostRef }` の解除 `removeState`。下がった瞬間にしか発火しないので、R2 の形になる。
4. **2 回目以降のバースト**（2.2 節）
   - 推奨: R1 を本命に、R2 も予測に書いて撮影で選ぶ（3 分の撮影で A2 のバーストは 4 回ほど）。R2 なら論点 3 の代わりの案で書く。
5. **A2 の S1 のチャージダメージ▲**（5 節）
   - 推奨: 同じ録画で確かめて、結論に結び付ける（R1 なら 2 回目以降のバーストの後 15 秒が S1 だけの窓。R2 なら 1 回目の 15 秒の前後で B モードの分を引いて読む）。
   - 代わりの案: B モードだけを結論にし、S1 は根拠なしのまま残す。
6. **ラプンツェル：ピュアグレイスの S2**（2.3 節）
   - 推奨: 前提の外の notes（C-0839）にする。語彙は足さない。
7. **PR の範囲**
   - 推奨: 2.1・2.2 節の語彙・A2 とラプンツェル：ピュアグレイスの定義・撮影の結論を 1 本にする。課題の行は、グレイブ（定義なし）だけに書き直す。

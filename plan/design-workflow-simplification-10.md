## 1. 撮影と読み取りの手引きを索引の大きさに戻す

**いま**

- [captures/guide.md](captures/guide.md) は 47.0KB（目安は 50KB。AGENTS.md「文書の書き方」）。2026-10-30 の 41.3KB から、1 日に約 0.7KB ずつ伸びていて、このままだと 4 日ほどで目安を超える。直近の 30 本の PR のうち 4 本が書き足した。
- 決まりは「1〜2 行の要約と ID」（[design-doc-roles.md](design-doc-roles.md) 3 節の表）。99 項目の中央値は 387 バイト（約 130 字）で、多くは守れている。一方で 600 バイトを超える項目が 20 個あり、合わせて 19.2KB（全体の 41%）。いちばん長い「バーストの段の切り替わり」は 2.2KB で、読み方の手順・例外・結論の ID が 1 項目に積み重なっている。
- 長い項目は、どれも後の検証で分かった例外を同じ項目に足していった形で、手順の中身は検証記録やレシピ（`burst-panel` など）にもある。
- 大きさの目安は、いまは誰も機械で見ていない（第 9 回は手で測った）。

**案**

- (a) 600 バイトを超える 20 項目を、「何に気をつけるか」の 1〜2 行と、根拠の ID・レシピの名前に縮める。手順や例外の細部は、指している検証記録・レシピの冒頭にあるので消す（無いものはそちらへ移す）。見込みは約 12KB 減って 35KB ほど。
- (b) `pr:prep` の文書の確かめ（進み具合の書き写しを見ている所。`tools/git/pr-prep.ts`）に、ブランチで変えた手書きの `.md` が 50KB（検証記録は 30KB）を超えたら知らせる 1 段を足す。止めずに知らせるだけ（目安なので）。生成物と凍結の文書は見ない。

**効果**: 読み取りのたびに開く索引が 3 割ほど短くなり、超えてから分け直す仕事が要らなくなる。(b) で、次に伸びたときにその PR の中で気づける。

**気をつけること**: 縮めるときに、索引にしか書いていない注意を落とさない。項目ごとに、残す 1〜2 行・指す ID・移す先を表にしてから消す。

## 2. 中身が main に入ったブランチを自動で消す

**いま**

- origin に `claude/*` のブランチが 11 本ある。開いている PR は 0 本。マージした PR のブランチは GitHub が消すが、PR を出さずに作業を別のブランチに移したものや、クラウドのセッションが main に揃えてから push したものは残る。
- 残ったブランチは、並行の作業の確かめ（次の作業の前に origin のブランチを見る）で毎回目に入り、オーナーが手で消している（第 2 回の 7・第 7 回の 4・第 8 回の 4）。クラウドの環境では、ブランチの削除は安全確認で止まる。

今の 11 本を、main と合わせたときに何が変わるか（`git merge-tree --write-tree origin/main <ブランチ>` の木が origin/main の木と同じか）で分けた。

**案**

- `tools/git/sync-after-merge.ts`（デスクトップのセッションの始め・発言・応答の終わりに回る）に、次の条件をすべて満たす origin の `claude/*`・`antigrav/*` のブランチを `git push origin --delete` で消す段を足す。
  - main と合わせても木が変わらない（上の表の「何も変わらない」。main の祖先であるものも含む）
  - 最後のコミットから 1 日以上たっている（いま動いているセッションの足元を消さない）
  - 開いている PR が無い（`gh pr list --head`）
- 消したものは、ほかの知らせと同じくフックの出力で 1 行ずつ知らせる。条件に合わないものは何もしない（撮影待ちのブランチや、作業中のブランチは「変わる」側なので消えない）。
- クラウドのセッションでは今のまま何もしない（削除が止まるため。フックはデスクトップでだけ消す）。

**効果**: 今の 11 本のうち 5 本が、手を使わずに消える。今後も、PR を出さずに移した・main に揃えて push したブランチは 1 日で消える。

**残る 4 本**（`stage17-read-v0598`〜`v0601`）は、中身が後で直された形で main に入っていて、木で比べると「変わる」側になる。機械では消さないので、オーナーが確かめて消す（GitHub のブランチの画面か、デスクトップで `git push origin --delete <ブランチ>`）。

## 3. 録画の置き場所の書き写しを 1 か所にする

**案**

## 1. 語彙

### 1.1 枠の防御力（バフ前）

- `TeamSlotInput.defenceOverride`（戦闘中の防御力（バフ前）。`attackOverride`・`hpOverride` と同じ流儀）。省略時は育成値から `computeStat(character, 'defence', growth)`。
- スペック固定: `computeFixedSpecDefence`（Lv400・凸・コア・好感度・T9 Lv5 の装備の防御力）。最大HP と同じく定数の表で持ち、育成の層（`fixedSpecBuild` を `computeCombatStat(…, 'defence')` に通した値）と同値なことをテストで固定する。
- 画面・CLI・録画の照合は、スペック固定と育成入力から入れる（最大HP と同じ）。スペック固定 OFF の録画の台帳には防御力が無いので、最終防御力を読む効果のある枠がスペック固定 OFF の録画に出たら、比べを止めて知らせる（いまアニス：スターの録画はどれもスペック固定 ON）。
- 名前の綴り: 枠の入力とスペック固定は、ステータスの種類（`StatKind` の `defence`）に合わせて `defence`。効果の stat は、敵の防御力▼（`enemyDefenseDown`）と経路（`defense`）に合わせて `defense`。

### 1.2 最終防御力

- 最終防御力 = バフ前の防御力 × (1 + 防御力▲ の比率の和)。「最終」は戦闘中の効果を含む値（ツールチップ「最終」）。
- 防御力▲ は与ダメージの式を読まない（被ダメージを減らす分は被弾で効くで、モデルは扱わない）。読む側は対象の絞り込みだけ。
- 発動者基準の防御力▲（「スキル発動者基準で防御力 X%▲」。モランのバースト）は、使い手を定義する時に足す（攻撃力の `casterAttack` と同じ形の見込み）。

### 1.3 防御力▲ の効果

- `stat: 'defense'`（比率）。いまは notes の stat にも無いので、効果の stat の語彙に足す。
- アニス：スターのバースト「自分に…防御力 X%▲（10 秒）」を `timed`（`burstUse`・自分・`defense`）にする（比べの自分の側。いまの間接の notes を置き換える）。

### 1.4 対象の絞り込み「自分より最終防御力が低い味方」

- `target: 'allies'` に `targetDefense: 'lowerThanSelf'`。自分は含む（説明文「自分と」）。
- 比べは発火の瞬間の最終防御力（その時に効いている防御力▲ を入れる）で決め、維持の間は対象を変えない（論点 3）。
- 同値は含まない（説明文「低い」、英語版「lower final DEF than self」。論点 2）。
- 判定は 1 パス目の発火で、対象の枠を決める（対象の語彙の `fixedTargets` と同じく、決まった枠に件を付ける）。最終防御力はその時の件から出す（最大HP の読み直しと同じ形。`skills/holders.ts`）。

## 4. 論点

1. **PR の分け方**
   - 推奨: PR 1（書き直し。撮影なし）→ PR 2（撮影）。PR 1 は既存の録画で値が変わらず、撮影を待たない。
   - 代わりの案: 撮影の後に 1 本にする（比べの読み（同値・防御力▲）を確かめてから語彙を入れる）。
2. **同値の扱い**
   - 推奨: 含まない（説明文「低い」・英語版「lower」）。録画 A で確かめる。
   - 代わりの案: 含む（自分と同じ防御力の味方にも乗る）。
3. **いつの最終防御力で比べるか**
   - 推奨: 発火の瞬間（その時に効いている防御力▲ を入れる）。維持の間は対象を変えない（ほかの対象の決め方と同じ）。
   - 代わりの案: 維持の間も比べ直す（防御力▲ の付き外れで対象が入れ替わる）。
4. **防御力▲ を効果にする範囲**
   - 推奨: アニス：スターのバーストの防御力▲ だけ（比べの自分の側。撮影で確かめるキャラ）。味方の防御力▲ は、読む側と組む録画を撮る時に効果にする（それまで間接の notes のまま。アニス：スターと組む編成では、最小構成の検査が未確定の要素として出す）。
   - 代わりの案: 定義のあるキャラの防御力▲ のうち、今の語彙で書けるもの（自分・味方全体）をすべて効果にする。
5. **最終防御力の丸め**
   - 推奨: 丸めない（比べだけに使う。同値はバフ前の整数どうしで決まる）。
   - 代わりの案: 攻撃力と同じく、四捨五入した整数で比べる（防御力▲ の端数で同値になる・ならないが変わる所がある）。

# V-0438: ミサト S1 の「残りの HP の割合が最も低い味方 1 機」は、満タンが並んだときに誰を選ぶか（回復の語彙 F4）

## 条件

- 対象はミサト（833）の S1 の 2 つ目の効果（回復）。いまは notes の未対応（C-0180）。モデルは HP を持たないので、満タンが並んだときの選び方は説明文から決まらない（設計書 3.2 節の E-a〜E-d）。
- 「回復効果が適用された時」の受け手はアスカ（830）の S1（自分の攻撃力▲・25 秒・発動中の再発動で延びる。C-0464・C-0087）。満タンでも回復は適用されたとみなす（C-0345 と同じ読み）。
- **的の攻撃が当たる枠**: 設計書の F4 は「◎アスカ」（アスカを操作して撃つ）だったが、撃つ枠は的の攻撃で HP が減り、HP の割合が最も低い 1 機がその枠に決まってしまう（満タンが並ばない）。C-0551（仮説）は「操作キャラを攻撃する」だが、根拠は単騎の録画だけで、AI の枠に当たるかは言っていない。多人数の録画の戦闘履歴のパネルの盾の欄を読み直すと:
  - AI で撃つ枠は 14 枠とも 0 でない（`113-06`）。
  - 撃つ操作枠も、6 枠のうち 5 枠が 0 でない（`113-07`。132 のドレイクだけ 0）。
  - 撃たない操作枠（AUTO 射撃 OFF・与ダメージ 0）は 3 枠とも 0（`125-16`）。
  - 盾の欄が被ダメージだけかは確かめていない（オーナーの注意）。値は数〜数十で、射撃場の被ダメージは HP バーで見えないほど小さい（録画 132・142 の HP バーは赤い画面の前後でも幅が変わらない。観測値にしていない）。ミサトの S1 の回復（最大 HP の数 %。パネルの緑の欄は単騎 142 で数百万）は 1 回で満タンに戻す見込み。
- そこで、**アスカを撃たない操作枠にし、ミサトを AI で撃たせる**（2026-10-17、オーナーの指示で条件を作り直した）。アスカは当たらず、いつも満タン。ミサトは当たることがあり、当たった後の最初の S1 はどの仮説でもミサト自身を選ぶ（HP の割合が低い）。前の S1 から当たっていなければ、2 機とも満タンで並ぶ。
- アスカは撃たないので、S1 は 1 発のダメージでは読めない。代わりに次の 2 つで読む:
  - 回復の数字（緑）: 操作枠の上に出る（録画 264 の f3000 で、ヘルムの回復の数字が操作のヘルムの上に出た）。アスカの上に出れば、その回はアスカが選ばれた。
  - アスカの S1 のアイコン: 画面下のアスカの顔の下のアイコンが、録画 264 で最初の回復（f895）の後に 1 つ増えた（f885 は 2 つ、f930 は 3 つ）。ミサトの S2（射撃マニュアル状態の間の味方全体のバリアに与えるダメージ▲）のアイコンもアスカに付きうるので、形で分ける。
- ミサトの S1 の時刻: アスカが撃たないので、HUD の総ダメージの増分はミサトの発だけ。マガジン（120 発・1440 rpm で約 5 秒）の区切り（リロードの空き）で 120 発目を読む。外れた発は増分に出ないので、マガジンの区切りで数える。的のジャンプでマガジンの途中のリロードが入ると、120 発の数えとマガジンがずれるので、その後は回復の数字か S1 のアイコンの時刻で合わせる。
- 最小構成: 未確定の要素は、ミサトの S1 の回復の対象（確かめたいもの）と、アスカの S1 の延び方（C-0087。確定）のほかに、ミサトの S1 の回復が満タンの味方にも適用されるか（C-0345 の味方への回復と同じ読み。仮説）。アスカは撃たないので、アスカの 1 発の式・コア命中率・距離は効かない。ミサトのバーストはオートバースト OFF で撃たない（アスカは III、ミサトは I でチェーンにならない）。
- 的は BigArms（灼熱タブ）・射撃場 3 分モード・スペック固定 ON。ミサトは AI なので AUTO 射撃の ON/OFF はミサトに効かない（操作のアスカだけ OFF）。

## 予測

モデルに対象の語彙が無いので、予測ファイルは作らない。仮説ごとの見え方（S1 のたびに、アスカが選ばれたか）:

| 仮説                         | A: アスカ（1 枠目）+ ミサト（2 枠目）                          | B: ミサト（1 枠目）+ アスカ（2 枠目） |
| ---------------------------- | -------------------------------------------------------------- | ------------------------------------- |
| E-a 発動者自身               | アスカは一度も選ばれない                                       | 同じ                                  |
| E-b 枠の順（左から）         | 並んだ回はすべてアスカ（ミサトが当たった直後の回だけミサト）   | 一度も選ばれない                      |
| E-b'（枠の順・右から）       | 一度も選ばれない                                               | 並んだ回はすべてアスカ                |
| E-c 乱数                     | 並んだ回の一部（2 機なら半分ほど）                             | 同じ                                  |
| E-d 満タンなら回復が起きない | アスカは一度も選ばれない。並んだ回は回復の数字がどこにも出ない | 同じ                                  |

- 枠順を入れ替えて結果が変われば E-b（か E-b'）、どちらの枠順でも一部だけなら E-c、どちらでも一度も選ばれなければ E-a か E-d。
- E-a と E-d は、アスカの見え方では分けられない。補助として、パネルの緑の欄（ミサトの回復の合計）を、S1 の回数 × 1 回の回復量と比べる（E-d なら、ミサトが当たった直後の回の分しかない）。1 回の回復量はアスカの上の数字か、単騎の録画 142 のパネルから見積もる。
- 見分けられなくなる場合: ミサトが S1 の間隔（約 6〜7 秒）ごとにほぼ毎回当たると、並ぶ回が無くなり、どの仮説でもアスカは選ばれない（E-a・E-d と見分けられない）。パネルのミサトの盾の欄と、並んだ回（前の S1 から当たっていない回）の数を、読みの最初に確かめる。AI のミサトの被弾の時刻は画面に出ない（赤い画面は操作枠の被弾とみる）ので、並んだ回を個別には決められない。
- 外れたときの影響: どの結果でも、段 8 で `heal` の対象（`lowestHpRatio` と並んだときの規則）を起案する材料になる。E-c なら乱数を起点にする効果と同じ扱いで定義しない（設計書 3.2 節）。

## 読み方

1. 取り込みの後、出撃画面と戦闘履歴のパネルで、枠順・操作枠（アスカ）・アスカの与ダメージ 0 と盾の欄 0・ミサトの盾の欄を確かめる。アスカの盾の欄が 0 でなければ、この録画は見分けに使わない（並ばない回が混ざる）。
2. HUD の増分（`records:read` の `hud-jumps`）からミサトのマガジンの区切りを取り、S1 の時刻（120 発目）を並べる。
3. S1 のたびに、その前後 60f の操作枠の上の回復の数字と、アスカの顔の下のアイコンの数・形を、ffmpeg で切り出したフレームで目で読む。アイコンの付き始め・切れ目の時刻も読む（25 秒で切れるなら、その間にアスカが選ばれなかった）。
4. 読んだ値は観測値にする（`source` に `V-0438`。S1 の時刻の並びと、アスカが選ばれた回の並び）。モデルに語彙が無いので比べる指定（`compare`）は付けない。

| -------- | --------------------------------------------------------------------------------------- | --------------------------------------- | ------------------ |

- 条件の確かめ: 戦闘履歴のパネルで、2 本とも枠順が計画どおり、アスカの与ダメージ・盾・緑の欄が 0（アスカは撃たず、的の攻撃も当たっていない）、ミサトの盾の欄は 0 でない（`472-03`・`473-02`）。HUD の最後の値はミサトの与ダメージと一致。
- 読み方 3 の回復の数字は読んでいない。アイコンだけで仮説が分かれたため。S1 のアイコンは、切れる前に暗く点滅する。A では、何度か点滅に入ってから付き直した（並ばない回、つまりミサトが被弾した後の回が続いた所とみる。見立て）。
- 読み方 2 の S1 の時刻の並びは作っていない。最初の S1（1 本目のマガジンの終わり）だけ時刻を合わせた（`472-01`）。ジャンプで途中のマガジンがあり、120 発の数えとマガジンがずれるため。
- パネルの緑の欄（ミサトの回復の合計）は A が B の約 1.8 倍（`472-03`・`473-02`）。どちらも S1 の回数はほぼ同じなので、緑の欄は回復の名目の量の和ではない（受けた側の実際の回復量か、受けた側の何かで変わる）とみる。理由は確かめていない。予測の節で挙げた E-a と E-d を分ける補助には使えなかった。

## 分かったこと・分からないこと

- **C-0567（仮説・単独実測）**: ミサトの S1 の「残りの HP の割合が最も低い味方 1 機」は、HP の割合が並んだとき、枠の順で若い枠の味方を選ぶ。満タンの味方にも回復が起き、「回復効果が適用された時」を起こす。E-a（自身）・E-c（乱数）・E-d（満タンなら起きない）は合わない。
- 確定にしない理由: 枠の順の向きごとに録画が 1 本ずつ。最小構成の警告も出る（ミサトの S1 の命中率▲・アスカのバーストの仮説。どちらも撃たない操作のアスカの S1 の付き方には効かない）。再現を 1 本ずつ撮れば反復実測にできる見込み。
- 分からないこと: ミサトが被弾した後の回に、ミサト自身が選ばれるか（AI の被弾の時刻が画面に出ないので、回ごとには確かめていない）。3 機以上が並んだときも若い枠からか（2 機でしか見ていない）。オーシャンの S1・S2・鈴原サクラの 2 機の対象が同じ規則か（同じ言い回し。確かめていない）。パネルの緑の欄が何を数えるか。
- 撮る前に分かったこと: 射撃場 3 分モードの的の攻撃は、多人数の録画では AI で撃つ枠にも当たる（戦闘履歴の盾の欄。`113-06`）。撃たない操作枠は 0（`125-16`）。C-0551 の「操作キャラを攻撃する」は単騎の録画からの見立てで、多人数では撃つ枠に当たると読む。盾の欄が被ダメージだけかは確かめていない。132 のドレイク（撃つ操作枠）が 0 の理由は分からない。

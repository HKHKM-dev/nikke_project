## 予測（撮る前に書く）

H1 はいまのモデル（OL の 2 行とキューブの値を足して round(60 × (1 + Σ))）、H0 はキューブが乗らない形（OL だけ）で、値は予測ファイル（records/predictions/V-0223.json）にある。H2（OL で丸めた弾数にキューブの (1 + 値) を掛けて丸める）は式を切り替える仮説なので、ここに手で書いた。どれも V-0222 の H1（OL の 2 行を足す）を前提にする。

| 仮説                          | マガジンの弾数 |
| ----------------------------- | -------------- |
| H1: 足して丸める              | 予測           |
| H0: 乗らない                  | 予測           |
| H2: OL の後にキューブを掛ける | 182            |

- 見分け方: V-0222 と同じ。3 つの仮説は 10 発以上離れる。
- 合えば: H1 ならモデルはそのまま。
- 合わなければ: `effectiveMaxAmmo` の合成（効果層の出どころごとの順）を直す。

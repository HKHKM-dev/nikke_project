# V-0864: MG の回転（発射レートの蓄積）は短いリロードの後も保たれるか

- 問い: MG（クラウン）のレートの蓄積は、リロードの後に最初からやり直すのか、止まりが短ければ保たれるのか。多人数の録画 1381 のクラウンの残弾の減り方で、リロードの前後の発の間隔を読む
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-22
- 録画: `1381`
- 状態: 調査中

## 条件

- 型: 探索（仮説を立てるために読む。2.1 節）。録画 1381 は 5 人の編成で、クラウンのリロードの速さに味方のリロード速度▲が効くので、この録画だけでは結論を作らない（AGENTS.md「事実と記録」）。
- 編成: アニス：スター（I）・クラウン（II・AI）・スノーホワイト：ヘビーアームズ（III・操作）・ドロシー：セレンディピティ（III）・プリバティ（III・宝物 段階 3）。射撃場 3 分モード・灼熱の BigArms・スペック固定 ON・AUTO・オートバースト ON。
- 出どころ: 録画 1381 をモデルと比べたら、チームの総ダメージが −4.3%、クラウンの与ダメージが −24%（`1381-12`）、ドロシー：セレンディピティが −11%（`1381-14`）だった。ほかの 3 人は ±2% の中（`1381-11`・`1381-13`・`1381-15`）。フルバーストは動画もモデルも 13 回で、入りの時刻はゲーム内の秒に直して ±1 秒の中（`1381-05`。`timer.ts --mode ticks` で直した）、III の順（スノーホワイトが先）も同じだった。クラウンの単騎（`0056-02`）は許容内なので、編成の中でだけ出るずれを、撃った数から切り分けた。

## 予測

なし

## 読み方

- クラウンの顔のカード（2 つ目の置き場所）の残弾を `ammo.ts --card 2 --max 148,300 --mode series` で全フレーム読み、同じマガジンの中の減りを足して撃った数にした（`1381-16`）。最大は 300 と、フルバースト中のプリバティの最大装弾数▼（C-0924）の 148 で、動画でも 148 になっていた。
- 残弾が満タンに戻ったフレームをリロードとして、リロードごとに最終弾・満タン・次の 1 発目と、1 発目から 11 発目までのフレーム数を並べた（`1381-17`）。
- モデルの発は `npm run sim -- --ids 17,330,471,234,170 --fixed-spec --controlled 3 --enemy range-bigarms-fire --treasure 170:3 --trace shots` で出し、同じ 4 つを数えた。

## 結果

- 撃った数: 動画 7,760 発、モデル 5,293 発（`1381-16`）。10 秒ごとに数えても、動画はどの区間もモデルより 2〜6 割多い。
- リロードそのものの長さは合う。最終弾から次の 1 発目まで、動画はふつう 30〜32f（最終弾 → 満タン 19f・満タン → 1 発目 12f。C-0115）、モデルも 31f。
- 違うのはリロードの後の撃ち方:

|                                                                     | 止まり（最終弾 → 1 発目） | 1 発目から 11 発目まで                  |
| ------------------------------------------------------------------- | ------------------------- | --------------------------------------- |
| 動画（31 回）                                                       | 30〜32f                   | どれも 11f（1 フレームに約 1 発のまま） |
| 動画（1 回。f3464〜3544）                                           | 80f                       | 10f                                     |
| 動画（11 回。フルバーストの切り替わりやジャンプで撃たない間を挟む） | 106〜146f                 | 63〜84f（9 回は 80〜84f）               |
| モデル（35 回。止まり 31f も 106〜149f も）                         | 31f・106〜149f            | どれも 82f                              |

- モデルはマガジンごとに蓄積を最初からやり直す（`packages/core/src/cadence.ts` の simulateShotFrames と `frame/shooter.ts`）。動画は、止まりが 80f までの回は蓄積を保ち、106f 以上の回はやり直しとほぼ同じ立ち上がりになった。106〜108f の 2 回（f2697・f10166）は 63f・38f で、やり直しと保つ形の間に出た。

## 分かったこと・分からないこと

- 分かったこと（仮説）: MG の発射レートの蓄積は、リロードでは最初に戻らず、撃たない間が短ければ保たれる。長い間（106f 以上）撃たないと、ほぼ最初からの立ち上がりになる。クラウンの単騎（`0056-02`）が合うのは、単騎ではリロード（2.5 秒）の止まりが長く、毎回やり直しと同じになるからとみる。
- クラウンの −24% は、主にこの撃った数の差とみる。足りない約 2,470 発に、モデルのクラウンの平均の 1 発の値を掛けると +1.2 億ほどで、実測との差（+0.85 億）を超える。増える発がフルバーストの外に寄る分などを、モデルを直して確かめる。
- 分からないこと:
  - 保たれる長さの境（80f と 106f の間）と、境で切り替わるのか、撃たない間に少しずつ下がる（立ち上がりの途中から始まる）のか。106〜108f の 2 回の中間の値は、少しずつ下がる形を指すが、読み違いか、止まりの中身（ジャンプ・バーストの演出）の違いかを見分けていない。
  - 長い止まりのどこまでがリロードで、どこからが撃たない間（バーストの演出・ジャンプ）か。
  - ほかの MG（クラウン以外）でも同じか。
- ドロシー：セレンディピティの −11% は、この問いの外。フルバースト中の命中率▲を中近・遠・中遠の SG の弾丸命中率に効かせていない（課題 2-1。C-1079 のモデル側）ことと向きが合う。区間ごとの残差は遠・中遠で大きく近で小さく、フルバースト中のその 3 区間でペレットの 93% が当たるとすると、ドロシーの差（+1.38 億）に届く（93% は差から逆算した値で、測っていない）。

## 次に撮るもの

1. 読み直し: クラウンが自分のフルバーストの S1（リロード速度▲。C-0394）で、止まりが 1381 の 31f と 2.5 秒の間になる録画（例: `1236`。クラウン + ソリン + エクシア・オートバースト ON）。残弾を同じ読み方で読み、止まりの長さごとに 11 発目までの長さを並べて、境か少しずつ下がる形かを見る。
2. 1 で決まらなければ撮る: MG の単騎（AI・AUTO）に、リロード速度▲だけを足す最小構成で、止まりの長さを何段かに振る。撮り方はオーナーと決める（plan/captures/protocol.md「撮影の依頼」の型）。

# V-0683: 命中率▼（マスト：ロマンチックメイドのほろ酔い）の 2・3 スタックのコア命中率・弾丸命中率

- 問い: マスト：ロマンチックメイドのほろ酔い（命中率 20%▼ × スタック数）は、2・3 スタックで MG のコア命中率と弾丸命中率を着地点ごとにどう変えるか。式か表のどの形が合うか
- 話題: 命中率・距離
- 日付: 2026-11-07
- 状態: 調査中
- 派生元: `V-0668`

## 条件

- 課題 2-57（plan/design-maids.md 3.3 節の論点 7 で案 A）。モデルは命中率▼をコア命中率にも弾丸命中率にも効かせていない（`frame/landing.ts` の `coreHitRateWithHitRateUp`・`bulletHitRateWithHitRateUp` は N ≤ 0 で変えない）。
- V-0668 の「結果」で分かっていること: 単騎（1 スタックまで）では、コア命中率が着地点で大きく違う割合で下がる。遠では弾丸命中率も下がる。2・3 スタックは、撮影 B（リター・マスト：RM・I-DOLL・サン）でほかの枠の発と格子が重なり、分けきれなかった。
- 単騎ではチェーンが 1 段階で止まり、ほろ酔いは 1 スタックまでしか付かない。2・3 スタックには、1 段階突入（ゲージの満タンと、チェーンの時間切れの後の入り直し）が 2・3 回要る（C-0941・C-0942）。

### 編成

- **I + マスト：RM（II）の 2 人で、III を置かない**。フルバーストが起きないので、ほろ酔いは 1 段階突入のたびに増えて 3 で止まり、フルスタックのフルバーストの終わりの解除と気絶（C-0943）が起きない。2・3 スタックの区間が長く続く。チェーンは、I・II の発動の後に 3 段階で時間切れするか、マスト：RM の CT（40 秒）が明けずに 2 段階で時間切れして、1 段階に入り直す。
- I の枠は、機構が確定したキャラで、マスト：RM のコア命中率に効く効果（命中率▲）を持たず、通常攻撃の格子が MG と重ならない SR か RL にする。
  - **撮影 D: ココア（311。SR・I）**。ダメージに効く効果を持たない（S1 は回復、S2・バーストは計算に無関係。C-0092・C-0822）。
  - **撮影 E: I-DOLL・フラワー（304。RL・I）**。S2 のゲージ（C-0176・C-0178）とバーストのダメージ（C-0220・C-0221）だけ。ゲージの溜まり方が違うので、スタックの増える時刻が撮影 D とずれ、遠の 2 スタックが取れる（下の表）。
  - どちらも SR・RL の 1 発の値は MG の 1 ヒットより桁が大きく、180 秒に約 100 発なので、同じフレームに重なった増分も、その 1 発を引けばマスト：RM の格子に戻る。
- マスト：RM は操作枠にする（V-0668 の撮影 A・B と同じ。1 スタックの値と比べるため）。
- 最小構成: 観測量（マスト：RM のコア命中率・弾丸命中率）に効く未確定の要素は、ほろ酔いの命中率▼だけ。マスト：RM の S1 の▲・バーストの▲とほろ酔いの付き方（C-0941・C-0942）は確定。ココア・I-DOLL・フラワーは機構が確定したキャラ。
- 的は BigArms（火）・3 分モード・スペック固定 ON・オート射撃 ON・オートバースト ON（V-0668 と同じ）。

## 予測

撮る前に書く。命中率▼の仮説はモデルで切り替えられない（予測ファイルの `override` に無い）ので、ここに手で書く。予測ファイル（`records/predictions/V-0683.json`）は、いまのモデルのチェーンの並び（バーストを撃った枠と時刻）だけを持つ。

1 スタックの値は V-0668 の撮影 A（0952・0953）の帯ごとの和（近 2,263/3,917 = 0.578、中遠 B・C 312/1,713 = 0.182、遠 206/2,388 = 0.086）、0 スタックは射撃場の表の MG の行（近 0.963、中近 0.965、中遠 0.961、遠 0.959）。

- **H-lin（スタック数に比例して下がる）**: 下がる幅が k × 1 スタックの幅。p_k = max(0, p0 − k (p0 − p1))。
- **H-geo（スタックごとに同じ倍率）**: p_k = p0 (p1 ÷ p0)^k。
- **H-N（命中率の和を着地点ごとの表に通す）**: コア命中率は着地点と命中率の和 N（▲と▼。ここでは N = −0.2k）だけで決まる T_L(N)。表の形は、照準の広がりの円が N で大きくなり、コアに入る割合が着地点ごとのコアの見かけの大きさで決まる形（上限は表の値）とする。この形では、どの N でも着地点どうしの比が同じ。1 スタックの比は、中遠 / 近 = 0.315、遠 / 近 = 0.149 で、AR の表の比（0.283・0.147）に近い（AR の広がりは MG の▲なしより大きい）。値の例として、広がりの半径が (1 − N) に比例する形（▲の C-0036 の面積の比）を k = 1 から延ばす: p_k = p1 (1.2 ÷ (1 + 0.2k))²。

| 着地点 | k   | H-lin | H-geo  | H-N（(1 − N) の例） |
| ------ | --- | ----- | ------ | ------------------- |
| 近     | 2   | 0.193 | 0.347  | 0.424               |
| 近     | 3   | 0     | 0.208  | 0.325               |
| 中遠   | 2   | 0     | 0.035  | 0.134               |
| 中遠   | 3   | 0     | 0.007  | 0.102               |
| 遠     | 2   | 0     | 0.008  | 0.063               |
| 遠     | 3   | 0     | 0.0007 | 0.049               |

- 見分け方:
  - 近の 2・3 スタック（1 本に数百ヒット。0.2 の割合の 1σ は約 0.015）で 3 つが分かれる。
  - 遠・中遠の 3 スタック（1 本に約 1,000 ヒット）: H-lin は 0、H-geo はほぼ 0、H-N は近の 3 スタックの値の 0.149 倍（遠）・0.315 倍（中遠）。H-N の比は (1 − N) の例に依らない（半径の延び方が違っても、着地点どうしの比は同じ）。
  - 中近の 1 スタック: H-lin・H-geo は値を持たない（着地点ごとに 1 スタックの値が要る）。H-N なら近と中遠の間（AR・SMG の表の中近 / 近の比 0.54・0.45 から、約 0.26〜0.31）。
- 弾丸命中率（当たったヒット / 撃った発）: V-0668 の遠の 1 スタックは 300 発のマガジンに 265〜272（下限）で、表（0.992）より下がる。2・3 スタックではさらに下がる見込み（H-lin なら 3 スタックの遠で約 0.70、H-geo なら約 0.73）。2 つの差は読みの幅より小さいので見分けには使わず、着地点 × スタック数の値を数える。
- チェーン（予測ファイル）: 撮影 D はココアだけの発動（マスト：RM の CT が明けずに 2 段階で時間切れ）が混ざり、撮影 E は I-DOLL・フラワーとマスト：RM が交互。どちらでも、スタックは 1 段階突入の回数どおりに増え、3 で止まる（フルバーストが無いので外れない）。3 段階に III がいないときの時間切れは、これまでの録画に無い（モデルは 2 段階の時間切れと同じに入り直す）ので、`burst-panel` で確かめる。

## 読み方

1. 取り込み: `tools/captures/intake.ts`。戦闘履歴のパネルで枠順と操作枠を確かめる。
2. スタック数の時刻: レシピ `burst-panel` で 1 段階突入（I の BURST バーが消えた所と、時間切れの後の入り直し）を置き、1 回ごとに 1 足す（C-0941・C-0942）。マスト：RM のバーストの窓の 1 ヒットの値（発動者基準の攻撃力 20.06% × k。C-0942）で、その時の k を確かめる。
3. 1 ヒットの値: レシピ `hud-jumps` の増分を、マスト：RM の格子（V-0668 の「読み方」2 と同じ。会心・コア・距離ボーナス・攻撃力の段）に当てる。I の枠の 1 発（ココアの SR、I-DOLL・フラワーの RL とバーストのダメージ）が乗った増分は、その値を引いてから当てる。2 通りに読める増分は数えない。
4. 着地点: V-0668 の「読み方」3 と同じ（距離ボーナスの有無とマガジンの途中で止まる所）。中遠は A と B・C を足元の y（レシピ `midfar-landing`）で、近は A・B を幅（`fb-near-width`）で分ける。
5. 数える: 着地点 × スタック数ごとに、コアのヒット / 当たったヒット（コア命中率）と、完全なマガジンの当たったヒット / 撃った発（弾丸命中率。外れは C-0780 の拾い方）。着地の直後の照準がコアに着く前の発と、撃ち始めの発（C-0292）は分けて数える。

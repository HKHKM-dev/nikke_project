# V-0012: Stage 21-C3（rpm をゲーム内の時計・リロード明けの遅れ）で残差はどう動いたか

- 問い: rpm の蓄積をゲーム内の時計にし（C-0058）、AR・SMG・SG のリロード明けに 22f の遅れを足したとき（C-0059）、録画と比べた観測値の予測はどう動き、確定の結論の根拠は許容幅に収まったままか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-09-27
- Stage: design-stage21.md 8.8 節（21-C3）
- 録画: `054`、`056`、`L-AD`、`L-AI`、`L-AN`
- 結論: `C-0058`、`C-0059`
- 状態: 完了
- 派生元: `V-0011`

## 条件

- 変更の中身は設計書 8.8 節と 7.4 節。武器の CDN の秒（リロード・チャージ・撃ち直し）は 1 秒 = 60f のまま。
- 比べたのは、`npm run records:check` の残差の一覧（`plan/residuals.md`）の変更前（Stage 21-C2 の後の main）と変更後。
- 撮影はしていない。3 分モードの合計は、的のジャンプの 1 回目のずれ（V-0009・V-0010）が混ざるので、換算の判定には使っていない（設計書 8.3 節の 4）。ここでは動きを残すだけにする。

## 予測（撮る前に書く）

予測は、実装の前に設計書 8.8 節と V-0011 に書いた（2026-09-27）。要点:

- rpm をゲーム内の時計にすると、AR・SMG の射撃数が約 2% 増える。
- リロード明けの遅れで、AR・SMG・SG の射撃数は 1 周期あたり約 20f 分減る（AR の 60 発では 1 周期の約 6%）。
- チャージ武器（SR・RL）は変わらない。MG は、スピンアップが 2f 早くなるだけで、ほとんど変わらない。

## 読み方

1. 変更前の `plan/residuals.md` を git から取り出し、変更後と観測値ごとに予測・差・判定を並べる。
2. 予測の変わらなかった観測値は並べない。

## 結果

予測が変わった観測値。実測は各観測値を見る:

- 許容外は 8 件から 6 件になった。

## 分かったこと・分からないこと

- AR・SMG の単騎の合計は、モデルの予測が実測より多すぎた分の大半が消えた（SMG 2 本は許容内、AR は +7.0% → +2.1%）。3 分モードの合計なので、的のジャンプのずれが残っている。
- MG の単騎（`056-02`・`L-AN-01`）はほとんど動かず、多すぎるまま。MG の差の理由は、この変更の外にある。

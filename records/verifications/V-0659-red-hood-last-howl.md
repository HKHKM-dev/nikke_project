# V-0659: レッドフードのバーストⅡのハウリングエンドの付与（0924〜0927 の回復の数字の読み直し）

- 問い: レッドフードのハウリングエンドは、バーストⅡで使った回にだけ付く（I・III で使った回には付かない）か
- 話題: スキル・キャラ固有
- 日付: 2026-11-03
- 録画: `0924`〜`0927`
- 結論: `C-0920`
- 状態: 完了
- 派生元: `V-0639`

## 条件

- 型: 読み直し。V-0639 の撮影の 4 本を、新しく撮らずに読み直す。
  - `0924`・`0925`: レッドフード（470。SR・全段階・操作）単騎。
  - `0926`・`0927`: リター（82。I）・デルタ（20。II）・レッドフード（III・操作）。
  - どれも射撃場 BigArms（灼熱）・3 分モード・スペック固定 ON・オート射撃 ON・オートバースト ON。
- burst の effects[3]（`data/skills/470.json`）: 『バーストⅡで使用時：ハウリングエンド』の呼び名を、II で使った時に自分に付ける維持 0 秒の状態 `theLastHowl`（中身なし）。読むのは S2 の「ハウリングエンドを適用時、自分に攻撃ダメージの 23.04% 回復（10 秒間維持）」だけで、その回復は計算に無関係の notes（S2 の notes[2]）。モデルの与ダメージには効かない。
- 見るもの: ハウリングエンドの付いた回は、S2 の吸収回復で、その後 10 秒のレッドフードの攻撃ごとにレッドフード（操作枠）の上に回復の数字（緑）が出る（操作枠の回復の数字は HP が満タンでも出る。[plan/captures/guide.md](../../plan/captures/guide.md)「回復の数字（操作枠）」）。発動ごとに、その後に数字が出始めたかを見る。
  - 単騎（0924・0925）は、1 回目のチェーンで I・II・III を続けて撃ち（約 29f おき）、2 回目からは I だけ（C-0894）。数字が II と III の間に出始めれば II の回。
  - リター・デルタと組んだ 2 本（0926・0927）は、レッドフードが III だけを撃つ回・I だけの回・II と III を続けて撃つ回がある（`0926-09`・`0927-08`）。
- 最小構成: この編成で回復を持つのは、レッドフードの S2（ハウリングエンドを適用時）だけ。リター・デルタは回復を持たない（デルタのバーストの効果の緑は、色の幅で拾わない。V-0501）。発動の段と枠の並びは確定の C-0894。

## 読み方

1. 回復の数字の地の色（R < 60・G > 220・B < 70 の純緑）の画素を、画面の中央下（x 560〜1360・y 400〜960）でフレームごとに数える（V-0501 の読み方。ffmpeg の生の画素を数える使い捨てのスクリプト）。150 を超えたフレームを、30f の切れ目でまとめる。
2. レッドフードの発動は、V-0639 の替わり目（`0924-01`〜`0924-03` など）と枠の並び（`0926-09`・`0927-08`）から。発動ごとに、次の発動までに数字が出始めたら 1、出なければ 0 とし、モデルの `stateAppliedAtBursts`（その発動に `theLastHowl` が付いたか）と比べる。

## 0. 今わかっていること

- 弾丸命中率は、射撃場の的の表（武器種 × 距離帯。SG は着地点）の値で、▲には効かせていない（`frame/landing.ts` の `autoConditionAt`。注記 `auto-condition` に未実装と出している）。
- コア命中率は、常時の▲を計画（`planLandings`）で、持続の▲を使う時点（`landingPartsWith`）で、どちらも `coreHitRateWithHitRateUp` で出し直している（C-0036・C-0170）。
- 1 パス目のゲージは、計画の弾丸命中率の区間（`hitRateSpansOf`。常時の N だけ）を掛けている。
- 自分に▲を乗せる単騎のうち、SMG はミサト（833。持続・スタック。C-0183）とミランダ（32。持続。C-0186 は仮説）。フルバーストの頭に味方へ配るのはドレイク（101）・モダニア（260）、SG の味方へはノワール（271）。アスカ（830）は自分の AR に持続。
- H2 を確かめたのは SMG の遠だけ（C-0192）。SG では近 A で H2 より強く、ほかの着地点では差が見えず、どの式でも説明できていない（C-0157）。

## 1. 式と範囲

- 的の表の弾丸命中率 p、命中率▲ N について、**p′ = 1 − (1 − p) ^ (1 ÷ (1 − N)²)**。
  - N ≥ 1 なら 1（コア命中率の C-0037 と揃える。確かめていない）。
  - N ≤ 0 なら p のまま（命中率▼の効き方は測っていない。コア命中率と同じ扱い）。
  - p = 1（SR・RL の表）は 1 のまま。合わせる係数は無い。
- **効かせる武器種: AR・SMG・MG**。表の値が 0.97 以上の帯（AR・MG の全部、SMG の近・中近）では、N が 0.15 でも上がりは 3% 未満。
- **SG は効かせない**（C-0157 と H2 が合わない）。注記に未実装と出す（いまの注記を SG に絞る）。
- 手入力の弾丸命中率と、表が null（未測定）の項目には効かせない（未測定の値に式を掛けない）。

## 2. 入れ方（core）

1. `frame/landing.ts` に `bulletHitRateWithHitRateUp(p, N)` を足す（1 節の式）。効かせる武器種の判定も同じ所に置く。
2. `autoConditionAt`: 表から取った弾丸命中率に、効かせる武器種なら 1 を掛ける（常時の N。計画の値）。
3. `LandingPart` に `tableBulletHitRate?: number`（効かせる武器種で、表から取ったときだけ。▲を掛ける前の値）を足す。`planLandings` が入れる。
4. `landingPartsWith`: `tableCoreHitRate` と同じく、`tableBulletHitRate` のある部分の `condition.hitRate` を区間の N（常時 + 持続）で出し直す。早い戻りは「どちらも無ければ」に直す。キャッシュの鍵は今のまま。
5. **1 パス目のゲージ**: 計画の値を使うので、常時の▲の上がりはゲージにも入る（AR・SMG の 1 発のゲージは弾丸命中率に比例。いまの扱いのまま）。**持続の▲の上がりはゲージに入れない**（被覆率の設計書 4.3 と同じ理由。1 パス目は持続の `hitRate` の窓を追っていない）。持続の▲の中では、モデルのゲージが実際より遅く溜まる側にずれる。注記に未実装と出す。
6. **注記と表示**:
   - `landingNotes` の `auto-condition` の文: 「命中率▲は弾丸命中率に効かせていない」を、武器種で分ける。AR・SMG・MG は「命中率▲（常時 + 持続）で外れの割合を (1 − p) ^ (1 ÷ (1 − N)²) にした（C-0192。仮説。確かめたのは SMG の遠だけ）。持続の▲の上がりは 1 パス目のゲージには入れていない」。SG は今の文のまま（C-0157）。
   - 画面の `NotesSummary.tsx` の全体の注記と README の 2 か所を、同じ内容に直す。条件欄（`SlotCard.tsx`）の「弾丸命中率」は発数平均で、`autoConditionSummary` が `landingPartsWith` を通るので、▲込みの値がそのまま出る。
7. **結論のモデル側**: C-0192 の `model` を「反映（仮説として。AR・SMG・MG。SG は未反映）」に直す。C-0157 のモデル側（SG は未反映）は変えない。

## 3. 確かめ方

- テスト（`stage18Landing.test.ts` などに足す）:
  - `bulletHitRateWithHitRateUp`: 表の SMG の遠の値で、ミサト S1 の 3 スタック（C-0183 の N）のとき 1 節の式どおり。N ≤ 0・N ≥ 1・p = 1 の端。
  - `planLandings`: 常時の▲のある SMG は表の値より上がり、SG は変わらない。手入力の枠は変わらない。
  - `landingPartsWith`: 持続の▲の区間で、コア命中率と弾丸命中率の両方が出し直される。
  - 1 パス目: 常時の▲のある SMG の枠はゲージが上がり、持続の▲では変わらない。
- 照合: 実装の前後で `npm run records:check` の残差を並べ、PR に書く。動くのは、条件が自動で▲が乗る枠（ミサト・ミランダ・ドレイク・モダニア・アスカのいる録画と、スペック固定 OFF の▲）。V-0118 のミサトの当たった数は、実測に近づく向きになるはず。どの録画でも、遠ざかったら原因を調べてから PR に書く（係数で埋めない）。
- 単騎で▲の無い録画（リターなど）の値は変わらない。

## 4. 確定に上げる撮影（この PR の後。別のブランチで起案する）

- 目的: C-0192 の判定の目安（ほかの候補はどれかの群で 3σ 以上離れる）を、H1 についても満たすか。
- **案 A（推奨）**: 群 2 と同じ組（ミサト・スペック固定 ON と、同じ日のリター）を 3 本ずつ撮り足す。V-0118 の群 2 と合わせた 6 本で q を出す（合わせることは撮る前に固定する）。V-0118 の群 2 の q が H1 から離れた幅が今のままなら、本数が倍になって σ が約 1/√2 になり、H1 から 3σ を超える見込み。機構が確定したキャラだけの最小構成。
- **案 B**: N をもっと大きくする（▲が大きいほど H1・H2 の予測が離れ、少ない本数で見分けられる）。単騎で N を足す手は、スペック固定 OFF の装備・キューブの▲になり、撮影の日の育成に依る。
- どちらでも、予測は実装した H2 のモデルで `records:predict` から出せる。H2 が落ちたら（2σ の外）、モデルから外して表の方式（SMG の遠の 3 点（`152-03`）から）に移る案をオーナーに諮る。

## 5. 決めてほしいこと

1. 効かせる武器種を AR・SMG・MG にし、SG は未反映のまま注記する（1 節）。
2. 持続の▲の弾丸命中率の上がりは、1 パス目のゲージに入れず、未実装と注記する（2 節の 5）。
3. 確定に上げる撮影を案 A にする（4 節）。

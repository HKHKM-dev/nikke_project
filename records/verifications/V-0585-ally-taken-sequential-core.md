3. 鈴原サクラの 1 ヒットの段から、▲の窓（付いたフレームと切れたフレーム）を決める。マリアン：クイーン（MG）と鈴原サクラ（SMG）がほぼ毎フレーム撃つので、増分は通常攻撃の和になりうる。そのときは V-0581 の「読み方」（候補の値を引いた残りが、前後 10f に繰り返し出る増分と ±2 で一致するか）で分ける。決まらない区間（鈴原サクラのリロードの空き・▲の付き始めと切れ目）は数えない。
4. 槍: I-DOLL・サンの窓の槍の発動を、発動のフレームの▲の有無で分け、1 ヒット（重なりを引いた値）を HS・HA と比べる。

6. 分かれた 1 ヒットを観測値にし、いまのモデル（HS）と比べる（`npm run records:residual`）。

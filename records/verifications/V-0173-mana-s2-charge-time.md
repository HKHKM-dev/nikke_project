# V-0173: マナ S2 のチャージ時間▼は基本チャージ時間が最も長い味方に付くか（録画 020 の読み直し）

- 問い: マナの S2（マターシグマ）の「フルバーストタイムが発動した時、基本チャージ時間が一番長い味方 1 機にチャージ時間 0.18 秒▼（10 秒）」は、チャージを持つ唯一の味方（デルタ）のフルバースト中の発と発の間を縮めるか
- 話題: スキル・キャラ固有
- 日付: 2026-10-05
- 録画: `020`
- 状態: 調査中

## 条件

- 設計: [design-target-vocab.md](../../plan/design-target-vocab.md) 4.2 節（2026-10-05 にオーナーが承認。論点 4 は推奨どおり、読み直しで始める）。語彙 `longestChargeTime` と `chargeSpeed` の `scaling: "flat"`（秒）は実装済みで、定義（`data/skills/290.json` の skill2）にはまだ入れていない（notes の未対応）。
- 録画 020: エーテル（291・SG。AI）+ デルタ（20・SR・チャージ 1 秒。AI）+ マナ（290・AR。操作）、BigArms（電撃・防 100）、射撃場 3 分、スペック固定 ON、オートバースト ON。フルバースト 5 回（`020-01`）。
- 基本チャージ時間（CDN の `shot.chargeTime`）はエーテル 0・デルタ 1・マナ 0 で、最も長い 1 機はデルタ。同値は無い。
- デルタの射撃の間隔に効きうる効果: エーテル（定義なし）の S1（受けるダメージ▼）・S2（敵へのダメージ・防御力▼）・バースト（バリア）はどれも射撃の間隔に効かない。デルタの 3 スロットはダメージに効かない（C-0081）。マナの S1（攻撃力▲）・S2（攻撃ダメージ▲・攻撃力▲・ゲージ速度▲）・バースト（持続ダメージ）も間隔に効かない。
- **最小構成について**: エーテルは「機構が確定したキャラ」ではないが、説明文に射撃の間隔に効く効果が無い。見る値に効く未確定の要素は無いという読みで、警告はオーナーの判断（論点 4）で通す。
- 既に読んだ値: デルタの射撃の間隔は読んでいない（`020-01`〜`020-07` は時計・ゲージ・ジャンプ）。録画 043（5 人。読み済み）のアリスの間隔は、マナの回の 101f が −0.18 秒で説明でき、アリスの回は 24f（見込み 22f）。これは仮説の出どころで、比べる指標にはしない。

## 予測（撮る前に書く）

既存の録画の読み直し。予測ファイル `records/predictions/V-0173.json` を読む前に commit する。

| 仮説 | 中身                                                                                                 | n 回目のフルバーストの窓の中と前の、デルタの発と発の間の中央値の差（動画のフレーム） |
| ---- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| H0   | マナの S2 のチャージ時間▼は無い                                                                      | 0（予測ファイル `delta-fb0-interval-diff`〜`delta-fb4-interval-diff`）               |
| H1   | フルバーストの開始に、基本チャージ時間が最も長い 1 機（デルタ）のチャージ時間が 0.18 秒縮む（10 秒） | 5 回とも同じ値（約 −10f。0.18 秒 = ゲーム内の約 10.6f）                              |

- 見分け方: 差は窓の中と前の両方の中央値なので、時計の傾き（C-0048・V-0168）は 1 秒に 1f 未満で消える。発のフレームの読み取りは ±1f。**判定の幅は ±2f**（中と前の読み取りの ±1f を足した分）。5 回のうち読めた回がすべて同じ仮説の幅に入れば、その仮説が合う。
- 外れたとき: H0 なら、チャージ時間▼は付かない（対象が違う・この編成では起きない）。H1 から −2f を超えて外れるなら、秒数の引き方（`chargeTimeFlat` の置き場所）か、0.18 秒の読みが違う。

## 読み方

- 取り寄せ: `node tools/captures/fetch.ts 020`。
- デルタ（AI）の発のフレームは、枠のアイコンの上の残弾の表示（`ammo.ts`。3 人編成のデルタの枠の位置を切り出して合わせる）か、HUD の増分（`hud.ts --mode jumps`。デルタのフルチャージの増分は数十万で、エーテル・マナの増分と大きさで分かれる）で読む。
- フルバーストの窓は、画面の FULL BURST の表示（`020-01` と同じ読み方）で区切る。窓の中の発と発の間（両端が窓の中）と、窓の前の同じ長さ（10 秒）の発と発の間（リロードをまたぐ間を含む。中央値で外す）の中央値の差を、回ごとに観測値にする。

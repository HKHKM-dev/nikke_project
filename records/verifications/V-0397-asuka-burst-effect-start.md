## 条件

**何を確かめるか**

- III のバースト使用時の効果は、3 キャラとも III のタイマーの 00.00 より前（入りの止まりの前）の発に乗り、補正は乗らなかった（C-0510・C-0511・C-0513）。付き始めは、雪子では CT の明け（00.00 の 6〜8f 前。C-0512）とほぼ同時、ルドミラ：WO では 00.00 の 1〜2f 前で、ラピは見分けられなかった（V-0396）。
- アスカ（830）は AR（発の間隔 5f。`063-14`）で、バースト使用時の攻撃ダメージ▲（150.04%・10 秒。`data/skills/830.json` の burst の effects[0]）が 1 発の値を大きく変える。00.00 の 7〜1f 前に 1〜2 発ある見込みで、付き始めの形を見分けられる回がありうる。
- あわせて、S2 の「フルバーストタイムが発動した時」の灼熱の味方のコアダメージ▲（60.07%・10 秒。skill2 の effects[0]）が、00.00 の前の発に乗るか（バースト使用と同じ時刻か、補正の窓の始まりと同じ 00.00 か）を見る。

**編成**

- 録画 `063`: I-DOLL・フラワー（304。I）+ デルタ（20。II）+ アスカ（830。III・操作・AUTO 射撃 ON）、オートバースト ON。射撃場・灼熱の BigArms・3 分モード・スペック固定（V-0022）。
- **最小構成**: フラワー・デルタは機構が確定。アスカのほかの効果のうち 00.00 の前後の発の値に効くのは、S1 の回復を受けた時の攻撃力▲（96.98%・25 秒。C-0464・C-0087。バーストの回復（攻撃ダメージの 3.16%）で付く）と、バーストの命中率▲（C-0076。AR の弾丸命中率に効くが 1 発の値には効かない）。S1 の▲は付く時刻が「最初の回復の後」なので、00.00 の前の発では▲の有無を値で分ける。

**読み方の前提**

- アスカの 1 発の値は、バーストの前（▲なし）と、止まりの明けの後（攻撃ダメージ▲・S1 の攻撃力▲・コアダメージ▲・補正）の値から、▲ごとの倍率を当てて分ける（攻撃ダメージ▲は 1 + 1.5004 倍の足し算の群、S1 は攻撃力、コアダメージ▲はコアの発のコアの倍率に足す。胴体の発には乗らない）。

## 分かったこと・分からないこと

- **C-0514（仮説）**: アスカのバースト使用時の攻撃ダメージ▲は、00.00 の 5f 前の発には乗らない。雪子（CT の明けとほぼ同時。C-0511）の形より、ルドミラ：WO（00.00 の 1〜2f 前。C-0510）の形に近い。4 キャラのうち、CT の明けの頃に付くのは雪子だけで、雪子の 1more の▲はバーストのヒット（00.00 の 1f 前。C-0419）より前に付く特別な形かもしれない（確かめていない）。
- 分からないこと: アスカの付き始めが 00.00 の 4〜1f 前か 00.00 か。フルバースト開始時の効果（S2）の付き始め。
- **最小構成**: C-0514 をアスカの burst の effects[0] に結んだので、確定の結論 4 件に警告が出た（C-0075 の `063-05`、C-0082 の `078-05`、C-0087 の `080-06`・`284-06`〜`284-08`、C-0345 の `264-03`〜`264-05`・`265-03`〜`265-05`）。比べるモデルのフレームはどれもアスカのバーストの窓の端から 96f 以上離れているか、録画にアスカのバーストが無いので、付き始めの数 f に効かない。それぞれの `minimal` に印を書いた（警告の件数は main と同じ）。

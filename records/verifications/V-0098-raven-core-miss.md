## 条件

- `V-0097` の弾の種類のうち、直進弾・弾速 400・爆発の範囲 500。紅蓮：ブラックシャドウ（直進弾・弾速 400・爆発の範囲 50）と弾速と弾の種類が同じで、爆発の範囲だけが違う。H1c（爆発の範囲）を分ける。
- レイヴン（851）は SSR・Attacker・鉄甲・バースト 3 段階。通常攻撃はチャージ 1 秒・装弾数 6（キャラデータの `shot`）。
- 最小構成は単騎（`V-0097`「条件」）。スキルの見込み（スキル定義は無い。モデルは通常攻撃だけ）:
  - S1: フルチャージの攻撃で、照準線に最も近い敵に持続ダメージ（1 秒ごと・スタック）。HUD の増分に 1 秒ごとの tick が混ざる。tick は通常攻撃の 1 ヒットと別の値なので、同じフレームに重なった増分は和に分けて読む。弾の行き先は変えない。
  - S2: 戦闘開始時とフルバーストで「急所攻略：パーツダメージ▲」。パーツを壊したときの効果もある。的のコア・胴体のダメージには効かない見込み（パーツに当たった発が出たら注記する）。
  - バースト: 単騎ではバースト 3 段階のバーストを使えないので起きない（自動バースト OFF）。

## 予測（撮る前に書く）

仮説ごとの見え方は `V-0097`「予測」の表のレイヴンの列（H1c なら外れがフラワーと同じ程度、それ以外ならほぼ 0）。予測ファイル `records/predictions/V-0098.json` には、いまのモデル（H0。コア命中率 1）の 1 ヒットの値（胴体・コア × 会心。増分をコアと胴体に分ける鍵）と、180 秒の射撃の数（区間ごとの母数の合計の目安）を固定した。H1a〜H1c はモデルの入力で表せないので、このファイルの範囲外。

- 1 ヒットの値が予測と合わないときは、スキルの効果（攻撃力に効くもの）が乗っている疑い。コアと胴体の比（2 倍）で分けられれば、区間ごとの数えには差し支えない。

## 読み方

1. `tools/captures/intake.ts` で取り込む（`--rid 851 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec on --auto-fire on --auto-burst off`）。台帳を埋めて `npm run records:table`。
2. `npm run records:read -- <録画 id> --recipe hud-jumps` で増分の列を出し、`V-0097`「読み方」の 1 と 3 のとおり、1 発の値（予測ファイルの `hit-body`・`hit-body-crit`・`hit-core`・`hit-core-crit`）と S1 の持続ダメージの tick の和に分けて、発のフレームと、コアか胴体かを取る。
3. 区間の切れ目（的のジャンプの窓）をこの録画で読み、区間ごとに「撃った発（部分チャージの発を除く）」「コアを外した発」「そのうち着地の後の 1 発目」を観測値（`use: "record"`、`source: V-0098`）にする。撃った発の数の合計は、予測ファイルの `shots` と比べる観測値（`shotCount`）にもする。1 ヒットの値が読めたら `hitDamage` の観測値にする。
4. 比べと判定は `V-0097` で行う。この記録は、`V-0097` の結論ができたら、その結論を裏付けた記録として閉じる。

## 分かったこと・分からないこと

- 直進弾・弾速 400・爆発の範囲 500 のレイヴンは、どの区間でもコアを外さない（`122-05`）。紅蓮BS と弾速が同じで爆発の範囲だけが違うので、爆発の範囲は効かない向き（H1c と合わない）。判定は `V-0097` で行う。
- 1 ヒットのコアの値はモデルと合う（`122-02`・`122-03`）。
- 問いの外で見えたこと: 発の刻みが 119f で、チャージ時間・連射速度が同じフラワー（82f）より長い（`122-06`）。A2 も同じ（`123-05`）。モデルは約 82f で撃つので、180 秒の射撃の数がモデルより約 3 割少ない。原因は分からない（plan/roadmap.md「今後の課題」に起票）。

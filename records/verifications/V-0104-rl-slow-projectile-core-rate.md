## 読み方

1. `tools/captures/intake.ts` で取り込む（`--rid 304|160|103 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec on --auto-fire on --auto-burst off`）。台帳を埋めて `npm run records:table`。出撃画面と戦闘履歴は録画の先頭と末尾の 1 秒ほどにあるので、先頭・末尾のフレームで確かめる（plan/captures/guide.md「画面の読み方」）。
2. `npm run records:read -- <録画 id> --recipe hud-jumps` で増分の列を出し、V-0097「読み方」と同じく 1 発の値（胴体・コア × 会心）に分ける。ジャンプの窓は射撃の空きから候補を出し、画面で確かめる。ラプラスUH は変わる前の武器の発だけを数える（V-0100「読み方」）。
3. 録画ごとに、区間ごとの「撃った発（フルチャージ）」「コアを外した発」「そのうち着地の後の 1 発目」を観測値（`use: "record"`、`source: V-0104`）にする。
4. キャラごと・弾の種類ごとに距離帯（近・中近・遠・中遠）の割合を出し、録画どうし・キャラどうしを二項分布の幅で比べる（`077`・`121` も合わせる）。

（2026-10-03。ユニの 2 本（`128`・`129`）とラプラスUH の 2 本（`130`・`131`）を読んだ。「次に撮るもの」の 6 本がそろった）

- 「予測」の仮説と比べると:
  - H0（弾の種類ごとに 1 つの割合）: 誘導弾は、近・中近・遠でフラワーとユニが幅の中で揃い、録画どうしでも揃う。直進弾 100 のラプラスUH も 4 つの距離帯で 3 本が揃う（遠はやや散らばる）。
  - H1（キャラで違う）: 誘導弾の中遠だけ、フラワーとユニで違う。ただし違うのはユニの `128` の 1 本で、`129` はフラワーと同じ程度なので、キャラの違いより録画の違い（H2）の向き。
  - H2（録画ごとに散らばる）: ユニの中遠で出た（`128` と `129`）。原因は分からない。`128` の 4 区間目は的が手前のコンテナの後ろを通った（コンテナに当たった発がある）ので、的の横の位置が効く見込みはあるが、確かめていない。ほかの録画の中遠の的の位置は見ていない。
- まとめ: 近・中近・遠は、弾の種類ごとに 1 つの割合で持てる（録画どうし・誘導弾のキャラどうしで揃う）。誘導弾の中遠は録画で散らばり、1 つの値に決めきれない。
- 分からないこと: ユニの `128` の中遠の外れの原因（的の横の位置か）。誘導弾の中遠の割合が `128` の方か、残りの 4 本の方か。外れが発ごとに独立でないときの、割合の本当の幅。

**オーナーに決めてほしいこと（表に値を入れる案）**

表（`data/enemies.json` の `range-bigarms` の `coreHitRate.RL.byProjectile`）は、行のキーに距離帯（`near`・`midNear`・`far`・`midFar`）を書ける。値はコア命中率（1 − 外す割合）で、着地の後の 1 発目は除いた（`ProjectileDirect:400`・`300` の行が 1 なのと同じ扱い。V-0091 の問い）。跳び始めの直前の発は除いていない。

| キー                   | 近     | 中近   | 遠     | 中遠                                            | 根拠の録画         |
| ---------------------- | ------ | ------ | ------ | ----------------------------------------------- | ------------------ |
| `HomingProjectile:100` | 0.9817 | 0.8851 | 0.5914 | 案 1: 未測定のまま / 案 2: 0.7407（5 本の合計） | フラワー 3・ユニ 2 |

- **推奨は誘導弾の中遠を案 1（未測定のまま）にし、ほかの 7 つを入れること**。理由: 7 つは録画どうし（と誘導弾のキャラどうし）で揃ったので、反復実測の結論にできる。誘導弾の中遠は録画で散らばり、どの値にも根拠の結論を作れない（AGENTS.md「根拠のない変更は行わない」）。未測定の距離帯は、今と同じく手入力の値（既定 1）と未測定の注記になる（`targetRateOf` は行に距離帯のキーが無ければ null を返す）。
- 案 2 は 5 本の合計をそのまま入れ、散らばりを注記する。`128` を除いた値（0.8194）は、除く根拠が無いので案にしない。
- 誘導弾の中遠を決めるには、ユニかフラワーの単騎をもう 2 本撮り、中遠の的の位置（コンテナの後ろを通るか）と外れの関係を見る（「次に撮るもの」）。
- 結論の下書き（判断の後に `npm run records:new -- claim --from V-0104` で作る）:
  1. 「射撃場の的（BigArms・3 分モード）で、誘導弾・弾速 100 の RL（I-DOLL・フラワー・ユニ）の単騎 AUTO の通常攻撃がコアを外す割合は、近・中近・遠の距離帯ごとに、録画どうし・キャラどうしで揃う（着地の後の 1 発目を除く）。中遠は録画で散らばる」。等級の見込みは反復実測。

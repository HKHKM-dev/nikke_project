# V-0754: クルミの 0059 の F4729 のまとまりの始まりの位相のぶれは、付いた後の発の刻みの飛びか（録画 0059 の読み直し）

- 問い: 0059 の F4729 のハッキングのまとまりの φ −2〜−1 ミリ秒（V-0744）は、0058 の F4724 と同じく、付いた後の時計の飛び（発の刻みと tick が同じだけ早まり、残り時間に出ない。V-0753）か
- 話題: スキル・キャラ固有
- 日付: 2026-11-12
- 録画: `0059`
- 結論: `C-0454`
- 状態: 完了
- 派生元: `V-0753`

## 条件

- V-0744: 0059 の F4729 のまとまり（38 tick）の始まりの φ は −0.11〜−0.06（−2〜−1 ミリ秒）。
- V-0753: 0058 の F4724 のまとまりは、付いた後の 4852 → 4856 で発が 1f 早く出て、発の刻みが 1.7〜3.0 ミリ秒ずれ、tick の φ と合った。0059 の F4729 のまとまりは、HUD の増分から取った発の 49 発で刻みがずれないとした（`0059-07`）。
- 0059 の 4967 の HUD の増分は「80」と読まれ（読み違い）、4968〜4985 の 18 フレームは HUD が読めていない。

## 予測

なし（V-0753 の数値を見た後の読み直し）。

## 読み方

1. tick の 1 つずつについて、付いた発 F4729 からの ceil(φ + k × 58.8235) の φ の許す範囲（ミリ秒）を出し、−2〜−1 を決めている tick を探す。
2. 発のフレームを、照準の横の残弾（`reticle-ammo.ts --mode series`。1 フレームずつ前後とも読めて 1 だけ減った所）から取り、マガジンごとに発の刻みの位相 θ を当てはめる（V-0753 と同じ。HUD の増分は使わない）。
3. 刻みから外れた発のフレームの前後を、ffmpeg で照準の横と画面上部の総ダメージを 1 フレームずつ切り出して目で読む。

## 結果

観測値は `0059-08`。

- tick の φ の範囲: 下の端 −2 ミリ秒は k = 5（5024）・22・39、上の端 −1 ミリ秒は k = 11（5376）・28 が決める。k = 1〜10 だけなら −2〜1 で、始まりの φ（0〜1）とも合う。φ が −2〜−1 になったのは、F から k = 11 までのどこか（0058 の F4724 も同じ並び）。
- 発の刻み（残弾から取った発）: 4724 を基準にすると、4724〜4999 の 52 発のうち 51 発が θ −0.3〜0 ミリ秒で、4969 の 1 発だけが 1f 早い（刻みどおりなら 4970）。5081 からのマガジンの 56 発は θ −0.3〜0 ミリ秒（リロードの後で、刻みの基準が戻る）。
- 目読み（4964〜4970）: 残弾は 008（4964）→ 007（4965〜4968）→ 006（4969・4970）。総ダメージは 4965 に 46,693,582（+133,411 = 1 発と tick）、4969 に 46,775,391（+81,809 = 1 発の 2 倍）。4969 に 1 発が出ている。
- 4969 の 1f 早い発は、i = 50（刻みどおりなら 245.098f）の発で、時計が 0.098〜0.5f（1.7〜8.5 ミリ秒）早まると出る（後の 4974〜4999 の発が刻みどおりなので 0.5f 未満）。tick の φ のずれ（0〜1 → −2〜−1 で、1〜3 ミリ秒）と合わせると 1.7〜3 ミリ秒。時刻は 4965〜4969 で、k = 4（4965）と k = 5（5024）の間。残り時間の区間 4441〜7441 は a 1.24 の 1 つ（止まりなし）。
- V-0753 の「0059 の F4729 は付いた後の発に飛びが無い」（`0059-07`）は、HUD の増分だけを使い、4969 の発（HUD が読めていない 18 フレームの中）を落とした読み違い。

## 分かったこと・分からないこと

- **0059 の F4729 のまとまりのぶれも、付いた後の 1.7〜3 ミリ秒の時計の飛び（発と tick が同じだけ早まり、残り時間に出ない）で説明がつく**。クルミの始まりの φ のぶれは 2 つとも、まとまりの始まりではなく途中の飛びだった。クルミのハッキングの起点は、付いた発のフレームで φ 0〜1 ミリ秒（例外なし）。
- 飛びは 0058 で 4852〜4856（戦闘開始から約 70 秒）、0059 で 4965〜4969（約 72 秒）。どちらも 1 回目の的のジャンプの窓が明けた後のマガジンの中。出どころは分からない。
- 残る説明のつかないぶれは、レイヴンの 0122 の F2136（0.12〜0.17。V-0747）だけ。RL の発からは時計の飛びが読めない。

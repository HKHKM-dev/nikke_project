# V-0739: 射撃姿勢維持型の RL へのチャージ速度▲の効き方（レイヴンの読み直し）

- 問い: 射撃姿勢維持型の RL のチャージ速度▲（チャージ時間の短縮）は、チャージだけを縮めるか、姿勢の長さ・満ちてから撃つまでにも効くか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-12
- 状態: 調査中
- 派生元: `V-0729`
- 録画: `0362`、`0407`

## 条件

- 型: 読み直し（撮影なし）。C-1103（仮説）と、3 節の残差 `1084-11`・`1085-11`（A2 の B モードの間の発と発の間がモデルより短い）の原因を、同じ射撃姿勢維持型のレイヴンで見分ける。
- いまのモデル（C-0216・C-0217）: 射撃姿勢維持型の発と発の間 = 姿勢の長さ ⌈S⌉ + 12f + チャージ C − 1（S = `maintainFireStance` ÷ 100 秒をゲーム内の時計で数えた長さ。満ちてから撃つまで H = ⌈S × `uptypeFireTiming` ÷ 10000⌉ は S の中にある）。チャージ速度▲は C だけを縮める（`frame/firing.ts` の `chargeShotIntervalFrames`）。レイヴンは S = 48.82f → 49・H = 16・C = 59 で 119f、A2 は S = 49.41f → 50・H = 24 で 120f。
- 読む録画: ココア（I）+ ソルジャーF.A.（II）+ アリス（III・操作）+ レイヴン（III・AI）。スペック固定 ON・オートバースト ON（`0362`・`0407`。V-0357・V-0407 の録画）。
  - アリスの S1（フルバーストの始まりに、最終攻撃力が最も高い味方 1 機へ、発動者基準のチャージ速度▲ 10 秒）。モデルではレイヴンに付き、発動者のチャージ時間からの 0.175 秒の短縮（`chargeTimeFlat`）になる。レイヴンのチャージ時間は 1 秒なので、チャージは 0.825 倍（比率の 17.5%▲と同じ）。窓の中のモデルの発の間は 109f、窓の外は 119f。
  - 9 回のフルバーストのどれも窓になる（III はアリスとレイヴンが交互）。レイヴンのバースト（A.N. モード）は持続ダメージ▲だけで、射撃を変えない。
- ユニの S1 の録画（`0303`・`0304`。チャージ速度 8.97%▲）は、形の差が小さい（下の表で 1〜6f）ので、0362・0407 で決まらないときに読む。
- 混ざる要素: アリスの▲がレイヴンに付くかはモデルの読み（`topAttack`）。付かなければ窓の中も 119f のまま。射撃場の的のジャンプ（撃てない窓）を跨ぐ間と、窓の端を跨ぐ間は使わない。

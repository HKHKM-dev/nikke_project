## 予測

なし。見分け: 本当の遅れ 0〜2f（C-0258）と、旧の「4〜7f」（欄の表示で数えた遅れ）は、CT の 0 どうしの間隔の読み（±0.5f）で分けられる。1 本に CT が律速の発動が 3〜4 回、CT の 0 どうしの間隔が 2〜3 個。

## 読み方

1. `timer.ts --mode changes` で時計の傾きと止まりを読む。
2. 右のバースト欄を ffmpeg で 1 フレームずつ切り出して目で読み、CT の 0（最後に出た 1/100 秒の値 u とそのフレーム g から g + u ÷ 0.017）、新しい CT の秒（「40」）が出たフレーム、次の段のアイコンのフレームを取る（V-0164 と同じ。画像はコミットしない）。
3. 本当の遅れ = CT の 0 どうしの間隔 − あいだの止まり − その録画の時計の傾きで数えた 40 秒。
4. 判定の目安: 本当の遅れが 0〜2f（読みの幅 ±0.5f）で、欄の CT の秒が CT の 0 の 3〜4f 後に出れば再現。

## 分かったこと・分からないこと

- **C-0258 は、決めるのに使っていない録画 4 本で再現した**: CT が律速の I の発動 14 回・CT の 0 どうしの間隔 11 個（`358-03`〜`361-05` の 12 件）。チェーンの II・III の 30 回も同じ並び。CT が律速の発動は 3 回を大きく超えたので、撮影 G は要らない。
- 結論の見込み: C-0258 は確定に戻せる。等級の候補は反復実測（根拠の録画 018・019・021 に加え、決めるのに使っていない 358〜361 の再現。編成のサクラ・デルタ・I-DOLL・サンは機構が確定したキャラで、`cooldownReduction` を持つキャラはいない）。根拠に `358-03`〜`358-05`・`359-03`〜`359-05`・`360-03`〜`360-05`・`361-03`〜`361-05` を足す。
- decidedOn: 止まりの取り方（直前の 10 個の変わり目の切片）は 358・359 を読みながら決めたので、358・359 を「読み方を合わせた」として足し、再現は 360・361（I の発動 7 回・間隔 5 個）で数える（2026-10-11 のオーナーの判断。厳しいほう）。取り方を変えた値（各観測値の注記の 5 個・20 個）も含めて目安に入る。
- → C-0258 を確定（反復実測）に戻した。
- 分からないこと:
  - 361 の 2 回目のフルバーストの区間の止まりがほかより約 3f 長い（`361-04` の注記）。間隔もその分長いので、その止まりのあいだも CT は進まない見込みだが、止まりの中身（入りの止まりの長さか、ほかの止まりか）は読んでいない。
  - 360 の 5 回目のように、欄の表示が前のフレームのまま残る録画の揺れ（キャプチャの重複）のある回の扱い。この検証では除いた。

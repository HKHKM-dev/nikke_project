## 予測（撮る前に書く）

予測なし。新しく撮る録画も読む値も無く、V-0096 で読んだ `118-04` を、直した N の式の値と比べ直すだけ。比べる式の値は、モデルの `coreHitRateWithHitRateUp`（`packages/core/src/frame/landing.ts`。C-0036）に、的の表の SMG の近（`range-bigarms`。0.2644）と N を入れて出した。

## 読み方

- 比べるのは `118-04` の「2 つの▲（0〜10 秒）− 外」の差（+0.179 ± 0.041。100f のブロック間の分散）。V-0096 の判定の目安（0 から 3σ 以上・H1 と 2σ の中で H1）をそのまま使う。
- モダニアだけの窓（10〜15 秒。N = 0.0856）と、114〜117（モダニアだけの▲か▲なし）の N は、ドレイク S1 を含まないので変わらない。

## 結果

| 2 つの▲の窓の N                     | 式の値（窓の中） | 式の差（窓 − 表の値） | `118-04` の差との隔たり  |

- V-0096 の「中と外の比は 1.83（式は 1.58）」の式の比は、直した N では 1.96。

## 分かったこと・分からないこと

- V-0096 の N（0.2041）は誤りで、正しくは 0.2865。判定（H1）は変わらないが、118 の差は直した式の値より 1.9σ 小さい。V-0165 でも、宝物版の N の H1 と合った（H1 から 1.2σ。実測のほうが大きい）。2 つの録画で、ずれの向きは逆。
- C-0170 の basis の N と σ の書き方を直した（この記録と V-0165 を足した）。C-0170 は仮説のまま（2026-10-05 のオーナーの判断）。
- 分からないこと: 118 の差が式より小さい（1.9σ）のは、4 体の編成で▲が 2 つ重なるとき（「▲は N の和で効く」）の効き方か、ばらつきか。V-0165 はドレイクの▲ 1 つだけなので、「和で効く」は確かめていない。

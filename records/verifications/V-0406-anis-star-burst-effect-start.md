## 条件

**何を確かめるか**

- 遅れの表（`burst/landing.ts` の `MEASURED_BURST_DELAYS`）にアニス：スター（17）の行は無く、バースト使用時の 3 つの効果（`data/skills/17.json` の burst の effects[0] シューティングスター・effects[1] チャージ時間固定・effects[2] 攻撃ダメージ▲）は本当の発動（六角形の替わり目の 6f 前。C-0503）で付く。シューティングスターのダメージは、発動から 0.25 秒ごとの刻みのフレームに置く（飛ぶ時間を足さない。ゲージだけ刻み + 飛ぶ時間。C-0504）。
- バースト使用時の効果の付き始めはキャラごとに違う（V-0399。HA: 表示の 5〜6f 前・HD: 1〜2f 前・HM: 表示の後）。I のアニス：スターはどの形かを、3 つの効果で別々に見る。
- チャージ時間固定は、押下チャージ型なのでチャージの途中で切り替わり、経過が 0.7 秒を超えていれば切り替わりの直後に撃つ（C-0380 の P1）。その発の発射のフレームが、切り替わりの時刻を直接示す。
- シューティングスターの最初のヒットの時刻は C-0211 で「確かめていない」。最後のヒットはチェーンの待ちの明け（替わり目の 588f 後）の後に、距離帯ごとに 4〜28f（C-0504）。

**編成**

- 録画 `320`・`321`（V-0297）: 同じ単騎・オートバースト OFF。バーストは遠の区間で手で使い、窓は 2 回ずつ。手で使うので、発動と発の位相が回ごとに違う。

  - 3 つの効果は同じ時刻に付く（同じ `burstUse` のきっかけ）。
  - シューティングスターの最初のヒットは H + 15 + D（上の値）。
- 既に見ていた値: 164 の替わり目（`164-16`・`164-36`）と、窓の発の値（`164-28`）、320・321 の窓の発の着弾のフレームと値（`320-04`・`321-04`。替わり目との位置は読んでいない）。
- 外れたときの影響: どの形でも、1 回のバーストで替わり目の前の 0〜1 発の▲の有無と、窓の最初の発の発射の数 f。O が −6 から離れていれば、モデル（本当の発動）との差として結論の `model` に書く（モデルは直さない。plan/burst-effect-delay-candidates.md 2.7 節の案 C）。シューティングスターの最初のヒットが H + 15 + D から外れれば、刻みが等間隔でないか、最初の刻みの置き方（`firstTick: afterInterval`）が違う。

## 読み方

1. 六角形の替わり目 H: 右のバースト欄（crop=200:60:1720:410）を 1 フレームずつ並べ、I の六角形の緑が終わったフレーム（`164-36` と同じ）。164 は既にある値を 1 フレームずつ並べて確かめる。
2. 発: HUD の増分（`hud-jumps@2` のキャッシュ）で着弾のフレームと値（▲の有無）、照準の横の残弾（`reticle-ammo.ts --mode series`）で発射のフレームを、H の 120f 前から 60f 後まで並べる。
3. 攻撃ダメージ▲: H の前後で、▲の無い最後の発と▲の付いた最初の発の発射・着弾のフレーム。
4. チャージ時間固定: H を跨ぐ発射の間隔（F0 → F1）。F1 − F0 < 59 なら、P1 で O = F1 − H − 1（経過が 42f を超えている回だけ）。
5. シューティングスター: H の後の最初の 60,902・121,805（会心は 91,353・152,256）の増分のフレームと、その時の距離帯（`164-31` などの区間）。発の値と重なった増分は、発 1 つ + シューティングスター 1 ヒットに分ける。

## 分かったこと・分からないこと

- **C-0520（仮説）**: アニス：スター（I）のバースト使用時の効果は、替わり目の 4f 前の頃（本当の発動の 2〜3f 後）に付く。V-0399 の形では HA（本当の発動の頃）と HD（表示の 1〜2f 前）のあいだで、どちらとも少し違う。モデル（本当の発動）との差は、1 回のバーストで窓の最初の 1 発の発射の 2〜3f（経過が 0.7 秒を超えていた回だけ）。
- **C-0521（仮説）**: シューティングスターの最初から最後のヒットまでは、モデルの刻み（573f）より 3〜4f 長い。最初のヒットから通常攻撃の飛ぶ時間（`164-31`）を引くと、どの帯も替わり目の 8〜9f 後（本当の発動の約 15f 後 = 最初の刻み）にそろうが、シューティングスターの飛ぶ時間が通常攻撃と同じかは確かめていない。付き始めと飛ぶ時間は、ヒットだけでは分けられない。
- 新しく見えたこと（1 回。結論にしない）: RL の通常攻撃の本体の▲は発射の時、S1 の追加ダメージの▲は着弾の時に決まる（`320-13`）。モデルも同じ扱い（追加ダメージは着弾のフレームに出す）。
- 分からないこと: 攻撃ダメージ▲の付き始めの 7f 前〜3f 前の中の位置（あいだに撃った発が無い）。チャージ時間固定と▲が同じフレームか。シューティングスターの刻みの間が 0.25 秒より長い理由（ゲームの時間の刻みか、動画の時刻の揺れか）。
- **最小構成**: C-0520・C-0521 を burst の effects[0]〜[2] に結んだので、アニス：スターの録画（150・162・163・165）を根拠にする確定の結論 18 件に警告が出た。比べる値はどれも、窓の中の決まったフレームの 1 発の値・ヒットの数・ゲージ・止まりなどで、付き始めとヒットの時刻の数 f に依らない（C-0380 の `165-14`・`165-33` は、切り替わりの時刻の数え方が 1f の幅で同じ）。それぞれの `minimal` に印を書いた（警告の件数は main と同じ）。

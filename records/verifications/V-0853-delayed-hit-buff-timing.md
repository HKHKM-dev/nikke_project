# V-0853: 遅れのある倍率ダメージの値を決めるバフの時点（ラピの S2 の読み直し）

- 問い: 遅れのある倍率ダメージ（ラピの S2。発動の 101f 後のヒット）の値は、発動の時のバフで決まるか、ヒットの時のバフで決まるか（フルバーストの効き目がパネルより遅れるか）
- 話題: 1 発の式・バフの掛かり方
- 日付: 2026-11-22
- 状態: 調査中
- 録画: `0221`、`0366`、`0018`、`0855`
- 結論: `C-1509`

## 条件

- 型: 読み直し（撮影なし）。課題 2-74（ネヴェの S1）と 2-70（ブリッドの S2）の同じ問いを、遅れの長いラピの S2 で見分ける。
- 結論の対象: ラピの S2 の倍率ダメージ（`data/skills/10.json` の skill2 の effects[0]。C-0403・C-0453。発動は戦闘開始から 1,177 ティックごと、ヒットは発動の 101f 後）が値を決める時点。
  - 説明 A: 値は発動の時（イサベルの S2 の C-0864 と同じく、発動の直前）のバフで決まる。
  - 説明 B: 値はヒットの時のバフで決まるが、フルバーストの効き目がパネル（III のタイマーの 00.00 と、その約 610f 後の終わり）より遅れる。V-0843 のネヴェの S1 から、遅れは始まりで動画の 27f 以上（入りの止まり 22f を含む）、終わりで 5f 以上（`1336-12`）。「約 30f」とみる。
  - いまのモデル（C-0453 の model）はヒットのフレームのバフで出す（B の遅れ 0 の形）。
- 見分けられる回: ラピが III の編成では、フルバーストの周期（約 2,352 ティック）が S2 の周期の 2 倍に近く、1 回おきの S2 の発動がフルバーストの終わりの 8〜40f 前に来て、ヒットは終わりの 60〜95f 後に出る（モデルの時刻表と、録画のパネルの 00.00 の観測値で挙げた）。
  - A なら、その回はラピのバーストの攻撃力▲（C-0457・C-0611）とフルバースト補正の乗った値。B なら、ヒットの時には攻撃力▲もフルバースト補正も切れている（ラピの通常攻撃は、終わりの約 20f 後から▲も補正も無い格子に乗る。`0221-17`・`0366-04`）。B で遅れが 95f を超えるとしても、補正だけで攻撃力▲は乗らない。
  - フルバーストの外の回（もう 1 回おきの S2）は、A・B とも▲の無い値（対照）。
- 録画: ラピ（III・操作）のいる自動バーストの録画のうち、ココア + デルタ + ラピの `0221`・`0366` と、エーテル + デルタ + ラピの `0018`・`0855`。どれも機構の確定したキャラで、ラピの S2 の値に効くのは、ラピのバーストの攻撃力▲・フルバースト補正・S1（被弾の攻撃力▲。モデルは被弾を扱わない）・エーテルの S2 の防御力▼。
  - `0221` の 1 回目（f2093）は、V-0271 で 1,211,336（フルバーストの中の値）と読んであり（`0221-09`）、これに気づいて問いを立てた（仮説の出どころ）。`0366`・`0018`・`0855` の S2 の値は、この予測の commit の後に読む。
- 最小構成: ラピの S2 の値に効く未確定の要素は、問いの「値を決める時点」だけ。S1 の▲は被弾で付く（前提の外）が、乗っていれば値が別の格子（0221 の 611,807 など）になるので読みで分かる。

## 予測

## 読み方

1. 録画の HUD の増分（レシピ `hud-jumps` のキャッシュ）を、レシピ `buff-edge` の `--opt grid` で、モデルのラピの S2 の 1 ヒットの格子に当てた。格子は、ヒットの時の値（502,167・会心 753,251。エーテルの S2 の▼の中は 502,215・753,322）と、攻撃力▲とフルバースト補正の乗った値（1,211,336・会心 1,615,115。モデルのフルバーストの中の回か、ヒットの時の値 × 2.4122170373）。予測の見当の ±8f の増分を見た。
2. 格子に合わない増分は、同じフレームのラピの通常攻撃との和（`R=3@3700`。和の格子 `AR`）と、S1 の乗った版（S1 の乗った S2 の値 611,807（`0073-19`）と▲の無い値の差を、攻撃力の項で足した値）で当てた。
3. ヒットのフレームは、どれも予測の見当から 0〜3f 後だった。

## 分かったこと・分からないこと

- **ラピの S2 のヒットは、発動の時の値で計算する** → C-1509（仮説。モデルを直すまで許容外。直すかは [design-delayed-hit-value.md](../../plan/design-delayed-hit-value.md) で諮る）: 発動の後・ヒットの前にフルバーストとラピのバーストの攻撃力▲が切れても、ヒットには両方が乗る。イサベルの S2（C-0864）と同じ形。
- 説明 B（ヒットの時の値で、フルバーストの効き目だけが遅れる）は、ラピの S2 では外れる。終わりの 64〜93f 後のヒットに、フルバーストと関係のない攻撃力▲も乗る。
- ネヴェの S1（課題 2-74）: `1336-12` の 2 回は、発動の時の値で 2 回とも合う（f1516 は▲も補正も無い 151,888、f2102 は補正と会心の 303,776）。いまのモデルは f1516 を 512,466 で出す。
- ブリッドの S2（課題 2-70）: 録画 1284 の 2 回（f1508・f2098）は、発動の時の値なら前者が会心・後者が会心なし、ヒットの時の値なら逆で、どちらも 449,859。この録画では見分けられないまま。
- **分からないこと**:
  - ネヴェ・ブリッド・エーテル・ニヒリスター・ノベルなど、ほかの周期の倍率ダメージを直接見分けた回は無い（ネヴェの 2 回は、B の遅れが 15f より長ければ B でも合う）。ラピ・イサベル・スノーホワイト（C-1417）と同じ形とみるかは、設計書の論点。
  - 回数のきっかけの遅れのある倍率ダメージ（2B の S2・リバーレリオの S1 など）。スノーホワイト：イノセントデイズの S2（C-1364）は発動の時の値だが、ほかは見ていない。
  - バースト使用時の遅れのある倍率ダメージは、ヒットの時（フルバーストの始まりの後）の値の例がある（C-0310・C-0716・C-0707）ので、同じではない。

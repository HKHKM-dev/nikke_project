# NIKKE ダメージ計算ツール

『勝利の女神：NIKKE』のダメージ算出ツール。

- https://hkhkm-dev.github.io/nikke_project/（GitHub Pages）

## できること

- 通常攻撃・バフ・スキルによる部隊毎のダメージを算出
- 複数の部隊の合計ダメージを算出
- 育成状況の入力・編集（シンクロレベル・限界突破・コア強化・スキルLV・好感度・装備・オーバーロードオプション・キューブ・コレクション・リサイクルルームの研究LV）

## 精度と未対応

- 未対応・近似・仮定を多数含む。
- モデル全体と編成ごとの未対応・近似・仮定は、画面の「未対応・近似・仮定の一覧」にまとめて出します。

# V-0076: ノワールとクイーン（真）の近のコア命中率を、的の上の数値で数えて出す

- 問い: スペック固定 ON の SG 単騎・AUTO の近のコア命中率は、ノワール・クイーン（真）でも、プロダクト23（V-0073 の 0.035）や今のモデル（C-0158 の 0.042）と同じか
- 話題: 命中率・距離
- 日付: 2026-10-01
- 録画: `074`、`103`、`104`
- 結論: `C-0158`、`C-0159`
- 状態: 完了
- 派生元: `V-0073`

## 条件

- 撮影なし。既存の録画の読み直し。どれも射撃場の灼熱の的（BigArms）・3 分モード・スペック固定 ON・単騎・AUTO・オートバースト OFF・180 秒。
  - ノワール（271）: `074`。近は 2 回とも近 A（`074-17`）。
  - クイーン（真）（870）: `103`・`104`。近は 2 回とも近 B（`103-04`・`104-03`）。
- 近の区間（V-0069 と同じ区切り）のトリガーごとに、増分から当たった数 h と「会心 + 2 × コア」u を一意に出し（1 ペレットの胴体はノワール 27,964、クイーン（真）31,381。クイーン（真）の近は戦闘開始から 15 秒より後なので、S1 の攻撃力▲は掛かっていない）、的の上のオレンジの会心の数値を数えて、コア =（u − 会心）÷ 2 を出す。読み方は V-0073 と同じ。
- クイーン（真）は S2 の攻撃ダメージ▲が常時あるが、1 ペレットの値に掛かるだけで、会心・コアの数には関係しない。ノワールのバーストの命中率▲は、オートバースト OFF なので出ない。

## 予測（撮る前に書く）

読む前に書いた（2026-10-01）。増分から出した近の u ÷ h は、`074` 0.215・`103` 0.231・`104` 0.255（この記録の読み方で出したもの。`074-18`・`103-05`・`104-04` と同じ）。

- 会心率は 3 本とも 0.15 前後（C-0159）。外れて 0.19 以上なら、キャラで会心率が違うことになる（3 体とも CDN は 0.15）。
- 会心率が 0.15 なら、コア命中率は `074` 約 0.03、`103` 約 0.04、`104` 約 0.05。
- **H1（キャラ・着地点によらず同じ）**: 3 本の合計で 0.035〜0.045 に入り、ノワール（近 A）とクイーン（真）（近 B）の差は誤差の幅（1 本あたり ±0.012 ほど）。
- **H2（近 B の方がコアに当たる）**: クイーン（真）（近 B）がノワール（近 A）より 0.015 以上高い。V-0073 のプロダクト23 では近 A 0.034・近 B 0.036 で差が無かったので、分は悪い。
- 外れたときの影響: H2 なら、モデルの SG の近のコア命中率を、弾丸命中率と同じく着地点ごとに持つかを設計で決める。

## 読み方

1. `hud.ts --mode jumps` の増分から、近の区間のトリガーごとに h と u を出す（20f 未満の割れは足し戻す）。
2. トリガーの 10・16 フレーム後の画を、`aim.ts` の照準の位置のまわり 520 × 360px で切り出し、オレンジの会心の数値を目で数える。
3. u − 会心が 0 以上の偶数にならないトリガーは、6〜14 フレーム後を見直して数え直す。見直しても決まらないトリガーは外す。
4. 会心率 = Σ会心 ÷ Σh、コア命中率 = Σ（u − 会心）÷ 2 ÷ Σh。

## 結果

読んだ日: 2026-10-01。観測値は `074-24`・`074-25`・`103-09`・`103-10`・`104-06`・`104-07`。V-0073 のプロダクト23（`101-16`・`101-17`・`102-13`・`102-14`）も並べる。

- 最初の数えで偶奇が合わなかったのは、`074` 8・`103` 6・`104` 6 トリガー。見直すと、どれも重なった会心の数値か、画面の上へ飛んだ小さな会心の数値の見落としだった。`103` の 2 つ（f4237・f10506）と `104` の 1 つ（f10267）は、見直しても重なりで決まらず外した。残りは全トリガーで u − 会心が 0 以上の偶数になった。

## 分かったこと・分からないこと

- **スペック固定 ON の SG 単騎の近のコア命中率は、ノワール・クイーン（真）でもプロダクト23 と同じで、3 体の計は 0.040（95% 区間 0.034〜0.046）**。今のモデルの近の 0.042（C-0158）は区間の中。モデルを変える必要はない。C-0158 の根拠に足した。
- 近 A と近 B で、コア命中率に差は見えない（ノワールの近 A とクイーン（真）の近 B で 0.8 SE）。弾丸命中率は着地点で分かれる（C-0156）が、当たったペレットのうちコアに当たる割合は分かれない。
- 会心率は 3 体とも CDN の 0.15 どおり（C-0159 の根拠に足した）。
- 分からないこと: コア命中率が録画ごとに 0.028〜0.053 と揺れる理由（5 本の幅は区間の重なりの中で、偶然の揺れで説明できる大きさ）。

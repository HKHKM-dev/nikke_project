- 状態: 2026-10-10 にオーナーが、論点 1 は案 1-A、論点 2 は案 2-C（案 C のまま）、`259-08` の比べるフレームの移動、録画 259・284 の読み直しを backlog に足すこと（2-32）を決め、実装した。案 1-A で推した範囲（入力が UP の RL・速度が下がるとき）は、backlog 2-32 の読み直しで確かめた（V-0410・V-0412・V-0413。C-0526・C-0528・C-0529）

## 0. 要約

- C-0523（確定）は 2 つのことを言う。(a) アリスのチャージ速度▲がチャージの途中で付くと、前の発からの経過を持ち越し、▲の速度のチャージ時間を超えていれば直後に撃つ（C1）。(b) バースト使用時の効果は III のタイマーの 00.00 の 2f 前の頃に付く（HD）。
- いまのモデルはどちらも入れていない。入力が UP のチャージ武器は撃った時点で次の発までの待ちを決めて途中で縮めず（C0）、効果は本当の発動（00.00 の 6f 前。C-0516）に付く（H0）。
- **論点 1（経過の持ち越し）**: 推奨は**案 1-A（入力が UP のチャージ武器の発と発の間に広げる）**。比べた観測値で動くのは `259-08`（確定の結論の観測値。許容内 → 許容外）と `284-10`（許容内のまま）だけで、`259-08` は比べるフレームの置き場所の問題（3.2 節）。
- **論点 2（付き始め）**: 1 だけを入れると、00.00 を跨ぐ発は 00.00 の 5f 前に出る（実測は 1f 前。`362-15`・`407-01`）。いまの「止まりの後まで遅れる」より実測に近いが、4f 早い形でずれる。付き始めも直すと 1f 前で合う。推奨は**案 2-C（付き始めは直さない。案 C のまま）**。付き始めも直す案 2-A は、2026-10-10 の案 C をアリスについて覆す提案になる。

### 2.4 部分チャージ（C-0109）との関係

- `partialChargeShot` は残りの待ち k とそのフレームのチャージ C から進みを出す。1-A では k を毎フレーム「C + 解放 − 経過」で決め直すので、進みは (経過 − 解放 + 1) / C（経過のフレーム数を、そのときのチャージ時間で割る）になる。チャージ時間が途中で変わらなければ、いまのモデルと同じ値（発と発の間の待ちは、C0 と 1-A で 1 フレームもずれない）。
- 途中で変わった後に的がいなくなった場合だけ値が変わる。いまのモデルは、変わる前のチャージで決めた k を変わった後の C で割るので、進みの意味がずれていた。どちらの値も確かめていない（C-0109 の「チャージのバフがある場合の値は仮定」）。
- 押下チャージ型は部分チャージを撃たない（C-0109）ので変わらない。

### 2.5 AGENTS.md の規則に照らす

- 「根拠のある変更は、乖離が広がっても実施する」: アリスの C1 は確定（反復実測）で、いまの C0 は唯一測った入力が UP の場面と合わない。少なくともアリスについては入れる理由がある（1-A・1-B のどちらでも）。
- 「根拠のない変更は行わない」: 1-A は、入力が UP の RL・速度が下がるとき・アリス以外の速度▲に、測っていない規則を当てる。ただし、そこでのいまの C0 も測った根拠の無い仮定で、測った 2 つの入力（押下チャージ型の RL・入力が UP の SR）はどちらも同じ P1 だった。1-B は「アリスだけ持ち越す」という、どの観測にも無い区別をモデルに持ち込む。
- `259-08` の許容外は、機構の誤りではなく、比べるフレームが発動の時刻のずれに追いつかない形（2.2 節）。1-A を入れるなら、比べるフレームを動かし、観測値の注記に理由を書く。ユニの S1 でバーストの時刻が約 40f ずれる、というモデルの動きそのものは、録画 259・284 のユニ・ココアのフルバーストの入りの前後の発を読めば確かめられる（読み直しの候補。3 節）。

### 2.6 推奨

**1-A**。測った 2 つの入力で同じ規則で、規則を 1 つにできる。確かめていない範囲（入力が UP の RL・速度が下がるとき）は C-0523 の model と `shooter.ts` の注記に書く。`259-08` は比べるフレームを 7235 に動かす。

## 3. 論点 2: 付き始めの時刻

### 3.1 4 通りの、00.00 を跨ぐアリスの発（録画 407 の編成のモデル。00.00 = T から数えたモデルのフレーム）

| 組                      | 00.00 を跨ぐ発                                                      | 実測（`362-15`・`407-01`: 経過が超えていた回は T − 1） |
| ----------------------- | ------------------------------------------------------------------- | ------------------------------------------------------ |
| H0 + C0（いまのモデル） | 前の発から窓の外の間隔で、T の後（動画では止まりの後）              | 合わない（約 36f 遅い。動画では止まりも足して約 58f）  |
| HD + C0（2 だけ直す）   | いまと同じ（00.00 の 6〜3f 前にアリスの発が無ければ何も変わらない） | 合わない                                               |
| H0 + C1（1 だけ直す）   | **T − 5**（効果の付いた T − 6 の 1f 後）                            | 4f 早い                                                |
| HD + C1（両方直す）     | **T − 1**                                                           | 合う                                                   |

- 1 だけ入れると「直らない」のではなく、**4f 早い形でずれる**。00.00 を跨ぐ発は▲が乗る（実測も乗る）ので値は合い、時刻だけが 4f 早い。その後の窓の中の発も、次のリロードか窓の終わりまで同じ 4f だけ早い位相で続く。
- 2 だけ入れても時刻は直らない（C0 は撃った時点で待ちを決めるので、付き始めが 4f 遅れても待ちは変わらない）。2 が効くのは 1 と組んだときだけ。
- モデルの総ダメージ（アリスの枠）は、H0 + C1 から HD + C1 で −0.2%（位相が 4f 遅れる分）。

### 3.2 案

| 案              | 変更                                                                                                                                                                                                                                                                                      | 備考                                                                                                                                   |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **2-C（推奨）** | 直さない（案 C のまま）。C-0523 の model に「1 を入れても跨ぐ発は 4f 早い」と書く                                                                                                                                                                                                         | 2026-10-10 の判断のまま。同じ HD の形で確定のクルミ（C-0517）も案 C で直していないので、扱いがそろう                                   |
| 2-A             | 遅れの表にアリスの行を足し、効果を 00.00 の 2f 前に置く。表は効果の遅れを段の表示から数え、0 を「本当の発動」と読むので、本当の発動と表示のあいだに置けない。2.7.2 節の案 A の印（段の表示から数えた値。負も可）を足す。窓の終わり（10 秒）は確かめていないので、始まりと一緒に 4f ずれる | **案 C を、アリスについて覆す提案**。入れるなら、同じく確定のクルミ（C-0517）も同じ印で行を足すかを一緒に決めるのが筋（案 A に近づく） |

### 3.3 推奨

**2-C**。1-A を入れれば、跨ぐ発の大きな食い違い（止まりの後まで遅れる）は 4f に縮み、値も合う。残る 4f は、案 C で直していないほかのキャラの数 f と同じ大きさで、アリスだけを直すと扱いが割れる。

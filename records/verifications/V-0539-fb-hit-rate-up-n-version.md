## 読み方

オーナーの承認の後、撮る前に固定する。読んだ後に変えない。

1. 鈴原サクラのヒットの格子・フルバーストの入り E・窓（E から 589f）・数えない端・窓の中で的のジャンプをまたいだ先を数えない規則・帯の区切り（的の立ち上がり）・着地点の分け方は、V-0492「読み方」の 1〜3 と同じ（レシピ `fb-window-cores`）。近 A・近 B は `0354-12` の読み方で読み、幅の中央値が手前のキャラなどで崩れた区間は、幅 300〜369px と 370〜459px のフレームの数の多いほう（8 割以上かつ 10 フレーム以上）で決める（V-0492「結果」の 3 回目の撮影と同じ）。
2. **K** = A の窓の中のコアのヒットの数 ÷ Σ（A の窓の中の各ヒットに、B の同じ着地点の窓の中のコア命中率を当てた値）。使う着地点は**中近・近 A・近 B の 3 つだけ**。遠・中遠 A・中遠 B/C は、参考に 6 つ全部の K を出すだけで判定に使わない。
3. **K_out** = 同じ式を、同じ 3 つの着地点の A と B の窓の外で取る（どの仮説でも 1）。
4. **σ**: 録画を 1 本ずつ抜いて出し直した値のばらつき（jackknife）と、2 項分布（A のコアの数と B の率の両方）の大きいほう。K・K_out とも。
5. **判定の目安**:
   - K_out が 1 と 2σ の中で合うことを先に見る。合わなければ K から結論を作らない。
   - K が H1 と 2σ の中で合い、H2 から 2σ 以上離れていれば **H1**（C-0641 の再現）。
   - K が H2 と 2σ の中で合い、H1 から 2σ 以上離れていれば **H2**（C-0641 を棄却し、N は基礎版の値とする結論を作る）。
   - K が H1 と H2 の両方と 2σ の中で合えば、A・B を 2 本ずつだけ足し、全部を合わせて同じ目安で 1 回だけ見直す。それでも決まらなければ、この撮り方では足さない。
   - K が H1 と H2 の両方から 2σ 以上離れていれば、結論は作らず、オーナーと次を決める。
6. 1 はレシピ `fb-window-cores`、2〜4 は `tools/captures/fb-window-k.ts --landings 中近,近A,近B`（オプションは撮る前に足す。設計書 2.5 節）で出す。

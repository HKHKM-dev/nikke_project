# V-0396: ラピのバーストの攻撃力▲は、III のタイマーの 00.00 の何 f 前から発に乗るか（録画 221 の読み直し）

- Stage: backlog 2-4（plan/burst-effect-delay-candidates.md の P3。III の自分への効果）・backlog 2-31

## 条件

**何を確かめるか**

- III のバースト使用時の効果の付き始めは、雪子（C-0511）では 00.00 の 5f 前（CT の明けの 0〜1f 後）、ルドミラ：WO（C-0510）では 00.00 の 1〜2f 前（CT の明けの 4〜6f 後）で、キャラで違った。III の CT の明けは 00.00 の 6〜8f 前（C-0512）。どちらがふつうの形かを、3 体目のキャラで見る。
- ラピ（10）のバーストの攻撃力▲（60.75%・10 秒。`data/skills/10.json` の burst の effects[1]。窓はフルバーストと同じ。C-0457）は、止まりの明けの最初の発から乗る（`221-08`）。00.00 の前の発は誰も読んでいない（`221-08` は止まりの明けから後の発）。
- ラピは AR で発の間隔が約 5f なので、00.00 の 8f 前から 1f 前までに 1〜2 発ある見込み。

**編成**

- 録画 `221`: ココア（311。I）+ デルタ（20。II）+ ラピ（10。III・操作・AUTO 射撃 ON）、オートバースト ON。射撃場・灼熱の BigArms・3 分モード・スペック固定（V-0201）。III のタイマーの 00.00 は f1390・3874・6417・8925（`221-01`）。
- **最小構成**: ココア・デルタは機構が確定。ラピの S1（被弾で自分に攻撃力▲。前提の外）は 1 発の値を 1.218 倍にする（`221-07`）ので、格子を別に持つ。S2 は定義上発動しない。

**読み方の前提**

- ラピの 1 発の格子（`221-16`・`221-17` の注記）: 距離ボーナスありの胴体は、▲なし 16,846・攻撃力▲だけ 27,091・攻撃力▲と補正 37,510（倍率グループ 1.0 あたり ▲なし 12,958.5・攻撃力▲ 20,838.9）。会心 +0.5・コア +1.0・距離 +0.3・補正 +0.5。攻撃力▲の有無は 1 発で分かれる（1.608 倍）。
- 00.00 の前は入りの止まりの前で、補正はまだ乗らない（V-0392・V-0393 の `192-15`・`258-18`）。

## 予測（撮る前に書く）

読む前に書いた（2026-10-10。手計算。予測ファイルは無い）。比べるのは、各回の 00.00 の 8f 前から 1f 前までのラピの発に攻撃力▲があるか。CT の明けは 00.00 の 6〜8f 前（C-0512）、新しい CT の秒（N）は 00.00 の 3〜4f 前。

| 仮説                                                               | 00.00 の 5〜3f 前の発            | 00.00 の 2〜1f 前の発 |
| ------------------------------------------------------------------ | -------------------------------- | --------------------- |
| H0: いまのモデル（照合では III の発動 = 00.00）                    | ▲なし                            | ▲なし                 |
| HY: 雪子の形（CT の明けの 0〜1f 後。00.00 の約 5〜7f 前）          | 攻撃力▲あり（補正なし）          | 攻撃力▲あり           |
| HL: ルドミラ：WO の形（CT の明けの 4〜6f 後。00.00 の約 0〜3f 前） | ▲なし（5〜4f 前）・境目（3f 前） | 攻撃力▲あり           |

- 予想は持たない（2 体で割れているので、この 1 体で決めない）。見分けるのは 00.00 の 5〜4f 前に発があった回（HY なら▲あり、HL・H0 なら▲なし）と、00.00 の 2〜1f 前に発があった回（HY・HL なら▲あり、H0 なら▲なし）。
- 外れたときの影響: どちらの形かで、III のバースト使用時の効果を「CT の明け（本当の発動）に付く」をふつうとし、ルドミラ：WO を遅れの行にするか、逆にするかが決まる（backlog 2-31 の設計の手がかり）。

1. HUD の増分（`hud.ts --mode jumps` のキャッシュ。無ければレシピで作る）を、各回の 00.00 の 15f 前から止まりの明けまで並べ、ラピの発を格子に当てる（ココア・デルタの SR の発と重なった増分は分ける）。

3. 00.00 の前で攻撃力▲の無い最後の発と、▲の付いた最初の発のフレームを記録する。

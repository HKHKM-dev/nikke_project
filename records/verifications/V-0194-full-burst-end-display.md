# V-0192: フルバーストの窓の終わりの表示の遅れ

- 問い: フルバーストの窓の本当の終わり（フルバーストのダメージ補正が切れるフレーム）は、録画で窓の終わりとして読んできたタイマーの黄色の 00.00（V-0167）より何フレーム前か。C-0285 の段の印と同じく 5〜6f 遅れて出るなら、C-0259 の跨ぐ発の読みは変わるか
- 話題: バーストの段階とフルバースト
- 日付: 2026-10-05
- 録画: `162`、`165`
- 状態: 調査中
- 派生元: `V-0189`

## 条件

- 課題: `plan/backlog.md` 2-24。V-0189 の論点 3 の X3。
- 録画の窓の終わり E は、フルバーストのタイマー（画面の上の中央）が黄色の 00.00 になった最初のフレーム（V-0167 の読み方）。C-0258・C-0285 では、右のバースト欄の印（新しい CT の秒・次の段のアイコン）が本当の発動の 2〜6f 後に出た。タイマーも同じだけ遅れて出るなら、本当の窓の終わり T は E より前になる。
- C-0259（確定）の根拠の跨ぐ発は、`165-15`（E の 6f 前に撃った）、`165-16`（12f 前）、`162-18`（1f 前）。どれも E を窓の終わりとして「窓の中で撃った」と読んだ。モデル（`burst/controller.ts`・`frame/firstPass.ts`）は着弾のフレームが窓の終わり以降ならゲージを足すので、撃ったフレームはモデルには効かない。効くのは C-0259 の読み（B: 窓の中で撃っても溜める。B0: 窓の中で撃った発は溜めない）の見分けで、T 以降に撃った発は B・B0 のどちらでも溜めるので見分けに使えない。
- 本当の窓の終わりの手がかり: フルバースト中のダメージの +50%（`162-11`・`162-12` などの 1.5 倍。会心・コアと同じ足し算の枠。V-0174）。総ダメージの HUD の増分（モデルの発のフレームを合わせてある所。C-0079）で、+50% の乗った最後の増分と、乗らない最初の増分のあいだに T がある。窓の中のゲージは溜まらず（C-0264）、BURST バーは 12.6% まで 0px（C-0084）なので、ゲージで T は読めない。ダメージの +50% が切れるフレームと、ゲージが溜まり始めるフレームは同じとみる（どちらもフルバーストの状態。分けて確かめる手は無い）。
- 足し算の枠のせいで、1 ヒットの値は「フルバースト・会心なし」と「フルバーストなし・会心」が同じになる（V-0174 の H-add の重なり）。会心の率は約 16%（`162-13` の 76 ヒットで 12）。見分けに使うのは、片方でしか出ない値（フルバーストのコアの会心 = 胴体の 3 倍、フルバーストなしの胴体 = 1 倍、アニス：スターの発の 1,838,007 と 1,413,182 の組、イサベルのペレット数から決まる増分）と、重なる値は「会心なし」とみた場合の両方を書く。イサベルの受けるダメージ▲（5 秒。窓と同じ長さ）が乗る窓では、×約 1.4 の別の掛け算が乗る（`162-27`）。▲が切れるフレームも同じ読みで出るが、T とは分けて書く。
- 既に見たもの（比べる値にしない）: 録画 165 の 1 回目の窓（E = f2010。V-0167）の HUD の増分を f1940〜2070 で並べた（この検証の起案のとき）。この窓は結果に書くが、d の見積もりには数えない。V-0167 で 162 の 5 回目・165 の 2・5 回目の窓の終わりの前後の発の着弾（HUD の増分のフレーム）を読んでいるが、+50% の有無は読んでいない。

- 見込み: D0（起案のときに見た 165 の 1 回目で、E − 2 のシューティングスターのヒットが +50% の値（会心なしなら）、E + 8 のアニス：スターの着弾が +50% なし。これだけでは会心と見分けられないので、見込みの出どころに留める）。
- 見分け方: 窓ごとに T の区間（+50% の乗った最後の増分 < T ≤ 乗らない最初の増分）を出し、d = E − T の区間を窓どうしで重ねる。シューティングスターのヒットは約 15f おきなので、1 つの窓の区間は 15f ほどの幅になるが、窓ごとに位相がずれるので、重ねると幅が縮む。会心と重なる値しか無い窓は、会心なしとみた区間と、会心とみた区間の両方を書き、会心でない側だけで重ねて、会心の側でも結論が変わらないかを確かめる。
- 外れたときの影響: D3・D5 なら C-0259 の文の「窓の終わりの 1f 前に撃った発も」と根拠の読みが変わる（モデルの振る舞いは変わらない。着弾のフレームで足すので）。D5 で根拠が 1 件になれば、C-0259 の等級と状態の見直しをオーナーに聞く。V-0167 の 165-10・165-13 の切り分け（録画とモデルの窓の終わりの前後の発の位相）も、E の代わりに T で数え直す。

## 読み方

1. 録画 162・165 を取り寄せる（`node tools/captures/fetch.ts 162 165`）。
2. 窓ごとに E を読む: タイマー（1920×1080 で 860,170 から 200×70 ほど）を 1 フレームずつ切り出し、黄色の 00.00 の最初のフレーム。最後の数フレームのタイマーの値（1/100 秒）も控え、0 になる時刻を外挿して E と比べる（タイマーの値の表示と、黄色に替わる表示の差）。
3. E − 60〜E + 45 の総ダメージの増分（`hud.ts --mode series`）を並べ、増分ごとに出どころを分ける: シューティングスター（約 15f おき。胴体の基準 147,125 の 1・1.5・2・2.5・3 倍、▲で × 約 1.4）、アニス：スターの発（照準の横の残弾。値は `162-06`〜`162-09` の組）、デルタ・イサベル（枠アイコンの上の残弾が減ったフレーム。イサベルは 21,002 の倍数でペレット数と会心を分ける）。
4. 増分ごとに +50% あり・なし・どちらとも取れる（会心と重なる）を付け、窓ごとに「+50% ありと決まる最後の増分 L」「なしと決まる最初の増分 F」を出す。T は L < T ≤ F、d = E − T は E − F ≤ d ≤ E − L − 1。
5. 窓ごとの L・F・E を観測値（`record`。`source` に `V-0192`）にする。

# V-0389: クラウンのバーストの効果の付き始めの再現（R2）

- 問い: クラウン（330）のバースト使用時の効果（味方全体の攻撃ダメージ▲）は、録画 302 と同じ編成の新しい録画でも、II の発動（六角形の替わり目）より前（本当の発動の頃）に付くか
- 話題: スキル・キャラ固有
- 日付: 2026-10-09
- 状態: 調査中
- 派生元: `V-0378`

## 条件

- 目的: クラウン（330）のバースト使用時の効果が II の発動より前に付く（C-0499。録画 302 の単独実測の仮説）を、新しい録画で再現する（backlog 2-4。plan/burst-effect-delay-candidates.md 2 節の R2。2026-10-09 のオーナーの判断）。
- 編成（録画 302 と同じ）: レイヴン（851。III・AI）+ I-DOLL・サン（308。III・AI）+ クラウン（330。II・操作・撃たない）+ ココア（311。I・AI）。灼熱の的（BigArms）・3 分モード・スペック固定 ON・オートバースト ON。
- 最小構成: ココアの定義はダメージに効く効果を持たず、レイヴン・サンは機構が確定（V-0378）。発動の前後 29f ほどの間に値を変えうる効果は、クラウンの burst のほかに無い（クラウンの S1 はフルバースト開始で付き、S2 はクラウンが撃たないので起きない）。
- 見るのは、各回の II の発動（六角形が II から III に替わるフレーム）の前後の、サン（AR）とココアの 1 発に、クラウンの攻撃ダメージ▲が乗っているか。あわせて、クラウンの顔が CT の秒に替わるフレームも読む（V-0378 の 9 回目の読み）。
- 新しい見方（2026-10-09）: 直前に入った plan/design-activation-stall-video.md 2 節で、六角形の替わり目は本当の発動の約 6f 後（C-0258。CT の秒の 3〜4f 後、アイコンはその 3f 後）と整理された。C-0499 の「替わり目の 3〜6f 前」は、**効果が本当の発動の頃に付く**と読める。V-0378 の「操作から表示までの遅れ」の見方はこれと同じものとみる。

## 予測（撮る前に書く）

仮説ごとに、この録画で何が見えるはずか。見分けられるか。外れたときの影響。数値は予測ファイル（records/predictions/V-0389.json。npm run records:predict -- V-0389）を指す。既存の録画の読み直しなら、冒頭の「録画」に挙げてから予測を出し、読む前に commit する。

撮る前に書いた（2026-10-09）。

- **H0**（いまのモデル。遅れ 0。予測ファイルの `effect-delay-1`〜`4` の H0）: 各回で、六角形の替わり目より後のサン・ココアの発は▲の値、前は▲の無い値。回ごとの幅（▲の無い最後の発 〜 ▲の乗った最初の発）に 0 が入れば合う。
- **HR**（本当の発動に付く。範囲外）: ▲は CT の秒の替わり目の頃（替わり目の約 6f 前。C-0258）から付く。回ごとの幅が替わり目より前（負）に寄り、共通部分が C-0499 の幅と重なる。CT の秒の替わり目から数えると、幅に 0 前後が入る。
- **HL**（遅れて付く。範囲外。アドミと同じ形）: 替わり目の後の何発かは▲の無い値。
- 見分け方: 回ごとの幅で、H0（0 を含む）・HR（負に寄る）・HL（正に寄る）を分ける。サンの発は密で、▲は全部の発に効くので、会心だけのアドミより細かく挟める。
- 予想: **HR**（302 で 6 回が替わり目より前。C-0258 の約 6f と合う）。
- 外れたとき: H0 なら、302 の読み（C-0499）は 302 だけの事情。HL なら、302 と矛盾するので両方の発動の読みを見直す。HR のときは、モデルの発動（本当の発動）に効果を付けるいまのモデルが合っていることになり、ずれは比べる起点（替わり目）の側にある。backlog 2-30（替わり目と本当の発動の差）と合わせて、起点の扱いをオーナーに出す。

## 読み方

1. 撮った録画を取り込む（台帳の条件に「V-0389（R2）。録画 302 と同じ編成」）。
2. 各回の II の発動（六角形の替わり目）と、クラウンの顔が CT の秒に替わるフレームを、右のバースト欄を 1 フレームずつ切り出して読む。
3. HUD の増分（`npm run records:read -- <録画 id> --recipe hud-jumps --source V-0389 --write`）から、発動の前 40f 〜 後 28f の増分を取り出し、サンの 1 発とココアの 1 発を、▲の外の値（302-03・302-04 の格子）と × (1 + 攻撃ダメージ▲) の値で分ける。
4. 回ごとに幅を出し、1〜4 回目を `burstEffectDelay`（slot 3・n 0〜3）の観測値（spread の range・許容は幅の半分）にする。5 回目より後と、CT の秒の替わり目から数えた幅は記録にする。
5. `npm run records:check` で予測と比べ、`records:minimal` で警告を確かめてから結論を書く。

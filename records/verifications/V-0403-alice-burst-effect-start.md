## 分かったこと・分からないこと

- **C-0523（仮説）**: アリスのバースト使用時の効果は HD の形（00.00 の 2f 前の頃）。チャージ速度▲がチャージの途中で付くと、入力が UP の SR でも前の発からの経過を持ち越し、▲の速度のチャージ時間を超えていれば直後に撃つ。モデルは撃った時点の待ちのままで、00.00 を跨ぐ 1 発が、1 回のバーストで止まりの後まで遅れる（実測は 00.00 の 1f 前）。
- 分からないこと: 経過を持ち越すのが、ほかの入力が UP のチャージ武器（SR・RL）とほかの速度▲でも同じか。アリスの発が 4 回とも 00.00 の 1f 前にそろうのは、経過がもう超えていたため（3 回）と、たまたま（7 回目）で、ラピ（`221-21`・`366-09`）の発の位相がそろう理由と同じかは分からない。
- **最小構成**: C-0523 を burst の effects[1] に結んだので、確定の結論 2 件（C-0134 の `094-01`、C-0474 の `362-03`・`362-05`・`362-06`）に警告が出た。どれも 1 発の値で、アリスのバーストの窓の端の数 f に掛からない。それぞれの `minimal` に印を書いた（警告の件数は main と同じ）。チャージ速度▲（effects[0]）には結ばなかった（付き始めは発射の時刻から見積もった値で、効果の値を直接見ていないため）。

# V-0533: ミハラのバーストの追加ダメージは、撃つ側のバフをヒットの時点で取るか発動の時点で取るか

- 問い: ミハラ（161）のバーストの追加ダメージ（perBurstHit）は、発動からヒットまでにほかのキャラが付けた撃つ側のバフ（アニス：スターのフルバーストの始まりの攻撃力▲・攻撃ダメージ▲）を見るか（H-a。ヒットの時点）、発動の時点のバフで固定するか（H-b）
- 話題: スキル・キャラ固有
- 日付: 2026-10-28
- 録画: `0727`、`0728`
- 結論: `C-0714`
- 状態: 完了
- 派生元: `V-0527`

## 条件

- 確かめること: `data/skills/161.json` の burst の effects[1]（追加ダメージ。`perBurstHit`）の撃つ側のバフの時点。V-0527（C-0657。シンデレラ）で、`frame/plan.ts` の planSkillHits は perBurstHit の全部で撃つ側のバフをヒットの時点で取るようになり、161 も [design-mihara-burst-hits.md](../../plan/design-mihara-burst-hits.md) 7 節の「発動のフレームで固定」から、根拠なしにこの扱いに変わった（同 8 節）。
- 既存の録画では決まらない: 161 の録画は 0469・0470（ラム・デルタ・ミハラ）だけで、発動からヒットまでの間に撃つ側のバフが変わらない。どちらの規則でも、比べる観測値（`0469-01`〜`0469-08`・`0470-01`〜`0470-08`）のモデルの値は 1 つも変わらない（同 8 節）。
- 撮るもの（「次に撮るもの」の撮影の依頼）: アニス：スター（17・I）・デルタ（20・II）・ミハラ（161・III・**操作**・オート射撃 ON）。射撃場 BigArms（風圧のタブ）・3 分モード・スペック固定 ON・オートバースト ON。2 本。V-0479 の B（録画 0543・0544）の III をミハラに替えた編成。
  - 風圧のタブは、録画 0469・0470 と同じ（ミハラの 1 ヒットの値が `0469-05`・`0470-05`・`0470-04` と同じになり、読みの手がかりに使える）。
- H-a と H-b の分かれ方:
  - アニス：スターの S2 は、フルバーストの始まりに味方全体へ攻撃力▲（私だけの星のとき。発動者のバフ前攻撃力の割合）と攻撃ダメージ▲を 10 秒付ける（C-0204。確定・厳密一致）。フルバーストの始まり（III のタイマーの 00.00）は、ミハラの発動より後で、ミハラの 1 ヒット目（00.00 の 17f 後。C-0575）より前。H-a なら 3 ヒットとも乗り、H-b なら乗らない。
  - デルタ（II）・ミハラ（III）のどちらも基本バースト段階 I ではないので、アニス：スターは私だけの星になる（攻撃力▲の条件）。攻撃ダメージ▲は私だけの星によらない。
  - 前のフルバーストの▲（10 秒）は、次のミハラの発動までに切れている（モデルでフルバーストの間は 1,912f）。発動の直前のバフには、アニス：スターの▲が入らない。
  - 追加ダメージは 3 回目以降のバーストで出る（条件のペインロード 2 は同じ発動で付いた状態を見ない。C-0566）。2 回目以降は、前の回のペインロード 1（攻撃力▲。C-0563）が発動の前から付いているので、H-a と H-b の差はアニス：スターの▲だけになる。
- 最小構成（観測量: 3 回目以降のミハラの追加ダメージの 1 ヒット（会心なし））:
  - 観測したい事象のほかに、この値に効く未確定の要素は無い。
  - ミハラ: 追加ダメージの値と時刻（C-0565・C-0566・C-0575）、ペインロード 1・2（C-0563・C-0566）、バーストスキルダメージ（C-0563・C-0564）は確定。S1 のクリティカルダメージ▲（根拠なし）は会心のヒットにだけ効くので、会心のヒットは判定に使わない。
  - アニス：スター: ミハラに効く効果は S2 の effects[0]〜[2]（C-0204・C-0205・C-0587・C-0588。確定）だけ。爆発のダメージ▲（effects[1]）はミハラの追加ダメージに乗らない（モデルの H-a の値は攻撃力▲と攻撃ダメージ▲だけで出る。「予測」）。バーストの攻撃ダメージ▲（burst の effects[2]）は自分だけ。未確定の要素（S1 の notes[0]: 誘導弾の飛ぶ時間とゲージ、burst の notes[0]・notes[2]: シューティングスターと通常攻撃のコア、C-0520・C-0521・C-0425（仮説））は、チェーンの時刻とアニス：スター自身のダメージに効くだけで、ミハラの追加ダメージの値に効かない。CT 短縮（S1 の effects[2]・[3]。確定）はバーストの回数を変えるだけ。
  - デルタ: ダメージに効く効果は S2 の防御力▲（C-0081・C-0589。確定）だけで、ミハラの与ダメージに効かない。S1 の最大HP▲・バーストのデコイは間接の notes で、この編成に HP・デコイを読む効果は無い。
  - 通常攻撃の条件（コア命中率・距離ボーナス・弾丸命中率）は、通常攻撃の値と HUD の増分の重なりに効くだけで、追加ダメージの 1 ヒットに効かない。
- 2 本: 1 本目で決め、2 本目で再現する（[verification-guide.md](../../plan/verification-guide.md) 2.2 節。1 本に 3 回目以降のバーストが 3〜4 回あるので、回でも数えられる）。

## 読み方

1. 撮った後に、戦闘履歴か一時停止のパネルで編成と枠順、出撃画面でスペック固定 ON・風圧のタブ、左上のオート射撃・オートバーストの ON を画で確かめる。
2. ミハラのバーストの 3 ヒットの組を、HUD の増分（`hud.ts --mode jumps`）で読む。1 ヒット目は III のタイマーの 00.00 から動画で 39f 後、2・3 ヒット目はその 10f・22f 後（C-0575・C-0564）。
3. 2 回目のバーストの 3 ヒット（追加ダメージは出ない。C-0566）から、バーストスキルダメージの 1 ヒット（会心なし）を読む。2 回目が会心（3 ヒットとも同じ大きい値。C-0564）なら、もう 1 本の 2 回目の値を使う。指標は `burstHitDamage`（slot 3・n 1・crit false。3 ヒットの和）。2 回目もフルバーストの始まりの後に当たるので、バーストスキルダメージにアニス：スターの▲が乗るか（C-0563 が外れるか）によらず、3 回目以降と同じ値になる。
4. 3 回目以降の 3 ヒットのそれぞれの増分から、3 の値を引いて追加ダメージ（会心なし）を出す。指標は `skillHitDamage`（slot 3・n・crit false。n は 3 回目のバーストの 1 ヒット目からの通し番号）。引いた値が会心なしの候補（「予測」）に合わない増分は、追加ダメージかバーストスキルダメージが会心（S1 のクリティカルダメージ▲が乗りうる）なので、判定に使わない。
5. 増分が「予測」の候補のどれとも合わないときは、同じフレームのほかのヒット（アニス：スターのシューティングスター（0.25 秒ごと。C-0206）、アニス：スター・デルタ・ミハラの通常攻撃。`0469-01` の 620,750 の形）の重なりを疑い、同じフレームの小さいヒットを差し引くか、的の上のポップアップをコマ送りで読む（[captures/guide.md](../../plan/captures/guide.md)「1 ヒットの値（多人数）」）。

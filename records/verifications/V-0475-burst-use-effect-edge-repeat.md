## 条件

**何を確かめるか**

- C-0510（ルドミラ：WO。V-0392）と C-0511（雪子の 1more。V-0393）は、どちらも仮説・単独実測。値（補正の切れ目との差・付き始め）は、それぞれ録画 192・258 だけで決めた（結論の `decidedOn` になる録画）。反復実測にするには、ほかの録画での再現が要る（plan/verification-guide.md 2.2 節）。
- 同じ編成をキャラごとに新しく撮り、192・258 で決めた値を下の「予測」に固定してから読む。
- 既存の録画で読み直せないかを先に見た。ルドミラ：WO を撮った録画は 192 のほか、099・184・440〜442（単騎か 2 人。オートバースト OFF でフルバーストが無い）。雪子は 260（灼熱。1more は風圧の的のときだけ付く）・259・261（クイーン（真）の仮説 C-0429・C-0522 が混ざる）。どれも使えないので、新しく撮る。

**編成（どちらも、値を決めた録画と同じ）**

- ルドミラ：WO: ラム（822。I）+ デルタ（20。II）+ ルドミラ：WO（194。III・操作・AUTO 射撃 ON）、オートバースト ON。射撃場・灼熱の BigArms・3 分モード・スペック固定（録画 192 と同じ）。
- 雪子: ラム（822。I）+ デルタ（20。II）+ 雪子（871。III・操作・AUTO 射撃 ON）、オートバースト ON。射撃場・風圧の BigArms・3 分モード・スペック固定（録画 258 と同じ）。
- **最小構成**: III のフルバーストを起こすには I・II が要る。ラム・デルタはダメージに効く効果が無い（C-0252 の根拠の編成）。
  - ルドミラ：WO のほかの未確定の要素は、S1 の受けるダメージ▲・追加ダメージの数え方（C-0257）と、S2 のフルバースト開始時のクリティカル確率▲（C-0249）。どちらも値（受けるダメージ▲は 1.1256 倍・会心は倍率グループの +0.5）が確定しており、1 発の値の格子の中の別の値を増やすだけで、攻撃力▲の有無（1.6254 倍）と補正の有無の読みを変えない（V-0392「読み方の前提」）。
  - 雪子のほかの効果は、値も窓も確定（V-0393「最小構成」）。終わりの前後で効くのは、1more の攻撃力▲・補正・S1 のフルバースト終了時の攻撃力▲の 3 つで、格子で分かれる（V-0393「読み方の前提」）。
- 本数: キャラごとに 2 本。ルドミラ：WO は 192 で 5 回のうち終わりを比べられたのが 3 回、雪子は 258 で 4 回のうち 2 回（リロードと発の間隔で読めない回がある）だったので、1 本では読める回が 1〜2 回に減るおそれがある。

**読み方の前提**

- 1 発の値の格子は、ルドミラ：WO は V-0392、雪子は V-0393 の「読み方の前提」の表と同じ（スペック固定で編成が同じなので値も同じ）。
- 比べる指標は `buffWindowEndFromFullBurstEnd`（攻撃力▲の窓の終わり − 補正の窓の終わり。モデルのフレーム。許容 `abs: 1`）。付き始め・フルバーストのタイマーの 00.00 は記録（`record`）にする。

- **HL・HY を予想する**（それぞれのキャラの値を決めた録画のとおり）。
- 見分け方: MG の 1 フレーム 1 発なので、終わりの前後がリロードに掛からなければ、ルドミラ：WO の −2 と H0 の −6・雪子の値（−4.5）は許容（±1）の外で分かれる。雪子の −4.5 と H0 の −6 の差は 1.5f で、許容をわずかに超えるだけなので、1 回ごとに切れ目の発を 1f の幅で読み（V-0393 の `258-14` のように補正の切れ目が 2 つのフレームのどちらか分からない回は、幅を書く）、読めた回をそろえて見る。付き始めは、HL（1f 前）と HY（5f 前）が 4f 離れ、どちらも止まりの前なので、発が密なら 1 回で分かれる。
- 外れたときの影響: 合えば C-0510・C-0511 を反復実測で確定にできる（`decidedOn` は 192・258 の「値を合わせた」）。どちらかが外れれば、その結論は録画ごとに揺れる値（または読み違い）で、仮説のまま幅を広げるか棄却する。どちらもモデルは直さない（2026-10-10 のオーナーの判断。plan/burst-effect-delay-candidates.md 2.7 節の案 C）ので、モデルの値は動かない。

## 読み方

1. HUD の増分は `npm run records:read -- <録画 id> --recipe hud-jumps` のキャッシュ。各回の III のタイマーの 00.00 と止まりの明けを、右のバースト欄の切り出しで読む（レシピ `burst-panel`）。
2. 00.00 の 10f 前から止まりの明けまでと、00.00 から 590〜625f の操作キャラの発の値を並べ、格子に当てる（ラム・デルタの SR の発と重なった増分は、モデルの SR の 1 発の値を引いて分ける。分けられない増分は除く）。
3. 画面中央上のフルバーストのタイマー（crop=300:90:810:165）を同じ範囲で 1 フレームずつ並べ、00.00 になったフレームを読む。
4. 終わり: 攻撃力▲の無い最初の発・補正の無い最初の発から `buffWindowEndFromFullBurstEnd`（`args` は `192-11`〜`192-13`・`258-14` と同じ形。許容 `abs: 1`）の観測値にする。リロードに掛かった回、戦闘の終わりで切れる回（雪子の 5 回目）は除く。
5. 記録: 各回の 00.00 → 攻撃力▲の付いた最初の発（止まりの前か）、00.00 → フルバーストのタイマーの 00.00、00.00 → 攻撃力▲の無い最初の発・補正の無い最初の発。

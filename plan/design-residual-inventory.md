## 1. 目的

残差の一覧の見る行（許容外・失効）と、課題の一覧 3 節の課題を、いまのモデルに合わせて整理する。見る行の 1 行ずつについて、どの課題・結論・検証記録で理由が分かっているかを確かめ、どこにも結び付いていない許容外を課題にする。モデルは変えない（AGENTS.md「事実と記録」）。

## 2. 案

- 案 A（推奨）: 見る行を、(1) 既知（課題があるか、結論・検証記録・設計書に理由が書いてある）、(2) 失効、(3) どこにも結び付かない許容外、に振り分ける。(3) は課題に起票する。(1) で課題の無いものは、理由の書いてある所をこの設計書に残し、課題にはしない。比べの設定が表の改訂に追いついていない行は、値と読み方をそのままにして比べの設定を直す（比べ直すか失効にする）。
- 案 B（採らない）: 理由の書いてある許容外も、すべて 3 節に起票する。3 節が結論・検証記録の写しになり、1 つの事実を 1 か所に置く決まりに合わない。
- 案 C（採らない）: 比べの設定の古い行も、課題にするだけで直さない。直し方が観測値の設定で一つに決まり（着地点は同じ録画の足元の観測値で読めている）、読み直しも要らないので、残すと見る行に誤った許容外が残るだけ。
- 案 D（採らない）: 振り分けの結果を検証記録に残す。完了の検証記録には結論が 1 つ以上要り、棚卸しには結論が無い。

## 3. 論点

1. **比べ直しの観測値の出どころ**: 元の比べを書いた検証記録（V-0491・V-0495）にする。値・読み方・録画の範囲は元の観測値のままで、変えたのは比べの設定と幅だけ。
2. **再現に数えるか**: 着地点 C の 5 本（`0647`・`0648`・`0653`・`0654`・`0655`）は C-0644 の値を決めた録画なので、比べ直しは許容内かを見るだけで、再現にはならない。結論の根拠は変えない。
3. **古くなった結論の本文**: 結論は記録なので書き換えない。今のモデルと合わなくなった所は、6 節に残す。

## 4. 決定と理由

- 案 A。依頼の手順（課題の見直しと、どこにも結び付かない許容外の起票）のとおりで、比べの設定の直しは、観測値の設定だけで済み、モデルを変えない。
- 論点 1〜3 は上のとおり。

## 6. 分かったこと

1. 見る行の許容外は、モデルの直しの後で新しく増えたものではなく、多くは理由の分かった古い差だった。課題に結び付いていなかったものの多くも、検証記録・設計書に理由が書いてあった。
2. 表を着地点ごとの値に改めた後に、比べの設定が追いついていない観測値があった（着地点を書かない比べと、B と C を合わせた値を B で比べる設定）。表の値を着地点ごとに分けるときは、その表と比べる観測値の着地点の設定も見る。
3. 的のジャンプを代表値にした比べが、許容外の大きなまとまりになっている（`residual-gauge-full-jump` の `-01`、`0916-06`・`0917-06`、`1350-21`、紅蓮BS の発の数）。録画のジャンプの窓（`jumpWindows`）で比べ直せるものは、そちらが正の比べになる。
4. 結論の本文が今のモデルと合わなくなっているもの: C-1142 の本文と model の 0754 の差（フルバーストの始まりが 15f 遅い）は、いまのモデルの値と合わない。C-1151 の根拠の文の「わけは分からない」は、C-1358 の後は大部分が説明されている。C-1502 の model は雛形の文のまま。
5. `0646-03` が読み違いなら、その値を含む C-0642 の値も少し動く（`residual-range-reading`）。

- 2026-11-28: 起案と棚卸し。3 節の課題を直し、どこにも結び付かない許容外を起票し、比べの設定の古い観測値を直した（5 節）。

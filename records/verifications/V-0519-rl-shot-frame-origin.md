# V-0519: モデルの RL の射撃のフレームは、撃ったフレームか着弾か（紅蓮BS・レイヴンの遅れの起点。読み直し R3）

- 問い: 紅蓮：ブラックシャドウ・レイヴン単騎の録画で、モデルの射撃のフレームは、撃ったフレーム（照準の横の残弾が減ったフレーム）と着弾（HUD の増分）のどちらに当たるか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-10-26
- Stage: plan/design-shot-count-trigger-frame.md 6.6 節（R3。論点 3）。backlog 2-38
- 録画: `0421`、`0422`、`0122`
- 状態: 調査中

## 条件

- 型: 読み直し（撮影なし）。2026-10-26 のオーナーの判断で進める。
- 見たいこと: 紅蓮BS の S1 の段（C-0651）とレイヴンの S1 の付与のゲージ（C-0181）の遅れは、撃ったフレーム F から測った値。RL は弾が飛ぶので、着弾（HUD の増分）N は F の 2〜8f 後（`0122-13` の注記・`0421-11`）。モデルの射撃のフレームが F に当たれば、測った遅れをそのまま `delayFrames` に書ける。N に当たれば、着弾の分を引くことになる（plan/design-shot-count-trigger-frame.md 6.3 節の論点 3）。
- 読む前に知っていたこと: モデルの戦闘開始からの 1 発目（`firstShotFrames`）と発と発の間の内訳は、紅蓮BS は `0046-19`、レイヴンは `0122-13`・`0122-14` の撃ったフレームで較正してある（C-0218 のモデル側）。紅蓮BS の 0421 の最初の増分は戦闘開始から 33f（`0421-07`）、レイヴンの 0122 の最初の F は 86f・最初のヒットは 90f（`0122-14`・`0122-12`）。
- 録画と再現:
  - 0421・0422（紅蓮BS 単騎・AUTO・オートバースト OFF・スペック固定 ON）: モデルの射撃のフレームの較正に使っていない。**判定に使う録画**。
  - 0122（レイヴン単騎・AUTO・オートバースト OFF）: レイヴンの射撃のフレームの較正に使った録画（結論の `decidedOn` に `値を合わせた`）。記録として読む。レイヴン単騎の AUTO の録画はほかに無い（0141 は手動）。射撃の式（`frame/firing.ts` の `stanceFrames`。射撃姿勢維持型）は紅蓮BS・レイヴンで同じ。
- 最小構成: 単騎・バーストなし。射撃のフレームに効く未確定の要素は無い（紅蓮BS の S1 の段・レイヴンの S1 の持続ダメージは射撃の時刻を変えない）。
- 範囲: 戦闘開始から 1 回目のジャンプまで（1 区間目）。的のジャンプの時刻は録画ごとに違い（C-0552）、モデルの代表値と合わないので、2 区間目からはモデルと録画の発を 1 つずつ結び付けられない。動画のフレームとゲーム内の時刻のずれ（C-0262 の止まり）も、1 区間目なら小さい。

## 予測

予測ファイルは無い（射撃のフレームと F・N の差を比べる指標が無い）。読む前に次を固定する（2026-10-26）。録画の 1 区間目の発ごとに、Δ_F = モデルの射撃のフレーム（戦闘開始の動画のフレーム + モデルのフレーム）− F、Δ_N = モデルの射撃のフレーム − N とする。

| 仮説                                           | 1 区間目の Δ_F の中ほど | 1 区間目の Δ_N の中ほど | 当たったときにすること                                                                             |
| ---------------------------------------------- | ----------------------- | ----------------------- | -------------------------------------------------------------------------------------------------- |
| HF: モデルの射撃のフレームは撃ったフレーム     | 0 に近い（−2〜+2）      | 負（−着弾までの f）     | C-0651・C-0181 の遅れを、そのまま `delayFrames` に書ける（紅蓮BS の段 A 10・B と C 9、レイヴン 6） |
| HN: モデルの射撃のフレームは着弾（HUD の増分） | 正（+着弾までの f）     | 0 に近い（−2〜+2）      | 測った遅れから着弾までの f を引いて書く形を考える。着弾までの f は距離で揺れるので、設計に戻す     |

- 判定: 録画ごとに、1 区間目の発の Δ_F・Δ_N の中央値を出す。|Δ_F の中央値| < |Δ_N の中央値| かつ |Δ_F の中央値| ≤ 2 なら HF、逆なら HN。0421・0422 の 2 本で同じ仮説になれば、その仮説とする。2 本で食い違うか、どちらにも当たらなければ決めず、撮影計画を「次に撮るもの」に書く。
- 0122 は記録（判定には使わない）。

## 読み方

1. F: 照準の横の残弾の表示（`reticle-ammo.ts --mode series`）を、戦闘開始から 1 回目のジャンプまで読み、前の読めたフレームとの間が 1f で値が 1 減ったフレームを F とする（V-0498 と同じ）。
2. N: HUD の総ダメージの増分（`hud.ts --mode jumps`）のうち、F の後 12f 以内の最初の通常攻撃の 1 発の増分（紅蓮BS は `0421-10` の注記の通常攻撃の値、レイヴンは `0122-02`・`0122-03` の値）。その増分の `gap` が 1 でない発は N を使わない。
3. モデルの射撃のフレーム: 録画の素性（`buildTeamInput`。敵 `range-bigarms-fire`・出来事 `range-3min-jump`・バーストなし）で sim を回し、枠 1 の射撃のフレームに戦闘開始の動画のフレーム（0421 は f748・0422 は f810（`0421-07`・`0422-07`）、0122 は f751（`0122-04` の注記））を足す。
4. 1 区間目: 録画の 1 回目のジャンプ（0421・0422 は `0421-08`・`0422-08` の 1 つ目、0122 は F の間が 3 秒を超えた所）とモデルの 1 回目のジャンプの早いほうより前の発。録画の F ごとに、15f 以内で一番近いモデルの射撃のフレームを結び付ける。結び付かない発は除いて数を書く。
5. 録画ごとの Δ_F・Δ_N の中央値と幅を、観測値（`kind: interval`・`use: record`・`scope`）にする。

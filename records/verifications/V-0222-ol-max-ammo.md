# V-0222: OL の最大装弾数増加は、マガジンの弾数にどう効くか

- 問い: スペック固定 OFF のマナ単騎で、OL の「最大装弾数増加」（2 行）は、マガジンの弾数（最大装弾数）にどう効くか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-10-06
- 録画: `250`
- 結論: `C-0328`
- 状態: 完了

## 条件

- V-0223（キューブの最大装弾数▲）の前提。マナの OL には最大装弾数増加が 2 行あり、キューブの録画では OL と重なるので、キューブなしの録画で OL だけの弾数を先に決める（オーナーの確認 2026-10-06: マナ・ノワールとも OL に最大装弾数の行がある）。
- 録画は V-0221 の録画 1（マナ単騎・キューブなし）。条件と最小構成は V-0221。マガジンの弾数に効くのは、CDN の最大装弾数（60）と OL の 2 行だけ（マナのスキルに最大装弾数の効果は無い。コレクション（AR）はコアダメージ▲で弾数に効かない）。
- OL の行の値は data/masters/overload.json（ShiftyPad の実数値で確かめた表。design-stage12.md 13.1 節）。

## 予測（撮る前に書く）

H1 はいまのモデル（2 行を足して round(60 × (1 + Σ))。スキルの最大装弾数▲と同じ C-0017 の形）、H0 は OL の行が乗らない形で、値は予測ファイル（records/predictions/V-0222.json）にある。H2（行ごとに掛け合わせて丸める）は式を切り替える仮説なので、ここに手で書いた。

| 仮説               | マガジンの弾数 |
| ------------------ | -------------- |
| H1: 足して丸める   | 予測           |
| H0: 乗らない       | 予測           |
| H2: 行ごとに掛ける | 167            |

- 見分け方: リロードを終えた直後の照準の横の残弾（`reticle-ammo.ts`）と枠アイコンの上の「残弾/最大」（`ammo.ts`）。3 つの仮説は 1 発以上離れる。
- 合えば: H1 ならモデルはそのまま。V-0223 の予測の前提（H1）が立つ。
- 合わなければ: `effectiveMaxAmmo` の合成を直し、V-0223 の予測を出し直す前に、V-0223 の録画の読みを止める。

# V-0695: ラプラス：アルティメットヒーローの変更後の武器の撃ち切りの最終弾とリロードの始まり（読み直し）

- 問い: 連射で撃ち切る押下チャージ型（ラプラス：アルティメットヒーロー）の全弾リロードの始まりは何に結び付くか。最後の間隔が 3〜4f に延びる回はどういう形か
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-08
- 録画: `0121`、`0130`、`0131`
- 状態: 調査中
- 派生元: `V-0681`

## 条件

- 型: 読み直し。backlog の 2-61。V-0681 で、ラプラスの全弾リロードの始まり（RELOADING のバーの 0 の点）を最終弾から数えると −0.46〜−1.75f とばらつき、最後の間隔（最後から 2 発目 → 最終弾）が 2・3・4f と回ごとに違うことから来ると分かった。最後から 2 発目から数えると約 1.5f 後に揃うが、最後の間隔が延びるわけは分からなかった（[design-reload-rounding.md](../../plan/design-reload-rounding.md) 9・10 節）。
- 連射は、S1 の使用武器の変更（エレクトリックパワー・フル・フルチャージ）の変更後の武器（1440rpm・即着弾・120 発。C-0699）で、撃ち切ると変更が終わり、変更の終わりの残弾数減少で変更前の武器がリロードする（C-0700）。
- 見分けの要: マガジンの頭（変更後の武器の最初の発）から全部の発を並べると、発射レートの蓄積（C-0058）を最初の発で 0 から始める形なら、n 発目（0 始まり）は最初の発の ⌈n × 125 / 51⌉ f 後（1440rpm の 1 発は 125/51 = 2.451f）に出て、最後の間隔はいつも 2f（119 発目 290f → 120 発目 292f）になる。最後の間隔が 3〜4f に延びるのが、どの発がずれた形かを見る。
- 最小構成: 単騎。読むのは射撃の時刻とリロードのバーだけで、ダメージの値に効く未確定の要素（S2 のオーバーエネルギーなど）は効かない。

## 予測

なし（読み直し）。

## 読み方

1. 録画は Drive から取り寄せた（`node tools/captures/fetch.ts`）。
2. `node tools/captures/hud.ts <動画> --mode jumps`（総ダメージの増分。変更後の武器は即着弾で、1 つの増分が 1 発）と `node tools/captures/reticle-ammo.ts <動画> --mode series`（照準の残弾）で、変更後の武器の発をマガジンの頭から終わりまで並べた。最初の発は照準の残弾が 120 → 119 に変わり、HUD に増分が出たフレーム。
3. `node tools/captures/reload.ts <動画> --mode fit` で、撃ち切りで始まる全弾リロードのバーの 0 の点と、バーが消えたフレーム（込め終わり）を読んだ。
4. 発のフレーム・0 の点・込め終わりを、変更後の武器の最初の発から数えて並べた（使い捨てのスクリプト）。各録画の 14 回目（最後の変更）は的のジャンプの窓に入り、バーの当てはめが無いので除いた。

### マガジンの頭から終わりまで

- 119 発目までは、3 本の 39 回のどれも、最初の発から毎回 0 で始める 1440rpm の蓄積のフレーム（⌈n × 125 / 51⌉）に HUD の増分が出る（119 発目は 290f）。外れは、照準の残弾が読めない空白で値が遅れて読めたフレームと、何回かの 1f の揺れ（`0121` の f6275 の回は 11 発目から後がどれも 1f 遅れ、`0130` の f7898・`0131` の f3371 の回は 119 発目だけ 1f 早い）だけ。最初の発の位相は回ごとに変わらない（125/51 の倍数の端数は 1/51 刻みなので、毎回 0 から始める形から 0.02f より動くと、どこかの発が 1f 動く）。
- 120 発目（最終弾）は、292f の回と 293f の回がある（`0121-33`・`0130-28`・`0131-28`。39 回のうち 293f が 22 回）。HUD の増分と照準の残弾の 001 → 000 が同じフレームで遅れる（V-0681 で 0121 の 3656 ほかを切り出して目で確かめたのと同じ）。蓄積の形では、119 発目までと合う位相（0 から 1/51 未満の幅）のどれでも 120 発目は 292f で、293f にはならない。
- 最後の間隔の 2・3・4f は、これで説明がつく: 2f は 120 発目が 292f の回、3f は 293f の回、4f は 293f の回のうち 119 発目が 1f 早く 289f に出た回（`0130` の f7898・`0131` の f3371）。延びているのは最終弾の 1 発だけで、マガジンの中の刻み（蓄積）は回ごとに同じ。

### リロードの始まりと込め終わり

- バーの 0 の点は、最初の発から 291.24〜292.18f で、中央値は 291.50・291.58・291.54f（`0121-34`・`0130-29`・`0131-29`）。120 発目が 292f の回と 293f の回で分かれない（0121 の 292f の回の平均 291.48f、293f の回 291.58f。11 発目から遅れた f6275 の回を除くと 291.52f）。
- 込め終わりは、最初の発から 39 回のうち 37 回が 451f（`0121-35`・`0130-30`・`0131-30`）。120 発目が 293f の回も 451f。452f の 2 回（`0130` の f10082・`0131` の f7840）は、終わりの何発かが 1f 遅れて出た回で、0 の点も遅い（291.68・292.18f）。
- 蓄積の上の 120 発目の本当の発の時刻（最初の発 + 119 × 125 / 51 = 291.67f。292f の発の余りから出す C-0984 のずれ −0.33f）と比べると、0 の点は約 −0.1〜−0.2f。チャージの無い 1440rpm の武器（チャイム・リター・ルドミラ）の 0 の点 − 最終弾（−0.3〜−0.46f。蓄積の余りから −0.33f。V-0681）と同じくらいの差で、C-0984 のチャージの無い武器の形に入る。
- 込め終わりは、0 の点を 291.67f として C-0983 の ⌈始まり + x + c⌉（x はリロード 2.5 秒の 147.06f、c は 11.9f）= ⌈450.63⌉ = 451f で、録画のとおり。最終弾の 293f から始めても、0 の点の中央値から始めても 451f。

### モデルとの比べ

- いまのモデル（設計書 13 節）は、変更後の武器の 120 発目を最初の発の 292f に撃ち、次のフレーム（293f）の残弾数減少で、始まりを 1 フレーム前の 292f（ずれ 0）にしてリロードする。込め終わりは 451f、次の変更前の武器の発は 522f で、録画（込め終わり 451f、`0121-17` の最後の発 + 230f = 522f）と同じ。
- 13 節で始まりを 1 フレーム前にした根拠「ラプラスのリロードは最後の発より前に始まっている」は、120 発目が 293f に遅れて出る回を見ていた形で、始まりは蓄積の上の 120 発目の時刻（チャージの無い武器と同じ C-0984 の形）に結び付く。292f（ずれ 0）は、整数の込め終わりは同じだが、0 の点の録画（約 291.5f）より約 0.5f 遅い。
- 試しに、残弾数減少の始まりのずれを変更後の武器の 120 発目の蓄積の余りから出す形（設計書 14 節の案 F。−1 − 余り ÷ 1 フレームの蓄積 = 291.67f）にすると、ラプラスの録画 12 本の比べる観測値の残差はどれも変わらなかった（コミットしていない）。

## 分かったこと・分からないこと

- 分かった: ラプラスの変更後の武器は、最初の発から毎回 0 で始める 1440rpm の蓄積の刻みで撃ち、119 発目までは回ごとに同じフレームに出る。最後の間隔が 3〜4f に延びるのは、120 発目（最終弾）だけが 1f 遅れて出る回（39 回のうち 22 回）で、4f は 119 発目の 1f の揺れが重なった回。
- 分かった: 撃ち切りで始まる全弾リロードの始まりと込め終わりは、見える最終弾によらず、蓄積の上の 120 発目の時刻に結び付く（0 の点は最初の発の約 291.5f、込め終わりは 451f）。V-0681 の「最後から 2 発目に結び付いて見える」は、119 発目が蓄積のとおりに出て、120 発目だけが揺れるため。
- 分からない: 120 発目が 1f 遅れて出る回と出ない回を分けるもの（録画の中の順・S2 のオーバーエネルギーの段階とは揃わない）。チャージの無い武器の最終弾でも、V-0681 の「最終弾のフレームの読みが 1f ずれた形」の回が同じ現象かは確かめていない。

# V-0139: フラワー（RL）のリロードの完了から 1 発目までは、待ちからの 1 発目と同じか

- 問い: I-DOLL・フラワー（RL・入力 UP・撃った後の区間が 0f）単騎でも、弾切れのリロードの完了から 1 発目までは待ちからの 1 発目（戦闘開始から 71f）と同じで、発と発の間（82f）ではないか（C-0225 を紅蓮BS の外で確かめる）
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-10-04
- 録画: `077`
- 状態: 調査中
- 派生元: `V-0135`

## 条件

- 撮影はしない。フラワー単騎・AUTO・オートバースト ON の `077` を読み直す。フラワーのスキルにチャージ・リロードの速さに効く効果は無い（`data/skills/304.json`。S2 はゲージ、バーストは 1 ヒット）ので、リロードの前後に未確定の要素は入らない。
- 新しく読むのは RELOADING のバー（レシピ `reload-segments`）の「完了 → 次の増分」と「最終弾 → 完了」。`077` は完了のフレームとバーの長さ（`077-11`）だけ既に読んであり、完了 → 次の発はまだ読んでいない。レシピが出すバーの長さは `077-11` と同じ読みなので、比べる値にしない。
- 窓をまたいだリロード・取り消しはレシピが除く。バーストの発動と重なった回も、完了 → 次の増分が長くなればレシピの「窓をまたいだ回」（中央値 + 5f 超）で除かれる。

**いま分かっていること**

- C-0225（確定）: 入力が UP のチャージ武器は、待ち（戦闘開始・窓の明け）から、発と発の間より撃った後の区間のぶん早く 1 発目を撃つ。リロードの完了から 1 発目までも待ちからと同じ。リロードの後の部分の根拠は紅蓮BS 単騎の 3 本（V-0135）だけで、ラム（`075-07`）は後付け。
- フラワーの発と発の間の内訳は、撃った後 0f・100% のまま 23f・チャージ 58f・満ちてから撃つまで 1f（`077-26`。C-0216）。戦闘開始から最初の発まで 71f（`077-27`。C-0225）。リロードをまたいだ発の間は 200f（`077-12` の注記）。
- 紅蓮BS（撃った後の区間 約 13f）はバーが撃ってから約 12f で出始め、ラム（撃った後 13f）はバーが最後の発から出る（`075-09`）。フラワーは撃った後の区間が 0f なので、構え解除にあたる区間が無いまま 100% で 23f 待つ形。

## 予測（撮る前に書く）

比べる値は `077` のリロード完了（RELOADING のバーが消えたフレーム）から次の発の総ダメージの増分まで。増分は撃ったフレームより弾が届くまで遅れる（遅れを d とする。フラワーの d はまだ測っていないので、紅蓮BS と同じ 1〜9f の幅で見る）。

| 仮説                                                                               | 完了 → 次の増分                               | 最後の発 → 完了（200f − 左の値の中の撃つまで） |
| ---------------------------------------------------------------------------------- | --------------------------------------------- | ---------------------------------------------- |
| H0: 完了から発と発の間と同じ 82f で撃つ（モデルの分け方）                          | 82 + d（83〜91f）                             | 約 118f（バー 約 130f より短く、合わない）     |
| H1: 完了から待ちからの 1 発目と同じ 71f で撃つ（C-0225 がフラワーでも成り立つ）    | 71 + d（72〜80f）                             | 約 129f（バーが最後の発から出る）              |
| H2: どちらでもない（撃った後の区間が 0f の武器はリロードの後の待ちが別の長さなど） | 81f 前後か 91f 超、または回ごとに大きく揺れる | —                                              |

- 見分けられるか: H0 と H1 は 11f 違い、d の幅を入れても重ならない。判定は全部の回の範囲と中央値（中央値が 72〜80f で、範囲が 83f に届かなければ H1）。
- 予測ファイル（`records/predictions/V-0139.json`）は、いまのモデル（H0 の分け方）の射撃の数を形の確かめとして固定しただけで、仮説を見分けない（V-0135 と同じ理由で、モデルの分け方を切り替える口が無い）。
- 外れたときの影響: H0 か H2 なら、C-0225 の「リロードの完了から 1 発目までも待ちからと同じ」は紅蓮BS（とラム）の形で、撃った後の区間の無い武器には当たらない。C-0225 の範囲を狭め、モデルの `unhideShooter` の直し（V-0135）をフラワーに効かせるかを見直す。H1 なら C-0225 の根拠にフラワーを足す。
- 見込み: H1。

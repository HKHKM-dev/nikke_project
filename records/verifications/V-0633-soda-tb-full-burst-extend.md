## 読み方

1. レシピ `burst-panel` の特徴のキャッシュ（`burst-panel@1`。六角形の所の平均の色とバーの行の紫の画素の数）で、00.00 の後の推移を見た。バーの紫は窓の途中で尽きる（窓の長さに比例して、終わりの手前で 0 になる）ので、終わりには使えない。窓の終わりでは、六角形の所がフルバーストの背景の橙から次の段の灰色に 1 フレームで替わる（青と緑が一度に上がる）。
2. この替わり目を、00.00 の 300f 後から次の 00.00 の前まで探す読みとしてレシピに足した（`burst-panel@3`。`burst-panel-lib.ts` の `fullBurstEnd`。閾値は 0542 の 1〜5 回目と 0543 の 4・5 回目の替わり目の前後の色で決めた）。
3. `npm run records:read -- 0542,0543,0544 --recipe burst-panel --source V-0633 --write` で、終わりのフレーム（`-13`）と 00.00 からの長さ（`-14`）を観測値にした（同じレシピの段の替わり目・00.00・CT の明けは既にある観測値と同じ値なので、足さなかった）。
4. 長さは、指標 `fullBurstLengths`（窓の始まりから終わりまでのモデルのフレームに、入りの止まり（C-0069）を足した動画のフレーム）と比べた。許容は ±2（入りの止まりは 21〜24f で、モデルは 22f。C-0069）。
5. 0463・0471 の発動の直前のゴールデンチップの数（`0463-07`・`0471-07`。記録だけ）は、延長を足したモデルの数と並べた（観測値は書き換えない）。

- **窓の長さ**（`0542-14`・`0543-14`・`0544-14`）: 3 本とも、5 回の窓が、1〜3 回目は延長 I と II（10 + 2 + 3 秒）、4 回目は延長 I（10 + 2 秒）、5 回目は延長なし（10 秒）の長さで、延長を足したモデルと 1 以内。延長の無いモデル（どの窓も 10 秒）では 1〜4 回目が許容外。延長の段は、V-0437 の一時停止画面の記録（1〜3 回目は +2 秒と +3 秒、4 回目は +2 秒、5 回目はなし）と同じ。

- **ゴールデンチップの数**（Q3）: 延長を足したモデルの、2〜5 回目の発動の直前の数は、録画（`0463-07`・`0471-07`）と 1 以内になった（延長の無いモデルでは、窓の中の発が足りず最大 7 少なかった）。2 本の録画どうしも 1 違うので、比べる指定にはしていない。

- C-0877（確定）。時間延長 I・II の状態（S2 の 2 行目が読む）は、読む側と一緒に V-0634 で足す。

## 分かったこと・分からないこと

- 分かった: 時間延長 I・II は説明文どおりの段で付き、延長の秒は足し算で、その後に始まる窓を延ばす。窓の終わりはバースト欄の六角形の所の色の替わり目で読める。
- 分からない: 窓が延びた時の、バーの紫の減り方（窓の長さに比例するか）。窓の終わりの読みには使わないので、調べない。

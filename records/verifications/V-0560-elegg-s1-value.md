## 分かったこと・分からないこと

### 読み直し（録画 0711・0712。2026-10-31）

HUD の総ダメージの増分（`hud.ts --mode jumps`）を読み直した。エレグはフルバースト中ほぼ 1 フレームに 1 発撃つので、S1 の組の 3 ヒットのどれにも、同じフレームのほかの 1 ヒット（多くはエレグのコアの 1 ヒット）が重なっている。重なりを引くと、30 組（0711 は 14 組、0712 は 16 組）の 1 ヒットはどれも、次の 5 つの値のどれかになり、同じ組の 3 ヒットは同じ値（`0711-17`・`0711-18`・`0712-16`・`0712-17`）。

| 組の条件（届いた発の次のフレーム）                               | 1 ヒット | 組の数（0711・0712） |
| ---------------------------------------------------------------- | -------- | -------------------- |
| 分配ダメージ▲あり・受けるダメージ▲なし・会心なし                 | 125,194  | 3・2                 |
| 同・会心                                                         | 166,925  | 2・2                 |
| 分配ダメージ▲あり・受けるダメージ▲あり・会心なし                 | 140,585  | 8・9                 |
| 同・会心                                                         | 187,447  | 1・1                 |
| 分配ダメージ▲なし（窓の切れた後）・受けるダメージ▲あり・会心なし | 104,982  | 0・2                 |

どの組も、S2 の攻撃力▲・防御力▼・フルバースト補正が乗っている。仮に S1 を定義に入れたモデル（`damage`・`distributed`。窓 1）の全額は、会心なし・受けるダメージ▲なしで 375,579.9（バフ後の攻撃力 113,005 − 防御力 64.36 = 112,940.64、× 158.65% × 1.5 × 1.3974）。

- **H1（1 ヒットは全額の 3 分の 1）**: 受けるダメージ▲の無い組は、全額の 3 分の 1 の 125,193.3 と、会心で倍率グループが 1.5 → 2.0 の 166,924.4 と合う。分配ダメージ▲の無い組は、(攻撃力 − 防御力) × 158.65% ÷ 3 × 1.5 × 1.1718 = 104,981.8 と合う。HUD はどれも小数を切り上げた値。V-0524 の 140,921 は 125,194 にエレグのコアの 1 ヒット 15,727 が重なった値。
- **H2（値は届いた発の次のフレームのバフで決まり、3 ヒットとも変わらない）**:
  - 0711 の f1161 の組（届いた発 f1153）: 鈴原サクラの受けるダメージ▲はエレグのコアの 1 ヒットに f1159 から乗る（15,727 → 18,429）が、組の 3 ヒット（f1161・1185・1197）は▲なしの 125,194 のまま。f11004 の組（届いた発 f10996）も、2・3 ヒット目（f11028・11040）の時にはエレグのコアの 1 ヒットに▲が乗っている（f11026 から 20,640）が、3 ヒットとも▲なしの 125,194。
  - 0712 の f8669 の組（届いた発 f8661）: 同じ発で S2 が付き直し（通算の命中 300 の倍数。▲は f8662 から。それまでのエレグのコアの 1 ヒットは▲なしの 18,250）、組の値は S2 の▲ありの 104,982。f1510 の組（届いた発 f1502。V-0524 の S2 の最後の発火）も S2 の▲あり。
  - 0711 の f6024 の組は、受けるダメージ▲が 1 ヒット目と 2 ヒット目の間で切れても（20,640 → 17,614）、3 ヒットとも 140,585。0712 の f1510 の組は、フルバーストとブームインストールが 2 ヒット目（f1534）と 3 ヒット目（f1546）の間で切れても（エレグのコアの 1 ヒットが 12,578 になる）、3 ヒットとも 104,982。0712 の f8669 の組も、頭の後に切れても 3 ヒットとも同じ。
  - 値を決めるフレームは、届いた発の 1〜5f 後のどこか（1 は 0712 の 2 組の S2、5 は 0711 の f1161 の組の受けるダメージ▲で挟む）。モデルの S2 の▲と同じ次のフレームと読む。
- **H3（受けるダメージ▲は分配ダメージ▲と同じ和に入る）**: 両方の▲がそろった組（2 本で 19 組）は、(1 + 0.3974 + 0.1718) = 1.5692 を掛けた 140,584.9（会心で 187,446.5）と合う。いまのモデルの別の乗数 (1.3974 × 1.1718 = 1.6375) の 146,701.5（会心で 195,602.0）とは合わない。分配ダメージ▲の無い組（104,982）では、受けるダメージ▲は説明文の 17.18% で乗るので、▲の値が小さく効くのではなく、置き場所の違い。
- **分配ダメージ▲の窓の終わり**: 0711 の窓 5 の f11004 の組（届いた発はブームインストールの始まり s_w の 545f 後）には分配ダメージ▲が乗り、0712 の窓 1 の f1510 の組（同 553f 後）と窓 4 の f8669 の組（同 579f 後）には乗らない。C-0691 の 10 秒（窓の終わりは測っていない）の切れ目は、この間にある。
- 外れたもの: 全額（375,580）・それぞれ全額は、どの組とも合わない。3 ヒットの値はヒットの時点のバフ（フルバースト・受けるダメージ▲の切れ目をまたいで変わる形）とも合わない。
- この読み直しは、式の仮説を 0711 で立て、0712 でも同じ式で全組が合うことを確かめた。両方とも仮説の出どころなので、別の録画で再現を取る（「次に撮るもの」。2.2 節の再現には、仮説を決めた録画を数えない）。

### まとめ

- 式の定義への反映は、撮り直しで再現を取ってから。
- 分からないこと: H3 が、エレグの S1 のほかの分配ダメージ（雪子のバースト・クイーン（真）の S1 など）にも当てはまるか。受けるダメージ▲と分配ダメージ▲がそろった分配ダメージのヒットは、ほかの録画には無い（V-0522 の 2 回目以降の雪子のヒットは、雪子自身の効果の窓との重なりが分からず使えない）。

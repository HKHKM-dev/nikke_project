## 条件

**何を確かめるか**

- III のバースト使用時の効果の付き始めは、雪子では III の CT の明けとほぼ同時（00.00 の 4〜6f 前。C-0614）、ルドミラ：WO では 00.00 の 1〜2f 前（CT の明けの 4〜6f 後。C-0510）で、キャラごとに違う（C-0540）。III の CT の明けは 00.00 の 6〜8f 前（C-0512）。
- ラピ（C-0513）は、録画 221・366 の 8 回とも発が 00.00 の 7〜8f 前と 1〜2f 前にあり、あいだに無かった。アスカ（C-0514）は、録画 063 の 00.00 の 5f 前の発に▲が無く、4〜1f 前に発が無かった。どちらも、見分けるには 00.00 の 6〜3f 前（CT の明けの 0〜3f 後）に発のある回が要る（V-0396・V-0397・V-0399 の「次に撮るもの」）。
- 撮る前に、ラピ・アスカが III でバーストを使う既存の録画のうち、まだこの問いで読んでいないものを探した（録画の台帳から、ラピ（10）・アスカ（830）が編成にいて、オートバースト ON の録画）。

**編成**（どれも射撃場・BigArms・3 分モード・スペック固定 ON・オートバースト ON）

- 録画 `018`: エーテル（291。I）+ デルタ（20。II）+ ラピ（10。III・操作・AUTO 射撃 ON）。電撃の的。フルバーストは 5 回。
- 録画 `461`・`462`（V-0436）: ラム（822。I・操作）+ デルタ（II）+ アスカ（830。III・AI）。風圧の的。フルバーストは 5 回ずつ。
- 読んだが使えなかった録画: `080`・`284`（フラワー（I）+ ユニ（II）+ アスカ（III・操作））は、8 回とも 00.00 の前 25f 以内にアスカの発が無い。`041` はラピのほかにクラウン（II）とデルタ（III・操作）がいて、クラウンの S1 のフルバースト開始時の攻撃力▲など、00.00 の頃にラピの 1 発に効く要素が増えるので読まない。`069` は照準を的から外した録画。ほかのアスカの録画はオートバースト OFF か、アスカが撃たない録画。
- **最小構成**:
  - `018`: エーテルの効果は 13 秒ごとの S2 のダメージ（確定。C-0405）と、ダメージに効かない効果だけ。デルタはダメージに効く効果が無い（C-0081）。ラピの S1（被弾で自分に攻撃力▲。前提の外）は 1 発の値を 1.218 倍にするので、`221-21` と同じく格子を別に持つ。ラピの 1 発の値に効く未確定の要素は、見ている付き始めだけ。
  - `461`・`462`: ラムの効果はバーストのバリア（C-0253・C-0557。確定）と、フルバーストの終わりの CT の短縮（C-0080 確定・C-0235 仮説。00.00 の前の発の値には効かない）。デルタは上と同じ。アスカの S1（回復を受けた時の攻撃力▲。C-0464）はバーストの回復で付くので、00.00 の前の発では▲の有無を値で分ける（バースト使用時の攻撃ダメージ▲と同じ発から付く）。S2 のフルバースト開始時の効果（コアダメージ▲・バリアを読む属性ダメージ▲。C-0075・C-0557）は、値で分ける。

**読み方の前提**

- ラピの 1 発の格子は `221-21` の注記と同じ（距離ボーナスの有無・会心・コアの倍率と、攻撃力▲・S1 の▲の有無で値が一通りに決まる）。
- アスカの 1 発（風圧の的）は、▲なし・S1 の▲だけ・S1 の▲と攻撃ダメージ▲・それにフルバースト開始時の効果と補正が乗った値で分かれる（格子は `461-14` の注記）。
- 付き始めは III の CT の明け（顔の CT の秒が消えたフレーム）から数える。CT の明けは burst-panel のレシピで読み、使った回は画で確かめた。動画とゲームのフレームは 1f ほど揺れる（V-0399「読み方の前提」）。

## 予測

なし（読み直し）。比べる仮説は V-0396・V-0397 の予測の表と同じ（HY: CT の明けの頃に付く（雪子の形）/ HL: CT の明けの 4〜6f 後に付く（ルドミラ：WO の形）/ H0: 00.00 から）。HY なら CT の明けの 1〜3f 後の発に▲があり、HL なら無い。

## 読み方

1. 録画ごとに `burst-panel` のレシピで、III のタイマーの 00.00 と III の CT の明けのフレームを読む（`018-27`〜`018-32`・`461-08`〜`461-13`・`462-08`〜`462-13`）。CT の明けを使う回は、右のバースト欄を 1 フレームずつ並べた画で、CT の秒の消えたフレームを確かめる。
2. HUD の増分（`hud-jumps` のキャッシュ）を、各回の 00.00 の 35f 前から 30f 後まで並べ、ラピ・アスカの発を格子に当てる（格子に乗らない増分はほかのキャラの発として数えない）。
3. 回ごとに、▲の無い最後の発と▲の付いた最初の発を、III の CT の明けから数える。

- **ラピは HY（雪子の形）**: CT の明けの 1f 後（2 回目）と 3f 後（3 回目）の発に攻撃力▲が乗り、補正は無い。HL（CT の明けの 4〜6f 後）なら、この 2 発には▲が無い。CT の明けと同じフレームの発（5 回目）には▲が無い。1 回目は CT の明けが無く（CT が律速でない）、00.00 の 7f 前の発に▲が無く 1f 前の発に有る（221・366 と同じ形）。
- **アスカは HL（ルドミラ：WO の形）**: CT の明けの 1f 後の発（`462` の 3 回目。00.00 の 5f 前）に攻撃ダメージ▲が無く（`063-15` の 4 回目と同じ）、CT の明けの 5f 後の発（`461` の 3・5 回目。00.00 の 1f 前）に有る。H0（00.00 から）は `461` の 2 回で外れ、HY は `063`・`462` の 2 本で外れた。
- 同じ CT の明けの 1f 後の発で、ラピには▲があり（`018` の 2 回目）、アスカには無い（`462` の 3 回目）。動画とゲームのフレームの 1f の揺れでは、ラピの 3f 後の▲（HL の始まりより 1f 以上前）と、アスカの 5f 後まで付かないことの両方は説明できない。
- アスカの S2 のフルバースト開始時の効果: `461` の 5 回目の 00.00 の 1f 前の発はコアの発で、S1 の▲と攻撃ダメージ▲は乗っているが、コアダメージ▲（コアの項が 1.6007 倍）も、バリアを読む有利コードの攻撃ダメージ▲（有利コードの倍率 1.1 → 1.4002。C-0557。フルバースト中の値 `461-01`・`461-02` は、補正とコアダメージ▲を除いてこの 1.2729 倍だけ大きい）も乗っていない（`461-14` の注記の値。3 回目の胴体の発も同じ）。フルバースト開始時の効果は 00.00 より前には付かない（V-0397 の F0。モデルもフルバーストの窓の始まりの 00.00 から付ける）。

## 分かったこと・分からないこと

- **ラピ**: バーストの攻撃力▲は、III の CT の明けの 1f 後の発から乗る（雪子と同じ形。C-0614）。CT の明けと同じフレームの発には乗らない。モデルは本当の発動（III は 00.00 の 6f 前。C-0516）から乗せるので、合う。
- **アスカ**: バースト使用時の攻撃ダメージ▲は、CT の明けの 1f 後の発には乗らず、5f 後の発には乗る（ルドミラ：WO と同じ形。C-0510）。付き始めは CT の明けの 2〜5f 後（00.00 の 4〜1f 前）。モデルは 00.00 の 6f 前から乗せるので、1〜4f 早い（直さない。plan/burst-effect-delay-candidates.md 2.7.2 節の案 C）。S2 のフルバースト開始時の効果は、00.00 の 1f 前の発には乗らない。
- 2026-10-23 のオーナーの判断で、C-0611・C-0612・C-0613 を確定（反復実測。比べる指標の無い記録の観測値なので、指標なしを上書き）にした。どの回で決めてどの回で再現したかは、各結論の gradeReason。
- III の付き始めの形は、雪子・ラピが CT の明けの頃、ルドミラ：WO・アスカが CT の明けの数 f 後。形を分けるもの（C-0540）はまだ分からない（4 キャラとも操作。ラピ・アスカは AR、雪子は SR、ルドミラ：WO は MG）。
- 分からないこと: アスカの付き始めの 2〜5f 後の中のどこか（CT の明けの 2〜4f 後に発のある回が要る）。

## 次に撮るもの

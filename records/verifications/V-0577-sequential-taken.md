# V-0577: 順番攻撃ダメージ▲と受けるダメージ▲の置き場所（マリアン：クイーン・スノーホワイト：ヘビーアームズの観測値で絞る）

- 問い: 順番攻撃ダメージ▲と受けるダメージ▲が同じヒットに乗ったとき、1 つの和で掛かるか、別の乗数で掛かるか

## 条件

- 型: 撮影なしの絞り込み（V-0538・V-0545・V-0553 の観測値だけを使う。新しく読まない）。
- 背景: 分配ダメージ▲は受けるダメージ▲と 1 つの和（C-0767 ほか）、発射体爆発ダメージ▲は別の乗数（C-0789）。順番攻撃ダメージ▲は攻撃ダメージ▲と同じ和（C-0752）で、受けるダメージ▲と両方乗ったヒットで置き場所を見分けた結論は無かった。いまのモデルは別の乗数（`skills/burstDamage.ts` の `computeBurstHit` の順番攻撃と `(1 + damageTaken)`）。
- 見るヒット:
  - マリアン：クイーン（19）の S1 の槍（順番の攻撃）。順番攻撃ダメージ▲ s は自分の S2（85.17%。ほかの III がバーストを撃った回。C-0752）、受けるダメージ▲ t は自分の S1 の弱点露出（5.05%。2 回目の槍から持続。C-0736）。録画 0752・0753 では、ラプンツェル：サンクチュアリの攻撃ダメージ▲（27.45%）も同じ和に入る。
  - スノーホワイト：ヘビーアームズ（471）のフルアクティブの発の順番の攻撃。s は S2 の 158.4%（C-0760）、t は S1 のチャージ中の 4.2%（C-0758）、攻撃ダメージ▲はバーストの 84.48%。
- 値はどれも説明文の値（スペック固定の Lv10）で、合わせ込みの定数は無い。t は s の無いヒットで確かめてある（槍の 1 ヒット 151,358 → 159,001 = × 1.0505。`0738-06` と V-0538 の注記。通常攻撃のコア `0738-13`）。
- 仮説（A は攻撃ダメージ▲、▲の無い値を X とする）:
  - HS（別の乗数。いまのモデル）: 1 ヒット = X × (1 + A + s) × (1 + t)
  - HA（1 つの和）: 1 ヒット = X × (1 + A + s + t)
- 最小構成: 比べる 1 ヒットに効く未確定の要素は、置き場所（和か別の乗数か）だけ（どの観測値も確定の結論の根拠で、最小構成の検査を通っている）。受けるダメージ▲の出どころは、どちらも本人の効果。

## 読み方

1. 観測値（`0740-21`・`0741-21`・`0752-12`・`0753-12`・`0776-04`・`0777-03`）を、いまのモデル（HS）と比べる（`npm run records:residual`）。
2. HA の値は、HS のモデルの値 × (1 + A + s + t) ÷ ((1 + A + s)(1 + t))。

## 分かったこと・分からないこと

- 分かったこと: 順番攻撃ダメージ▲（攻撃ダメージ▲と同じ和。C-0752）は、受けるダメージ▲とは別の乗数 (1 + Σ攻撃ダメージ + Σ順番攻撃ダメージ) × (1 + Σ受けるダメージ) で掛かる。モデルは変えない。
- 分からないこと: 受けるダメージ▲の出どころが本人の効果（マリアン：クイーンの弱点露出・スノーホワイト：ヘビーアームズの S1）だけ。味方の受けるダメージ▲（鈴原サクラなど）では見ていない。

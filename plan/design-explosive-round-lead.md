# 徹甲炸裂弾の受けるダメージ▲の付く時刻（C-0816 をモデルに入れる）

- 関連: C-0816（V-0588）・C-0810（V-0586）・C-0795（V-0576）・C-0312・C-0509（[design-eunhwa-tu-burst-shot-timing.md](design-eunhwa-tu-burst-shot-timing.md)）・C-0512・C-0809、[design-burst-landing.md](design-burst-landing.md) 11 節（バーストのヒットが見る時点）
- 起案: 2026-11-01
- 状態: 起案。2026-11-01 にオーナーが案 B（徹甲炸裂弾の▲の付く時刻だけを直す）に決めた。形（3 節）の承認待ち

## 0. 要約

- 録画では、徹甲炸裂弾の▲は、炸裂弾の HUD の増分が III のタイマーの 00.00 の 5f 前までの回で III のバーストのヒットに乗り、3f 前より後の回は乗らない（C-0816）。
- いまのモデルは、00.00 の 5〜7f 前に着いた回でも▲を落とす（V-0588 の 6 件と、0819・0820 の 1・2 回目が許容外）。
- バーストのヒットが見る時点をずらす形（案 A）では、鈴原サクラの S1 の▲（C-0795）と炸裂弾の▲をモデルの同じフレームで逆に扱うことになり、合わない（2 節）。
- 案 B: 徹甲炸裂弾の状態の効き始めを、炸裂弾の発のフレームの 2f 前にする。炸裂弾自身には乗せない（C-0312）。ほかは変えない（3 節）。

## 1. モデルのいまのフレーム

V-0588 の録画 0837 の編成（リター・ウンファ：タクティカル・アップ・ベスティー：タクティカル・アップ）をモデルで回した 1 回目のフルバースト（ゲームのフレーム。00.00 からの差で書く）:

<!-- prettier-ignore -->
| 出来事 | フレーム | 決まり |
| --- | --- | --- |
| II の発動の印（六角形の替わり目） | −29 | `hexagonFrameOf` |
| III の発動 | −6 | `FULL_BURST_AFTER_ACTIVATION_FRAMES`（C-0512） |
| III のバーストのヒットが見る値 | −7 | `burstHitBuffs` の `preActivation`（発動の直前。C-0795） |
| 炸裂弾の発 | 中近 −5・近 −7・中遠 −4・遠 −1 | 印 + 的の表の `weaponChangeFirstHitFrames`（C-0509） |
| 徹甲炸裂弾の▲の効き始め | 炸裂弾の発 + 1 | 状態の付与の決まり（撃った次のフレーム。95.json の burst の effects[0]） |

- モデルの炸裂弾の発は、録画の HUD の増分と同じフレームに置いている（C-0509 は替わり目から HUD の増分までを測った）。
- いまの▲の効き始めは、どの帯でも −6 より後なので、ヒットに乗らない。

## 2. 見る時点をずらす形（案 A）が合わないわけ

- 鈴原サクラの S1 の▲（V-0576）: 00.00 の 5f 前の命中で付き、モデルの効き始めは −4。ヒットに乗らない。
- 徹甲炸裂弾（V-0588）: 00.00 の 5f 前の炸裂弾で付き、モデルの効き始めは −4。ヒットに乗る。
- モデルの効き始めが同じ −4 で、乗る・乗らないが逆なので、見る時点を 1 つにずらす形ではどちらかが外れる。違いは、HUD に見えるフレームと▲が付くフレームの関係（炸裂弾の▲は HUD の増分より前に付いている）にあり、炸裂弾の側を直す。

## 3. 案 B の形

- 徹甲炸裂弾の状態（ウンファ：タクティカル・アップのバーストの effects[0]）の効き始めを、炸裂弾の発のフレームの **2f 前**にする（いまは 1f 後）。窓の長さ（10 秒）は効き始めから数える。
  - 2f 前にした理由: 00.00 の 5f 前の発で −7 から効き（乗る）、3f 前の発で −5 から効く（乗らない）。3f 前でも録画と合う（−4 の発の回が無い）ので、小さい方を取り、結論の `edge` に幅を書く。
- 炸裂弾自身には乗せない（C-0312）。
- 発のフレームは、使用武器の変更の始まりで決まっている（的の表の行がある敵は印 + 帯の値。行の無い敵は持ち替えの後の待ち）。件は変更の始まりで、撃つ予定のフレームから作る。1 パス目で状態を見るもの（ベスティーの S2 の `enemyState`。C-0809）も、新しい効き始めから見る。
- 定義の語彙: 状態の付与に、回数のきっかけ `weaponChangeShot` のときだけ書ける「発の n フレーム前から効く」項目を足す（名前は実装で決める）。使い手はウンファ：タクティカル・アップだけ。

### 効くところ

- III のバーストのヒット（00.00 の 5f 前より前に着いた回）: ▲が乗る。V-0588 の 6 件と 0819・0820 の 1・2 回目（C-0810 の根拠）が許容内になる見込み。
- 炸裂弾の前後 3f に当たったほかの発（リター・エマ：タクティカル・アップの通常攻撃など）と、窓の終わりの前後 3f の発: ▲の有無が 3f ずれる。実装のときに `records:residual` で、変わる観測値を全部見る。
- 実戦（的の表の無い敵）の炸裂弾も同じく 2f 前から効く。

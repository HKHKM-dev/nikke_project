# NIKKE ダメージ計算ツール

『勝利の女神：NIKKE』のソロレイド / ユニオンレイド（単体ボス・180 秒）を対象に、5 人編成の総ダメージの期待値を算出するツール群です。

- **Web 版（calc）**: https://hkhkm-dev.github.io/nikke_project/ （GitHub Pages）
- `packages/core` … Blablalink 公開 CDN からのデータ取得、キャラデータ、育成のマスタ（装備・好感度・キューブ・コレクション・リサイクルルーム・OL オプション）、ステータス・ダメージ計算（calc / sim で共有）
- `apps/calc` … 数式ベースの期待値計算 Web アプリ。編成はブラウザの localStorage に保存し、JSON で書き出し / 取り込みできる
- `plan/` … 要件定義・ロードマップ・設計書・検証記録（[verification.md](plan/verification.md)）

## できること

- 5 人編成の通常攻撃（武器種ごとの発射サイクル・チャージ・MG のスピンアップ・リロード）と、コア・会心・距離・属性・フルバーストの補正
- スキルのバフ（常時・持続・回数トリガー・スタック・条件付き）、バーストゲージの蓄積と CT で回るフルバースト、バーストスキルと倍率ダメージ、宝物（お気に入りアイテム）版のスキル
- 育成入力: シンクロレベル・限界突破・コア強化・スキル Lv・好感度・装備（T9 / T9 企業 / OL と強化 Lv）・OL オプション・キューブ・コレクション・リサイクルルーム・その他の攻撃力加算
- ユニオン射撃場のスペック固定（Lv400・T9 Lv5 × 4 など）のプリセット
- 実戦向けの入力: 枠ごとの命中率（射撃場 = 1。通常攻撃のダメージとゲージに掛ける）、敵のプリセット（防御力を測った敵だけ。いまは射撃場の的）
- sim（フレーム逐次のシミュレーション。CLI の `npm run sim`）と calc（区間の期待値）で、同じ時刻表・バフ・式を使う

## 精度と未対応

- **確かめたのはユニオン射撃場の録画だけです。** スペック固定の攻撃力、主力キャラ（リター・クラウン・アリス・モダニア・紅蓮：ブラックシャドウ）の 1 ヒット・発射サイクル・バーストの時刻表・総ダメージを射撃場の録画と照合しています（結果と残差は [verification.md](plan/verification.md)）。
- **実戦（迎撃戦・ソロレイド・ユニオンレイド）とは未照合です。** 公開後に行い（ロードマップの Stage 15）、結果をここと verification.md に足します。
- **スペック固定 OFF の育成は仮定を含みます。** キューブ・コレクション・リサイクルルームがコア強化の内側に入るか、OL の上昇値（コミュニティの表の転記・未検証）、OL・キューブ・コレクションの効果の掛かり方は、射撃場の実測待ちです。
- スキル定義があるのは 15 体（ラピ・リター・エマ：タクティカル・アップ・ウンファ：タクティカル・アップ・ドレイク・ユニ・アドミ・アリス・紅蓮：ブラックシャドウ・イサベル・モダニア・ノワール・マナ・クラウン・クイーン（真））です。ほかのニケは通常攻撃だけで計算します（味方からのバフは受けます）。
- 扱わないもの: 命中率の中身（入力した値を掛けるだけで、敵の動き・カバー・中断は扱わない）、ボスの行動・パーツ破壊、貫通・範囲攻撃の複数ヒット、被弾・HP・回復量・シールド、アカウント連携。
- calc の画面の「未対応・近似・仮定の一覧」に、編成ごとの未対応の項目をまとめて出します。

## 開発

Node.js 24 以上が必要です。

```bash
npm install
npm run fetch-data   # Blablalink CDN からキャラデータと育成のマスタを取得して packages/core/data に書き出す
npm test
npm run dev          # apps/calc を起動
npm run sim -- --ids 82,330 --build builds.json   # sim と calc の内訳を CLI で出す
```

`main` への push で GitHub Pages に配信します（`.github/workflows/pages.yml`）。リポジトリが公開のときだけ配信し、非公開のあいだはビルドとサブパスの確認だけ行います。

- ゲーム内データ・キャラクター名・画像（`plan/captures/frames` の録画の切り出しを含む）などは SHIFT UP / Level Infinite の権利物であり、本リポジトリのライセンスの対象外です。本ツールは非公式のファンメイドで、SHIFT UP / Level Infinite とは関係ありません。
- `packages/core/data` は Blablalink 公開 CDN（認証不要）から取得したデータを正規化したもので、calc が静的に配信します（ブラウザから CDN へは直接アクセスしません）。権利者から要請があれば同梱をやめ、利用者が `npm run fetch-data` で取得する形に切り替えます。
- 装備の強化 Lv 別の値（`data/masters/gear.json` の Lv1〜5）と OL オプションの Lv 別の上昇値（`data/masters/overload.json`）は CDN に無いため、コミュニティの検証値を転記しています（装備の Lv0 は CDN、T9 Lv5 の合計は射撃場の実測で確認。OL はオプションの種類だけ CDN と照合し、数値は未検証）。
- スキルの効果の定義（`data/skills`）は、スキルの説明文と射撃場の録画から手書きしたものです。

# V-0264: キューブのリロード速度▲の短縮は、リロードの長さに比例するか

- 問い: スペック固定 OFF のルドミラ（SMG・リロード 2.76 秒）単騎で、レリックベアーキューブの「リロード速度▲」は、最終弾から次の 1 発目までをリロードの秒 × (1 − 値) + 24f（C-0331・C-0148）にするか。マナ（V-0224）で予測より約 1f 大きかった短縮は、リロードの長さに比例して大きくなるか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-10-06
- 録画: `305`、`306`
- 結論: `C-0397`
- 状態: 完了

## 条件

- V-0224「次に撮るもの」と backlog の 2-27。V-0224 では、指標をバーの長さにしたため、武器種ごとの切片（C-0135・C-0145）が予測に入っていなかった。ここでは、モデルの通る形（最終弾 → 次の 1 発目。C-0148）を指標にする（照合ランナーの `reloadToNextShotAt` を足した）。
- キャラ: ルドミラ（190、SMG・水冷・バースト I）。所持キャラのうち、チャージの無い武器でリロードが最も長い（2.76 秒。マナの 1.67 秒の約 1.65 倍）。装備は OL なし、コレクションなし。MG（ルドミラ：ウィンターオーナーの 3 秒）は弾丸チャージの効果があり、マガジンが長く回数も少ないので選ばない。
- 最小構成: 最終弾 → 次の 1 発目に効くのは、CDN のリロードの秒（2.76 秒）をゲーム内の時計で数えた長さ（C-0145）、リロード明けの 24f（C-0148。SMG を含む 12 本で確定）と、問いのキューブだけ。ルドミラのスキルにリロード速度・最大装弾数の効果は無い（S1 は最後の弾丸の命中で的に防御力▼・攻撃力▼、S2 はフルバーストの時、バーストは手動で使わない）。単騎なのでフルバーストは起きない。スキルの定義は無いが、比べる指標は与ダメージによらない。
- キューブの値は data/masters/cubes.json の段階の値（Lv15 は段階 3。V-0224 と同じキューブ）。キューブのアンチコード（有利コードの攻撃ダメージ▲）は、水冷のルドミラなら灼熱の的で乗るが、与ダメージにしか効かない。
- 録画は 2 本: 録画 1 はキューブなし（同じキャラで切片と 24f を確かめる）、録画 2 はレリックベアーキューブ Lv15。キューブのほかは同じ条件。

## 予測（撮る前に書く）

H1 はいまのモデル（リロードの秒 × (1 − 値) + 24f）、H0 はキューブが乗らない形で、値は予測ファイル（records/predictions/V-0264.json）にある。録画 1（`gap-base`）はキューブが無いので、H1・H0 とも同じ値になる。

残差の形の仮説は、モデルを切り替えないと出ないので、ここに手で書いた。V-0224 の短縮の超過（予測の 29.2f より 0.3〜1f 大きい）から、ルドミラの短縮（予測ファイルの `gap-base` − `gap-cube` の H1。約 48.2f）を見積もる。

| 仮説                                                       | 最終弾 → 次の 1 発目（録画 2、f） | 短縮（録画 1 − 録画 2、f） |
| ---------------------------------------------------------- | --------------------------------- | -------------------------- |
| H1: × (1 − 値)                                             | 予測                              | 予測の差（約 48.2）        |
| H0: 乗らない                                               | 予測                              | 0                          |
| Hp: 超過がリロードの長さに比例（実際の値が表示より大きい） | 136.5〜137.7                      | 48.7〜49.9                 |
| Hc: 超過がリロードの長さによらない（一定の短縮）           | 137.2〜137.9                      | 48.5〜49.2                 |
| H2: ÷ (1 + 値)（C-0331 で棄てた形）                        | 149.2                             | 37.2                       |

- 見分け方: 録画ごとに、`reload-segments` の最終弾 → 完了と完了 → 次の増分を足した値（リロードごと）の中央値を観測値にし、録画 1 − 録画 2 を短縮とする。H1 と H0 は約 48f、H1 と H2 は約 11f 離れる。
- Hp と Hc の見分けは弱い。超過が 1.2f を超えれば Hp、0.5f を下回れば Hc 寄り、その間なら決めない。超過が 0〜0.3f なら、V-0224 の超過はマナの読みの誤差だった見込み。
- 合えば: H1 ならモデルはそのまま。C-0331 の「約 1% の残差」の書き方を、ルドミラの結果に合わせて直す。
- 合わなければ: H0・H2 なら C-0331 を見直す（オーナーに確かめる）。録画 1 が予測（C-0148）から外れたら、キューブの比べの前に、SMG 2.76 秒のリロード明けを調べる。

## 分かったこと・分からないこと

- 分かったこと: キューブのリロード速度▲は × (1 − 値) で効き、リロード 2.76 秒のルドミラでは、最終弾 → 次の 1 発目がキューブの有無のどちらでも予測と 1f 以内で合う（C-0397）。リロードの長いキャラで超過が出ないので、V-0224 のマナの超過は、値の比例（Hp）でも一定の短縮（Hc）でも説明されない。C-0331（短縮の超過を含む仮説）は、2026-10-07 のオーナーの判断で棄却し、C-0397 に置き換えた。モデルは変えない（照合ランナーに指標 `reloadToNextShotAt` を足しただけ）。
- 分からないこと: V-0224 のマナ（キューブあり）で、最終弾 → 次の 1 発目が予測より約 1f 短かった理由。マナの録画の読みか、マナの条件（AR・OL の最大装弾数など）に固有の何かかは、この録画からは分からない。残差は係数で埋めない。

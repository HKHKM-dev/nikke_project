# 検証記録

- 関連: [design-stage1-2.md](design-stage1-2.md)、[roadmap.md](roadmap.md)
- 目的: 計算値と実測値の突き合わせ結果と、そこから較正した定数を記録する。
- 方針（2026-09-22 決定）: 「90 秒の総ダメージ」で合わせるのはやめ、式の要素ごとに実測しやすい量で検証する。
  - 攻撃力は Blablalink（ShiftyPad）の表示値を正とする。ゲーム内表示は上乗せ分があるので絶対値では比較しない。
  - ダメージ式は射撃場の 1 ヒット数値で検証する。時間や距離のブレ、スキルの影響を受けにくい。
  - 発射サイクルはダメージではなく時間（録画のフレーム数）で測る。測るのは疑わしい SR/RL のチャージと MG のスピンアップだけ。

## Stage 2-A: ダメージ式（1 ヒットの実測）

射撃場で通常攻撃 1 ヒットの表示値を読む。敵は雑魚（防御 100）とし、属性相性なし・距離ボーナスは適正距離で撃つ（RL は距離ボーナスなし）。バーストは撃たない。通常攻撃に影響するスキル（自己バフ・攻撃ダメージ増加・弾数変化）を持たないキャラを選ぶ。

期待値の式（1 ヒット、期待値ではなく実値）:

```
基礎     = 攻撃力（ゲーム内表示の実攻撃力。ここは上乗せ込みの値をそのまま使う） − 100
1 ヒット = 基礎 × 武器倍率（SG は 1 ペレット分 = damage / shotCount）
           × (1 + コア命中なら (coreDamageRate − 1) + 会心なら (crit.damage − 1) + 距離ボーナスなら 0.3)
           × 属性有利なら 1.1
           （小数点以下は四捨五入。SR/RL はさらに × fullChargeDamage）
```

### 測定条件（2-A 共通）

- 場所: 射撃場。敵は雑魚（防御 100）。敵の属性と「コアの有無」を記録する（コアが無い的ならコア列は空欄）。
- 編成: 測定するニケ 1 体だけを出撃させる（味方バフの混入を防ぐ）。バーストは撃たない（自動バースト OFF）。
- 位置: 移動せず初期位置で撃つ。適正距離かどうかは、1 発の値が 1.3 倍違うかで判別できるので、判別結果を記録する。
- 撃つ弾: 戦闘開始直後の最初のマガジンだけ読む（「通常攻撃 N 回で自己バフ」型のスキルが乗る前）。SR/RL はフルチャージのみ。SG は 1 ペレットの値。
- 記録する値: そのニケの部隊画面の攻撃力（コンソール・装備込みの表示値そのまま）と、1 ヒットの 4 パターン。会心は 15% なので同条件の中で大きい方が会心。
- スキル 1・2 が通常攻撃の 1 発の値に影響しないキャラを使う（`packages/core/data` のスキル説明文から抽出。持っているものを優先）:

読み取りのコツ:

- 会心は 15% なので、同じ条件で数発撃てば「大きい方の値」が会心。コアは狙う位置で切り替える。

## Stage 2-B: 発射サイクル（時間の実測）

固定レート武器（AR 720rpm / SMG 1440rpm / SG 90rpm / SR・RL 60rpm）と装弾数・リロード時間は CDN の `shot_detail` の値を採用する。参考 OSS（Infernal-Crack-LED/nikke-sim）の実測でも同じ値が確認されているため、個別計測はしない。60fps 量子化（SMG 1440rpm → 3 フレーム = 20 発/秒）も同 OSS の検証結果に従う。

計測するのは次の 2 点だけ。PC で画面録画（60fps）し、フレーム数を数える。動画ファイルがあればフレーム計測は代行可能。

### 録画条件（2-B）

- 録画: PC 版を 60fps で録画（Xbox Game Bar の Win+G、または OBS。設定で 60fps を確認）。解像度は問わない。戦闘開始の合図から最初のリロード完了後の 1 発目までを含める（15 秒程度）。
- 操作: 射撃ボタンを押しっぱなしにするだけ。移動・カバー・バーストはしない。SR/RL はフルチャージ攻撃を連続で撃つ（押しっぱなしで自動的にフルチャージ連射になる）。
- キャラ: 2-A と同じ（SR: デルタ、RL: I-DOLL・フラワー、MG: エマ）。装弾数・リロードを変えるスキルが無いことが条件。
- 読み取るもの（動画をもらえればこちらで数える）:
  - SR/RL: 1 発目から 6 発目までの発射間隔（フレーム）と、6 発目からリロード後の 1 発目までのフレーム数。モデルは 60f 間隔、リロード 120f（デルタは 90f）。
  - MG: 1 発目から 300 発目（弾切れ）までのフレーム数と、リロード後の 1 発目までのフレーム数。モデルは 468f + 150f。
  - 任意（AR 1 種）: 1 発目から 60 発目までのフレーム数（モデル 300f）とリロード（クルミ 60f）。
- 動画は `D:/nikke_project/plan/captures/`（.gitignore 対象にする）に置くか、ファイルの場所を教えてください。

| 項目                   | 測り方                                                                                                               | 実測 | 現在のモデル            | 較正後 |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- | ---- | ----------------------- | ------ |
| SR/RL チャージ解放遅延 | フルチャージ連射で、発射から次の発射までのフレーム数を数発分平均。60 フレーム（チャージ 1.0 秒）を超えた分が解放遅延 |      | 60f + 0f                |        |
| MG スピンアップ        | 撃ち始めから最大レート（毎フレーム 1 発）に達するまでの秒数と、1 マガジン 300 発の撃ち切り秒数                       |      | 3.4 秒 / 7.8 秒（Emma） |        |

任意: リロード時間（`reloadTime`）が CDN 値どおりか、撃ち切りから次の 1 発までのフレーム数で 1 武器種だけ確認する。

## Stage 2-C: 目安（総ダメージ）

# V-0068: SG の分割リロードの最終弾から込め終わりまでの内訳

- 問い: プロダクト23（9 発・0.67 秒・3 発ずつの分割リロード）の最終弾から次のマガジンの 1 発目までが、モデル（3 段 + 24f）より長いのはどの部分か。段の数・段の長さ・段と段の間・最終弾から 1 段目の満ち始めまで・込め終わりから 1 発目までに分けると、どこがずれているか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-10-01
- 録画: `101`、`102`、`074`、`092`、`036`、`009`
- 結論: `C-0154`、`C-0117`
- 状態: 完了
- 派生元: `V-0063`

## 条件

- 撮影はしていない。V-0063 で撮ったプロダクト23 単騎・AUTO・3 分モード・スペック固定 ON・灼熱タブ・オートバースト OFF の 2 本（`101`・`102`）を読み直した。
- 発端: `101-01`・`102-01` で、モデル（sim）の与ダメージが実測より多い。モデルの発の数は 180 秒で 201、`101` の実測は 189 トリガー。全弾リロードのクイーン（真）では合っている（V-0063）。
- プロダクト23 の CDN の値: 最大装弾数 9、リロード 0.67 秒、reloadBullet 0.33（1 段 3 発。C-0012）、90 rpm。
- モデル（Stage 24）: 最終弾から段を 3 回（段の秒をゲーム内の時計で数えた端数つきの長さ。C-0142）込め、込め終わりから 24f（C-0148）で 1 発目。段の前にも段の間にも、足す長さは無い。

## 予測（撮る前に書く）

読む前に書いた（2026-10-01）。手がかりは、既存の分割リロードの SG の最終弾 → 込め終わり（`017-01`・`026-06`・`074-06`（ノワール 0.23 秒）、`016-01`・`036-01`（ドレイク 0.5 秒）、`092-03`（ソーダ：TB 0.67 秒）、`009-01`（プロダクト23 0.67 秒・2026-09-22 の録画））と、ノワールの 1 回目の段のバーの並び（`074-04` の注記: 最終弾の約 26f 後に 1 段目が満ち始める）。

段の長さ s（ゲーム内の時計。0.67 秒なら 39.41f）で書くと:

- **H1（4 段ぶん + 約 13f）**: 最終弾 → 込め終わりは、どのキャラも 13.5f + 4s に合う（ノワール 67.6f・ドレイク 131.1f・ソーダ：TB とプロダクト23 170.6f。0.23 秒と 0.67 秒の 2 点から傾きを出すと 3.99 段）。見える段は 3 つ（000 → 003 → 006 → 009）で、1 段目の満ち始めの前に、バーの見えない約 1 段ぶん（13f + s）がある。この録画では:
  - 最終弾 L → 1 段目の満ち始め ≈ L + 52〜53f
  - 段のバーは 3 つ、どれも 0 から約 39.4f で満ち、段と段の間は 0〜1f
  - 込め終わり（残弾が 009 に戻る）≈ L + 171f、照準の横の残弾は段の満ち終わりごとに 003・006・009
  - 込め終わり → 1 発目 12f（C-0117）、最終弾 → 1 発目 ≈ 183f
- **H0（今のモデル）**: 最終弾 → 込め終わり ≈ 3s + 12f = 130f、最終弾 → 1 発目 ≈ 142f。旧の録画の `009-01` と、似た 3 体がどれも H1 なので、H0 には合わないとみる。
- 見分け: 最終弾 → 込め終わりが 130f 前後か 171f 前後かで、1 回で見分けられる（差 41f）。
- H1 なら、モデルとのずれは「最初の段の前の約 1 段 + 1.5f」に集まる。外れたときの影響: 3 段なのに 4 段ぶん待つので、0.67 秒の SG（プロダクト23・ソーダ：TB・ペッパー・シュガー・メイデン・ジャッカル・アニス）は、マガジンの周期（発と発の間 8 回ぶん + 最終弾 → 1 発目 142f）が約 41f 延び、撃つ回数が 1 割近く減る。
- 分からないこと（読んで見るもの）: 見えない約 1 段ぶんのあいだ、バーがほんとうに出ないのか（薄く出るのか）。その間に照準の横の残弾が変わるか。込め終わりの後の 12f が SG でも同じか。

## 読み方

読んだ日: 2026-10-01。

1. `hud.ts --mode jumps` で総ダメージの増分の列を取り、`reload.ts --stages --shots` で RELOADING のバーを段ごとに読んだ（段のバーが消えたフレーム = 段の満ち終わり、最後の段 = 込め終わり。段ごとの伸びを 0 に遡った点 = 満ち始め）。
2. 取り消し・窓をまたいだ回を除き、さらに最終弾 → 込め終わりが録画の最頻値から 2f 以上ずれた回を、最終弾の読み違い（HUD が隠れて増分が遅れた回。`101` の 6019 は 18f 読めないフレームが続いた後の増分）として除いた。段の区切りの値は、段が 3 つに分かれて読めた回だけ（スキルのエフェクトが重なって段が割れた回は、込め終わりにだけ使った）。
3. `101` の 1 回目（最終弾 1069）と `102` の 1 回目（1092）は、照準の横の残弾を 1 フレームずつ切り出して目で読んだ。最終弾から 1 段目の込め始めまでのキャラの動きも 4 フレームおきに見た。
4. 同じ読み方を、似た分割リロードの SG の既存の録画（`074` ノワール、`092` ソーダ：TB、`036` ドレイク、`009` プロダクト23）にも当てた。
5. モデルは変えていない（変えるのはオーナーの承認の後。plan/design-sg-split-reload.md）。モデルの値は `cadence.ts`・`frame/shooter.ts` のコードから出した（段 39.41f の端数を持ち越して 39・40・39f、込め終わりから 24f）。

## 分かったこと・分からないこと

- **分割リロードは、込める段の数より 1 段ぶん長くかかる**。最終弾の後、約 11〜12f と 1 段ぶんは、バーも残弾も変わらない。その後に 3 段で込める（C-0154）。C-0135 の形（リロードの秒を 58.82f で数えた長さ + 約 11〜12f）で、「リロード」を（段の数 + 1）× 切り上げた段の長さとみれば説明できる。
- **段の長さは切り上げた整数で、端数を持ち越さない**（C-0154）。段のバーの伸びが端数つきの長さで満ちる（C-0142）のとは別の値。
- 込め終わり → 1 発目の 12f は、プロダクト23・ソーダ：TB・ドレイクでもノワールと同じ（C-0117 に根拠を足した）。
- モデルのずれは上の 2 点。直し方は plan/design-sg-split-reload.md に起案した（オーナーの承認待ち。直すのは承認の後）。
- 分からないこと:
  - 込め始めの前の 1 段の中身（キャラはカバーに戻ってエフェクトが出るだけで、画面では何をしているか分からない）。
  - リロード速度のバフで、その 1 段も縮むか。段の数が 3 でない武器（グレイブの 2 段、6 発の SG）でも「段の数 + 1」か。
  - 全弾リロード（C-0145）は丸めない長さのほうが合うのに、分割リロードの段が切り上げの整数になる理由。
  - 足す長さがノワールだけ 12f で、ほかは 11f の理由。

## 条件

**何を確かめるか**

- C-0171（確定）で、弾速 100 の直進弾・誘導弾・曲射の RL は、近ではほとんど外さず遠で多く外すと分かった。区間ごとの割合は弾の種類ごとに 1 本ずつしか無いので値を決めておらず、表（plan/design-rl-core-by-projectile.md）では未測定にする。
- 2026-10-02 にオーナーが、外す側の割合は先に追加で計測してから表に入れると決めた。この記録はその計測。
- 表は `<fireType>:<弾速>` ごとに 1 つの値を持つので、確かめることは 2 つ: (1) 同じキャラの録画どうしで距離帯ごとの割合が再現するか、(2) 同じ弾の種類の別のキャラでも同じ割合か（キャラによらないか）。

**計る弾の種類とキャラ**

| 弾の種類（キー）       | キャラ                                  | 既存の録画 | 新しく撮る | 理由                                                                                            |
| ---------------------- | --------------------------------------- | ---------- | ---------- | ----------------------------------------------------------------------------------------------- |
| `HomingProjectile:100` | I-DOLL・フラワー（304）                 | `077`      | 2 本       | RL の大半がこの弾の種類。録画どうしの再現                                                       |
| `HomingProjectile:100` | ユニ（160）                             | 無し       | 2 本       | 同じ弾の種類の別のキャラ（チャージ 1.5 秒でフラワーの 1 秒と違う）。キャラによらないかを見る    |
| `ProjectileDirect:100` | ラプラス：アルティメットヒーロー（103） | `121`      | 2 本       | この弾の種類はこのキャラだけ。変わる前の武器の発はマガジンごとに 5 発で、1 本あたりの発が少ない |

- 曲射（`ProjectileCurve:1500`。シンデレラ）は撮らない。damage.ts が曲射の弾を扱わず計算が止まるので、表に値を入れても使われない（曲射の計算に手を付けるときに撮る）。

**最小構成**: 単騎・AUTO 射撃・3 分モード（180 秒）・スペック固定 ON・自動バースト OFF・BigArms（灼熱タブ）。V-0097 と同じ組み方。フラワーの `077` はオートバースト ON だったが、新しい 2 本は OFF にする（バーストのヒットが増分に混ざらない）。

- ユニ（160）は RL・SSR・Defender・灼熱・バースト 2 段階。スキル定義あり（plan/skills.md）。S1 はフルバースト時のチャージ速度▲で、単騎では起きない。S2 はフルチャージのたびに味方全体の防御力▲・回復・最大装弾数▲で、ダメージの増分には混ざらない（装弾数が増えるので、マガジンの長さは読みで見る）。

## 予測（撮る前に書く）

予測なし（予測ファイルは使わない）。比べるのは距離帯ごとのコアを外した発の割合で、表が未測定なのでモデルの出力にならない。代わりに、見込みを手で書く。

| 仮説                                                     | 見えるはずのもの                                                                                                                               |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| H0: 弾の種類ごとに 1 つの割合で、録画・キャラによらない  | フラワーの 3 本・ユニの 2 本で、距離帯ごとの割合が二項分布の幅の中で揃う（遠で最も多く、近ではほとんど 0）。ラプラスUH の 3 本も、それぞれ揃う |
| H1: キャラで違う（チャージ時間・撃つ間隔など）           | ユニの割合がフラワーと幅を超えて違う。表を弾の種類ごとに 1 つで持てない                                                                        |
| H2: 録画ごとに大きく散らばる（的の動きの時刻の違いなど） | 同じキャラの録画どうしで、同じ距離帯の割合が幅を超えて違う。表に入れる値は平均で、散らばりの注記が要る                                         |

- 外れたときの影響: H0 なら、距離帯ごとの割合（合計した値）を表の `HomingProjectile:100`・`ProjectileDirect:100` の行に入れる（別の変更。根拠の結論を作ってから）。H1 なら、表のキーを弾の種類から変える設計を起こし直す。H2 なら、値を入れるかをオーナーと決め直す。
- 遠の割合の目安は V-0097「結果」の表（フラワー・ラプラスUH とも半分前後）。

## 読み方

1. `tools/captures/intake.ts` で取り込む（`--rid 304|160|103 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec on --auto-fire on --auto-burst off`）。台帳を埋めて `npm run records:table`。出撃画面と戦闘履歴は録画の先頭と末尾の 1 秒ほどにあるので、先頭・末尾のフレームで確かめる（plan/captures/guide.md「画面の読み方」）。
2. `npm run records:read -- <録画 id> --recipe hud-jumps` で増分の列を出し、V-0097「読み方」と同じく 1 発の値（胴体・コア × 会心）に分ける。ジャンプの窓は射撃の空きから候補を出し、画面で確かめる。ラプラスUH は変わる前の武器の発だけを数える（V-0100「読み方」）。
3. 録画ごとに、区間ごとの「撃った発（フルチャージ）」「コアを外した発」「そのうち着地の後の 1 発目」を観測値（`use: "record"`、`source: V-0104`）にする。
4. キャラごと・弾の種類ごとに距離帯（近・中近・遠・中遠）の割合を出し、録画どうし・キャラどうしを二項分布の幅で比べる（`077`・`121` も合わせる）。

## 結果

**I-DOLL・フラワー（`HomingProjectile:100`）の 2 本**（2026-10-02 に読んだ。「読み方」の 1〜3。区間は 1〜6 の順）

| 録画  | 自動バースト | 撃った発（フルチャージ） | コアを外した発 | うち着地の後の 1 発目 |
| ----- | ------------ | ------------------------ | -------------- | --------------------- |
| `077` | ON           | `077-16`                 | `077-17`       | `077-18`              |
| `126` | OFF          | `126-02`                 | `126-03`       | `126-04`              |
| `127` | OFF          | `127-02`                 | `127-03`       | `127-04`              |

- 1 発の値は `077-16` と同じ 4 つで、どの増分も 4 つの値か部分チャージの発に分かれた（刻みの抜けは無い）。総ダメージの最後の値（`126-01`・`127-01`）は戦闘履歴の与ダメージと一致した。
- 区間の切れ目（ジャンプの窓）は、5 回とも窓の中で的が跳んで着地するのを画面で見た（`126-02`・`127-02` の注記）。窓の始まりの戦闘時刻は、`127` は `077` とほぼ同じで、`126` は 3 回目から 4〜5 秒早い。`126` は 5 回目の着地の後に 2 発撃ち、`127` は 5 回目の着地の前に戦闘が終わった（6 区間目の発の数が違う）。

**距離帯ごと**（コアを外した発 ÷ 撃った発。着地の後の 1 発目は分子・分母とも除く。近は 2・5 区間目、遠は 3・6 区間目の合計。V-0097「結果」の表と同じ数え方。観測値から数えた）

| 録画       | 近    | 中近 | 遠    | 中遠  |
| ---------- | ----- | ---- | ----- | ----- |
| `077`      | 2/36  | 2/19 | 10/20 | 3/19  |
| `126`      | 0/36  | 3/19 | 7/19  | 4/19  |
| `127`      | 0/36  | 3/19 | 10/20 | 3/19  |
| 3 本の合計 | 2/108 | 8/57 | 27/59 | 10/57 |

- 3 本は、どの距離帯でも二項分布の幅の中で揃う（遠は 3 本の割合の違いの χ² が自由度 2 で 0.9 ほど）。自動バースト ON の `077` と OFF の 2 本で形は変わらない。
- 中近（1 区間目）のコアを外した発には、1 回目の窓の前の最後の発（跳び始めの直前の発）が 3 本とも入っている（`077-17`・`126-03`・`127-03` の注記のフレーム）。`127` は 3 回目の窓の前の最後のフルチャージの発（遠）も外した。A2 の跳び始めの直前の 1 発（`123-04`）と同じ種類の外れの見込み。この数え方では除いていない（V-0097 と同じ）。

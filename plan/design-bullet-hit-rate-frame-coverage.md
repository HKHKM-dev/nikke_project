## 0. 今わかっていること

### 0.1 関係する結論

- 照準円の画面上の半径は、約 0.285 × CDN の `*_accuracy_circle_scale`（C-0038）。▲で半径 × (1 − N) と矛盾しない（C-0041。×1/(1 + N) とは区別できていない）。
- 照準円は、撃たない間は CDN の速さで戻る（C-0039）。MG は 1 発ごとに縮む（C-0040、仮説）。
- 常時の▲はコア命中率を 1/(1 − N)² 倍にする（C-0036、確定）。これは「弾が照準円の中で一様」「コアが照準円の中に収まる」「半径 × (1 − N)」の 3 つから、そのまま出る式。
  - **N が小さく、コア命中率が小さいときは、一様と正規分布を区別しない**。コアが照準円より十分小さければ、中心の密度が半径² に反比例する散らばりは、どれも 1/(1 − N)² になる。根拠のうちクルミのキューブ（N = 0.0509）の倍率は、どちらの形の予測も信頼区間に入る。
  - **N が大きいと区別できる**。根拠のうち旧のクエンシー：エスケープクイーン（SMG、N = 0.4942。verification.md Stage 18-A「照準円と命中率▲」）では、実測が一様の式とほぼ一致した。同じ集計の値から正規分布（σ = R/√2。1.1 節）で出すと、約 0.09 低くなる（帯の重みを無視した概算）。旧の 1 本で、帯ごとには分けていないので、決め手にはしないが、一様を支持する材料になる。
  - C-0183（ミサトの 3 スタック、N = 0.1512）の帯ごとの倍率は、揺れが大きく、2 つの形を分けられていない。
  - C-0192 の H2（外れの割合の対数が 1/(1 − N)² 倍）は、「正規分布の散らばり + 中心に円の的」でそのまま出る形（外れ = exp(−r²/2σ²)）。ただし、一様の散らばりでも、的の形（前提 1・2）しだいで H2 に近い効き方になりうる。一様の散らばりで的がまるごと照準円に収まると H3 になる。
  - 散らばりの形は、この案でいちばん先に確かめるもの（5.1）。**散らばりの形はコアにも胴体にも同じものが効くので、正規分布を選ぶと、C-0036 のモデル側（p ÷ (1 − N)²）と食い違う**（10 節の 5）。
- コアの当たり判定は、半径が距離に反比例する円とみなせる（C-0046、仮説）。
- ▲は弾丸命中率を上げる。H3（当たり全体を 1/(1 − N)² 倍）より弱い（C-0192、仮説）。
  - 一様な散らばりのもとで H3 になるのは、的の当たり判定がまるごと照準円の中に収まっている場合。外れたのは、手足が照準円の外まで伸びているためと説明できる（前提 1・2）。
- 弾丸命中率の表は、距離帯ごとの値（C-0034）で、▲には効かせていない。

## 1. 方式の要点

### 1.1 式

着地点（場面）L、照準円の大きさ s（CDN の単位。▲の後の値 = CDN の値 × (1 − N)）について、次のように置く。

- 弾丸命中率 h(L, s) = 撃っていたフレーム t での C_t(s) の平均。
- C_t(s) = フレーム t で、照準の中心 a_t に置いた散らばり K（半径 R = 0.285 × s）のうち、的の当たり判定 M_t（マスク）に入る割合。

決めていること:

- **散らばり K は 2 通りで表を作り、下見（5.1）で 1 つに決めてから判定の撮影（5.2）に進む**。
  - 一様: 半径 R の円の中に一様。
  - 正規: 中心を a_t とする 2 次元の正規分布で、σ = R/√2（打ち切らない）。中心の密度が一様と同じになる σ で、コアが小さいときのコア命中率（C-0036・C-0046）は一様と変わらない。**調整する係数は持たない**。
  - K を選ぶ材料には、弾丸命中率（マスクから作る表）のほかに、マスクの要らないコアの▲の倍率（5.1 の 0）を使う。散らばりの形は、コアにも胴体にも同じものが効くため。
  - 正規を選ぶと C-0036 のモデル側と食い違う（0.1）。その場合は 5.2 に進む前に、C-0036 の扱いをオーナーに諮る（10 節の 5）。
  - 選んだ K は、5.2 の予測の前に commit して固定する。
- **照準の中心は、実際に読んだ位置を使う**。コアに合っているとは仮定しない。照準の遅れ（0.2 の (a)）も C_t に入る。
- **形と動きは、M_t と a_t の時系列に入っている**。向き・移動・姿勢の変化・跳ぶ前後を、式では表さない。フレームの標本が、そのまま時間の重みになる。
- **距離の推定は要らない**。画面の px のまま数えるので、C-0045（推論）に頼らない。
- s を変えた表を作れば、▲（N）と武器種（CDN の値）の違いは、同じ表を引く s の違いになる。▲の弾丸命中率の式（C-0192 の H2 など）を別に持たない。

### 1.2 敵によらない部分と、敵ごとの部分

| 部分                               | 中身                                         | 敵によるか                         |
| ---------------------------------- | -------------------------------------------- | ---------------------------------- |
| 照準円の大きさ                     | 0.285 × CDN の値 × (1 − N)（C-0038・C-0041） | よらない                           |
| 散らばり方                         | 一様か正規（σ = R/√2）。5.1 で決める         | よらない                           |
| 被覆率の数え方                     | 道具（2 節）の計算                           | よらない                           |
| 当たり判定の形・動き・照準の追い方 | 録画から読んだ M_t と a_t                    | **敵ごと**（録画を道具に通すだけ） |

### 1.3 前提 1〜3 との関係

- 前提 1・2（中心の塊 + 細い手足で、比例しない）: 形の仮定を置かないので、そのまま入る。
- 前提 3（向きで面積が変わる）: 向きの分布を推定せず、フレームの標本の重みとして入る。
- ほかの敵（部位が分かれる・宙に浮く・大きく姿勢が変わる）も、M_t が読めれば同じ式で入る。
- 大型のボスで照準円が当たり判定の中に収まるなら、C_t は 1 に近くなり、特別な扱いをしなくても片付く（確かめる。7 節）。

## 2. 道具（`tools/captures/coverage.ts`。新規。`aim.ts` の処理を使う）

1. **フレームを選ぶ**:
   - 撃っていたフレームだけを使う。残弾の列（`ammo.ts`）で、残弾が減っている間とする。
   - 区間（着地点）の境目は、既存の読み方（ジャンプ・着地の時刻）で切る。
2. **照準の中心 a_t**: `aim.ts` の照準の検出をそのまま使う。信頼度の低いフレームは落とす。
3. **的のマスク M_t**:
   - `aim.ts` の背景差分の連結成分を、外接矩形ではなく画素のマスクとして出すように広げる。いまは半分の解像度で探しているので、輪郭だけ全解像度で取り直す。
   - 次のフレームは落とし、落とした割合を出力に残す。
     - `fx` が高い（爆発など）。
     - 的が探す範囲の端に接している。
     - 遮蔽物（緑の箱）が的とつながっている。遮蔽物に当たった発の扱い（C-0108）は、別の欄で数える。
4. **被覆率 C_t(s)**:
   - 一様: 半径 1 の円の中に一様に置いた固定の点の組（約 2,000 点。ひまわり型の配置）を、半径 0.285 × s に縮めて a_t に置き、M_t に入る割合を数える。
   - 正規: 同じ点の組を、半径方向だけ 2 次元正規分布の半径の分布（レイリー分布）の分位に写した組にする（重みは等しい）。
     - 一様の組の i 番目の点（n 点中）の半径² を u_i = (i + 0.5)/n とし、半径を ρ_i = σ√(−2 ln(1 − u_i)) に置き換える（向きはそのまま）。u = 1 を使わないので、無限大の点は出ない。
     - n = 2,000 のとき、いちばん外の点は約 2.9R。正規は円の外にも点が出るので、マスクを探す範囲を半径の 3 倍まで取る。
   - s は格子で持つ（例: 0 と、5〜260 の CDN の単位で 30 点程度）。s = 0 は「照準の中心がマスクに入る割合」で、▲が 100% 以上のとき（C-0037）にそのまま引く。
5. **出力**:
   - 着地点ごとに、s の格子と h(L, s) の表を出す。採ったフレームの数、落としたフレームの割合、録画の中でのばらつき（区間ごとの h の標準偏差）も出す。
   - これは録画から読んだ値なので、観測値（`records/observations/`）として置く。
   - マスクの画像は、証拠フレームと同じ扱いにして `E:/nikke_project_captures/` に置く（コミットしない）。
6. **設定の固定**: 背景差分のしきい値・フレームを落とす条件（`fx` のしきい値など）・点の組・K は、設定ファイルに書き、出力に設定の版を残す。判定の撮影（5.2）の前に commit し、撮った後は変えない（6 節）。

## 3. データの形（`data/enemies.json`）

`targetProfiles[*]` に、着地点ごとの被覆率の表を任意の欄として足す（例）。

```json
"bulletCoverage": {
  "unit": "accuracyCircleScale",
  "landings": {
    "far": { "s": [5, 10, 20, 40, 75, 110, 160, 250], "h": [/* 観測値から */], "source": "観測値の ID" }
  },
  "source": "plan/design-bullet-hit-rate-frame-coverage.md。値は観測値（ID）"
}
```

- `bulletCoverage` の無い敵・着地点は、いまの `bulletHitRate` の表を使う（後戻りできる形）。
- どちらの表も無い敵・着地点は、いまのとおり手入力の弾丸命中率で計算し、未測定と注記する（`autoConditionAt` の `manual`）。**形の分類や形の関数から推計した値は出さない**（8 節）。
- 表は武器種で分けない。武器種の違いは s（CDN の値）に入る。ただし、照準の追い方が武器種で違うかは分からない（9 節の 3）。その分が確かめで出たら、武器種ごとに表を分けられるよう、`landings` の下に武器種の鍵を置ける形にしておく。

## 4. 入れ方（core）

- `autoConditionAt` で、弾丸命中率を次の順で決める。
  1. 枠の武器種が **AR か SMG**。かつ、`bulletCoverage` にその着地点がある。この場合は、s = `accuracy.autoStart` × max(0, 1 − N) で表を線形に引く。N ≥ 1 なら s = 0 の値を引く（C-0037。2 節 4）。
  2. それ以外は、いまの `bulletHitRate` の表を使う（▲を見ない）。
- 条件を「照準円が撃つたびに変わらない（`accuracy.autoChangePerShot` が 0）」にしない。それだと SR・RL・ふつうの SG も満たし、下の範囲外の武器が被覆率の表に置き換わる（CDN のデータで、SR・RL は 10/10、ふつうの SG は 250/250 で、どれも 0）。
- N は、コア命中率と同じ値（常時の和 + その区間の持続の和）を使う。
- 1 パス目・ゲージ・区間の割り方は変えない（弾丸命中率の値が変わるだけ）。
- 「弾丸命中率を測ったか」の判定（`frame/landing.ts` の `measuredHitRate` と、未測定の注記 `auto-condition-unmeasured`）も、被覆率の表から取った枠を「測った」側にするよう、同じ順で判定する。
- 表示: 条件の注記に、弾丸命中率の出どころが「被覆率の表（▲を含む）」か「距離帯の表」かを出す。
- 範囲外（いまの表のままにする）:
  - MG・照準円が縮む SG（プリバティ）: 撃つたびに照準円が変わる（C-0039・C-0040）。
  - ふつうの SG: ペレットの当たる割合（C-0156）が、照準円の大きさから見込むより高く、照準円とペレットの広がりの関係が分かっていない。
  - SR・RL: 弾丸命中率は 1 で確定している（C-0168）。RL は弾が飛ぶ間に的が動き（C-0173）、爆発の範囲もあるので、撃った瞬間の照準と輪郭では表せない。

## 5. 確かめ方

### 5.1 段 A: 下見（撮影なし）

次の順に進め、前の段を通らなければ先に進まない。

0. **コアの▲の倍率で K を比べる（机上。マスクも道具も要らない）**:
   - コアを照準の中心に置いた円（C-0046）とみなし、▲なしのコア命中率 p から、▲ありの値を K ごとに出す。
     - 一様: min(1, p ÷ (1 − N)²)。
     - 正規（σ = R/√2）: 1 − (1 − p) ^ (1 ÷ (1 − N)²)。
   - 比べる材料は、C-0036 の根拠（クルミのキューブ・旧のクエンシー：エスケープクイーン）と、C-0183 の帯ごとの倍率。帯ごとの p で出し、帯の重みはそれぞれの記録のヒットの数で付ける。
   - どれも既に見た値なので、K を選ぶ材料にとどめる。照準の中心とコアのずれ（0.2 の (a)）は、ここでは入れない。
   - 結果は 2 の選び方に入れる（2 の「選び方」）。ここで正規が 2σ 以上離れたら、2 に進む前に、正規を候補から外すかをオーナーに諮る。
1. **マスクの質（遠の霧を最初の関門にする）**:
   - 既存の AR・SMG 単騎・AUTO の射撃場の録画（V-0118 の 152〜160 など）を道具に通し、M_t と a_t が読めるかを確かめる。見るもの:
     - 落とすフレームの割合。
     - 遠の脚が霧で欠ける程度。
       - 霧に隠れない上半身の幅と高さで、近と遠の縮みの比を出す。推定距離（C-0045）は使わない（1.1 節）。
       - その比で近のマスクを縮め、遠のマスクと**脚の部分だけ**（長さ・面積）を比べる。全体の面積は、的の向きの分布が近と遠で違う（前提 3）ので比べない。
       - デバッグ画像を目で見る。
     - デバッグ画像を目で見たときの、マスクの誤り。
   - 外れが最も多いのは遠で、判定（5.2）も遠で行う。遠のマスクが使えなければ、この案は判定に進めない。
   - 霧の扱い（そのまま使う・近の輪郭を縮めて補う・遠を範囲の外にする）は、**h と外れの割合を並べる前に**、マスクの質だけで決めて commit する。並べた後で選ぶと、合うほうを選ぶことになるため。
2. **散らばりの形（K）を決める**:
   - 読めた録画から、着地点ごとの h(L, s) を一様と正規の両方で出し、次のものと並べる。
     - **主な材料**:
       - 同じ録画の実際の外れの割合（V-0118 の判定の指標と同じ数え方）。
       - V-0118 の▲の 2 群。対照の録画から作った表を s × (1 − N) で引き、外れの割合の比 q（V-0118 の指標）で比べる。
     - **参考**（選び方に入れない）: C-0034 の表。旧の別の日の録画で、σ がはっきりしないため。
   - 選び方は、並べる前に決めて commit しておく:
     - 主な材料と 0 の材料について、K ごとに χ² = Σ((予測 − 実測) ÷ σ)² を出す（σ は録画単位）。
     - χ² の差が 4 以上なら、小さいほうを採る。
     - 4 未満なら 1 つに決めず、2 つとも 5.2 に持ち込み、▲の大きい群で分ける。
     - 0 の材料と、弾丸命中率の材料とで、選ぶ K が逆になったら、5.2 に進まずオーナーに諮る。
   - どちらも大きく合わなければ、5.2 に進まない。当たり判定が見た目の輪郭と違うか（5.3 の結果を見る）、散らばりがどちらの形でもないかを疑う。
   - 正規を採った場合（2 つとも持ち込む場合も含む）は、5.2 に進む前に、C-0036 の扱いをオーナーに諮る（10 節の 5）。
   - どれも**既に見た値なので、K を選ぶ材料と再現の確かめにとどめ、結論は作らない**。

### 5.2 段 B: 判定の撮影（予測を固定してから撮る）

- **最小構成**: SMG 単騎・AUTO・射撃場の遠（V-0118 と同じ。外れが最も多い）。
- **予測の作り方**:
  - 同じ日に撮る対照（▲なし）の録画を道具に通し、表を作る。
  - ▲ありの群の弾丸命中率を、その表から予測する。
  - 撮る前に、道具の版・設定（2 節 6）・K・予測の手順を commit する。対照の表は撮った後に作るので、固定するのは道具と手順と比べる指標。
  - 撮った後に道具や設定を直したら、その撮影は判定に使わず、直した版を固定して撮り直す。
- **比べるもの**（撮る前に 2 つとも指標として固定する）:
  - 絶対値: ▲ありの群の外れの割合の実測と、表から引いた予測。
  - 比 q: ▲ありの群の外れの割合 ÷ 対照の外れの割合（V-0118 の指標）。予測は、表の (1 − h(s × (1 − N))) ÷ (1 − h(s)) で出す。
  - 2 つを分けるのは、マスクに系統的な偏りが残ると▲なしの水準がずれ、▲の効き方が正しくても絶対値で外れと出るため。q が合って絶対値が外れたら、▲の効き方は合い、水準（マスクか、当たり判定）がずれていると読む。
  - 比べのために、H2（C-0192）の予測も並べる。
  - 5.1 で K を 1 つに決められなかったときは、一様と正規の両方の予測を並べる。
- 群の組み方（例）:
  - 対照（リター）。
  - ミサト・スペック固定 ON（V-0118 の群 2 と同じ）。
  - 可能なら▲がより大きい枠。▲が大きいほど、H2・一様・正規の予測が離れる見込み。
- 判定の目安（σ の幅・何本撮るか）は、5.1 の値を見て、検証記録の起票のときに決める。

### 5.3 当たり判定の探り（5.1 と並行して、5.2 より前に）

- 当たり判定と見た目の輪郭が違えば、マスクから作る表はまるごとずれ、道具の手間が無駄になる。この案でいちばん大きい危険なので、5.1 の結果を待たずに確かめる。
- SR は照準円が約 3px で、ほぼ点として狙える（C-0038 の比から。実際の円は小さくて読めていない）。SR を手で操作し、次の場所を狙って当たるかを見る。
  - 手足の上。
  - 手足の間の隙間。
  - 輪郭のすぐ外（数 px）。
- **近の着地点で探る**。照準の中心の誤差（±2px）と SR の照準円（半径約 3px）を合わせると約 ±5px になり、遠の細い手足では当たりか外れかを照準の位置から言えない。近なら手足の幅が広く、余裕がある。当たり判定の形は距離で縮むだけとみて、近の結果を遠にも使う（遠は 5.1 の 1 のマスクの質で見る）。
- 判定のしかた: 撃った瞬間のフレームのマスクに、照準の中心が入るか（予測）と、当たったか（ダメージの表示）を、発ごとに並べる。照準の中心がマスクの縁から 5px 以内の発は、判定に使わない。マスクの作り方は 2 節の道具の版で固定してから撮る。
- **撮る前に確かめること**:
  - `aim.ts` が見分けるのは、十字（AR など）とリング（MG・SMG）だけ。手で操作する SR の照準を検出できるかは分かっていない。既存の SR を手で操作した録画（あれば）か、試しの短い録画で確かめ、検出できなければ、SR の照準の検出を道具に足す（6 節の段 2 の手間が増える）。
  - 動いている的の隙間を手で狙うので、判定に使える発（縁から 5px 以上離れた発）が足りるとは限らない。1 回の撮影で足りなければ撮り足す。要る発の数は、起票のときに決める。
- 合わないときは、ずれ方（輪郭より太い・細い、部位ごとに違う）を記録し、マスクを広げる・縮める根拠にする。係数で合わせない。

## 7. 別の敵への広げ方

- **最初の 1 体は大型のボスにし、「照準円が当たり判定の中に収まるか」だけを先に確かめる**。
  - 大型のボスは、照準円が当たり判定の中に収まり、表がほぼ 1 になる見込み。
  - 手順: 単騎・AUTO の録画から一定の間隔でコマを選び、手で輪郭を付け、照準円が輪郭からはみ出すコマの割合を出す。照準円は、範囲の武器（AR・SMG）でいちばん大きい CDN の値（SMG の 110）で見る。
  - はみ出すコマの割合の線引き（例: 1% 未満）は、輪郭を付ける前に決めて commit する。
  - はみ出すコマが線引きより少なければ:
    - K が一様なら、その敵の表は「どの s でも 1」と置ける（観測値として。外れの割合との再現で確かめる）。手間はコマ数枚の輪郭で済み、道具を実戦の画面に合わせる必要が無い。
    - K が正規なら、円の外にも裾が出るので 1 にはならない。同じ輪郭のコマで C_t(s) を数えて表にする（コマ数枚で済むのは同じ）。
  - はみ出すなら、下の通常の手順に進む。
- 通常の手順: その敵を単騎・AUTO で撮る（武器は照準円の変わらない AR か SMG）→ 道具に通す → 場面ごとの表を `bulletCoverage` に置く。確かめは、同じ録画の外れの割合との再現と、別の日の 1 本との比べ。
- 背景が動く場面・演出の多い場面（迎撃戦・レイド）:
  - 背景差分が使えない。最初は「一定の間隔で選んだコマに手で輪郭を付け、その間は前後のコマの輪郭を使う」形で補う。
  - 自動の切り出しは、要るようになってから考える。
- 表を作るまでの敵は、手入力の弾丸命中率と未測定の注記のまま（3 節）。
- 部位（破壊できる部位・コア）を分けたいときは、マスクにラベル（胴体・部位・コア）を付け、ラベルごとの割合を出す。弾丸命中率の表とは別の欄にする。最初の範囲ではしない。

## 8. やらないこと（この案の範囲の外）

- コア命中率を被覆率から出し直すこと。コアの検出は信頼できず（0.3）、コア命中率は C-0036 の式で▲まで入っている。被覆率で出すのは弾丸命中率だけにする。
- MG・SG・SR・RL の弾丸命中率（4 節の範囲外）。
- 照準の遅れや向きを、式（モデル）として持つこと。この案では、数える中に入れるだけにする。
- 形の分類（塊型・多肢型など）や、係数を置いた曲線で、未測定の敵の弾丸命中率を推計すること。
  - 被覆率の表 h(L, s) は、敵ごとに測った「照準円の大きさ → 弾丸命中率」の関数にあたる。関数の形を仮定せず、観測値のまま持つ。
  - 曲線の形でまとめるかは、複数の敵で表がそろい、形が共通だと分かってから考える。
- 残差を合わせるための係数。表は観測値で、合わない分は 5.1・5.3 で原因を確かめる。

## 9. 分からないこと・危険

1. **当たり判定 = 見た目の輪郭か**。違えば、マスクから作る表がずれる。いちばん大きい危険なので、5.3 で先に確かめる。
2. **散らばりの形**。
   - 材料が両方に分かれている（0.1）。C-0036 の根拠のうち N の大きい旧の 1 本は一様を支持し、C-0192 の H2 は正規分布で自然に出る形。ただし、H2 は一様でも的の形しだいで近い効き方になりうる。
   - 5.1 の 0（コア）と 2（弾丸命中率）で、並べる前に決めた規則で 1 つを選ぶ。
   - 正規を選ぶと、確定の結論 C-0036 のモデル側と食い違う（10 節の 5）。
   - どちらでもない形（縁に寄る・偏る）なら、どちらの表も合わない。
3. **照準の追い方は武器種で同じか**。表は武器種で分けない前提（3 節）。AR と SMG の録画で、同じ着地点の表がそろうかを 5.1 で見る。近い側の食い違い（0.2）がここに当たる可能性がある。
4. **遠の脚が霧で欠ける**。欠けると h を低く見積もる。判定を行う遠でいちばん弱いので、5.1 の最初の関門にする。補い方は、h と外れの割合を並べる前に、マスクの質だけで決める。
5. **撃っていたフレームの選び方**。残弾が読めない場面（リロード明け・ジャンプの間）の扱いで、h が少し動く。
6. ×(1 − N) と ×1/(1 + N) の区別（C-0041）。N が小さいうちは差が小さい。大きな▲の群で h の予測が分かれるかを、5.2 の起票のときに見積もる。

## 10. 決めてほしいこと

1. この方式（フレームごとの被覆率。形と動きをモデル化しない）を、ほかの案と比べる候補に入れてよいか。
2. 最初の範囲を、射撃場の的・AR と SMG の弾丸命中率にしてよいか（コア命中率・MG・SG は範囲の外）。
3. 最初の一歩を、机上のコアの▲の比べ（5.1 の 0）にし、続けて道具（段 1）と、当たり判定の探り（5.3）・撮影なしの下見（5.1 の 1・2）に進めてよいか。
4. 未測定の敵は、形からの推計を出さず、いまのとおり手入力と未測定の注記のままにしてよいか（3 節・8 節）。
5. 5.1 で正規分布を選んだ（または 1 つに決められなかった）とき、確定の結論 C-0036（コア命中率 p ÷ (1 − N)²。モデル側も同じ式）をどう扱うか。次のどれかを、そのときにオーナーが決める。
   - (a) 正規分布を候補から外し、一様だけで進める。
   - (b) C-0036 を見直す検証を、別に起票する。コアの▲を、N の大きい枠で撮る。
   - (c) コア命中率と弾丸命中率で散らばりの形を分けて持つ。物理的に筋が通らないので、推奨しない。

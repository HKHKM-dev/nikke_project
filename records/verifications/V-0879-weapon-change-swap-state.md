# V-0879: 使用武器の変更の最初の発と、持ち替えの直前の元の武器の状態

- 問い: 使用武器の変更の最初の発は、持ち替えの時の元の武器の状態（撃っている途中・撃った直後・リロード中）でどう変わるか。マクスウェル・ドレイク：グレイトヴィラン・レッドフード・紅蓮：神殺に共通の規則があるか
- 話題: スキル・キャラ固有
- 日付: 2026-11-28
- 状態: 調査中
- 派生元: `V-0818`、`V-0824`
- 録画: `1295`、`1296`、`1300`、`1301`

## 条件

- 型: 読み直し。V-0824（マクスウェル。102 の burst の notes）と V-0818（ドレイク：グレイトヴィラン。104 の skill1 の notes）の未対応の notes を、同じ録画で読み直す。どちらも、フルバーストの始まり（III のタイマーの 00.00）に持ち替え、変更後の武器の最初の発の時刻が、持ち替えの直前の元の武器の状態で変わった。
- 4 本とも、マクスウェル・ドレイク：グレイトヴィランを操作した III で、ほかの枠（ココア・ソルジャーF.A.・レイヴン）は機構が確定したキャラ。読むのは、元の武器の発のフレーム（HUD の増分と照準の左の残弾）・00.00・変更後の武器の最初の発のフレームだけで、ダメージの値は発を見分けるのにだけ使う。
- いまある規則（C-0897。レッドフード。`firstShotAfterSwapFrames`）: 持ち替えの時の元の武器が、リロード中なら持ち替えから、構え解除の途中（最後の発から 13f 以内）なら構え解除の終わりから、構え直し・チャージの途中なら持ち替えから構え解除 1 回分（13f）の後から、同じ長さで最初の発を撃つ。紅蓮：神殺（AR。C-0965）・ネオン：ブルーオーシャン（C-1413）も同じ規則で書いてある。マクスウェル（`firstShotDelayFrames` 119）とドレイク：グレイトヴィラン（同 112）は、持ち替えの時の状態を見ない即値。
- 仮説の出どころ: V-0824 の「結果」（基礎の SR の最後の発が 00.00 の 15f・10f 前の 2 回が 139f・144f。16f 前の回は 137f）と、V-0818 の「結果」（元の SG がリロード中だった 2 回が 123f・128f。撃っている途中の回は最後の発が 00.00 の 7〜38f 前でどれも 135f）。

## 予測

読み直しなので、確定の条件にしない（verification-guide.md 2.2 節）。仮説の出どころの値は上の「条件」のとおり既に見ている。読む前に、仮説ごとに次を固定する。d は元の武器の最後の発が 00.00 の何 f 前か（動画のフレーム）、B は「構え直し・チャージの途中（撃っている途中）」の回の 00.00 から最初の発まで（マクスウェル 136f、ドレイク：グレイトヴィラン 135f）。

- H-RH（C-0897 の規則をそのまま当てる。構え解除は武器種によらず毎発の後に 13f）: 撃っている途中で d < 13 なら、構え解除の終わり（00.00 の 13 − d f 後）から数えて、最初の発は B − d。d ≥ 13 は B。リロード中は B − 13。
  - マクスウェル: d = 10 は 126f、d = 15・16 は 136f。ほかの回は 136f。
  - ドレイク：グレイトヴィラン: 撃っている途中の回のうち d < 13 の回は 135 − d（d = 7 なら 128f）。リロード中の 2 回は 122f。
- H-RH2（構え解除は、チャージ武器の毎発の後と、マガジンの最後の発の後（リロードに入る）にだけある。チャージの無い武器の撃っている途中は構えたまま）: チャージの無い武器の撃っている途中は d によらず B。リロード中でも、マガジンの最後の発から 13f 以内なら構え解除の終わりから数えて B − d、13f より後は B − 13。チャージ武器は H-RH と同じ。
  - マクスウェル: H-RH と同じ。
  - ドレイク：グレイトヴィラン: 撃っている途中の回はどれも 135f。リロード中の回は、マガジンの最後の発の d が 13 以上なら 122f、13 未満なら 135 − d。
- H-late（撃った直後は遅れる。最後の発から A f 経つまで持ち替えが待つ。A は V-0824 の 2 回から約 18f）: 最初の発は B + max(0, A − d)。
  - マクスウェル: d = 10 は 144f、15 は 139f、16 は 138f、d ≥ 18 は 136f。
  - ドレイク：グレイトヴィラン: d < 18 の撃っている途中の回が遅れる（d = 7 なら 146f）。リロード中が早いことは説明しない。
- 見分け方: マクスウェルの各回の d と最初の発（H-RH・H-RH2 と H-late が分かれる）、ドレイク：グレイトヴィランの撃っている途中の回のうち d が小さい回（H-RH・H-late と H-RH2 が分かれる）と、リロード中の 2 回のマガジンの最後の発の d（H-RH と H-RH2 が分かれる）。

## 読み方

1. 00.00 は、既にある観測値（`1295-03`・`1296-03`・`1300-05`・`1301-05`）。
2. 元の武器の発: HUD の総ダメージの増分（レシピ `hud-jumps`）を、V-0818・V-0824 の 1 発の格子で、操作キャラの発とほかの枠の発に分ける。ドレイク：グレイトヴィランは、照準の左の残弾（`reticle-ammo.ts`）の減りのフレームも読み、マガジンの最後の発（残弾が 1 → 0）とリロードの始まりを決める。
3. 変更後の武器の最初の発は、既にある観測値（`1295-23`・`1296-24`・`1300-18`・`1300-19`・`1301-18`・`1301-19`）と、その回の HUD の増分。
4. 回ごとに、d・元の武器の状態（撃っている途中・リロード中）・00.00 から最初の発までを表にする。

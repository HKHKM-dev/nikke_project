# 要件定義

- 何のための文書か: このツールが何を作り、何を扱い、何を扱わないか（範囲と前提）と、変えない方針。いまの決まりだけを書く。
- 関連: [roadmap.md](roadmap.md)（Stage の一覧）、[backlog.md](backlog.md)（残っている仕事）、[references.md](references.md)（外の資料）

## 1. 目的

『勝利の女神：NIKKE』のソロレイド / ユニオンレイド（単体ボス・180 秒）で、5 人編成が戦闘の始めから終わりまでに与えるダメージの期待値を出す。通常攻撃・スキル・バースト・バフ / デバフを含む。

## 2. 方針

- **確かめてから入れる**: メカニクスは録画で確かめてから計算に入れ、小さく足して確かめる（根拠の決まりは AGENTS.md「事実と記録」）。
- **未対応は明示する**: 定義の無いキャラや効果は「未対応」と出し、黙って無視しない。
- **UI は最小限**: ヘッドレスなコアと自動テストで確かめる。画面は入力と結果の表示に絞る。
- **公開する**: ソースコードは公開リポジトリ（MIT）、サイトは GitHub Pages。個人の情報と認証情報はコミットしない。
- **既存の OSS のコードは流用しない**: 仕様と検証の参考にだけ使う（[references.md](references.md)）。
- **番号**: Stage・バージョンは 1 始まりの整数（v0 や v0.5 は使わない）。

## 3. 構成

- core（`packages/core`）: データの取得と正規化、キャラと育成のマスタ、ダメージの式、共通のフレームループ（1 パス目）と 2 パス目の集計（sim。用語は AGENTS.md）。ヘッドレス。メカニクスは 1 パス目に足す。
- Web アプリ（`apps/web`）: 静的サイト（TypeScript + React + Vite）。計算は Web Worker で回す。
- 検証の記録（`records/`）と道具（`tools/`・`packages/core/scripts/`）。

## 4. 範囲と前提

### 4.1 扱うもの

- 通常攻撃: 武器種（AR・SMG・SR・RL・SG・MG）ごとの発射の間隔・装弾数・リロード・チャージ・スピンアップ、コア・会心・距離ボーナス・属性有利・フルバースト補正。
- バースト: ゲージの溜まり方と、I → II → III → フルバーストの巡り・CT。
- スキル: バフ・デバフ・状態・スタック・回数のきっかけ・倍率ダメージなど、スキル定義の語彙で書ける効果（`packages/core/src/skills/types.ts`）。宝物（お気に入りアイテム）版を含む。
- 育成の入力: シンクロレベル・限界突破・コア強化・スキル Lv・好感度・装備・OL・キューブ・コレクション・リサイクルルーム。
- 敵: 防御力・属性・コアの有無。射撃場 3 分モードの的のジャンプは、敵の出来事として入れる。
- 命中の条件: 射撃場の的は表（実測）から、ほかの敵は手入力のコア命中率・弾丸命中率・距離ボーナス。

### 4.2 前提（モデルで扱わないもの）

- 敵は静止した単体ボスで、行動パターン・パーツ・阻止部位・バリアを持たない。
- 被弾しない（被弾のきっかけ・被弾による HP の減りは起きない）。HP の割合は枠ごとの想定の値で、戦闘の間は変わらない。
- 味方は倒れない。
- 貫通・範囲攻撃の、複数の敵へのヒット。
- アカウント連携（ログインが要り、規約のリスクがある）。

スキル定義の notes の「前提の外」（`outOfScope`）は、この節の前提では起きない・効かない効果に付ける（[skills-guide.md](skills-guide.md) 1.2 節）。

## 5. データ

- キャラと育成のマスタは Blablalink の公開 CDN（認証不要）から取得し、正規化してリポジトリに同梱する（`npm run fetch-data`。取得と正規化は `packages/core/scripts/fetch-data.ts` の冒頭、CDN のパスの形は [references.md](references.md)「Blablalink 公開 CDN」）。ブラウザから CDN へは行かない。
- CDN に無い値（装備の強化 Lv 別の値・OL の Lv 別の上昇値）は、コミュニティの検証値を転記する（README.md「ライセンスとデータの扱い」）。
- スキルの効果は、説明文と Lv 別の値から手書きの JSON（`packages/core/data/skills/`）で定義する。値は書き写さず、説明文の値を参照する（[skills-guide.md](skills-guide.md)）。

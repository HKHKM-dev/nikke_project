# V-0141: レイヴン・A2（射撃姿勢維持型の RL）のリロードの完了から 1 発目までは、待ちからの 1 発目と同じか

- 問い: 撃った後の区間（姿勢の残り）が長いレイヴン（33f）・A2（26f）の単騎でも、弾切れのリロードの完了から 1 発目までは待ちからの 1 発目（レイヴン 86f・A2 94f）と同じで、発と発の間（119f・120f）ではないか（C-0225 を射撃姿勢維持型で確かめる）
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-10-04
- 録画: `122`、`123`
- 状態: 調査中
- 派生元: `V-0139`

## 条件

- 撮影はしない。レイヴン単騎（`122`）・A2 単騎（`123`）の AUTO・スペック固定 ON・バーストなしの録画を読み直す。A2 のバーストのチャージ速度▲は、バーストが無いので入らない。レイヴンの S1（持続ダメージ）・A2 の S2（追加ダメージ）はリロードとチャージに効かない。
- 2 本ともリロード（RELOADING のバー）はまだ読んでいない。レシピ `reload-segments` で完了のフレームとバーの当てはめを出す。
- 総ダメージの増分には、レイヴンは S1 の持続ダメージの tick（約 82,012 × スタック数）、A2 は S2 の追加ダメージ（発と同じフレームに足される）が混ざる。レシピの「完了 → 次の増分」は次の増分が tick のことがあるので、**次の発は 1 発の値（レイヴンは `122-02`・`122-03`、A2 は `123-02` の組み合わせ。tick と同じフレームなら和）で見分けて数え直す**（使い捨てのスクリプト。結果の節に書く）。

**いま分かっていること**

- C-0225（確定）: 入力が UP のチャージ武器は、待ち（戦闘開始・窓の明け）から、発と発の間より撃った後の区間のぶん早く 1 発目を撃つ。リロードの完了から 1 発目までも待ちからと同じ。リロードの後の根拠は紅蓮BS 単騎の 3 本（V-0135）と、但し書きつきのフラワー（V-0139）。
- 発と発の間の内訳は、レイヴン 撃った後 33f・100% のまま 12f・チャージ 58f・満ちてから撃つまで 16f（`122-13`）、A2 26f・12f・58f・24f（`123-06`）。戦闘開始から最初の発まで レイヴン 86f・A2 94f（`122-14`・`123-07`）、窓の明けから 85〜86f・92〜93f（`122-15`・`123-08`）。C-0216・C-0225。
- バーの出始めは武器で違う: 紅蓮BS は撃ってから約 12f（V-0135）、ラム・フラワーは最後の発から（`075-09`・V-0139）。レイヴン・A2 は分からない。
- 弾が届くまでの遅れ（d）は、紅蓮BS（RL・直進）で 1〜9f、フラワー（誘導弾・速さ 100）で区間により 7〜22f（V-0139）。レイヴン・A2 は直進弾（速さ 400・300）で、測っていない。

## 予測（撮る前に書く）

比べる値は、リロード完了（RELOADING のバーが消えたフレーム）から次の発（1 発の値で見分けた増分）まで。V-0139 の見込み違いを繰り返さないよう、d の幅は 1〜22f（これまでの RL の両端）で見る。

| 仮説                                                                             | レイヴンの完了 → 次の発の増分 | A2 の完了 → 次の発の増分 |
| -------------------------------------------------------------------------------- | ----------------------------- | ------------------------ |
| H0: 完了から発と発の間と同じで撃つ（モデルの分け方）                             | 119 + d（120〜141f）          | 120 + d（121〜142f）     |
| H1: 完了から待ちからの 1 発目と同じで撃つ（C-0225 が射撃姿勢維持型でも成り立つ） | 86 + d（87〜108f）            | 94 + d（95〜116f）       |
| H2: どちらでもない（姿勢の残りの一部だけが早まるなど）                           | 109〜119f                     | 117〜120f                |

- 見分けられるか: H0 と H1 はレイヴン 33f・A2 26f 違い、d の幅（21f）より大きいので重ならない。判定は録画ごとに全部の回の範囲で行う（全部の回が H1 の幅に入り、H0 の幅の回が無ければ H1）。
- 補助（判定には使わない）: 最後の発の増分 → バーの出始め（当てはめの 0 の点）。d を引くと、撃ってからバーが出始めるまで（紅蓮BS 型なら撃った後の区間に近い長さ、ラム・フラワー型なら 0f）が分かる。d は戦闘開始の最初の発（残弾が減ったフレーム `122-14`・`123-07`）と、その増分の差で見る。
- 予測ファイル（`records/predictions/V-0141.json`）は、いまのモデルの射撃の数を形の確かめとして固定しただけで、仮説を見分けない（V-0135 と同じ理由）。
- 外れたときの影響: H0 か H2 なら、C-0225 の「リロードの完了から 1 発目までも待ちからと同じ」は射撃姿勢維持型には当たらない。C-0225 の範囲を狭め、`unhideShooter` の直し（V-0135）をレイヴン・A2 に効かせるかを見直す。H1 なら C-0225 の根拠に足す。
- 見込み: H1。

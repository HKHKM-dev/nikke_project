## 条件

- C-0567（仮説・単独実測）の再現を撮る。C-0567 は V-0438 の録画 0472（A）・473（B）で、枠の順の向きごとに 1 本ずつ。仮説は撮る前に書いた（V-0438「予測」）ので、472・473 は `decidedOn` に入らないが、再現には別の録画が要る（plan/verification-guide.md 2.2 節）。
- 条件は V-0438「条件」と同じにする:
  - A: アスカ（830）1 枠目・撃たない操作（AUTO 射撃 OFF）+ ミサト（833）2 枠目・AI。
  - B: ミサト 1 枠目・AI + アスカ 2 枠目・撃たない操作（AUTO 射撃 OFF）。
  - どちらも射撃場 BigArms・灼熱のタブ・3 分モード・スペック固定 ON・オートバースト OFF。
- アスカを撃たない操作枠にするのは、撃つ枠には的の攻撃が当たって HP の割合が下がり、満タンが並ばなくなるため（V-0438「条件」。`0113-06`・`0113-07`・`0125-16`）。アスカは満タンのまま、ミサトは当たることがある。
- 受け手はアスカの S1（回復効果が適用された時の自分の攻撃力▲・25 秒・発動中の再発動で延びる。C-0464・C-0087）。アスカは撃たないので、1 発のダメージではなく、画面下のアスカの顔の下の S1 のアイコンで読む（V-0438 と同じ）。
- 最小構成: V-0438 と同じ。未確定の要素は、ミサトの S1 の回復の対象（確かめたいもの）と、満タンの味方にも回復が適用されるか（C-0567 に含む）。アスカの 1 発の式・コア命中率・距離は、アスカが撃たないので効かない。バーストはオートバースト OFF で撃たない。V-0438 で出た最小構成の警告（ミサトの S1 の命中率▲・アスカのバーストの仮説）は、撃たない操作のアスカの S1 の付き方に効かない（V-0438「分かったこと・分からないこと」）。

## 予測

予測ファイルは作らない（見分けたい仮説は対象の選び方そのもので、`setup` の上書きでは切り替えられない）。仮説ごとの見え方は V-0438「予測」の表と同じ:

- C-0567（枠の順・若い枠から）: A ではアスカの S1 がミサトの最初の S1 から戦闘の終わりまで切れない（並ばない回が続くと、切れる前の点滅に入ってから付き直すことはある）。B では一度も付かない。モデル（段 8 の PR 1）も同じ見え方で、比べる指定は `0472-04`（`buffWindowEnds`）・`0473-03`（`buffWindowStarts`）と同じ形にする。
- 枠の順・右から: A で一度も付かず、B で付く。乱数: A・B とも付いたり付かなかったりする。発動者自身・満タンなら起きない: A・B とも一度も付かない。
- 見分けられなくなる場合: ミサトが S1 の間隔ごとにほぼ毎回当たると、並ぶ回が無くなり、A でもアスカが選ばれない。パネルのミサトの盾の欄で確かめる（V-0438 の録画では A・B とも 0 でなく、それでも A で切れなかった）。

## 読み方

V-0438「読み方」「結果」と同じ:

1. 取り込みの後、出撃画面と戦闘履歴のパネルで、枠順・操作枠（アスカ）・アスカの与ダメージ 0 と盾の欄 0・ミサトの盾の欄を確かめる（`0472-03`・`0473-02` と同じ形の観測値にする）。アスカの盾の欄が 0 でなければ、その録画は見分けに使わない。
2. HUD の増分（`hud.ts --mode jumps`）からミサトの 1 本目のマガジンの最後の増分を取る（最初の S1 の時刻）。
3. 画面下のアスカの顔の下のアイコンの並び（`0472-01` の `method` の範囲）を、ffmpeg で 60f ごとに切り出して並べ、S1 のアイコン（攻撃力▲）が付いているかを目で読む。切れる前の点滅も付いているとして数える。A は付いたフレームと、戦闘の終わりまで切れなかったか、B は一度も付かなかったかを読む。
4. 観測値にする（`source` に `V-0450`）。比べる指定は `0472-04`（A: `buffWindowEnds`・slot 1）・`0473-03`（B: `buffWindowStarts`・slot 2）と同じ形（`skill1`・`attack`・`tolerance.abs` 0・`setup` は `range-bigarms-fire`・`range-3min-jump`・`burst` false・`condition` auto）。

## 分かったこと・分からないこと

- **C-0567 を確定（反復実測）にした**: ミサトの S1 の「残りの HP の割合が最も低い味方 1 機」は、HP の割合が並んだとき、枠の順で若い枠の味方を選ぶ。満タンの味方にも回復が起き、「回復効果が適用された時」を起こす。V-0438 の 472・473 と、この 497・498 で、枠の順の向きごとに 2 本ずつ。仮説は 472・473 を撮る前に書いた（V-0438「予測」）ので `decidedOn` は空。
- 最小構成の警告（アスカのバーストの命中率▲・ミサトの S1 の命中率▲。どちらも仮説の結論に立つ）は、効かない理由を C-0567 の `minimal` の印にした（バーストは撃たない。命中率▲ はミサトの発が当たるかだけを変え、アスカの S1 の付き方に効かない）。根拠の観測値のうち `compare` の無いものに `scope` を足した。
- 分からないこと: ミサトが被弾した後の回に、ミサト自身が選ばれるか。3 機以上が並んだときも若い枠からか（鈴原サクラのバーストの 2 機は、3 機の編成で若い 2 枠に付いた。C-0590）。オーシャンの S1・S2 の対象が同じ規則か。パネルの緑の欄が何を数えるか。

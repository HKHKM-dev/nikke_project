# V-0375: アニス：スターの遠の着地点（遠 A・遠 B）でコアの割合は違うか（と MG の遠 B の距離ボーナス）

- 問い: 射撃場の的の遠で、アニス：スター単騎の通常攻撃（バーストの窓の外）のコアの割合は、遠 A と遠 B で違うか。あわせて、遠 B に降りた MG 単騎（録画 099・226）の遠の通常攻撃に距離ボーナスが乗るか
- 話題: 命中率・距離
- 日付: 2026-10-09
- 状態: 調査中

## 条件

- 出どころ: plan/backlog.md 2-18 の「次の 1 手」。遠の着地点は 2 か所（C-0477）で、2026-10-06 のオーナーの判断は「アニス：スターのモデルは 1 か所のまま。遠 A・遠 B で違う値（命中率・距離ボーナスなど）が見つかったら分ける」。その後 V-0328 で、射撃場の遠を 2 か所にし（C-0477）、SMG の遠の弾丸命中率を着地点ごとにした（C-0476）。アニス：スターに効く値で、着地点ごとにまだ比べていないものを読む。
- アニス：スターに効く遠の値と、この検証で読むもの:
  - 誘導弾の飛ぶ時間: 着地点で違うことは確定（C-0413。遠 A 26〜27f・遠 B 28〜29f。録画 161・164・211・288・289）。2026-10-05 のオーナーの決定（帯の代表値のまま）と、遠を 2 か所にした 2026-10-08 の承認（plan/design-far-landings.md 1 節の 2。`flightFrames` の遠は帯のまま）は、この差を知った上での判断なので、この検証では読み直さない。
  - 距離ボーナス: RL には無い（`data/characters/17.json` の `bonusRange` が null。C-0026）。着地点で変わりえない。
  - 弾丸命中率: RL は 1 で、距離帯によらない（C-0168）。
  - 通常攻撃のコアの割合（C-0425。仮説）: 遠 A と遠 B の差は言い切れていない（V-0297。遠 A の 164・320・321 の窓の外 25/39、遠 B の 161 の 11/27。p = 0.080）。遠 A に降りた 289 と遠 B に降りた 288（V-0284 の録画。遠のコアの割合はまだ数えていない）で、仮説の出どころ（V-0297 の 4 本）と独立に比べる。**これを読む**。
- MG の遠 B の距離ボーナス: MG の `bonusRange` は 35〜55 で、モデルは遠 A・遠 B とも距離の範囲 45〜55（C-0477 の「遠 B が距離ボーナスの境目（55）を跨ぐかは測っていない」）。遠 B に降りた MG 単騎の 099（ルドミラ：ウィンターオーナー。`099-11`）・226（エマ：タクティカル・アップ。`226-04`）の遠（3 区間目）のヒットに距離ボーナスが乗るかを読む。
- 録画（読み直し。撮影なし）: 288（遠 B。`288-09`）・289（遠 A。`289-09`）。どちらもアニス：スター単騎・操作・AUTO 射撃 ON・オートバースト OFF・手でバースト（窓の外のマガジンの 5 発目の前後）・射撃場 3 分モード・BigArms（火）・スペック固定 ON。MG は 099・226（単騎・AUTO・オートバースト OFF・スペック固定 ON）。
- 最小構成: どれも単騎。アニス：スターの発の形とヒットの値は確定（C-0424・C-0297）、窓の中と外は発の値で分かれる（V-0297 の読み方）。未確定の要素は遠の着地点ごとのコアの割合だけ。MG の 2 本は、1 ヒットの値（099 は V-0158、226 は V-0209・V-0230 の格子）が分かっていて、未確定の要素は遠 B の距離ボーナスだけ。
- モデル（いま）: 遠のコアの割合は遠 A・遠 B に共通の帯の値（`coreHitRate.RL.byProjectile` の `HomingProjectile:100:750` の `far` 45/90。C-0425）。MG の遠は、遠 A・遠 B とも距離ボーナスが乗る（`frame/landing.ts`。範囲 45〜55 が 35〜55 に入る）。

## 予測（撮る前に書く）

| 仮説                             | 見え方                                                                                                                                        |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| L0（いまのモデル。予測ファイル） | 遠の窓の外のコアの割合は遠 A・遠 B とも 0.5（`far-out-A`・`far-out-B`）。289 と 288 で差が無い                                                |
| L1（手書き。V-0297 の H-L）      | 遠 A が遠 B より高い。仮説の出どころの 4 本の割合なら遠 A 約 0.64（25/39）・遠 B 約 0.41（11/27）で、289 − 288 は +0.2 前後                   |
| D0（いまのモデル。手書き）       | MG の遠 B のヒットは、どれも距離ボーナス付き（099 は胴体 7,722 × 1.3 などの格子、226 は胴体 5,560.25 × 1.3 などの格子）。照準は水色（C-0043） |
| D1（手書き）                     | 遠 B は 55 より遠く、MG の遠 B のヒットに距離ボーナスが付かない（099 は 7,722 × {1, 1.5, 2, 2.5} の格子だけ）。照準は白                       |

- 判定（読む前に決めた）:
  - 遠 A・遠 B の差は、新しい 2 本（289 の遠 A と 288 の遠 B）の窓の外の発の合計で Fisher の正確検定（両側）。p < 0.05 で、向きが L1 と同じ（遠 A が高い）なら「違う」（L1）。p ≥ 0.05 なら「見分けられない」。仮説の出どころの 4 本（V-0297）は、遠 A の中でも録画どうしで食い違う（164 と 320・321。p = 0.043）ので、合計の検定は参考にとどめ、判定に使わない。
  - 観測値の比べの許容は ±0.25（V-0297 と同じ）。
  - MG は、遠の区間のヒットを距離ボーナス付きと無しの格子に分けた数で決める（どちらかがほぼ全部なら D0・D1。混ざるなら「境目を跨ぐ」として判定なし）。
- 見分けられるか: 遠の区間は約 38 秒で、288・289 は遠の区間にもバーストの窓がある（手で、クールタイムごと）ので、窓の外の発は 1 本あたり 15〜25 発の見込み。差 0.23 だと Fisher の検定で見分けられる見込みは 3 割ほどで、見分けられないことが多い。MG は 1 本の遠の区間で数百ヒットあり、格子が重ならない値で見分けられる。
- 外れたときの影響: L1 なら、表の遠の行を遠 A・遠 B に分ける案（10-06 の判断を変える）をオーナーに諮る。D1 なら、遠 B の距離の範囲を 55 より遠くに直す案（SR・RL・MG など `bonusRange` の上端が 55 の武器種の遠 B の距離ボーナスが外れる）をオーナーに諮る。

## 読み方

1. 区間: `npm run records:read -- <録画 id> --recipe hud-jumps` で総ダメージの増分と的のジャンプを出し、3 区間目を遠にする。
2. アニス：スター（288・289）: V-0297 の読み方の 5 と同じく、HUD の増分を窓の外の 2 単位（コア 1 ヒット + S1 の追加ダメージ。480,330、会心 566,600、追加ダメージの会心 547,955・634,225）と 1 単位（胴体。307,791、会心 394,060、追加ダメージの会心 375,416）、窓の中の 2 単位（649,406・766,043・740,836）と 1 単位（416,132・532,769・507,562）に分けて、遠の区間の窓の外のコア / 読めた発を数える。区間の着地の後の 1 発目は除く。シューティングスターと同じフレームの発は、値の和で一意に分けられるものだけ数える。観測値は `far-out-A`・`far-out-B` と同じ `metric`・`args`・`setup`（`farLanding` は読んだ着地点）。発ごとの形は `record` に。
3. MG（099・226）: 遠の区間の HUD の増分を、距離ボーナス付きと無しの 1 ヒットの格子（会心・コア・受けるダメージ▲・追加ダメージの組み合わせ）に分け、分け方が一通りになる増分だけを数える。照準の色（C-0043）は、遠の区間から数コマを切り出して確かめる。

# V-0518: オートバーストは同じ段階の候補から左の枠を優先して撃つか

- 問い: オートバーストで同じ段階の候補が 2 人とも撃てるとき、キャラや操作の有無に依らず、左（若い枠）のキャラが撃つか
- 話題: バーストの段階とフルバースト
- 日付: 2026-10-26
- 状態: 調査中

## 条件

- モデル（`burst/controller.ts` の `pickCandidate`）は、同じ段階の候補（専任 → AllStep）を、CT が明けていてこのチェーンで未使用のもののうち枠の若い順に選ぶ。これは設計の仮定（plan/design-stage7.md 9 節の 4「自動バーストの実際の優先順は未確認」）で、結論は無い。
- 仮説の出どころ（既存の録画。どれもオートバースト ON・射撃場 3 分モード）:
  - `0460-01`: I の段にアニス：スター（1 枠目・操作）とアビスタ（2 枠目）が両方撃てる状態で並び、アニス：スターが撃った。
  - `0163-01`: I の段にアニス：スター（2 枠目・操作）と I-DOLL・フラワー（3 枠目）が並び、アニス：スターが先に撃った。
  - `0465-09`・`0466-09`: III の段に I-DOLL・サン（1 枠目・AI）とマナ（2 枠目・操作）が並び、5 回ともサンが撃った。
- どれも左の枠が撃っていて、左が操作でも AI でも同じ。ただし、どの録画もキャラの左右を入れ替えていないので、「左だから」か「そのキャラだから（ID・レア度など）」かを分けられない。
- 編成は録画 0465・0466 の 4 人（ラム I・デルタ II・サン III・マナ III。どれも CT 40 秒）で、III の 2 人の左右だけを入れ替える。III の 2 人はどちらも操作しない（操作の有無を候補から外す）。操作はラム。
  - 撃つ枠を決めるのは段階・CT・枠の順で、スキルの値は効かない。CT に効くスキルはラムの S1（フルバースト終了時に自分の CT▼）だけで、III の 2 人の CT は変えない。
  - どのフルバーストでも III の 2 人は同じ CT 40 秒なので、両方撃てる状態で III の段に入る（1 回目は戦闘開始から CT が回っていないので必ず並ぶ。2 回目以降は前の回に撃った方の CT の明けと III の段の入りがほぼ同じ時刻で、録画 0465・0466 では左のサンの CT が 0.15〜0.30 秒残っていた）。

## 予測

予測ファイルは使わない（モデルは H1 しか持たない）。モデルでは A・B とも 5 回のフルバーストで、III は毎回 1 枠目が撃つ（`npm run sim -- --ids 308,290,20,822` と `290,308,20,822`、`--fixed-spec --controlled 4 --enemy range-bigarms-fire --events range-3min-jump`。撃った枠の並びは A・B とも 4,3,1 の繰り返し）。

| 仮説                                                 | A（1 枠目サン・2 枠目マナ）の III | B（1 枠目マナ・2 枠目サン）の III |
| ---------------------------------------------------- | --------------------------------- | --------------------------------- |
| H1: 左（若い枠）を優先                               | 毎回サン                          | 毎回マナ                          |
| H2: キャラで決まる（入れ替えても同じキャラ）         | 毎回サン                          | 毎回サン                          |
| H3: 最後に撃ってから長い方（交互。設計書の代替の案） | サン・マナ・サン…                 | マナ・サン・マナ…                 |

- H1 と H2 は B の 1 回目で分かれる。1 回目は両方の CT が回っていない状態なので、ほかの要素が混ざらない。
- H3 は 2 回目で分かれる（録画 0465・0466 とは合わないが、操作を外した編成で確かめる）。
- 2 回目以降の III の段の入りで左の CT が少し残っているとき（録画 0465・0466 の 0.15〜0.30 秒）、「撃てる候補のうち左」（モデル）なら右が撃ち、「左の CT の明けを待つ」なら左が撃つ。1 回目では分からない副次の問いで、欄の CT の表示が実際の CT より遅れて見えているだけかもしれない（結論にするなら別の検証に分ける）。
- B ではマナがバーストを撃つので、マナのバーストの持続ダメージの tick（録画 0212）が HUD に出る（A では出ない。`0465-09` の注）。撃った人の補助の確かめになる。

## 読み方

- 右のバースト欄（`burst-panel` のレシピ、または欄の切り出しの目視。`0460-01` と同じ読み方）で、各段で撃ったキャラの顔と、III の段に入った時の 2 人の CT の残りを読む。
- 観測値は撃った枠の並び（`burstActivationSlots`、n = 15。`0465-09` と同じ比べる指定）。B の 1 回目の III の枠を主に見る。

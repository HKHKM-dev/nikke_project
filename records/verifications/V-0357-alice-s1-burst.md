## 条件

**なぜ確かめるか**

- 最小構成の検査の束 4（根拠の無い効果。[plan/design-minimal-relevance.md](../../plan/design-minimal-relevance.md) 11 節）。アリスの skill1 の effects[0]・effects[1] と burst の effects[0]・effects[1] に根拠の結論が無く、[plan/minimal.md](../../plan/minimal.md) で録画 042・043・048〜050・094 を根拠にする確定の結論（C-0134 など）の警告に残っている。片付け方は backlog 5-2 と同じく、最小構成の録画の読み直しか撮影で結論を作る（[plan/design-skill-claims-5-2.md](../../plan/design-skill-claims-5-2.md)）。

**説明文**（`data/characters/191.json`。Lv10）: S1「フルバーストタイムが発動した時、最終攻撃力が最も高い味方 {値 1}（2）機に スキル発動者基準でチャージ速度 {値 2}（11.67）%▲（{値 3}（10）秒）・チャージダメージ {値 4}（7）%▲（{値 5}（10）秒）」。バースト「自分に チャージ速度 {値 1}（80.15）%▲（{値 2}（10）秒）・攻撃力 {値 3}（55.12）%▲（{値 4}（10）秒）」。定義は `data/skills/191.json`（S1 は `target: topAttack`・`targetCountRef: 1`、チャージ速度▲は `scaling: casterChargeTime`）。機構の結論: 速度▲の効き方は C-0013、足し算のチャージダメージ▲の置き場所は C-0134。

**既存の録画の読み直しで足りない理由**

- 042（フラワー + アドミ + アリス（操作）+ サン）・043（フラワー + クラウン + アリス（操作）+ マナ + アドミ）はスペック固定 ON だが、アリスの S1 とバーストが効く値（フルバーストの中のアリスの発の間隔と 1 発の値、S1 の 2 機目のアドミの発の間隔）は、凍結の記録（plan/verification.md の Stage 11「アリス」）で既に読まれ、S1 の「スキル発動者基準」の読み（`casterChargeTime`）はその値から決めた（仮説の出どころ）。比べれば後付けになる（[plan/skills-guide.md](../../plan/skills-guide.md) 2 節）。042 でまだ読んでいない S1 の 2 機目（アドミ）の 1 発の値は、アドミの skill1 の notes[0]（被弾 20 回でのチャージダメージ倍率▲。3 分モードでは的が反撃するので起きうる）と混ざる。043 はマナの S2 の根拠なしの効果（チャージ時間▼ など）も混ざる。
- 094（ラム + デルタ + アリス（操作））は、アリス以外のダメージに効く要素が確定で、最小構成に近い。ただし `094-01`（フルバーストの中とバーストの後の 1 発）は V-0053 で読み、C-0134 の出どころになった。残る値（発の間隔・S1 の 2 機目の 1 発）は、スペック固定 OFF なので予測に枠ごとの育成（`build`）が要るが、台帳と録画にはアリスの攻撃力と OL の行しか無い（ラム・デルタの育成は映していない）。アリスの間隔も、装備のチャージ速度（`089-05` の注）が効く。
- 048〜053 はスペック固定 OFF の 5 体（リター・紅蓮：ブラックシャドウなど）か迎撃戦で、最小構成でない。089 は単騎でバーストを使わず、S1 もバーストも起きない。

- 効果ごとの見え方（H1）:
  - バーストの攻撃力▲（burst の effects[1]）: アリスが III の回とレイヴンが III の回の、フルバーストの中のアリスの 1 発（`alice-fb-own`・`alice-fb-s1only`）の比。どちらも S1 のチャージダメージ▲とフルバーストの補正が乗り、違いはバーストの攻撃力▲だけ。
  - S1 のチャージダメージ▲（skill1 の effects[1]）: `alice-fb-s1only` と、S1 の 2 機目のレイヴンの 1 発（`raven-fb-alice-round`。窓の外は `raven-base`）。
  - バーストのチャージ速度▲（burst の effects[0]）: アリスの発の間隔の、フルバーストの中と直前の差が、アリスが III の回（`alice-interval-own`）とレイヴンが III の回（`alice-interval-s1only`）で違う分。
  - S1 のチャージ速度▲（skill1 の effects[0]）: `alice-interval-s1only` と、レイヴンの間隔の差（`raven-interval-alice-round`）。H2 とはレイヴンの間隔だけで分かれる（差は数 f。値は予測ファイル）。
  - 秒数（どれも 10 秒）: 1 回目のフルバーストの後、次のバーストより前のアリスの 1 発（`alice-after`）が、窓の外（`alice-base`）と同じか。
- 判定の目安: 1 発の値は、どの指標も H1 と ±1 で合えば H1（説明文の値と機構の結論だけで決まり、合わせ込みの定数が無いので、合えば厳密一致）。間隔の差は ±1f。H2 と H1 はレイヴンの間隔の差だけで分かれるので、レイヴンの回を除く全部のフルバースト（アリスが III の回）の差の中央値で決める。
- 外れたときの影響: H3 なら、アリスを含む編成で S1 がアリス自身に付かず、アリスの与ダメージが下がる（定義の対象を直す）。H2 なら、S1 の 2 機目のチャージの速さが変わる（`scaling` を外す）。どの仮説とも合わなければ、効果ごとに上の指標で切り分ける。

## 読み方

1. 撮ったら `tools/captures/intake.ts` で取り込む（`--rid 311,301,191,851 --controlled 3 --target BigArms --element Fire --mode range-3min --fixed-spec on`）。戦闘履歴のパネルで枠と名前、画面左上で AUTO 射撃・オートバーストを確かめる。編成・枠順が計画と違えば、その編成で予測を出し直して commit してから読む。
2. HUD の総ダメージの増分（`npm run records:read -- <録画 id> --recipe hud-jumps --source V-0357 --write`）から、アリス・レイヴン・ココアの 1 発を予測ファイルの値の格子（コア・会心・距離ボーナス）で分ける。ソルジャーF.A. のペレットは 1 桁以上小さい。
3. フルバーストの始まりと III の枠を、右のバースト欄で読む（[plan/captures/guide.md](../../plan/captures/guide.md)「バーストの段の切り替わり」「バーストを撃った枠」）。
4. 1 発の値: 予測の指標と同じ区間（最初のバーストより前・アリスが III の回のフルバーストの中・レイヴンが III の回のフルバーストの中・1 回目のフルバーストの後）の、会心でない 1 発を観測値にする（`hitDamage`。`args`・`setup` は予測ファイルと同じ）。
5. 間隔: 各枠の発のフレーム（増分のフレーム。アリスは照準の横の残弾でも確かめる）から、フルバーストの中と直前の同じ長さの間隔の中央値の差を、フルバーストごとに出す（`fullBurstShotIntervalDiff`）。的のジャンプ・フルバーストの入りの止まり・リロードをまたぐ間隔は除く。

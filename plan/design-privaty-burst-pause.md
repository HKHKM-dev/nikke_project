# プリバティのバーストの後の撃たない間（バーストの使用で射撃を止める効果）

- 関連: [skills-guide.md](skills-guide.md) 1.4 節、`skills/types.ts` の `ShotPauseEffect`（V-0534。射撃の回数のきっかけで射撃を止める）、V-0660（プリバティの宝物版スキル）、V-0661（この読み直し）
- 作成日: 2026-11-03
- 状態: 起案（オーナーの承認待ち）

## 1. 何を足すか

プリバティ（170。宝物版）は、自分のバースト（III）の発動の後、ミサイルの 3 ヒットが終わるまで撃たない（V-0661）。

- 録画 0938・0939 の 9 回のフルバーストで、プリバティの最初の発は III のタイマーの 00.00 の +125〜+130f（動画。入りの止まり 22f を含む）。3 ヒット目（+117〜+118f）の約 8f 後。
- 対照: 同じ III・操作のミハラ（録画 0469）は、止まりが明けた +27f から撃ち、バーストのヒットの間も撃つ。プリバティだけの止まり。
- いまのモデルは止めないので、フルバーストの入りに 20 発ほど多く撃ち、最後の弾丸（S2 の追加ダメージ）の時刻が録画からずれる（1 回目のフルバーストの最初の最後の弾丸は、モデルが 00.00 の +89f、録画は +195f。V-0660「分からないこと」）。

今の語彙では書けない。射撃を止める効果 `shotPause` のきっかけは、射撃の回数（`{ count }`）だけ。

## 2. 案: `shotPause` のきっかけに `burstUse` を足す

```json
{
  "kind": "shotPause",
  "trigger": "burstUse",
  "frames": 109,
  "assumes": { "ja": "…", "en": "…" },
  "claims": ["C-NNNN"]
}
```

- **意味**: 自分のバーストの発動のフレームの次のフレームから `frames` フレームの間、自分の射手を進めない。止めている間の扱いは、いまの `shotPause` と同じ（撃たず、待ち・リロードも進めない。残弾・スピンアップ・レートの蓄積は持ち越す）。
- **フレーム数**: 録画で読む値（説明文に無い）。最初の発の 00.00 からの動画のフレーム（+125〜+130f）から、入りの止まり 22f を引き、III の発動から 00.00 までの 6 ティック（C-0512）を足して約 109f。実装の後に、モデルの最初の発が録画（2 本の 9 回）と合うように決める。
- **書ける場所**: burst スロットだけ（`burstUse` は自分の発動）。`framesOnLastShot` は書けない（射撃の回数のきっかけでないので）。
- **実装**: `frame/firstPass.ts` で、枠のバーストの発動のフレームに `pauseLeft`（いまの `shotPause` の止まりの残り）を立てる。読み込み（`skills/parse/attack.ts` の `parseShotPauseEffect`）と、解決（`resolveShotPauses`）に `burstUse` の形を足す。1 パス目は sim と calc で共有なので、どちらにも効く。

## 3. 論点

1. **止めている間にリロードを進めるか**。推奨: 進めない（いまの `shotPause` と同じ）。0938・0939 では、どの回も発動の時に残弾があり、止まりの明けにマガジンの残りから撃っていて、リロードの進みは見分けられない。未確定と `assumes` に書く。
2. **基礎版（宝物なし）にも入れるか**。推奨: 入れない（宝物版のバーストだけ）。基礎版は撮れず（スペック固定でも宝物版が出る）、3 ヒットの遅れの表の行も宝物版だけ（C-0923）。基礎版の burst の notes に、未測定と書く。
3. **語彙の形**。推奨: いまの `shotPause` のきっかけを広げる（別の効果の種類を作らない）。止まりの扱いが同じで、射手の側の実装（`pauseLeft`）をそのまま使える。

## 4. 確かめ方（V-0661）

- 実装の後、0938・0939 で、各フルバーストの最初の発の時刻と、最後の弾丸（S2 の増分）の時刻をモデルと比べる。
- V-0660 で合わなかった S2 の増分 3 つ（0938 の f9555、0939 の f7339・f9642）が、時刻のずれを直すと合うかを見る。
- 既存の観測値（C-0921〜C-0924 の根拠）が許容内のままかを見る。

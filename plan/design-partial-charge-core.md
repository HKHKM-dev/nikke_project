# 設計書: 敵のジャンプの始まりの部分チャージの発のコア命中率（A2・レイヴン）

- 何のための文書か: 射撃場 3 分モードの敵のジャンプの始まりに、A2・レイヴン（満ちてから撃つまでの長い射撃姿勢維持型）が撃つ部分チャージの発の当たる部位を、モデルに入れる形を決める
- 関連: V-0656（部位の読み直しと撮影）・V-0624（部分チャージの発の値。C-0855）、[design-hide-reload-detect.md](design-hide-reload-detect.md)（部分チャージの発の時刻と値）、課題 `records/backlog/2-48.json`
- 起案: 2026-11-03
- 状態: 決定（モデルに入れない。5 節）

## 1. いまのモデル

- 部分チャージの発の値は、その区間の 1 トリガーの値（`slotTriggerDamage`）のフルチャージ倍率を、D の時点の進みで置き換えた値（`partialChargeTriggerDamage`。C-0855）。コア命中率はふだんの発と同じ、的の表のその区間の着地点の値（RL の直進弾・弾速 300・400 は 1。C-0172）。
- 窓（狙えない 2 秒）は、その前の区間（跳ぶ前の着地点）に入る（`enemyLandingsOf`）。窓の中に撃つ部分チャージの発は、跳ぶ前の着地点のコア命中率で数えられる。

## 2. 分かったこと（V-0656）

- 当たる部位は、キャラと跳ぶ前の着地点で決まり、同じ組では揃う。部分チャージの進み（3〜40f）・味方の▲・フルバーストの中かどうか・操作か AI かには、よらない。
- 距離だけでは決まらない（レイヴンは遠でも近でも胴体、A2 は中遠 A（近い方）で胴体・中遠 B・C（遠い方）でコア）。なぜ胴体に当たるか（敵がジャンプを始めた後に撃つためか）は分からない。
- 読んでいない組: レイヴンの中近・中遠から跳ぶ窓、A2 の近・遠から跳ぶ窓（どれも手元の録画に部分チャージの発が無い。同じ条件なら窓の時刻がそろうので、単騎の AUTO では出ない）。

## 3. 案

- **案 A（推奨）**: 的の表に、部分チャージの発のコア命中率の行を足す。
  - `targetProfiles` の `coreHitRate.partialChargeShots`（キャラの resourceId → 着地点の id → 帯 → `all` の順に引く。`weaponChanges` と同じ引き方）。
  - 行は読んだ組だけ: レイヴン（851）は近・遠が 0、A2（811）は中近・中遠 A が 0、中遠 B が 1。中遠 C は 1 本だけなので行を置かない（ふだんの値の 1 と同じなので、値は変わらない）。
  - 行の無いキャラ・着地点は、ふだんのコア命中率のまま（未実装。的の表の `source` に、読んでいない組を書く）。
  - 2 パス目は、部分チャージの発だけ、この行でコア命中率を替えた 1 トリガーの値から `partialChargeTriggerDamage` で値を出す（区間のふだんの発の値は変えない）。1 パス目の `shotValueAt`（蓄積爆破の発の値）も同じ。
  - 会心はふだんの会心率のまま（V-0656 の 23 回のうち会心は 1 回で、会心率で数えるのと見分けられない）。
- 案 B: 射撃姿勢維持型の部分チャージの発を、どこでも胴体にする。A2 の中遠 B・C（コア）と合わない。採らない。

## 4. 効くところ

- 射撃場の的（`range-bigarms`）で、着地点の自動の計画がある時だけ。手入力の条件・ほかの敵は変わらない。
- A2・レイヴンの単騎の総ダメージは、部分チャージの発 1〜2 発ぶん（胴体はコアの半分）減る。

## 5. 決めたこと（2026-11-03 オーナー）

1. モデルに入れない（案 A・案 B のどちらも採らない）。部分チャージの発も、的の表のふだんのコア命中率で数える。
2. 的の表（`source` を含む）には書かない。
3. 結論 C-0930（レイヴン）・C-0931（A2）は仮説のままにする（モデルと比べる指標が無い。人の判断で確定にはしない）。

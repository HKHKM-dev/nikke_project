# V-0556: レイヴンの S1 の持続ダメージの tick は、撃ったフレームから数えるか、付けたフレーム（撃った 6f 後）から数えるか

- 問い: レイヴン単騎の録画で、S1 の持続ダメージの最初の tick は、きっかけのフルチャージの発を撃ったフレーム F（照準の横の残弾が減ったフレーム）の何フレーム後に出るか（いまのモデルは F + 59。付けたのは F + 6）

## 条件

- 型: 読み直し（撮影なし）。
- 結論の対象: `data/skills/851.json` の skill1 の effects[0]（`dot`・`firstTick: afterInterval`・間隔 1 秒）の tick のフレーム。モデル（`frame/dot.ts` の `dotTickTracker`）は、まとまりの最初の発のフレーム（射撃のフレーム。撃ったフレーム F に当たる。C-0661）を起点にし、k 回目の tick を起点 + ceil(k × 58.8235)（k ≥ 1。C-0454）に置く。最初の tick は F + 59。
- 出どころ: 付けたのは F の 6f 後（C-0181。付けたときのゲージは `gaugeOnApplyDelayFrames: 6` で入れた）。V-0111 は 0141 で「付いたフレームから 58〜59f 後に最初の tick」と書いていた（`0141-01` の注記）が、モデルは tick を F から数えている（plan/design-shot-count-trigger-frame.md 6.6 節。tick の当てはめ `0122-24` の起点は最初の tick から逆算した値で、F とは結び付けていなかった）。
- 見る所: 持続ダメージが付いていない所で付けた発（戦闘の最初の発と、切れた後の最初の発）の F と、そのまとまりの最初の tick。付け直し（維持の途中の発）は刻みを変えない（C-0129）ので、起点はまとまりの最初の発だけで決まる。
- 録画:
  - 0141（単騎・操作。コアに 2 発 → 約 18 秒撃たない → コアに 1 発 → 約 13 秒 → 空に 3 発）: まとまりが 3 つ。V-0111 で「付いたフレームから 58〜59f」と書いた録画なので、**仮説の出どころ**（結論の `decidedOn`）。
  - 0122（単騎・AUTO・オートバースト OFF）: 持続ダメージは最初に付いてから切れない（撃つ間はいちばん長くても 276f で、最後に付けてから消えるまでの 5 秒（294f）より短い。`0122-04` の注記）ので、見られるのは戦闘の最初の 1 回だけ。F（`0122-14`。V-0130）と最初の tick（`0122-07`。V-0111）は別々の検証で読まれていて、この問いの値を決めるのには使っていない。**再現**に数える。
- 最小構成: 単騎。tick の時刻に効く未確定の要素は無い（S1 の攻撃力▲はフルバースト開始時で、バーストを使っていない。S2 は射撃場で起きない（C-0365））。

## 予測

なし（読み直し）。仮説は次の 2 つ。

| 仮説                                              | 最初の tick − F |
| ------------------------------------------------- | --------------- |
| HS（いまのモデル）: 撃ったフレームを起点に数える  | 59              |
| HA: 付けたフレーム（F + 6）の 1f 前を起点に数える | 64              |

- HA の「1f 前」は、atApplication（ニヒリスター・マナ）の起点を 1 回目の tick の 1f 前と読んだ形（V-0317「分かったこと」）にそろえた読み。0141 の 3 つのまとまりの「付いたフレームから 58f」から立てた。

## 読み方

1. F: 照準の周りを 1 フレームずつ切り出して並べ、照準の横の残弾が減ったフレームを目で読む（0141 は `reticle-ammo.ts` が撃つ前後の表示を読めなかった。0122 は V-0130 の読み `0122-14`）。0141 の空の 1 発目は `0141-03` の注記の f2858。
2. 最初の tick: `0141-01`・`0122-07`（HUD の増分のうち、1 スタックの値の整数倍のもの）。
3. F → 最初の tick のフレーム数を、録画ごとに観測値（`kind: interval`・`use: record`・`scope`）にする。

## 分かったこと・分からないこと

- 分かったこと: レイヴンの S1 の持続ダメージの tick は、付けたフレーム（撃った 6f 後）の 1f 前（撃ったフレームの 5f 後）を起点に数える。最初の tick は撃ったフレームの 64f 後で、いまのモデル（59f 後）より 5f 遅い。
- 分からないこと: 起点が「付けたフレーム」ちょうどでなく 1f 前になる理由（バーの伸びが 1f 遅れて写るのか、起点の数え方なのか）。ほかの afterInterval の持続ダメージ（クルミ）の起点が、付けたフレームか 1f 前かは、ここでは見ていない。
- モデル: tick の起点を撃ったフレームから 5f 後ろにずらす案を、オーナーの判断に出す（plan/design-shot-count-trigger-frame.md 6.7 節）。
- 結論（2026-10-31。オーナーの判断）: C-0765（確定。指標なし。plan/design-shot-count-trigger-frame.md 6.7 節の論点 11）。モデルにも入れた（同 論点 9。`tickDelayFrames: 5`）。

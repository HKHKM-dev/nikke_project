# V-0126: 散らばりの形（一様・正規）を、コアの▲の倍率で机上で比べる

- 問い: 既存のコアの▲の倍率（C-0036 の根拠・C-0183）は、照準円の中の弾の散らばりが一様か正規分布（σ = R/√2）かで、どちらの予測と合うか
- 話題: 命中率・距離
- 日付: 2026-10-04
- Stage: plan/design-bullet-hit-rate-frame-coverage.md 6 節の段 0（別紙 verify の 5.1 の 0）
- 録画: `054`、`057`〜`062`、`137`〜`140`、`142`、`143`
- 状態: 打ち切り

## 条件

- 撮影なし。既に読んだ値だけで計算する（設計書の段 0）。結論は作らず、散らばりの形 K を選ぶ材料にとどめる（設計書 5.1）。
- 2 つの形の、コアの▲の効き方（コアを照準の中心に置いた円とみなす。C-0046）:
  - 一様（主）: p → min(1, p ÷ (1 − N)²)（C-0036 の式）。
  - 正規（対立。σ = R/√2）: p → 1 − (1 − p) ^ (1 ÷ (1 − N)²)。p が小さいと一様と同じで、p が大きいほど一様より弱く効く。
- 照準の中心とコアのずれは入れない（どちらの形にも入れない。設計書 5.1 の 0）。
- 選び方は、計算の前に設計書（2026-10-04 承認、commit 96e7d7d）に固定してあった: 材料ごとに χ² = ((実測 − 予測) ÷ σ)²（σ は録画単位）を出し、正規が一様より 4 以上悪ければ正規を対立仮説から外す。そうでなければ正規を残して下見の 2 に進む。
- 材料（設計書 5.1 の 0 に書いたもの）:
  1. クルミのキューブ（C-0036 の根拠。N = 0.0509。verification.md Stage 18-B「撮影 1」の録画 57〜62 の区間ごとのコア / 当たった数）。
  2. ミサトの S1 の 3 スタック（C-0183。N = 0.1512。`054-17` と同じ組: ミサト `137-03`・`139-03`・`142-03`、対照のリター `138-03`・`140-03`・`054-13`・`143-03`）。
  3. 旧のクエンシー：エスケープクイーン（C-0036 の根拠。N = 0.4942。旧 `docs/実測突合記録_2026-08.md` §116）。
- 計算: 距離帯ごとに、▲なしのコア命中率 p（対照の合計）を 2 つの形の式に入れ、▲ありの枠の距離帯ごとの当たった数で重みを付けて、4 つの帯に共通の倍率 r（`054-17` と同じ定義: ▲ありのコアの数 ÷ Σ（▲ありの当たった数 × 対照の率））の予測を出す。

## 予測（撮る前に書く）

予測なし（撮影の無い机上の計算。既に見た値で、選び方は計算の前に設計書に固定した）。

- 見分けられる見込み: 2 つの形の r の差は N とともに広がる。ミサトの対照の率と当たった数の重みで計算すると、差は N = 0.0509 で約 1%、0.1512 で約 4%、0.3 で約 10%、0.5 で約 24%。録画単位の σ（ミサトで r の約 6%）と比べると、材料 1・2 の N では見分けにくい見込み。

## 読み方

- 材料 1: 録画 58〜60（キューブなし）の合計を p、録画 57・61・62（あり）を▲ありとする。録画単位の σ は、ありの 3 本の r と、なしの 3 本の r（なしの合計の率に対する倍率）のばらつきを合わせて出した（√(s_あり² / 3 + s_なし² / 3)）。
- 材料 2: `054-17` の値の組をそのまま使い、σ は `054-17` の録画単位の 0.081。
- 材料 3: 旧の §116 は、単騎の増分のうち 1 ヒットの格子に乗った 1,103 件（35%）だけで数え、距離帯は「適正距離（×1.30）か距離外か」の 2 つにしか分かれていない。▲なしの p と、距離帯ごとの当たった数が無い。
- 計算は使い捨てのスクリプト（Python。上の式をそのまま書いたもの）で行った。

| 1 クルミのキューブ    | 0.0509 | 1.084  | 1.110      | 1.085      | 0.067        | 0.15       | 0.00       |
| 2 ミサトの 3 スタック | 0.1512 | 1.305  | 1.388      | 1.337      | 0.081        | 1.06       | 0.15       |
| 合計（材料 1・2）     |        |        |            |            |              | 1.21       | 0.15       |

- 材料 1 の実測 r（1.084）は、帯ごとの合計の率から出した値。Stage 18-B の 1.076 は二項分布のプロファイル尤度で出した値で、定義が少し違う。録画単位の σ（0.067）は、Stage 18-B の信頼区間から出る幅（約 0.033）の約 2 倍。ありの 3 本の r は 1.111・1.007・1.133、なしの 3 本は 1.088・0.899・1.014 だった。

**材料 3（旧のクエンシー）**

- 設計書の材料の作り方（帯ごとの▲なしの p と、帯ごとの当たった数）では計算できない（読み方）。選び方の χ² には入れない。
- 参考に、▲なしの p を C-0034 の SMG の表、帯の重みを材料 2 の対照の当たった数で置いて試算した。

| 距離帯の組                      | 実測（旧 §116）    | 一様の予測 | 正規の予測 |
| ------------------------------- | ------------------ | ---------- | ---------- |
| 適正距離（近・中近）            | 0.649（430 / 663） | 0.855      | 0.615      |
| 距離外（中遠・遠）              | 0.311（137 / 440） | 0.170      | 0.159      |
| 旧の集計（帯を混ぜた p 0.1331） | 0.514              | 0.520      | 0.428      |

- 旧の集計で一様と合ったのは、帯を混ぜた 1 つの p に式を当てたため。式は p について線形でない（一様は上限 1 で切れ、正規は曲がる）ので、帯を混ぜた p に当てた値は、帯ごとに当てて混ぜた値と一致しない。
- 帯を 2 つに分けると、どちらの形とも合わない。適正距離では一様が大きく出すぎ（近の p × 3.9 が上限 1 に当たる）、距離外ではどちらも実測の半分ほど。基準の p が別のキャラ・別の日の表で、クエンシーは銃口が 2 つの SMG（CDN の `muzzle_count` 2）であり、1 ヒットの格子に乗った増分だけを数えた選び方の偏りもありうる。照準の中心とコアのずれ（設計書 0.2 の (a)）は、照準円が半分になる N では効きが大きくなる。どれが効いたかは分けられない。

## 分かったこと・分からないこと

- 段 0 の判定: 材料 1・2 の χ² の差は 1.06（4 未満）。**正規は対立仮説に残り、下見の 2（弾丸命中率の材料と合わせた選び方）に進む**（設計書 5.1 の 0 の規則どおり）。
- 材料 1・2 の N（0.05・0.15）では、コアの▲の倍率で 2 つの形はほとんど見分けられない（予測の差 1%・4% に対し、録画単位の σ は 6%）。差が σ の 2 倍を超えるのは N が約 0.35〜0.4 から。
- **設計書 0.1 の「旧のクエンシー（N = 0.4942）は一様を支持する（概算）」は取り下げる**。帯を混ぜた集計に式を当てた比べで、帯に分けるとどちらの形とも合わない。設計書の「一様を主にする」理由は、C-0036 と同じ前提であることだけになる（オーナーの判断で主にした扱いは変えない）。
- 分からないこと 1: 旧のクエンシーの帯ごとの外れ（適正距離で一様より低く、距離外で両方より高い）が、基準の p の違い・2 発撃つ武器・数え方の偏り・照準のずれのどれによるか。
- 分からないこと 2: 帯ごとの倍率が近で小さく出る向き（材料 1・2）が、正規の形によるものか、揺れか。

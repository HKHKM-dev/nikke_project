# V-0399: バースト使用時の効果は段の表示の 1f 前に付くか（録画 244・113・366 の読み直し）

- 問い: バースト使用時の効果の付き始めは、多くのキャラで段の表示（I・II は六角形の替わり目、III はタイマーの 00.00）の 1f 前という 1 つの形か、キャラごとに違うか
- 話題: スキル・キャラ固有
- 日付: 2026-10-10
- Stage: backlog 2-4（plan/burst-effect-delay-candidates.md 2.6 節。バースト使用時の効果の付き始めの全体の形）
- 録画: `244`、`113`、`366`
- 状態: 調査中

## 条件

**何を確かめるか**

- いまのモデルは、遅れの表（`burst/landing.ts` の `MEASURED_BURST_DELAYS`）に行の無いキャラのバースト使用時の効果を、本当の発動（I・II は六角形の替わり目の 5f 前。C-0503。III はタイマーの 00.00 の 6f 前。C-0516）に置く。
- 既に読んだ付き始め（段の表示から数えた動画のフレーム。▲の無い最後の発 → ▲の乗った最初の発）を並べると、次の 3 つに分かれて見える（plan/burst-effect-delay-candidates.md 2.6 節。値は各観測値）。
  - **表示の 1f 前の形（HD）**: リター（V-0370。8 本・32 回。`213-12`〜`220-10`。▲の無い最後の発は替わり目の 2f 以上前、▲の乗った最初の発はほとんどが 1f 前）、クルミ（`100-10`）、エマ：TU（`022-16`・`263-08`）、ルドミラ：WO（`192-15`。00.00 の 2f 前に無く 1f 前に有る）。ラピ（`221-21`）・アスカ（`063-15`）も矛盾しない。
  - **本当の発動の頃の形（HA）**: クラウン（C-0499。替わり目の 5〜6f 前）、雪子の 1more（C-0511。00.00 の 5f 前）。
  - **表示の後の形（HM）**: ミランダ（宝物版。C-0450。録画 318 の 3 回とも、替わり目の 1f 前の発に▲が無く、替わり目の 1〜2f 後の発に有る）。
- HD は後付けの並べで、予測を固定して確かめた形ではない。ミランダが HD と違うのも 1 本・3 回だけ。この 3 本で、HD を予測に固定して確かめる。

**編成**（どれも灼熱の的・3 分モード・スペック固定 ON・オートバースト ON）

- 録画 `244`（V-0216）: ミランダ（32。I・宝物 3 段階・操作・AUTO 射撃）+ デルタ（20。II・AI）。III がいないのでフルバーストは無い。デルタはダメージに効く効果を持たない（C-0252 の根拠と同じ）ので、ミランダの 1 発の値に効く未確定の要素はミランダのバーストの効果の付き始めだけ（最小構成）。
- 録画 `113`: クルミ（862。I・操作・AUTO 射撃）+ デルタ（II・AI）。クルミのバーストは敵全体の受けるダメージ▲（C-0494）。クルミの 1 発で見る（デルタの発も▲を受けるが、SR で疎）。最小構成。
- 録画 `366`（V-0367。221 と同じ編成）: ココア（311。I）+ デルタ（II）+ ラピ（10。III・操作・AUTO 射撃）。ラピの攻撃力▲（C-0513）を、00.00 の前のラピの発で見る。ココア・デルタは機構が確定。最小構成（`221-21` と同じ）。

**読み方の前提**

- I・II の段の表示は、右のバースト欄の六角形が替わった最初のフレーム。III は III のタイマーが 00.00 になったフレーム（入りの止まりの始まり）。
- 動画は 60fps、ゲームは 1f = 0.017 秒なので、同じ事象でも動画のフレームで 1f ほど揺れる（V-0370 のリターでも、▲の乗った最初の発が替わり目の 2f 前の回と、▲の無い最後の発が 2f 前の回がある）。

## 予測（撮る前に書く）

読む前に書いた（2026-10-10。手計算。予測ファイルは無い。3 本とも、付き始めの前後のフレームの値はまだ見ていない）。比べるのは、各回の段の表示から数えた、▲の無い最後の発（lastAbsent）と▲の乗った最初の発（firstPresent）の動画のフレーム。

| 仮説                                           | 段の表示の 6〜3f 前の発 | 2f 前の発 | 1f 前の発 | 表示の後の最初の発 |
| ---------------------------------------------- | ----------------------- | --------- | --------- | ------------------ |
| HD: 表示の 1f 前（多くのキャラの形）           | ▲なし                   | どちらも  | ▲あり     | ▲あり              |
| HA: 本当の発動の頃（クラウン・雪子の形）       | ▲あり（5f 前から）      | ▲あり     | ▲あり     | ▲あり              |
| HM: 表示の後（ミランダの録画 318 の形）        | ▲なし                   | ▲なし     | ▲なし     | ▲あり              |
| H0: いまのモデル（本当の発動。I・II は 6f 前） | ▲あり                   | ▲あり     | ▲あり     | ▲あり              |

- 予想:
  - `113`（クルミ）: **HD**（`100-10` と同じキャラの再現）。
  - `244`（ミランダ）: **HM**（C-0450 と同じキャラの再現。キャラごとに違うなら HM、1 つの形なら HD）。
  - `366`（ラピ）: **HD**（`221-21` では見分けられなかった。HA なら 00.00 の 5〜3f 前の発に▲がある）。
- 判定: 各回で、lastAbsent ≤ −2 かつ firstPresent ≥ −2（表示の 3f 以上前の発に▲が無く、1f 前より後の発に▲がある）なら HD と合う。lastAbsent ≥ −1 の回があれば HM 寄り、firstPresent ≤ −3 の回があれば HA（H0）寄り。発が無く挟めない側は数えない。
- 外れたときの影響:
  - 3 本とも予想どおりなら、付き始めはキャラごとに違い、多くは HD（リター・クルミ・エマ：TU・ルドミラ：WO・ラピ）、ミランダは HM、クラウン・雪子は HA。モデルの既定（本当の発動）を HD に替え、クラウン・雪子（とヘルム（宝物版）。C-0167）を表の行にする案を出す。
  - ミランダが HD なら、録画 318 の 3 回は揺れの範囲とみて、HA 以外は HD の 1 つの形とする。
  - ラピが HA なら、III のキャラは雪子と同じ形が多いことになり、HD は I・II だけの形かを別に確かめる。

## 読み方

1. 段の表示のフレームを読む。I・II は右のバースト欄を 1 フレームずつ切り出して並べ（ffmpeg の select=between(n,…)・crop=200:60:1720:410・tile。V-0311・V-0370 と同じ）、六角形が替わった最初のフレーム。III はタイマーが 00.00 になったフレーム（`221-01` と同じ読み方）。
2. HUD の増分（`hud-jumps` のキャッシュ。無ければ `npm run records:read -- <録画 id> --recipe hud-jumps --source V-0399` で作る）から、表示の 15f 前〜10f 後の増分を取り出し、操作キャラの 1 発の格子（▲なし・▲あり）に当てる。ミランダは `318-03` の注記の格子、クルミは `100-10` の注記の格子、ラピは `221-21` の注記の格子。
3. 回ごとに lastAbsent・firstPresent を観測値（記録。`100-10` と同じ形）にする。

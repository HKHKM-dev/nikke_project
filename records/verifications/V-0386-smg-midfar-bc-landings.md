## 予測（撮る前に書く）

足元を読む前に `npm run records:predict -- V-0386` を回し、予測ファイル（`records/predictions/V-0386.json`）を commit した。値は予測ファイルを指す。

- 指標は `bulletHitRate`（4 区間目の中のフレーム。着地点を B・C に固定）。予測ファイルの `midfar-b`・`midfar-c`。
- 仮説:
  - **H0**: 着地点 B と C で弾丸命中率は同じ（d = 0）。予測ファイルでは今の表の帯の値（0.921）。
  - **H1**: B と C で違う。B 0.9564、C 0.9078（V-0373 の 12 本）。d = 0.0486。予測ファイルでは H1-B（`midfar-b` だけで比べる）・H1-C（`midfar-c` だけで比べる）に分ける（V-0328 の H2-farA・H2-farB と同じ書き方）。
- **判定の指標**: d = p̄_B − p̄_C。p̄_B・p̄_C は、判定に使う 34 本を足元で B・C に分け、録画ごとの 4 区間目の完全なマガジンの弾丸命中率を平均した値。
- σ:
  - σ_B = max(0.0098 ÷ √k_B, √(0.9564 × 0.0436 ÷ n_B))、σ_C = max(0.0127 ÷ √k_C, √(0.9078 × 0.0922 ÷ n_C))。0.0098・0.0127 は V-0373 の B・C の録画ごとの標準偏差、k は録画の数、n は撃った数の合計。
  - σ_d = √(σ_B² + σ_C²)。
- **判定の目安**（読む前に固定する。V-0328 の主な指標と同じ形）:
  - **B と C で違う（H1）**: |d − 0.0486| < 2σ_d かつ |d| ≥ 3σ_d。
  - **同じ（H0）**: |d| < 2σ_d かつ |d − 0.0486| ≥ 3σ_d。
  - どちらでもなければ**判定なし**。
  - 参考（判定に使わない）: p̄_B・p̄_C の H1 の値との差（σ_B・σ_C で）。V-0215 の 8 本の d。
- 見込み（配分 0.3 : 0.4 で B 15 本・C 19 本、1 本 360 発のとき）: σ_B 0.0028、σ_C 0.0035、σ_d 0.0045。H1 の d は σ_d の約 11 倍で、H0 とは見分けがつく。
- 外れたときの影響:
  - **H1**: 「中遠の B と C で SMG の弾丸命中率が違う」結論を作り、表の SMG の中遠を `midFarB`・`midFarC` に分ける案をオーナーに諮る。表に入れる値と結論の等級は結果を見て諮る（着地点ごとの値は参考の確かめにとどまるため）。H1 の値なら中遠の区間の期待値は +0.0053（3 分全体で約 +0.12%）。
  - **H0**: B・C は分けない。B・C の値（表 0.921 と、ここまでの B・C を合わせた値の違い）は残り、新しく撮る問いになる。
  - **判定なし**: 表を変えず、d の位置と、更新の前後で分けた比べを書いて、次の手をオーナーに諮る。
  - どの場合も、読んだ B・C の数を中遠の配分（C-0044 の 0.3 : 0.3 : 0.4）と比べて書く（配分を見直すかは諮る）。

## 分かったこと・分からないこと

- 中遠の着地点 B（足元 571 前後）と C（561 前後）で、SMG の弾丸命中率が違う。仮説を立てた V-0373（ゲームの更新の後）と、区別を読んでいなかった V-0200・V-0328（ほとんど更新の前）で、差の向きと大きさが揃う。B は表の帯の値 0.921 よりはっきり高く、C は表の値に近い。
- 録画の組によって B・C を合わせた値が違っていた（V-0200 のリターの 18 本 5,908 / 6,360 = 0.9289・V-0328 の 16 本 0.9413）のは、組ごとに B と C の本数の割合が違ったため（V-0200 は C が 2/3、V-0328 は B が 2/3）と説明できる。
- 中遠の配分（C-0044 の 0.3 : 0.3 : 0.4。10 本）と比べると、止め方が A の数に依らない V-0200（チャイムの 098 を除く 24 本）・V-0215（16 本）・V-0328（20 本）の 60 本で A 18・B 19・C 23（0.30 : 0.32 : 0.38）で、配分と合う（V-0373 は A の数で止めたので数えない）。
- オートバースト ON の V-0215 の 8 本は判定なしで、C が高め（234・238 が 0.958）。B が 2 本しかなく、バーストの効果の窓のマガジンも入っている。
- 分からないこと: 着地点ごとの値そのものの確かめ。この検証の 34 本は、録画ごとの値と B・C を合わせた平均を見た後なので、p̄_B・p̄_C は参考にとどまる（「条件」の注意）。
- 計算への効き（中遠の区間の期待値の変わり方と、区間の時間で重みを付けた 3 分全体の当たった数の変わり方。いまの表との差）:

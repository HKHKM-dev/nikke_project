# V-0273: イサベルの S2 のヒットはバーストゲージを溜めるか（探索）

- 問い: イサベルの S2（約 15 秒ごと。C-0402）のヒットは、スキルのダメージのヒット（C-0085・C-0104・C-0105）と同じく射手の target_burst_energy_pershot（4,000）のゲージを溜めるか。HUD の増分が S2 だけのフレームで BURST バーが伸びるかを見る
- 話題: バーストゲージ
- 日付: 2026-10-07
- 録画: `038`、`162`、`163`、`165`
- 結論: `C-0404`
- 状態: 完了

## 条件

- V-0269「分からないこと」（S2 のヒットがゲージを溜めるか）。スキルのダメージのヒットは、射手の `target_burst_energy_pershot` を 1 回溜める（C-0085・C-0104・C-0105。確定）。イサベルは 4,000（バー 113px の約 0.5px）。
- 録画: S2 を読んだ 038・162・165（V-0269・V-0270）と、イサベル入りでまだ読んでいなかった 163（デルタ + アニス：スター + I-DOLL・フラワー + イサベル）。
- 結論: `C-0404`
- 見方: HUD の増分が S2 の値だけのフレーム（そのフレームにほかのダメージが無い）で、BURST バーが伸びるか。ゲージはヒットのフレームに溜まる（C-0083）ので、ほかの発の無いフレームで伸びれば S2 の分。

## 予測（撮る前に書く）

探索（予測ファイルは無い）。量が px の刻み（約 0.9%）より小さいので、溜めるなら「伸びる回と伸びない回が混ざる」、溜めないなら「伸びる回はほとんど無い」と見込んで読んだ。

## 読み方

- 163 の S2 のフレームは、V-0269 と同じく HUD の増分を S2 の値に突き合わせて特定した（`163-16`）。
- 各録画の S2 のフレームの前後 3 フレームを `node tools/captures/gauge.ts <録画> --mode series` で読み、バーが読めて 0 でも 100% でもない回だけを並べた（`162-35`・`165-37`・`038-31`・`163-17`）。

## 結果

- 並べられたのは 8 回。5 回（162 の f2339・3223・4130、165 の f4066、038 の f1835）で、直前まで平らだったバーが S2 のフレームでちょうど 1px（+0.8〜0.9%）伸びた。3 回（165 の f3158、038 の f4509、163 の f8400）は伸びなかった。
- ほかの 18 回は、バーが 0（フルバーストの後の CT の間）・読めない・100%・下がっている途中で使えなかった。
- 前後のフレームのバーはほとんど平らで、S2 のフレームにだけ 1px の伸びが重なる偶然は起きにくい。伸びない回があるのは、量が 1px より小さく、px の刻みをまたがない回があるためとみた（4,000 なら約 0.5px）。

## 分かったこと・分からないこと

- 分かったこと（C-0404、仮説・推論）: イサベルの S2 のヒットはゲージを溜める。量は 1px 未満で、スキルのダメージのヒットと同じ 4,000 の形と矛盾しない。
- 分からないこと: 量（4,000 か、ほかの値か）。px より細かい読みが要る（同じ px の中の位置が分かる録画か、S2 の回の前後の満タンのタイミングから逆算する）。ラピの S2（C-0403）が溜めるかは読んでいない（073 は単騎でバーが読めるので、同じ読み方で見られる）。

# V-0057: 武器の CDN の秒（リロード・チャージ）は 1 秒 = 58.82f で進むか（V-0011 の見直し）

- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-09-30
- Stage: 武器の秒の換算（plan/design-weapon-seconds.md）
- 録画: `001`〜`010`、`012`、`014`、`016`、`017`、`023`、`024`、`026`、`028`、`029`、`031`〜`034`、`036`、`045`、`046`、`054`〜`062`、`070`〜`077`、`082`、`086`〜`090`、`092`、`L-AD`、`L-AI`、`L-AN`
- 結論: `C-0140`、`C-0141`、`C-0142`

- 派生元: `V-0055`

## 条件

- 設計は design-weapon-seconds.md。仮説は W0・W0'（60f で、足す長さが武器種ごとに違う）・W1（丸めは切り上げ W1c・切り捨て W1f・丸めない W1x）と、旧の録画の差についての H-old（2 節・6 節）。判定の基準は 4 節（design-stage21.md 8.4 節の延長）。
- **段 A（撮影なし）**: 上の録画は、どれも操作キャラの RELOADING のバーが写る単騎（紅蓮BS は 7 節の較正の読み直しにだけ使う）。武器種・リロードの秒ごとの割り当ては設計書 5.1 節。旧の録画（`L-AD`・`L-AI`・`L-AN`）は、時計の速さ（H-old）と世代の中の傾きにだけ使う。

## 予測（撮る前に書く）

読み直しの前（2026-09-30）に書いた。W1 の値は切り上げ（W1c）と丸めない（W1x）の両方を書く。

**A-1 リロードの主判定（武器種ごとに切片を持たせた傾き）**

| 仮説 | 傾き  | 武器種ごとの切片（C-0135 の c） |
| ---- | ----- | ------------------------------- |
| W0   | 60    | そろう（武器種によらない）      |
| W0'  | 60    | 武器種ごとに違う                |
| W1   | 58.82 | そろう（今の世代で約 11〜12f）  |

- 武器種の中の 1 組だけでは差が小さい（W0 / W1x / W1c）: AR 1 → 1.67 秒 40.2 / 39.4 / 40（切り上げ 41 / 40）、SMG 1 → 1.5 秒 30 / 29.4 / 30、SR 1.5 → 2 秒 30 / 29.4 / 29、SG 1.5 → 1.86 秒 21.6 / 21.2 / 21（切り上げ 22 / 21）、MG 2.3 → 2.5 秒 12 / 11.8 / 12。どれも 1f 未満で、1 組では見分けられない。まとめた傾きだけが見分けに使える。
- 今の 4 点の試算（条件の (1)）どおりなら、傾きは 58.8〜59.1 の間に出て、W1 が合い W0 は外れる。そのとき W0' を外せるかは、武器種ごとに切片を持たせても傾きが 60 から離れるか（W0' なら 60 に戻る）で決まる。

**A-2 足す長さ c が武器種によらないか（秒が 2 の SR・RL）**

- W0・W1 とも、SR（ラム・ヘルム・アリス）と RL（フラワー・ベロータ）の最終弾 → 完了は ±1f でそろう。そろわなければ W0' の形（武器種ごとの足す長さ）がありうることになり、武器種をまたいだ比較（段 B の別案）は使わない。W0 と W1 はこの値では見分けられない。

**A-3 チャージの主判定（チャージの長さ = 表示の幅 ÷ 1 フレームの伸び）**

| 武器（チャージ）                 | W0   | W1x   | 1 フレームの伸びの例（W0 / W1x）  |
| -------------------------------- | ---- | ----- | --------------------------------- |
| ラム・デルタ・ヘルム（1 秒）     | 60.0 | 58.82 | ラム（100 → 250%）: 2.50 / 2.55 % |
| ベロータ（1.5 秒）               | 90.0 | 88.24 | —                                 |
| 紅蓮BS（0.3 秒。見分けられない） | 18.0 | 17.65 | 100 → 150%: 2.78 / 2.83 %         |

- `075-05` の注記（1 フレーム約 2.6%）は W1 寄りだが、概算の値なので判定に使わない。
- 表示が秒に比例して伸びない（始まりか終わりで止まる）なら、チャージの長さはこの読み方では出せない。そのときは、伸びの一定な区間だけで伸びを出し、全長は表示が 100% を出たフレームと満ちたフレームの差（整数）で補う。

**A-4 補助**

- 分割リロードの段の長さ（段ごとの足す長さが無いとき）: ソーダ：TB・プロダクト23（0.67 秒）は W0 40.2 / W1x 39.4、ノワール（0.23 秒）は 13.8 / 13.5。
- チャージ武器のリロードの分（最終弾 → 次の 1 発目 − 発と発の間）: リロード 2 秒で W0 120 / W1c 118、1.5 秒で 90 / 89。1f 未満の足す長さを含みうる。
- 旧の録画の世代の中の傾き: 条件の (1) の 59.29 から大きく動かない見込み（読み直すのは時計の速さだけ）。

**A-5 旧の録画の時計の速さ（H-old）**

- 旧の録画も 1 秒あたり約 58.82f なら、今との 1〜1.5f の差は時計ではない（ゲームの更新・キャラの違いが残る）。
- 旧の録画の 1 秒あたりのフレームが多く、その値 × リロードの秒を引いた残りが今の c と ±0.5f でそろえば、H-old（旧の録画は時計の進みが違い、リロードはどちらの世代でもゲーム内の時計で進む）。そろうのに要る速さは、AR・SMG・MG の 3 点で 1 秒あたり約 59.5〜60f。

## 読み方

1. **バー**: 設計書 8 節の `tools/captures/reload.ts`（作るまでは V-0046 の読み方と同じ使い捨てのスクリプト）で、各録画のバーの区間を全部拾う。的のジャンプの窓をまたぐ回（取り消し・満ちきらない回）は除く。まず 073・054・072・075 で `073-04`〜`075-09` の値が再現できることを確かめる。
2. **最終弾**: `hud.ts --mode jumps` の、バーの区間の前の最後の増分。バーの伸びを遡った 0 の点から 3f 以上離れた回は、増分の読み違いとして 1 フレームずつ切り出して画面の残弾で確かめる（V-0055 と同じ）。操作の録画（001〜036）は、照準の横の残弾が 000 になってからのリロードだけを使う（手でリロードした回を除く）。
3. **平均と SE**: 録画ごとに、最終弾 → 完了の平均・標準偏差・回数（10 回以上）を出す。バーの伸びから出したバーの長さも同じように出す。
4. **当てはめ**: 今の世代の点に、傾きが共通で切片が武器種ごとに違う直線を、点ごとの SE の重みで当てはめる。秒をそのまま使ったもの（W1x）と、仮説の丸めでフレームにしたもの（W0・W1c）の両方で判定する（設計書 4 節）。
5. **c の武器種の違い**: 秒が 2 の SR・RL の平均を並べる（A-2）。
6. **チャージ**: 照準の横のチャージの表示を `still.ts` で切り出し、1 回のチャージの 100% を出た直後と満ちる直前の 2 フレームの % を目で読む。伸び = % の差 ÷ フレームの差、チャージの長さ = 表示の幅（フルチャージの % − 100%）÷ 伸び。1 本につき 10 回以上。アリス（`089`）はチャージ速度▲が付いていない発だけ。
7. **旧の録画の時計**: `timer.ts --mode summary` で `L-AD`・`L-AI`・`L-AN` の残り時間 1 秒あたりのフレーム数を出す（C-0048 と同じ読み方）。録画のフレームの刻み（`probe.ts`）も確かめる。
8. **紅蓮BS**: `046`・`055` の発と発の間・最終弾 → 完了 → 次の 1 発目を観測値にする（設計書 7 節の 4。C-0014 の根拠は凍結した記録なので）。判定には使わない。
9. 読んだ値は観測値にする（`source` に `V-0057`）。録画ごとの最終弾 → 完了の各回とバーの長さ、チャージの伸び、旧の録画の時計の速さ。

- バーの読み取りは `tools/captures/reload.ts` にした（設計書 8 節）。

- バーは y 525〜533、x 776 から伸び、溝（x 776〜1142 の 367px）が満ちたフレームで消える。見えた最大の長さ（約 363px）は溝より短い。
- RL（`002`・`006`・`032`・`033`・`077`）は、弾が届くまで総ダメージの増分が遅れ、最終弾を増分から取れなかった。そこで、どの録画でもバーだけで出せる「完了 − バーの伸びを 0 に遡った点」（以下「バーの値」）も出した。

### リロードの主判定（A-1）

今の世代の点に、傾きが共通で切片が武器種ごとに違う直線を当てはめた。点ごとの SE は、各回の標準偏差（0.5f を下限）÷ √回数。

| 値（点の数）              | 傾き（f/秒） | SE   | W1 からの距離 | W0 からの距離 | 各点の残差の最大（W1x / W0） |
| ------------------------- | ------------ | ---- | ------------- | ------------- | ---------------------------- |
| 増分の値（34）            | 57.55        | 0.35 | −3.6SE        | −7.0SE        | 0.72 / 1.26                  |
| 同、モダニアを除く（32）  | 58.10        | 0.33 | −2.2SE        | −5.8SE        | —                            |
| バーの値（39。RL を含む） | 58.59        | 0.31 | −0.8SE        | −4.6SE        | 0.55 / 1.01                  |

- 増分の値では、傾きがどちらの仮説の ±2SE にも入らない。武器種の中の秒の幅が小さく（MG は 0.2 秒）、キャラごとの増分の遅れ（上の 0.6f など）が、そのまま傾きに入る。
- バーの値では W1 が合い、W0 は外れる。各点の残差も W1x は全部 ±0.55f に入り、W0 は 1 点（`023`）が 1.01f で外れる（`024` が 0.99f・`005` が 0.92f）。ただし SE が 0.31 で、基準（SE ≤ 0.3）に届かない。
- 丸めは、W1x（丸めない）のほうが W1c（切り上げ）より当てはまりがよい（バーの値で χ² 14.5 と 24.5）。

### 足す長さ c が武器種によらないか（A-2）

- 秒が 2 の SR（`075`・`076`・`082`・`088`・`089`）と RL（`002`・`006`・`032`・`033`・`077`）のバーの値は、0.4f の幅にそろう。RL のほうが約 0.2f 長い。
- SR と RL の足す長さは、武器種によらないとみてよい。

### チャージ（A-3）

- ラム（1 秒）: 3 回のチャージの 32 フレームの表示が、「100 + 伸び × 経過フレーム」の切り捨てで、伸びが 1 フレーム 2.542〜2.554% のときだけすべて合う。チャージの長さは 58.74〜59.01f（`075-12`）。W1 の 58.82f は入り、W0 の 60f は 1f 外れる。
- ベロータ（1.5 秒）: 2 回とも、6 フレームごとにちょうど 17% ずつ伸びた。チャージの長さは 87.8〜88.6f（`006-03`）。W1 の 88.24f は入り、W0 の 90f は 1.4f 外れる。
- 足す長さの入らない値で、1 秒と 1.5 秒の両方が W1 に合い、W0 は合わない（設計書 4 節の 3）→ **チャージは W1**（C-0140）。

### 補助（A-4・A-5）

- **分割リロードの段の長さ**: どの点も、W1x の予測との差は 0.07f 以内（数の少ない `009` だけ 0.28f）。W0 の予測とは 0.3〜0.8f 違う（`074-07`・`036-02`・`092-04` ほか）。3 つの秒の平均に当てはめると、傾き 59.03 ± 0.11 f/秒・切片 −0.07f（W1 から 1.9SE、W0 から 8.8SE）→ C-0142。
- **旧の録画の時計（H-old）**: 残り時間の 1 秒は動画の 59.21〜59.34f で、今の 58.82f と違う（`L-AD-08`・`L-AI-05`・`L-AN-06`）→ C-0141。
  - この速さでリロードを数えると、旧の残りは 11.5〜12.0f になり、今の 11.0〜12.0f（増分の値の武器種ごとの切片）と 0.5f 前後でそろう。
  - 旧の世代の中の傾き（条件の (1) の 59.29）も、旧の時計の速さと同じ。
- チャージ武器のリロードの分: 判定に足すものが無いので読み直していない（条件の (2) と V-0011 のまま）。

### 判定（設計書 4 節）

- **チャージ: W1**（C-0140）。
- **リロード: 段 A では決まらない**（W0 のまま）。
  - 主判定のうち、増分の値ではどちらの仮説も合わず、バーの値では W1 だけが合うが、SE が基準に届かない。
  - 補助（段の長さ・旧の時計）はどれも W1 を指し、主判定のバーの値とも食い違わない。
  - 増分の値とは食い違うので、4 節の 4 のとおり採らずにオーナーに相談する。続きは V-0058（段 B の撮影か、今の結果で採るか）。

## 分かったこと・分からないこと

- チャージは、ゲーム内の時計で進む（C-0140）。表示は一定の速さで伸び、足す長さは無い。モデルの 1 秒 = 60f のチャージは、1 秒あたり約 1.2f 長い。反映は Stage 23（設計書 10 節）。
- 分割リロードの段の長さも、ゲーム内の時計で進む（C-0142）。リロードの秒の換算の強い手がかりだが、設計書の判定では補助で、全弾リロードの主判定は決まらなかった（V-0058）。
- 旧の録画は、ゲーム内の時計の速さが今と違う（C-0141）。C-0135 の今と旧の差の多くは、この違いで説明がつく。
- 最終弾の増分の表示の遅れは、キャラで 0〜1.3f 違う。リロードの長さを 1f より細かく比べるときは、増分よりバーの伸びを遡った点を使う。
- 分からないこと: 旧の録画で時計の速さが違う理由（録画の設定か、ゲームの更新か）。増分の値の傾きが 57.5 と小さく出た理由（キャラごとの増分の遅れの違いとみているが、確かめていない）。紅蓮BS（0.3 秒）とヘルム・デルタのチャージの表示。

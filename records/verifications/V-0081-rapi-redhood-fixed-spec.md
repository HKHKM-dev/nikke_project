# V-0081: ラピ：レッドフードのスペック固定の攻撃力（好感度の上限）

- 問い: ラピ：レッドフード（16）のスペック固定の攻撃力が、モデル（119,896）でなくモダニアと同じ 120,694 に見える（116-06）のはなぜか。スペック固定の好感度の上限（いままではピルグリム所属の SSR だけ rank40）は、何で決まるか
- 話題: 育成・ステータス

- 状態: 完了

## 条件

- 撮影なし。V-0074 の対照の録画 116 で読んだ 1 ヒット（`116-06`。ラピ：レッドフードだけが当たったフレームの増分）と、CDN のデータ（roledata・`AttractiveLevelTable`）から考える。
- スペック固定の攻撃力の式（Lv400・限界突破とコアはレア度上限・好感度・T9 Lv5 装備。コア強化は「突破後の素の攻撃力 + 好感度」に掛かる）は plan/verification.md「Stage 2-A › スペック固定の仕様」（凍結）。好感度の上限は、そこで「ピルグリム所属のみ rank40」とした（非ピルグリムの SSR 2 体・ピルグリムのイサベルで確かめた）。
- ラピ：レッドフードの CDN の `corporation` は `ELYSION`（ピルグリムでない）。

## 予測（撮る前に書く）

探索（撮影なし。既存の観測値の読み直し）。録画 116 は V-0074 のために撮ったもので、この問いの予測は撮る前に書いていない。

- 仮説 A（いまのモデル。ピルグリムだけ rank40）: ラピ：レッドフードは rank30 で 119,896。1 ヒット（胴体）は 5.57% × (119,896 − 100) ≒ 6,673。
- 仮説 B（ラピ：レッドフードも rank40）: 120,694 で 6,717。rank30 と rank40 の差は好感度の加算の差 700（Attacker）× コア強化 1.14 = 798 で、120,694 − 119,896 = 798 とちょうど同じ。
- B なら、rank40 になる条件を CDN のデータから探す。ピルグリム全員と、ラピ：レッドフードに共通で、rank30 と確かめたキャラ（エマ・フォルクヴァンなど）に無い印があるはず。

## 読み方

1. `116-06` を照合（`hitDamage`、slot 1・frame 0・胴体・非会心・距離ボーナスなし）にして、`npm run records:check` で仮説 A と B のモデルの値と比べる。
2. CDN の roledata を全キャラ（202 体）取り、ピルグリムとラピ：レッドフードに共通の欄を探す。

## 分かったこと・分からないこと

- ラピ：レッドフードのスペック固定の好感度は rank40（C-0166。録画 116 の 1 本なので仮説・単独実測）。モデルの好感度の上限を、所属（`corporation`）ではなく CDN の `corporation_sub_type` が `OVERSPEC` かで決めるようにした（`fixedSpec.ts` の `fixedSpecAffectionRank`。キャラのデータに `corporationSubType` を足した）。ピルグリム 23 体の値は変わらない。
- ピルグリムでない残りの OVERSPEC 3 体が rank40 かは、データの印からの推し量りで、実測は無い。

# V-0521: エレグのバースト（バーストスキルダメージとブームインストールの防御力▼）

- 問い: エレグのバーストの、照準線に最も近い敵へのバーストスキルダメージ（最終攻撃力の説明文の値）と、同じ敵へのブームインストール（防御力▼・10 秒）を、burstDamage と敵に付く状態の付与（中身は enemyDefenseDown）と読んで、ヒットの値・フレーム、同じ発動の▼がヒットに乗るか、▼の付き始めと切れ目は実測と合うか
- 話題: スキル・キャラ固有
- 日付: 2026-10-26
- Stage: plan/design-elegg.md 8 節（段 2）
- 録画: `0690`、`0691`
- 結論: `C-0689`、`C-0690`
- 状態: 完了

## 条件

- 型: 撮る。
- 結論の対象: `data/skills/500.json` の burst に足す効果（`burstDamage`・`ref: 3`・`skill` と、状態 `boomInstall` の付与（敵。中身は `enemyDefenseDown`・`ref: 4`・`durationRef: 5`）。plan/design-elegg.md 8.1・8.2 節）。撮る前の定義では未対応の notes。
- 見たいこと（plan/design-elegg.md 8.3 節の B1〜B5）: バーストスキルダメージの値（B1）、ヒットのフレーム（B2）、同じ発動の防御力▼がそのヒットに乗るか（B3）、▼の付き始め（B4）と切れ目（B5）。
- 編成 C: 鈴原サクラ（1 枠目・AI）・I-DOLL・サン（2 枠目・AI）・◎エレグ（3 枠目・操作・撃たない）。オートバースト ON。
  - II はエレグだけ（I・III は CT 40 秒、エレグは CT 20 秒なので、II は毎回エレグ）。エレグの S2 のゲージ（C-0662）で 1 回目のチェーンは戦闘開始から約 1.5 秒で始まる。
  - 3 枠目にキャラがいると戦闘開始の操作枠は 3 枠目になるので、撃たないエレグを 3 枠目に置く。枠は空けない（モデルの編成は枠を詰めて並べる。plan/design-elegg.md 8.4 節）。
- 最小構成:
  - 鈴原サクラ・I-DOLL・サンは、機構が確定したキャラ（V-0504 と同じ）。I-DOLL・サンのバースト（最大装弾数▲）は 1 ヒットの値を変えない。鈴原サクラの S1 の受けるダメージ▲（確定）は値に効くが、モデルにある。
  - エレグは撃たないので、S1・S2 の前半（ブームインストール中の命中の回数のトリガー。段 3）は起きない。最小構成の検査がこれらの未対応の notes を出したら、効かない理由を結論の `minimal` に印として書く（plan/design-elegg.md 8.5 節）。
  - 分配ダメージ▲（同じバーストの 3 行目）は、この編成に分配ダメージが無いので効かない（V-0522 で見る）。
  - モデルには撃たない枠が無いので、モデルではエレグも撃つ。エレグの弾が効くのはゲージだけで、比べるのは 1 回目のチェーンの値と、発動から数える量（ヒットの遅れ）にする。2 回目以降のバーストのヒットの値は記録にとどめる（鈴原サクラの▲の窓との重なりがモデルと違いうる）。
- 撮る条件: 射撃場・BigArms・灼熱のタブ・3 分モード・スペック固定 ON・オート射撃 OFF（操作枠のエレグは撃たない）・オートバースト ON。反復実測のため 2 本。

## 読み方

1. 取り込む（`--rid 836,308,500 --controlled 3 --auto-fire off --auto-burst on --target BigArms --element Fire --mode range-3min --fixed-spec on`）。一時停止 / 戦闘履歴のパネルで枠順を確かめる。
2. `burst-panel` のレシピで、毎回の I → II・II → III の替わり目と III のタイマーの 00.00 を読み、II が毎回エレグか（右のバースト欄のアイコン）を見る。
3. 総ダメージの増分（`tools/captures/hud.ts --mode jumps`）から、エレグのバーストスキルダメージのヒット（ほかの 1 ヒットより桁が大きい）の値とフレームを読む。会心かは値で分ける。
4. 1 回目のチェーンの II の替わり目の前後と、▼の窓の終わりの見込み（W0）の前後で、総ダメージの増分を I-DOLL・サン・鈴原サクラの 1 ヒットに値で分ける（種類 × ▼の有無 × 鈴原サクラの▲の有無の組。同じフレームに 2 人のヒットが重なった増分と、どの組にも合わない増分は使わない）。▼ありの最後と▼なしの最初のヒットのフレームを取る（V-0433 の `0305-10` と同じ形）。
5. 観測値: `burstHitDamage`（n 0）、`burstHitDelays`（count 3）、`burstActivationVideoFrames`（n 3）を予測ファイルの指標と同じ指定で書き、▼の付き始めと切れ目は `interval` の記録（`use: record`）にする。

## 分かったこと・分からないこと

観測値は `0690-06`〜`0690-13`・`0691-06`〜`0691-12`（ヒットの値・遅れ・▼の前後の 1 ヒット・戦闘履歴）。モデルへの入れ方は plan/design-elegg.md 8.9 節の論点 6（案 A。2026-10-26 にオーナーが承認）。下は読んだ値（動画のフレーム）。

- 枠順は戦闘履歴のパネルで確かめた（鈴原サクラ・I-DOLL・サン・エレグ）。エレグの与ダメージはバーストの分だけで、撃っていない。II はどの回もエレグ。
- 戦闘開始（残り時間の 02:59 が出たフレーム。`timer.ts --mode changes`。V-0504 と同じ読み方）は 0690 が f869、0691 が f918。1 回目のチェーンの I → II・II → III の替わり目と III の 00.00 は、戦闘開始から 0690 が 29・59・88f、0691 が 29・58・87f で、予測 [30, 59, 88] と許容（±3）の中。
- **B2（ヒットのフレーム）**: エレグのバーストスキルダメージは、どの回も II の六角形の替わり目（II の発動の印）から 51f 後に、総ダメージに足される（0690 の 1〜3 回目、0691 の 1〜3 回目の 6 回とも 51f）。III の 00.00 の 22f 後で、フルバーストの入りの止まり（画面を覆う帯）が明けるフレームにあたる。Hb（−6f。本当の発動）・Ha（+1f）のどちらとも違う。HUD の値は帯の下で薄く、`hud.ts` は読めないので、`ffmpeg` で切り出した画を目で読んだ。
- **B1・B3（ヒットの値）**: 帯の下の HUD の増分は、エレグのヒットとほかの 1 ヒットの和だった。和からほかの 1 ヒット（前後の発で同じ値が繰り返す種類）を引くと、エレグのヒットは 316,106 で、Hb の会心なしの値 316,105.845 と端数まで合う（Ha は 316,218.703 で 113 違う）。
  - 0690 の 1 回目: f958 までの 588,469 → f979 の 935,227（+346,758 = 316,106 + I-DOLL・サンの 30,652）。
  - 0690 の 3 回目: f5710 までの 31,948,382 → f5734 の 32,275,065（+326,683 = 316,106 + 鈴原サクラの 10,577）。
  - 0691 の 1 回目: 562,831 → 909,589（+346,758。0690 の 1 回目と同じ組）。909,589 は帯の下で下 3 桁が読みにくく、次の値 925,807 から鈴原サクラの 16,218 を引いて決めた。
  - 2 回目は鈴原サクラの受けるダメージ▲の窓の中で、ほかの 1 ヒットの組が決まらなかった（記録にとどめる）。
  - バーストスキルダメージにはフルバーストの補正が乗らない（`BURST_SKILL_FULL_BURST_BONUS`）ので、ヒットがフルバーストの入りの後でも値は Hb と同じ。
- **B4（▼の付き始め）**: II の発動からエレグのヒットまでの間の 1 ヒットは、どれも▼なしの値（0690 の 1 回目: I-DOLL・サンの 22,126・27,113・32,099 は発動の前と同じ値、3 回目: 鈴原サクラの胴体 7,048（▼ありなら 7,051））。エレグのヒットの後の最初の発（0690 の f985 の鈴原サクラ 12,692）から▼ありの値になる。**▼は発動ではなく、エレグのヒットから付く**。W0（発動の次のフレームから）は外れ。
- **B5（▼の切れ目）**: 0690 の 1 回目は、鈴原サクラの 12,692（フルバースト・▼あり。▼なしなら 12,686）が f1564 まで続き、f1569 の 9,162（フルバーストなし・▼なし。▼ありなら 9,166）で切れている。フルバーストの終わり（f1564〜f1566 の間）と同じ頃で、W1（ヒットから 588f。モデルではフルバーストの終わりとほぼ同じ）と矛盾しない。W0 なら切れ目はフルバーストの終わりの約 34f 前で、その間の鈴原サクラは 12,686 になるはずが、12,692 だった。▼の切れ目とフルバーストの終わりの前後は、この編成では見分けられない。
- 分からないこと: 帯の下でヒットが足されるのが、止まりの最後のフレームか明けた最初のフレームか（モデルのフレームで 1f の差）。

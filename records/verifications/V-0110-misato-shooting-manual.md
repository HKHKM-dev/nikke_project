# V-0110: ミサト S1（射撃マニュアル）の命中率▲は、AUTO のミサトのコア命中率を C-0036 の式で上げるか

- 問い: ミサト単騎の AUTO で、S1 の自分への命中率▲（60 発ごとに 5.04%・3 スタック・5 秒）が 3 スタックのとき、コア命中率は対照の SMG（命中率▲なし）の 1 ÷ (1 − 0.1512)² 倍（H1）になるか、変わらない（H0）か
- 話題: スキル・キャラ固有
- 日付: 2026-10-03
- Stage: plan/skills-guide.md（キャラのスキル定義。命中率▲を持つキャラの 1 体目）
- 状態: 保留
- 待ち: 撮影（ミサト単騎 2 本・対照のリター単騎 2 本。「次に撮るもの」）

## 条件

**何を確かめるか**

- ミサト（833。SMG・SR・I）のスキルのうち、ダメージに効きうるのは S1 の命中率▲だけ（説明文の分解は下の表）。定義は `packages/core/data/skills/833.json`。語彙は足していない（射撃の回数トリガー・効果のあるスタック・持続の `hitRate` は既存）。
- 解釈は 2 件の結論にした（どちらも仮説・推論）。
  - `C-0179`: S1 は撃った通常攻撃 60 発ごとに自分に 1 スタック（上限 3・5 秒。足すたびに全スタックの維持時間を数え直す）で、スタック数 × 5.04% を N として、コア命中率を C-0036 の式で上げる。
  - `C-0180`: S1 の回復・S2・バーストは、射撃場の的へのダメージに関係しない。
- 持続の命中率▲がコア命中率に効くことは C-0170（仮説。根拠はフルバースト中に配られる▲だけ）でモデルに入っている。V-0103 の続き（V-0109）は、2026-10-03 のオーナーの判断で後回しにした。この記録は、**フルバーストと関係なく、自分のスタックで乗る持続の▲**で、同じ式が合うかを見る。

**説明文の分解**（Lv10。`packages/core/data/characters/833.json`）

| スロット | 説明文                                                                              | 分け方                                                              |
| -------- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| S1       | 通常攻撃で 60 回攻撃した時、自分に「射撃マニュアル：命中率 5.04%▲」3 スタック・5 秒 | 語彙にある（`timed`・回数トリガー `normalShot` 60・`maxStacksRef`） |
| S1       | 通常攻撃で 120 回攻撃した時、HP の割合が最も低い味方 1 機に HP 回復                 | ダメージに関係しない（notes）                                       |
| S2       | 射撃マニュアル状態の間、味方全体に「バリアに与えるダメージ 150%▲」                  | 射撃場の的にはバリアが無いので効かない（notes）                     |
| S2       | 射撃マニュアルのフルスタックの間、自分に「与える HP 回復量 30.05%▲」                | ダメージに関係しない（notes）                                       |
| バースト | 味方全体に持続回復（5 秒）                                                          | ダメージに関係しない（notes）                                       |

- 「通常攻撃で N 回攻撃した時」は、ほかの定義（ドレイク S2）と同じく、撃った発（`normalShot`）で数える。当たった発（`normalHit`）で数える説明文は「命中した時」。
- スタックの維持時間の数え方は `skills/stacks.ts` の `STACK_REFRESH`（'all'。モダニアで仮に決めた形）。ミサトは約 2.5 秒で 60 発撃つ（SMG 1440 rpm。録画 005 の `005-01`・`005-02`）ので、撃ち続ける間は 3 スタックが切れない。どちらの数え方でも、撃ち続ける間の N は同じ。

**最小構成**

- 単騎で撮る。ミサトのほかの効果はダメージに関係しないので、コア命中率に効きうる未確定の要素は S1 の命中率▲だけ。
- **対照**: 命中率▲を持たない SMG の単騎 AUTO。リター（82）にする。射撃場の表の SMG の値（C-0034）の根拠の録画 054 と同じキャラ・同じ条件で、定義があり、単騎ではコアの当たり方に効く効果が無い（S1 はフルバースト開始時、バーストはオートバースト OFF で使わない）。
- 同じ SMG でもキャラでコア命中率が違う、という可能性は残る（H0 の別の形）。これは対照と比べるだけでは分けられないので、ミサトの録画の中で、的のジャンプの後にスタックが積み直る窓（N = 0・5.04%・10.08%）を参考に並べる（下の「予測」）。

**撮る条件**（ミサト・リターとも同じ）

- 射撃場・灼熱タブの BigArms・3 分モード・スペック固定 ON・180 秒。単騎・操作枠で AUTO 射撃 ON・**オートバースト OFF**（録画 054・098 の単騎 AUTO と同じ。ミサトのバーストは回復だけなので、使わない方が未確定の要素が減る）。

## 予測（撮る前に書く）

撮る前に書いた（2026-10-03）。予測ファイル `records/predictions/V-0110.json` は、分解の格子の基準にするミサトの 1 ヒットの値（近の胴体・コア・会心と、距離ボーナスの中の胴体）と、180 秒の総ダメージで、仮説は H1（いまのモデル）だけ。H0 はモデルのコードの切り替えなので、予測ファイルの範囲外で、ここに手で書く（予測ファイルの `note` にもそう書いた）。1 ヒットの値は H0 でも同じ。

**仮説**

- **H1**（C-0179・C-0170。いまのモデル）: 3 スタック（N = 0.1512）の窓で、コア命中率は対照の 1 ÷ (1 − 0.1512)² = **1.388 倍**（どの距離帯でも同じ倍率。上限 1 には届かない）。
- **H0**: S1 の命中率▲はコア命中率を変えない。ミサトのコア命中率は対照と同じ（倍率 1）。

**距離帯ごとのコア命中率**（3 スタックの窓。的の表の SMG の値を対照の見込みに使った）

| 距離帯 | 対照の見込み（表の SMG） | H1    | H0     |
| ------ | ------------------------ | ----- | ------ |
| 近     | 0.2644                   | 0.367 | 0.2644 |
| 中近   | 0.1179                   | 0.164 | 0.1179 |
| 中遠   | 0.0516                   | 0.072 | 0.0516 |
| 遠     | 0.0342                   | 0.047 | 0.0342 |

- 参考（判定には使わない）: 的のジャンプの後にスタックが積み直る窓では、H1 は N = 0 で対照と同じ、5.04% で 1.108 倍、10.08% で 1.237 倍。sim では、近の区間の頭に 1 スタック・2 スタックの窓が約 2.5〜4 秒ずつ入る（スタックが切れるかは、ジャンプの前の最後の発火からの時間で決まるので、録画で読む）。
- 180 秒のミサトの総ダメージは、H1 28,043,846（予測ファイルの misato-total）、H0 27,090,855（定義を外した sim）。差は約 3.5%。的のジャンプの時刻とリロードの位置でも動くので、判定には使わない。
- sim の自動の条件（発数平均）: H1 のコア命中率 0.1906・命中率▲の平均 13.55%、H0 0.1427。リター単騎は 0.1424（録画 054 の実測 0.142。`054-01`）。

**判定の指標**: 倍率 r = （ミサトの 3 スタックの窓のコアの数）÷ Σ（ミサトの 3 スタックの窓の、距離帯ごとの当たった数 × 対照のその距離帯のコア命中率）。4 つの距離帯に共通の倍率を 1 つ出す（verification.md Stage 18-B 撮影 1 と同じ考え方）。対照の距離帯ごとの値は、新しく撮るリターの 2 本と録画 054 の合計。σ は 100f のブロック間の分散から出し（V-0096 と同じ）、録画ごとの r も並べる。

**発数の見込み**: ミサトは 1 本で約 3,240 発・3 スタックの窓に約 2,440 ヒットで、H0 ならコアは約 350（H1 なら約 490）。リターは 1 本で約 400 コア。2 本ずつと 054 で、r の σ はブロックの分散（2 項分布の約 1.4 倍）で約 7%、録画ごとの揺れ（クルミ単騎 AUTO の 3 本で近の値が ±0.04 程度。verification.md Stage 18-B 撮影 1）（録画 1 本あたり約 10%）を足して約 11% とみる。H1 と H0 は約 3.4σ 離れ、判定の目安の 3σ にぎりぎり届く見込み。届かなければ、ミサトとリターを 1 本ずつ足す。

**判定の目安**

- r が 1 から 3σ 以上離れ、1.388 と 2σ の中で合えば **H1**。
- r が 1 と 2σ の中で合い、1.388 から 3σ 以上離れていれば **H0**。
- どちらでもなければ結論にしない。r が 1 と 1.388 の間なら、「効くが式より弱い」か「ミサトの素のコア命中率がリターより低い」かが残るので、積み直る窓（参考）の向きと合わせて次の手を決める。
- 近だけの差（ミサト − 対照）も並べる（H1 で +0.103）。

**検算**

- ミサトの 1 ヒットの値（近の胴体・コア・会心、距離ボーナスの中の胴体）が予測ファイルの値と合う（スペック固定の攻撃力の確かめ。録画 005 の値と同じ見込み）。命中率▲は 1 ヒットの値に効かない。
- 対照のリターの近のコア命中率が、表の SMG の値（0.2644）と σ の中で合うか。合わなければ録画ごとの揺れとして書き、表は直さない。
- 総ダメージの増分が、ミサトの通常攻撃の格子（コア・会心・距離ボーナス）だけで説明できる（S1 の回復・S2・バーストがダメージを出さない。C-0180）。

**外れたときの影響**

- H1 なら、C-0179 を確定にできる候補になり、C-0170 の式（持続の▲も同じ式）の、フルバーストと関係ない形の根拠にもなる（C-0170 を確定にするかはオーナーが決める。backlog 4-8）。モデルは変えない。
- H0 なら、C-0179 の「コア命中率を上げる」の部分を棄却し、ミサトの S1 の効果を定義から外すか `partial` にする。C-0170 との違い（フルバースト中に配られる▲と、自分のスタックの▲）を切り分ける問いを起こし、モデルを直すかはオーナーに諮る。
- どちらでも係数は動かさない。

## 読み方

- HUD の総ダメージの増分を `tools/captures/hud.ts --mode jumps`（レシピ `hud-jumps`）で読み、ミサトの 1 ヒットの格子（胴体・コア・会心・距離ボーナス。予測ファイルの値）に分ける。単騎なので、増分はほとんど 1 ヒットずつ（約 2.5f ごと。2 発が 1 つの増分に入ったものは和で分ける）。
- 区間（距離帯）は的のジャンプ（ヒットの 100f を超える空き）で切り、距離ボーナスの有無で中近・中遠を確かめる（125-03 と同じ）。
- スタックの窓: 戦闘開始から数えた撃った発（当たった数 ÷ 弾丸命中率ではなく、`ammo.ts` の残弾か、HUD の増分の数とリロードの位置から数える）で、60・120・180 発目を決める。的のジャンプの後は、最後の発火（60 発ごと）から 5 秒で切れたとみて積み直しを数える。読み切れないときは、各区間の頭の 180 発を除いた残りを 3 スタックの窓とみる（保守的な切り方）。
- コア命中率 = コアのヒット数 ÷ 当たったヒット数。距離帯ごと・録画ごとに出し、σ は 100f のブロック間の分散。
- 対照のリターも同じ格子で読む（1 ヒットの値は録画 054 の値）。054 も同じ読み方で読み直して、対照の合計に入れる。

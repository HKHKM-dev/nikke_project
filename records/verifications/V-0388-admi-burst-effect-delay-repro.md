# V-0388: アドミのバーストの効果の遅れの再現（R1）

## 条件

- 目的: アドミ（172）のバースト使用時の効果の遅れ（C-0479。録画 042 の読み直しの後付けの仮説）を、値を決めるのに使っていない新しい録画で再現する（backlog 2-4。plan/burst-effect-delay-candidates.md 2 節の R1。2026-10-09 のオーナーの判断）。
- 編成（V-0368「次に撮るもの」の最小の編成。録画 042 と同じ）: I-DOLL・フラワー（304。I・AI）+ アドミ（172。II・AI）+ アリス（191。III・操作）+ I-DOLL・サン（308。III・AI）。灼熱の的（BigArms）・3 分モード・スペック固定 ON・オートバースト ON。操作枠のアリスは AUTO 射撃 ON（042 の台帳は AUTO 射撃・オートバーストが未記入だが、042 ではアリスが撃ってリロードしている（`042-13`））。
- 最小構成: サン・フラワー・アリスは機構が確定したキャラで、サンの会心の 1 発に効く未確定の要素はアドミの burst の効果のほかに無い（V-0362・V-0368）。
- 見るのは、各回の II の発動（右のバースト欄の六角形が II から III に替わるフレーム。plan/captures/guide.md「バーストの段の切り替わり」）の後の、サン（AR）の**会心の 1 発に▲が乗っているか**。窓の終わり（▲が切れるフレーム）も同じ録画で読む。
- 起点の約束: 遅れの定数は六角形の替わり目から数える（plan/design-activation-stall-video.md 2 節・3.5 節。替わり目と本当の発動の差は backlog 2-30）。II の発動はフルバーストの入りの止まりより前なので、替わり目からの動画のフレームの差を、そのままモデルの遅れと比べる。

## 予測（撮る前に書く）

仮説ごとに、この録画で何が見えるはずか。見分けられるか。外れたときの影響。数値は予測ファイル（records/predictions/V-0388.json。npm run records:predict -- V-0388）を指す。既存の録画の読み直しなら、冒頭の「録画」に挙げてから予測を出し、読む前に commit する。

撮る前に書いた（2026-10-09）。

- **H1**（いまのモデル。C-0479 の行）: 各回で、II の発動の後のサンの会心の発は、遅れの幅（予測ファイルの `effect-delay-1`〜`4` の H1）より前は▲の無い値、後は▲の乗った値。回ごとの幅（▲の無い最後の会心の発 〜 ▲の乗った最初の会心の発）が、どの回も H1 の値を含めば合う。
- **H0**（遅れ 0。予測ファイルの範囲外。遅れの表の行を外すと出る）: 発動の後の会心の発は、どれも▲の乗った値。発動の後に▲の無い会心の発が 1 つでも出れば合わない。
- **H2**（遅れはあるが、値が C-0479 の幅の外。範囲外）: 回ごとの幅の共通部分が C-0479 の幅と重ならない。
- 窓の終わり（記録。範囲外）: C-0479 の読み（窓は遅れた始まりから数える。V-0368 の E1）なら、▲は発動から「遅れ + 10 秒 + 入りの止まり」で切れる。発動から数える読み（E2。`windowFromActivation`）なら、それより遅れの分だけ早く切れる。
- 見分け方: H0 は発動の後の▲の無い会心の発で外れる。H1 と H2 は回ごとの幅の共通部分で分ける。サンの会心は確率なので、回によっては幅が広い。9 回前後の発動の共通部分で挟む（V-0368 と同じ）。
- 予想: **H1・E1**（042 と同じ編成・同じ操作なので）。
- 外れたとき: H0 なら、042 の読み（C-0479）は発動の時刻の見誤りか、042 だけの事情。C-0479 を棄却し、アドミの行を外す案を出す。H2 なら、2 本の幅の共通部分で行の値を直す案を出す。

## 読み方

1. 撮った録画を取り込む（`tools/captures/intake.ts`。台帳の条件に「V-0388（R1）。録画 042 と同じ編成」）。
2. 各回の II の発動を、右のバースト欄を 1 フレームずつ切り出して読む（六角形が II から III に替わる最初のフレーム）。III のタイマーが 00.00 になったフレーム（III の発動）も読む。
3. HUD の増分（`npm run records:read -- <録画 id> --recipe hud-jumps --source V-0388 --write`）から、各回の発動の前 30f 〜 後 60f と、発動から 590〜650f のサンの増分を取り出し、042-30 と同じ格子（サンの胴体の 1 発 × (1 + コア + 距離 + フルバースト + 会心 + ▲) の組み合わせ）で、会心の発の▲の有無を決める。
4. 回ごとに、発動から数えた下端・上端を出し、1〜4 回目を `burstEffectDelay`（slot 2・n 0〜3）の観測値（spread の range・許容は幅の半分）にする。5 回目より後と窓の終わりは記録（use: record）にする。
5. `npm run records:check` で予測と比べ、`records:minimal` で警告を確かめてから結論を書く。確定にするなら C-0479 を新しい結論で置き換える（等級は反復実測の候補）。

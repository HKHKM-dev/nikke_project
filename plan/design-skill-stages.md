## 0. 目的と前提

- 目的: 分類（1 段目）を元に、語彙の家族をどの順で足し、どのキャラで確かめるかを決める。
- 前提（決まっていること）:
  - 語彙は、持ち主ごとの一覧の操作として書く（組み直しの設計書 6 節。付ける・延ばす・外す・スタックを変える・出来事を流す）。語彙の形は [design-named-state.md](design-named-state.md) 8 節のまま。
  - 効果の呼び名も目録に入れる（分類の設計書の論点 4）。解除と消去は別に実装し、解除不可は件の印で持つ（同 論点 8）。HP の条件は利用者が選べる想定で書く（同 論点 12）。ツールチップはデータ明記の根拠にできるが、モデルの値が変わる結論は撮影か既存の録画で 1 度確かめる（同 論点 10）。
  - 根拠の規則は変えない。撮影で確かめるキャラだけ定義する。使い手のいない語彙は入れない（段の語彙は、その段で確かめるキャラが使う分だけ足す）。
  - 段の制約（いまの 1・1.5・2・2.5 段目の見え方）は、組み直しの論点 2 のとおり件の段の印で再現し、外すのは根拠ができてから。

## 1. 段の選び方

次の順に見て段の順を決めた。

1. **依存**: 状態の条件と外れ方（段 1）が、スタック・状態の出来事・バリアとデコイの土台になる。
2. **効く広さ**: 一覧 2 節（スロットごとに残る「語彙なし・要確認」）で、その語彙だけで片付くスロット（「それだけ」）が多い家族を先にする。いちばん多いのは「自分が〈状態〉なら」で、次が敵の防御力▼。
3. **確かめやすさ**: 次の順に確かめやすい。
   - 定義のあるキャラの近似（分類の別紙 4.4 節）の書き直し。値が変わらないことを、既存の観測値（`npm run records:check`）で確かめられる。
   - 既存の録画の読み直し（AGENTS.md「事実と記録」。読み直しでも確定にできる）。
   - 単騎か最小構成での撮影。
4. **論点の決まり具合**: 間接に効く効果の notes の種類（分類の設計書の論点 7）が要る段（バリア・HP・防御力）は、論点 7 が決まってからにする。

### 2.1 段 1 の新しい定義の候補

書き直しの後に、状態が戦闘中に付いたり外れたりするキャラを 1 体定義し、外れ方の時刻（出来事のフレームか次のフレームか。[design-named-state.md](design-named-state.md) 8.2 節の見込み）を撮影で確かめる。候補は、一覧 2 節で「自分が〈状態〉なら」だけで片付くスロットを持つキャラのうち、状態の付き外れが単騎か最小構成で見えるもの。

- メイデン・ミハラ（バースト: 自分が〈状態〉なら追加ダメージ）
- マスト：ロマンチックメイド S1（ほろ酔い状態の時に限り味方全体に▲。続いている間の条件）
- 外したもの: ユルハ（バーストの「自分が平常心状態なら」。平常心は 30 回攻撃を受けた時に付くが、射撃場 3 分モードの的の攻撃は 180 秒に十数回（C-0551）なので付かない見込み）

どれにするかは段 1 の設計で、撮影の最小構成と合わせて決める。

### 2.2 書き直しを段の最初の使い手にする

- 分類の別紙 4.4 節の近似（アニス：スターの `burstStepMix`、マナの `assumes`、クラウンの `stacksRef`、エマ：TU・ウンファ：TU の `withCharacter`、アスカ S2 の前提の外）は、その語彙を入れる段で書き直す。
- 値が変わらないことを、既存の観測値（`npm run records:check`・`npm run records:minimal`）で確かめる。アニス：スターは、単騎で私だけの星になる録画（0161）、再突入のニケと組んで私だけの星になる録画（0460）、I のニケと組んでみんなの星になる録画（0150・0151 など。151 は一時停止画面で適用中の効果を開いた）がある。
- 値が変わったら、その差は近似が外れていたことを示す。モデルの変更になるので、直さずにオーナーに諮る（組み直しの設計書 4 節と同じ扱い）。
- 書き直しで語彙を入れると、段の最初の PR は撮影を待たない（使い手は定義のあるキャラで、根拠は既存の結論と観測値）。新しい定義（2.1 節）は、撮影を伴う次の PR にする。

## 4. 段ごとの進め方

## 5. 論点

決定（2026-10-16、オーナー）: 論点 1〜5 は推奨どおり。

1. **段の順**
   - 推奨: 2 節の表の順（状態 → 敵の防御力▼ → スタック → 状態の出来事 → バリア・デコイ → HP → 防御力 → 回復の残り → バフの残り）。状態の語彙が土台で、「自分が〈状態〉なら」だけで片付くスロットがいちばん多い。
   - 代わりの案: 敵の防御力▼を段 1 にする。状態と依存が無く、既存の録画の読み直しで早く片付く見込み。
2. **書き直しを段の最初の使い手にするか**（2.2 節）

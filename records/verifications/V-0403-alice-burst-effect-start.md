## 条件

**何を確かめるか**

- 遅れの表にアリス（191）の行は無く、バースト使用時の効果（burst の effects[0] チャージ速度▲ 80.15%・effects[1] 攻撃力▲ 55.12%。10 秒。C-0475）は本当の発動（III のタイマーの 00.00 の 6f 前。C-0516）で付く。
- III のバースト使用時の効果の付き始めはキャラごとに違う（V-0399。HA: 00.00 の 5〜6f 前・HD: 1〜2f 前・HM: 00.00 の後）。
- アリスは SR で発が疎（チャージの間隔は数十 f）。攻撃力▲は 00.00 の前の発の値で、チャージ速度▲は 00.00 を跨ぐチャージの長さで見る。
- チャージの途中で速度が変わったとき: いまのモデルは、撃った時点で次の発までの待ちを決め、途中で変えない（`frame/shooter.ts`。押下チャージ型のアニス：スターだけ経過を持ち越す。C-0380）。入力が UP の SR で途中の変化を確かめた結論は無い。

**編成**

- 録画 `362`（V-0357）: ココア（311。I）+ ソルジャーF.A.（301。II）+ アリス（191。III・操作・AUTO 射撃 ON）+ レイヴン（851。III・AI）、オートバースト ON。射撃場・灼熱の BigArms・3 分モード・スペック固定 ON。フルバーストの始まり（00.00）は f1368・2571・3772・4974・6175・7378・8578・9823・11024 で、アリスが III の回は 1・3・5・7・9 回目（`362-03` の注記）。
- **最小構成**: ココア・ソルジャーF.A. はダメージに効く効果が無い。レイヴンは機構が確定（V-0378）で、アリスの発には効かない。アリスのほかの効果は S1（フルバースト開始時に上位 2 機へチャージ速度▲・チャージダメージ▲。C-0474）だけで、確定。S1 が 00.00 より前に付くかは確かめていない（V-0397 の F0・F1 と同じ問い）ので、攻撃力▲（×1.5512）とチャージダメージ▲（フルチャージ倍率に +7%）を値で分ける。

**読み方の前提**

- アリスの 1 発の格子は、`362-03` の注記の予測ファイル V-0357 の H1 の格子（コア・会心・距離ボーナス・補正の組み合わせ）。00.00 の前は補正が乗らない。攻撃力▲の有無は 1 発で分かれる（1.55 倍）。
- チャージの長さは、発（HUD の増分のフレーム。SR は着弾 = 発射）と発の間。入りの止まり（約 22f）を跨ぐ間は 22f を引く。

## 予測（撮る前に書く）

読む前に書いた（2026-10-10。手計算。予測ファイルは無い）。

攻撃力▲（00.00 の 8〜1f 前のアリスの発）:

| 仮説                                                   | 00.00 の 6〜3f 前の発 | 2〜1f 前の発 | 止まりの明けの最初の発 |
| ------------------------------------------------------ | --------------------- | ------------ | ---------------------- |
| H0: いまのモデル（本当の発動 = 00.00 の 6f 前。HA 形） | ▲あり                 | ▲あり        | ▲あり                  |
| HD: 00.00 の 1〜2f 前                                  | ▲なし                 | どちらも     | ▲あり                  |
| HM: 00.00 の後                                         | ▲なし                 | ▲なし        | ▲あり                  |

チャージ速度▲（00.00 を跨ぐチャージ。前の発 F0 → 次の発 F1）:

| 仮説                                       | F1 − F0 − 止まり                                                     |
| ------------------------------------------ | -------------------------------------------------------------------- |
| C0: いまのモデル（撃った時点の待ちのまま） | ▲なしのチャージの間隔（窓の外の間隔）                                |
| C1: 経過を持ち越す（C-0380 の P1 の形）    | 付き始めまでの経過 + 残りを▲の速度で（窓の外と窓の中の間隔のあいだ） |

- 予想: 攻撃力▲は **HD**（V-0399 の多くのキャラの形）。チャージ速度▲は C0 か C1 かの予想は持たない（入力が UP の SR で確かめた結論が無い）。2 つの効果は同じ時刻に付く。
- 既に見ていた値: `362-01`〜`362-14`（窓の中・外の 1 発の値と発の間隔の平均・残差）。00.00 の前の発の値と、00.00 を跨ぐ間隔は誰も読んでいない。
- 見分けられない場合: 00.00 の 6〜1f 前に発の無い回は、攻撃力▲の付き始めを数えない。00.00 を跨ぐチャージで C0 と C1 の差が 3f 未満の回は数えない。
- 外れたときの影響: 攻撃力▲は 1 回のバーストで 00.00 の前の 0〜1 発の▲の有無。C1 なら、00.00 を跨ぐ 1 発が数 f 早くなり、モデルの射撃の位相が 1 回のバーストで数 f ずれる。モデルは直さない（plan/burst-effect-delay-candidates.md 2.7 節の案 C）。

## 読み方

1. 00.00 は `362-03` の注記のフレームをそのまま使い、アリスが III の 5 回を見る。
2. HUD の増分（`hud-jumps@2` のキャッシュ）を、各回の 00.00 の 120f 前から止まりの明けの 120f 後まで並べ、アリスの発を格子に当てる（ココア・レイヴンの発と重なった増分は分ける）。
3. 00.00 の前で攻撃力▲の無い最後の発と、▲の付いた最初の発のフレームを記録する。
4. 00.00 を跨ぐ発の間隔（止まりの分を引く）を、窓の外のマガジンの中の間隔と、窓の中の間隔と比べる。

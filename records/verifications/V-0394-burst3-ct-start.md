## 条件

**何を確かめるか**

- I・II の発動は、CT が律速なら CT が 0 になってから 0〜2f（平均約 1f）で、新しい CT の秒が出るのは CT の 0 の 3〜4f 後、次の段の六角形はその 3f 後（C-0258）。六角形の替わり目は本当の発動の 5f 後（C-0503）。
- III で同じかは測っていない。いまのモデルは III の発動（CT の走り出し）・フルバーストの窓の始まり・入りの止まり・III の遅れの起点を、同じ 1 つのフレームに置き、照合では III のタイマーの 00.00 に当てている（`activationVideoFrameOf`）。backlog 2-31 の設計（plan/design-burst-hit-origin.md 8 節。別のブランチで起案中）は「III の CT が走り出すフレームは測っていない」としている。
- V-0392・V-0393 を読んだとき、録画 192（ルドミラ：WO）・258（雪子）で、CT が律速の III の 7 回の右のバースト欄を並べた。CT の表示が消えて顔が明るくなったフレーム（B）から III のタイマーの 00.00（Z）までは 6・6・6・7・6・6・6f、新しい CT の秒（「40」）が出たフレーム（N）から Z までは 3f だった。この値は仮説の出どころなので、192・258 は**後付け**として記録し、合う仮説の数に入れない。
- ほかの III のキャラの録画で、CT が律速の III の回の B → Z を読み、同じ 6f かを確かめる。

**録画**（どれも射撃場・BigArms・3 分モード・スペック固定・オートバースト ON。III のキャラが違う）

- `221` ココア + デルタ + ラピ（操作）、`222` ココア + デルタ + ドレイク（宝物あり・操作）、`224` ココア + デルタ + クイーン（真）（操作）、`225` ココア + デルタ + レイヴン（操作）、`248` サクラ + デルタ + ユニ（操作・撃たない）+ ノワール、`280` サクラ + デルタ + ソルジャーE.G.（操作）、`317` ココア + デルタ + モダニア（操作）。
- 後付け: `192` ラム + デルタ + ルドミラ：WO（操作）、`258` ラム + デルタ + 雪子（操作）。
- **最小構成**: 見ている事象は右のバースト欄の表示（CT の秒・顔・III のタイマー）の時刻で、ダメージの値を使わない。CT の長さに効く未確定のスキル（`cooldownReduction`）は、この編成に無い。

## 予測（撮る前に書く）

読む前に書いた（2026-10-10。手計算。予測ファイルは無い）。比べるのは、CT が律速の III の回（III の段の六角形が出た後も III の顔に CT の秒が出ていて、それが明けてから 00.00 になった回）の B → Z（動画のフレーム）。ゲージが律速の回（III の段に入った時に CT が明けている回）は B が無いので比べない。

| 仮説                                                                               | B → Z               | N → Z   |
| ---------------------------------------------------------------------------------- | ------------------- | ------- |
| H0: いまのモデル（III の発動 = CT の明け = 00.00）                                 | 0〜2（C-0258 の幅） | —       |
| H1: 録画 192・258 と同じ（00.00 は CT の明けの約 6f 後。I・II の替わり目と同じ形） | 6（±1）             | 3（±1） |

- **H1 を予想する**。見分け方: H0 と H1 は 4f 以上離れ、B と Z はどちらも 1 フレームずつ並べた右のバースト欄で読めるので、1 回でも分かれる。
- 当たったときの影響: H1 なら、III の CT が走り出すのは 00.00 の約 5〜6f 前（C-0258 の「発動は CT の 0 の 0〜2f 後」を足すと）で、I・II の本当の発動と替わり目の差（C-0503 の 5f）と同じ形になる。backlog 2-31 の案 C（III の発動ごと 00.00 に揃える）は III の CT の始まりを実機から 5〜6f 遅らせ、案 C'（CT は今の位置で、窓と遅れの起点だけ後ろ）は CT の始まりを合わせる。V-0393 の雪子の 1more の▲（00.00 の 5f 前。CT の明けとほぼ同じフレーム）は、C' の「バースト使用時の効果は本当の発動で付く」と合い、C では発動より前に置くことになる。

## 読み方

1. 各録画のフルバーストの III のタイマーの 00.00（Z）は既存の観測値（`221-01`・`222-01`・`224-01`・`225-01`・`248-09`・`281-04`（280 は `280-06`）・`317-03`〜）か、右のバースト欄で読む。
2. 各回の Z の 15f 前から Z まで、右のバースト欄（crop=240:180:1680:400）を 1 フレームずつ並べ、III の顔の CT の秒（0.xx）が最後に出たフレーム L、顔が明るくなった最初のフレーム B（= L + 1 のはず）、新しい CT の秒が出たフレーム N を読む。
3. III の顔が Z の 15f 前に明るい（CT が明けている）回は、ゲージか I・II の CT が律速で、B を読まない（N → Z だけ記録）。

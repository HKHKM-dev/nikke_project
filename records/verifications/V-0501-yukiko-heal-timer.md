# V-0501: 雪子の S1・S2 の 3 秒ごとの味方全体の回復の時刻

## 条件

- 読み直し。0476 は対照（下の「読み方」）。雪子を操作した既存の録画 4 本（ラム（AI）+ デルタ（AI）+ 雪子（操作・AUTO 射撃 ON）・オートバースト ON・射撃場 3 分モード・スペック固定 ON。0258・0538・0539 は風圧、0260 は灼熱）。雪子の上に回復の数字（緑の 154,260。発動者の最終最大HP の 5.7%）が出る。ラム・デルタは回復を持たない（ラムのバーストはバリア）ので、雪子の上の回復の数字は雪子の S1・S2 の回復だけ。
- 説明文（データ）から決まること: S1 のペルソナは戦闘開始時に付く「持続」「解除不可」の状態で、効果 1 が「3 秒ごとに味方全体にメディア（回復）」。ペルソナは戦闘の終わりまで続く（C-0354。確定）。S2 の真紅の華はバースト使用時に付き、フルバーストタイムの終了で外れる状態で、効果 1 が「3 秒ごとに味方全体にメディラマ（回復）」。どちらも 1 回の回復（維持時間なし）で、値の ref は S1・S2 とも description_value_02、間隔は description_value_01（Lv1〜10 とも 3）。
- 説明文から決まらないこと: 周期の起点（1 回目が状態の付いた時か 3 秒後か）、S2 の周期が真紅の華の付いた時から数えるのか。
- 仮説（録画を見る前に立てた）: S1 は戦闘開始から 3 秒・6 秒…（0 秒には起きない）。シンデレラの S2 の「デコイが存在する時 3 秒ごと」（戦闘開始時に付く状態の間の周期。0 秒には付かず 3 秒から。C-0584）からの類推。S2 の起点は、立てる前に 0538 を見た（下の「読み方」）。
- 回復は与ダメージを変えない。「回復効果が適用された時」の効果を持つ味方（アスカの S1・クラウンの S2）の発動を変える。1 回の回復は満タンの味方にも適用され、そのたびに起こす（C-0570・C-0567）。

## 予測

なし（読み直し）。見分け方:

- S1 の起点: 0 秒にも起きるなら、戦闘開始の直後（対照の `0476-12` では開始の 2f 後）に回復の数字が出る。3 秒からなら、開始から約 177f は出ない。
- S2 の起点: 真紅の華の付いた時（バースト使用時）に起きるなら、バースト使用のフレーム（III のタイマーの 00.00 の約 6f 前）に格子の外の数字が出る。バースト使用から 3 秒ごとなら、フルバーストごとに格子の外の数字が 3 回ほど出る。S1 と同じ格子なら、格子の外に数字は出ず、真紅の華の間の格子の点で 2 つが重なって出る。

## 読み方

- 戦闘開始は、`timer.ts --mode changes` の WARNING の表示の後の変わり目で、HUD（残り時間 03:00）が出たフレーム（0538 は f812・0539 は f837・0258 は f832・0260 は f810。画で確かめた）。
- 回復の数字の地の色（R < 60・G > 220・B < 70 の純緑）の画素を、画面の中央下（x 560〜1360・y 400〜960）でフレームごとに数え、150 を超えた最初のフレームを数字の出たフレームとした（20f 未満で消える光は除く）。この読み方は 0538 を見て組んだ（ほかの緑（デルタのバーストの効果など）を拾わない色の幅と閾値）。0538 では、フルバーストの中で数字が 2 つ重なって出ること（S2 の回復）も見て、S2 の仮説（S1 と同じ格子の点に重なる）を立てた。0539・0258・0260 は同じ読み方で読んだ。
- フルバーストの入り（III のタイマーの 00.00）は、レシピ `burst-panel@1` の値。
- 重なりは、数字の出始めから 14f までの画素の山が 3300 を超えた回（1 つのときは 2,400〜3,100）。1 つに見える回のうち、カメラが動いた回と同じ位置に重なった回は画で確かめた。
- 対照: 戦闘開始時に回復が起きると分かっている録画 0476（エマ：TU の S1 の持続回復。C-0578）で、同じ読み方で開始の直後の回復の数字を見た（`0476-12`）。
- モデルと比べる指標を 2 つ足した: `healVideoFrame`（枠が出した n 回目の回復の、フルバーストの入りの止まりを足した動画のフレーム）と `healFrameCount`（枠が出した回復のフレームの数。同じフレームの回復は 1 つ）。

## 結果

読んだ日: 2026-10-25。観測値は `0538-08`〜`0538-11`・`0539-07`〜`0539-10`・`0258-23`〜`0258-26`・`0260-12`〜`0260-15`・`0476-12`。

- **S1 は 3 秒から**: 4 本とも、1 回目の回復の数字は戦闘開始の 178〜179f 後に出て、それより前には出ない（`0538-08`・`0539-07`・`0258-23`・`0260-12`）。モデル（`{ everySeconds: 3 }`。177 ティック）と ±3f の中。対照の 0476 では、戦闘開始時の回復の数字が開始の 2f 後に出た（`0476-12`）ので、0 秒の回復を画面が隠したのではない。4 回目（`-09`・`-08`・`-24`・`-13`）もモデルと ±3f。
- **周期はフルバーストの中も同じ**: 4 本とも、戦闘の全体で回復の数字は 59 回出て、前の数字との間隔はどれも 173〜182f（フルバーストの入りの止まりを挟む回は 194〜204f）。モデルの回復のフレームの数（59。180 秒ちょうどは戦闘の終わりで起きない）と同じ（`0538-10`・`0539-09`・`0258-25`・`0260-14`）。
- **S2 は S1 と同じフレーム**: 格子の外に出た数字は 4 本とも 0 で、バースト使用時にも、バースト使用から 3 秒ごとにも数字は出ない。フルバーストの窓の中の 14〜15 回の回復のうち 9〜13 回で、数字が 2 つ同じフレームに重なって出始めた。窓の外で重なった回は 0（`0538-11`・`0539-10`・`0258-26`・`0260-15`）。3 回目のフルバーストでは、00.00 の 50〜52f 後の格子の点（バースト使用から 3 秒より前）で既に重なった（0538・0539・0260）。1 つに見えた窓の中の回は、2 つの数字が同じ位置に重なったか、雪子がリロードで隠れてカメラが動いた回で、S2 の回復が起きなかったとは読まない。
- テスト（`packages/core/src/__tests__/yukikoHealTeam.test.ts`）: 録画と同じ編成で、雪子の回復が 3 秒ごと（0 秒には無い）に全員に起き、雪子 + アスカでアスカの S1 が 3 秒から戦闘の終わりまで切れずに付く。

## 分かったこと・分からないこと

- **C-0647（確定・反復実測）**: 雪子の S1 のメディアは、戦闘開始から 3 秒ごと（3 秒・6 秒…。0 秒には起きない）に 1 回ずつ起き、フルバーストの中も同じ周期のまま戦闘の終わりまで続く。`heal`（`{ everySeconds: 3 }`・`allies`・`ref: 2`）で定義した。
- **C-0648（確定・反復実測）**: 雪子の S2 の真紅の華のメディラマは、真紅の華の間、S1 のメディアと同じフレームに重なって起き、ほかのフレームには起きない。回復を受けた時の効果の発動は S1 の定義で入るので、S2 は補足の notes にした（別に定義しない）。周期は状態の付いた時からではなく、戦闘開始から数えた格子に乗る（ペルソナ・真紅の華のどちらも）。
- 新しい語彙（状態の付いた時を起点にする周期・`heal` の条件）は要らなかった。
- 最小構成: 未確定の要素は確かめたい回復の 2 つだけ。ラム・デルタの効果は雪子の回復の時刻に効かず、フルバーストの入りは録画の値で読んだ。
- 分からないこと: 真紅の華の間の格子の点ごとに S2 の回復が毎回起きるか（2 つの数字が同じ位置に重なると 1 つに見える）。同じフレームの 2 つ目の回復は、いまの受け手（持続の効果）の窓を変えないので、モデルの値には効かない。回復を受けた回数を数える受け手が出たら確かめ直す。アスカ・クラウンと組んだ録画は無い（回復のたびに「回復効果が適用された時」を起こすことは C-0570 などで確定）。

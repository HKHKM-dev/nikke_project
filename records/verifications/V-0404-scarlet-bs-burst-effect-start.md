読む前に書いた（2026-10-10。手計算。予測ファイルは無い）。比べるのは、各回の 00.00 の 8f 前から 1f 前に撃った紅蓮：BS の発の値（攻撃力▲・チャージダメージ▲の有無）と、その発の後に段が出るか。

- 予想: **HD**（V-0399 の多くのキャラの形）。3 つの効果は同じ時刻に付く。
- 既に見ていた値: `363-01`〜`363-18`。とくに `363-16`（5 回目。残弾が f11040 に 8 → 7、f11042 に 14 になり、f11040 の発の値が窓の中の値 1,188,135）と `363-15`（2〜5 回目の弾丸チャージのフレーム）。5 回目の 00.00 のフレームは読んでいないので、`363-16` の発と 00.00 の位置はまだ分からない。5 回目は後付けとし、合う仮説の数に入れない。
- 見分けられない場合: RL で発が疎（チャージの間隔は数十 f）なので、00.00 の 6〜1f 前に発の無い回は数えない。
- 外れたときの影響: 1 回のバーストで、00.00 の前の 0〜1 発の▲と段の有無。モデルは直さない（plan/burst-effect-delay-candidates.md 2.7 節の案 C）。

## 分かったこと・分からないこと

- **C-0524（仮説）**: 紅蓮：BS のバースト使用時の効果は、00.00 の 2f 前までに付く（HD か H0）。定義の notes の「バースト使用の 1〜2f 前の発が窓の中の段と値になった（V-0356）」は、00.00 から数えると 2f 前の発で、HD・H0 のどちらとも合う。
- 分からないこと: 付き始めが 00.00 の 6〜2f 前のどこか。段の条件の変更とチャージダメージ▲が攻撃力▲と同じ時刻か（この発ではどれも付いていた）。
- **最小構成**: C-0524 を burst の effects[1] に結んだので、確定の結論 C-0085 の `047-02`（180 秒の与ダメージ）に警告が出た。付き始めといまのモデルの差は 00.00 の 6〜3f 前の 4f で、1 回のフルバーストで多くて 1 発、180 秒の与ダメージの 0.2% 程度（許容 2%）なので、`minimal` に印を書いた（警告の件数は main と同じ）。段の条件の変更（effects[0]）とチャージダメージ▲（effects[2]）には結ばなかった（値を別々に見ていないため）。

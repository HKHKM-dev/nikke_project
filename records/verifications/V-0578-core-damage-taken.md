# V-0578: コアダメージ▲と受けるダメージ▲の置き場所（マリアン：クイーンの観測値で絞る）

- 問い: コアダメージ▲と受けるダメージ▲が同じヒットに乗ったとき、受けるダメージ▲はコアダメージ▲と同じ倍率グループの和に入るか、別の乗数で掛かるか
- 話題: 1 発の式・バフの掛かり方
- 日付: 2026-10-31
- 録画: `0738`、`0740`、`0741`、`0752`、`0753`
- 結論: `C-0792`
- 状態: 完了

## 条件

- 型: 撮影なしの絞り込み（V-0538・V-0545 の観測値だけを使う。新しく読まない）。
- 背景: コアダメージ▲は倍率グループのコアの項に足す（C-0327。`damage.ts` の `boostCore`）。受けるダメージ▲と両方乗ったヒットで置き場所を見分けた結論は無かった。いまのモデルは、受けるダメージ▲を倍率グループとも攻撃ダメージ▲とも別の乗数で掛ける。
- 見るヒット: マリアン：クイーン（19）が自分でバーストを撃った回（臨戦：胸を刺す願い）の、コアに当たったヒット。
  - コアダメージ▲ s: 自分の S2 の 24.64%（フルバーストの開始から。C-0741）。
  - 受けるダメージ▲ t: 自分の S1 の弱点露出（5.05%。C-0736）。
  - 同じ窓に、自分のバーストの攻撃力▲（78.4%）・攻撃ダメージ▲（78.14%）とフルバースト補正も乗る。録画 0752・0753 では、ラプンツェル：サンクチュアリの▲も乗る。
- 値はどれも説明文の値（スペック固定の Lv10）で、合わせ込みの定数は無い。t は単騎のコアダメージ▲の無いヒット（`0738-13`）で確かめてある。
- 仮説（倍率グループを B = 1 + (コア倍率 − 1 + s) + 会心 + 距離 + フルバースト補正、▲の無い値を X とする）:
  - HS（別の乗数。いまのモデル）: 1 ヒット = X × B × (1 + t)
  - HA（1 つの和。t がコアダメージ▲と同じ倍率グループに入る）: 1 ヒット = X × (B + t)
  - t が攻撃ダメージ▲の和に入る形も対抗に数える（下の注）。
- 最小構成: 比べる 1 ヒットに効く未確定の要素は、置き場所（和か別の乗数か）だけ（どの観測値も確定の結論の根拠で、最小構成の検査を通っている）。受けるダメージ▲の出どころは本人の効果。

## 予測

なし（撮影なしの絞り込み）。

## 読み方

1. 観測値（`0740-22`・`0740-23`・`0741-22`・`0741-23`・`0752-11`・`0753-11`）を、いまのモデル（HS）と比べる（`npm run records:residual`）。
2. HA の値は、HS のモデルの値 × (B + t) ÷ (B (1 + t))。コアの会心でない距離ボーナスなしのヒットは B = 1 + (1 + 0.2464) + 0.5 = 2.7464。

## 分かったこと・分からないこと

- 分かったこと: コアダメージ▲（倍率グループのコアの項。C-0327）があるヒットでも、受けるダメージ▲は倍率グループに入らず、別の乗数 (1 + Σ受けるダメージ) で掛かる。モデルは変えない。
- 分からないこと: 受けるダメージ▲の出どころが本人の効果（マリアン：クイーンの弱点露出）だけで、コアダメージ▲もマリアン：クイーンの S2 だけ（アスカ・ナガのコアダメージ▲では見ていない。録画 0708・0709 のフルバーストの窓のアスカのコアの発に、ブランの受けるダメージ▲と両方乗る見込みだが、読んでいない）。

1. 各回の I の発動を、右のバースト欄の六角形の色で読む（緑の I から緑でない色に替わった最初のフレーム。V-0370 と同じ）。
2. HUD の増分（`npm run records:read -- <録画 id> --recipe hud-jumps --source V-0376`）から、発動の前 40f 〜 後 40f の増分を取り出し、エマ：TU の 1 発の値が▲の無い値の群か、約 1.40 倍の群かで分ける（値の格子は録画の窓の外の増分から測る。環境コントロールの受けるダメージ▲（3.9%）の窓の境が近い回は、その分も分ける）。
3. 回ごとに、発動の後の最初の発から▲の乗った最初の発までのフレーム数を観測値にする（`burstEffectFirstShot`（slot 1・n は回の順・fromShot true）・許容 `abs: 1`）。022 は比べる観測値、263 は記録（後付け）にする。回ごとの発動と▲の有無の時刻も記録にする。
4. `npm run records:check` で予測と比べ、`records:minimal` で警告を確かめてから結論を書く。

## 分かったこと・分からないこと

- **分かったこと**: エマ：TU のバースト使用時の効果（味方全体の攻撃力▲）は、I の発動の後の最初の発から乗る（遅れ 0）。モデルの扱い（遅れの表に行が無い）のままでよい。
- **新しく見えたこと（結論にしていない）**: 022 の 6 回目と 263 の 1 回目（後付け）で、六角形の替わり目の 1f 前の発に▲が乗った。リター（V-0370）・クルミ（V-0371）と同じ。
- **最小構成**: 022 のデルタはダメージに効く効果を持たず、エマ：TU の 1 発の値に効くのはエマ：TU 自身の効果だけ。
- **分からないこと**: 環境コントロール強化（burst の effects[1]）の付き始めは、この検証では問いにしていない（強化は環境コントロールの窓の中で撃った回だけ付く。C-0335）。

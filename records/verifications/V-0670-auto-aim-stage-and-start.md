# V-0670: AUTO 射撃の照準は、何で段を切り替え、いつコアへ跳び、武器種ごとにいつ撃ち始めるか

- 問い: 窓の明けから動く AUTO の照準の速さの段の切り替わりとコアへの跳びは、何に対する条件で起きるか。SG・SR・誘導弾の RL は、照準がどこにあるときに撃ち始めるか
- 話題: 命中率・距離
- 日付: 2026-11-04
- Stage: plan/design-auto-aim.md 4 節の段 1（Q1・Q2）
- 録画: `0046`、`0054`、`0055`、`0070`〜`0073`
- 状態: 調査中
- 派生元: `V-0120`

## 条件

- 撮影はしない。V-0120 で照準の速さを測った単騎・AUTO の 7 本（紅蓮：ブラックシャドウ（RL）`0046`・`0055`・`0070`・`0071`、リター（SMG）`0054`、ラピ（AR）`0073`、エマ（MG）`0072`）の窓の明けを、`aim.ts --step 1` で読み直す。
- 最小構成は単騎（観測したい事象は操作キャラの照準の動きだけ）。7 本とも AUTO 射撃・オートバースト ON で、180 秒のあいだ画面に触っていない（台帳の `autoFire` と条件の注記）。
- 窓の明けの動き出しのフレームは V-0091 の観測値（`0046-29`・`0055-20`・`0070-13`・`0071-14`・`0054-20`・`0073-09`。`0072` は `0072-10` の 1 回目と、2 回目以降は録画の中で探す）。

**いま分かっていること**

- 照準の速さは速い段（17px/f）・遅い段（約 6.5px/f）・コアへの跳び（C-0199）。切り替わりの残りは 165〜230px で散らばる（`0046-34` ほか）。跳ぶ距離は着地点で分かれるが、同じ着地点の中のばらつきは説明できない（C-0200。仮説）。
- design-landing-aim.md 9 節の使い捨ての読み: 跳ぶ距離のばらつきは、コアの見かけの半径・的の見かけの幅・照準の大きさ・遅い段の長さでは分かれなかった。跳ぶ向きはどの回もほぼ横で、跳ぶ前に縦のずれは揃っていた。
- AR・SMG は照準が的に掛かるまで撃ち始めず、MG は待たない（C-0291）。SG の撃ち始めは読んでいない。

**オーナーの知見**（2026-11-04。プレイ中に得た知見で、特定の録画には基づかない。V-0091 の K1〜K6 に続く番号）

- K7: 照準の動き（C-0193・C-0199）は、AUTO 射撃に射撃を全部任せた状態で起きる。AUTO 射撃 ON でも、人がクリック・タップすると、照準はその位置をすぐに狙う。押している間は照準はマウス・タップの位置にとどまり、離した後はその位置からコアへ向かう。
- K7 から、AUTO の間に人が画面に触った録画は、照準の読みに使えない。台帳には触ったかどうかの項目は無い。

## 予測

探索（予測ファイルは作らない）。読む前に仮説を固定する。

| 仮説                                                                              | 見えるはずのもの                                                                 |
| --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| S-a: 段の切り替わりは、照準とコアの画面上の距離が一定（約 200px）を切ったフレーム | 切り替わりのフレームの残り（照準 − コア）が、着地点・回によらず一定の幅に収まる  |
| S-b: 段の切り替わりは、照準が的の外形（外接矩形）に入ったフレーム                 | 切り替わりのフレームで、照準が外接矩形の縁にある（縁からの距離が 0 付近で揃う）  |
| S-c: 段の切り替わりは、的までの距離で換算した一定の角度                           | 切り替わりの残りが、コアの見かけの大きさ（`core_r`）や的の見かけの高さに比例する |
| J-a: 照準は縦と横を別々に追い、縦が合った後に横の残りが条件を切ると跳ぶ           | 跳ぶ直前の縦のずれが小さく揃い、跳ぶ 1 歩はほぼ横                                |
| J-b: 跳びは、照準円（照準の大きさ）とコアの円が重なったフレーム                   | 跳ぶ直前の照準とコアの距離 ≈ 照準の大きさ + コアの半径                           |

- 見込み: S-b（実測の残りの散らばりが、的の見かけの幅の違いで説明できそう）と J-a（9 節の形）。
- SG・SR・誘導弾の RL（Q2）は、この 7 本に無いので、別の録画で読む（「次に撮るもの」）。

## 読み方

1. 各回の窓の明けの 15f 前から 90f 後まで、`aim.ts --step 1` で照準・コア・的の外接矩形を毎フレーム測る（背景は 1500〜11500f の 400f ごと）。
2. 照準の歩（1 フレームの移動）を並べ、重複フレーム（歩 0）とその次の歩を除いて、速い段（15px 以上）から遅い段（11px 未満）へ切り替わったフレームを決める。そのフレームの、照準とコアの距離（S-a）、照準と外接矩形の縁の距離（S-b）、コアの見かけの半径・的の見かけの高さ（S-c）を並べる。
3. 跳んだフレーム（遅い段の中で、歩が前の歩の 2 倍以上で、跳んだ後に照準がコアの上に止まる）の直前の、照準とコアの縦・横のずれと照準の大きさを並べる（J-a・J-b）。
4. 回ごとの値は観測値（`use: "record"`、`source: V-0670`）にする。7 本は C-0199・C-0200 を決めた録画なので、立てた形の再現は照準を読んでいない録画で取る（plan/design-auto-aim.md 3 節）。

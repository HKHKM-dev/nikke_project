## 1. 語彙

### 1.1 対象の絞り込み `targetClass`

- `targetClass: "Attacker" | "Defender" | "Supporter"`（火力型・防御型・支援型。`CharacterData.class`）。対象の枠のキャラのクラスで絞る。武器種（`targetWeapon`）・コード（`targetElement`）と同じ形で、書ける効果と対象もそれと同じにする（論点 2）。
- 自分もクラスが合えば対象に入る（「味方全体」は自分を含む。エヌ：ミラクルフェアリーは支援型なので、S1 の支援型への回復は自分にも付き、バーストの火力型への効果は自分に付かない）。
- 編成で決まる静的な絞り込みなので、発火のたびの文脈は要らない（`skills/targets.ts` の `matchesTargetFilter` に足す）。最小構成の検査も、武器種・コードと同じく「対象のクラスが観測した枠と違う」で外す。
- 画面: 効果の出どころに「（火力型の味方）」のように出す。

### 1.2 攻撃速度 `attackSpeed`

- 比率の stat。チャージしない武器（PR 2 の使い手は SG）の発と発の間（射撃の刻み。`frame/firing.ts`）を縮める見込み。1 パス目で窓を追う stat（射撃の刻みを変える）にする。
- 式（間を (1 + 比率) で割るか、(1 − 比率) を掛けるか。フレームへの丸め）は、PR 2 の撮影で決める（リロード速度・チャージ速度は `speedScaledSeconds` の式。同じかは確かめていない）。チャージ武器への効き方は使い手がいないので決めない（書けないようにする）。

## 2. 使い手と確かめ方

### 2.1 PR 1: エヌ：ミラクルフェアリー

| 説明文の行（スキル Lv10）                                                                        | 書き方                                                                                                                           |
| ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| S1: 通常攻撃で 3 回攻撃した時、支援型の味方全体に「攻撃ダメージの X% 回復」（5 秒間維持）        | `heal`（`{ count: "normalShot", everyRef: 1 }`・`allies`・`targetClass: "Supporter"`・`durationRef: 3`。吸収回復）               |
| バースト: 火力型の味方全体に「スキル発動者の最終最大HP の X% 回復」「攻撃力 X%▲」（10 秒間維持） | `heal`（`burstUse`・`allies`・`targetClass: "Attacker"`）と `timed`（`burstUse`・`allies`・`attack`・`targetClass: "Attacker"`） |
| バースト: 戦闘不能の火力型の味方の復活                                                           | いまの前提の外の notes のまま                                                                                                    |

- 確かめ方: 撮影。I・II（エヌ：ミラクルフェアリー）・III のチェーンで、火力型の味方の 1 ヒットがバーストの 10 秒だけ攻撃力▲（77.22%）の分上がり、火力型でない味方とエヌ：ミラクルフェアリー自身は上がらないことを見る。編成（I と III、操作枠、比べる枠）は、撮影計画（検証記録）を起こす時に、機構が確定したキャラから選ぶ（回復を受けた時の効果を持つアスカ・クラウンは、攻撃力▲の比べには入れない）。
- 回復は、回復を受けた時の効果を持つ味方がいる編成でだけ値に効く（アスカは火力型、クラウンは防御型）。PR 1 で定義するかは論点 3。

### 2.2 PR 2: トーブ S2

| 説明文の行（スキル Lv10）                                                                          | 書き方                                                                                          |
| -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 自分が応急改造のフルスタック状態の時のみ、味方全体に「クリティカル確率 X%▲」（持続）               | 味方全体の `critRate`。応急改造のフルスタックの間だけ効く形（下の 3 つ目）。基礎版・宝物版の S2 |

- 応急改造は、宝物版の S1 の代用弾丸から付く（C-0559）。基礎版の S1 の代用弾丸は確率のきっかけで未対応なので、基礎版ではフルスタックにならない（条件を満たさない）。
- 確かめ方: 撮影。宝物版のトーブと、機構が確定した SG の味方の編成で、応急改造が 3 スタックの間だけ SG の発と発の間が縮むこと（式）を見る。クリティカル確率▲は、会心の割合でしか見えないので、撮影計画で見分けられるかを決める。編成は撮影計画で決める。
- 「フルスタックの間だけ持続」の形（スタック数の条件。段 3 の 1.4 節）が、いまの語彙でどう書けるか（常時の効果か、状態の中身か）は、PR 2 の実装の時に確かめる（書けなければ PR 2 の設計に足す）。

## 3. 段の外の確かめ方（分類の論点 5）

- **貫通ダメージ**: 貫通特化の状態のニケ（アリス S2 など。定義あり。いまは間接（貫通）の notes）と、貫通ダメージ▲を持つ味方（ツバイなど。未定義）を組み、敵 1 体の的で、貫通特化の発に貫通ダメージ▲が乗るかを撮る（ツールチップ T2）。貫通ダメージ▲の使い手を定義する時に起案する。
- **適正射程距離**: エード：エージェントバニーを定義する時に、適正射程距離▲の間に距離ボーナスの乗る帯が広がるか（ツールチップ T6）と、「フルチャージ攻撃が適正射程距離内の」の条件を、的の距離の帯（着地点）ごとの距離ボーナスで撮る。
- マシンガン立ち上げ速度（レイ（仮称）・アスカ：WILLE）と同一効果は重複不可（K）も、使い手を定義する時に、その撮影で決める。

## 5. 論点

決定（2026-10-18、オーナー）: 論点 1〜4 は推奨どおり。論点の文は諮った時のまま。

1. **段 9 の範囲**（決定: 推奨どおり）
   - 推奨: 定義のあるキャラに使い手がいるクラスでの絞り込み（PR 1）と攻撃速度（PR 2）だけを段 9 で足す。ほかの家族は、使い手を定義する時にその PR で足す（確かめ方は 3 節）。
   - 代わりの案: 段 9 の中で、ほかの家族の使い手（ツバイ・エード：エージェントバニーなど）も 1 体ずつ新しく定義して撮る。
2. **クラスでの絞り込みを書ける範囲**（決定: 推奨どおり）
   - 推奨: 武器種・コードの絞り込みと同じ（自分のほかの対象の、常時・持続・付与・即時の効果）。キリ・ビスケット・D（未定義）の使い方もこの形で書ける。
   - 代わりの案: 使い手のいる `timed` と `heal` だけに書けるようにする。
3. **エヌ：ミラクルフェアリーの回復を PR 1 で定義するか**（決定: 推奨どおり）
   - 推奨: 定義する（説明文の読み）。回復を受けた時の効果を持つ味方がいない編成では値は変わらない。撮影でアスカ（火力型）にバーストの回復が付くかも見られれば一緒に確かめる。
   - 代わりの案: 攻撃力▲だけを定義し、回復は未対応の notes のまま（回復を受けた時の効果を持つ味方との撮影の時に足す）。
4. **PR の順**（決定: 推奨どおり）
   - 推奨: PR 1 → PR 2（PR 1 は段の最初の使い手。PR 2 は攻撃速度の式を撮って決めるので、撮影の計画が大きい）。
   - 代わりの案: 2 つの撮影を 1 回にまとめる（編成は別なので、録画は別）。

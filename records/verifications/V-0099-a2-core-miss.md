- 問い: A2 単騎 AUTO の通常攻撃がコアを外す割合は、区間（距離帯）ごとにいくらか

## 条件

- `V-0097` の弾の種類のうち、直進弾・弾速 300。紅蓮：ブラックシャドウ・レイヴン（弾速 400）とラプラス：アルティメットヒーロー（弾速 100）の間の弾速で、H1a（飛ぶ時間）の弾速の並びを見る。爆発の範囲は 750 で、紅蓮BS（50）・レイヴン（500）と違う（H1c が残ったときの 3 つ目の値）。
- 同じ弾速 300 のラプラス（rid 100。爆発の範囲 500）は、S1 でフルチャージのたびに爆発の範囲が伸びるので選ばなかった（`V-0097`「条件」）。
- A2（811）は SSR・Attacker・灼熱・バースト 3 段階。通常攻撃はチャージ 1 秒・装弾数 6（キャラデータの `shot`）。的（灼熱タブ）と同じ属性なので、属性の有利は無い。
- 最小構成は単騎（`V-0097`「条件」）。スキルの見込み（スキル定義は無い。モデルは通常攻撃だけ）:
  - S1: バーストを使ったときにチャージダメージ▲と爆発の範囲▲。単騎ではバースト 3 段階のバーストを使えないので起きない。
  - S2: フルチャージ攻撃が命中したとき、対象に追加ダメージ（最終攻撃力の割合）と、自分にパーツダメージ▲。HUD の増分は 1 ヒット + 追加ダメージになる見込み。追加ダメージがコアで変わるかは読みで見る（変わらなければ、コアと胴体は 1 ヒットの部分で分かれる）。弾の行き先は変えない。
  - バースト（B モード）: 使えないので起きない。

## 予測（撮る前に書く）

仮説ごとの見え方は `V-0097`「予測」の表の A2 の列（H1a なら紅蓮BS とフラワーの間で遠に出る、H1c なら爆発の範囲 750 の値、H1b ならほぼ 0）。予測ファイル `records/predictions/V-0099.json` には、いまのモデル（H0。コア命中率 1）の 1 ヒットの値（胴体・コア × 会心。増分をコアと胴体に分ける鍵。S2 の追加ダメージは入らない）と、180 秒の射撃の数を固定した。H1a〜H1c はモデルの入力で表せないので、このファイルの範囲外。

## 読み方

1. `tools/captures/intake.ts` で取り込む（`--rid 811 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec on --auto-fire on --auto-burst off`）。台帳を埋めて `npm run records:table`。
2. `npm run records:read -- <録画 id> --recipe hud-jumps` で増分の列を出し、`V-0097`「読み方」の 1 と 3 のとおり、1 発の値（予測ファイルの `hit-body`・`hit-body-crit`・`hit-core`・`hit-core-crit`）と S2 の追加ダメージの和に分けて、発のフレームと、コアか胴体かを取る。追加ダメージの値は、増分から 1 ヒットの値を引いた残りの並びで決める。
3. 区間の切れ目（的のジャンプの窓）をこの録画で読み、区間ごとに「撃った発（部分チャージの発を除く）」「コアを外した発」「そのうち着地の後の 1 発目」を観測値（`use: "record"`、`source: V-0099`）にする。撃った発の数の合計は、予測ファイルの `shots` と比べる観測値（`shotCount`）にもする。
4. 比べと判定は `V-0097` で行う。この記録は、`V-0097` の結論ができたら、その結論を裏付けた記録として閉じる。

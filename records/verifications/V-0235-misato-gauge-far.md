# V-0235: ミサト単騎の遠の区間の満タンで、持続の命中率▲の上がりがゲージに効くか（C-0265）

- 問い: ミサト S1 の持続の命中率▲で増えた的への当たりも、ゲージを溜めるか（C-0265。1 パス目に持続の▲を入れたモデル H1 と、入れないモデル H0 のどちらと合うか）。外れの多い遠の区間で、チェーンが切れてから次の満タンまでの当たった数と撃った発の数を比べる
- 話題: バーストゲージ
- 日付: 2026-10-06
- Stage: backlog 2-23
- 派生元: `V-0188`
- 状態: 調査中

## 条件

- 確かめる結論は C-0265（仮説・推論）。設計は [design-sustained-hit-rate-gauge.md](../../plan/design-sustained-hit-rate-gauge.md) 4 節・6 節の論点 5。前の検証 V-0188（1 回目の満タン。中近）は判定なしで閉じた（2026-10-05 のオーナーの判断。案 A）。これは V-0188「次に撮るもの」の案 B を、2026-10-06 のオーナーの判断で組み直したもの（下の「最小構成」）。
- 2026-10-06 のオーナーの判断で、SMG の遠の弾丸命中率（backlog 2-25）は表の 0.760 のまま（C-0320）。中近・近・中遠 A は新しい値（C-0287・C-0294・C-0319）がモデルに入っている。
- 根拠のつながり:
  - ゲージは、的に 1 回当たるごとに `target_burst_energy_pershot`（ミサトは 2,000）溜まり、500 ヒットで満タン（BURST バーが消える）。SMG でも確かめた（C-0083・C-0255。V-0188 でもミサトとリターの 1 回目の満タンが約 500 ヒット目）。コンテナに当たった弾は半分の量を溜める（C-0139）。
  - 単騎のオートバーストでは、I の発動から約 600f でチェーンが切れ、BURST バーが戻る。その間のヒットはゲージに入らず、戻った後のヒットから 0 で溜め直す（C-0009。`077-21`）。
  - ミサト S1 の持続の命中率▲（1 段 5.04%、3 段。C-0183）は、弾丸命中率の外れを減らす（C-0192。確定。確かめたのは SMG の遠）。遠の弾丸命中率は、▲なしの 0.760 から 3 段で 0.862 に上がる（モデル）。
- **H0 と H1 の差が大きく出る所**: 遠の区間（3 区間目）は外れが多いので、▲で増える当たりが多い。モデル（オートバースト ON）では、2 回目のチェーン切れ（約 77 秒）から 3 回目の満タン（約 107 秒）までが遠の区間に入る。1 回目のチェーン切れから 2 回目の満タンまでは近の区間で、外れがほぼ無いので H0 と H1 が同じになる（参考の確かめに使う）。
- 録画（これから撮る）: ミサト単騎を同じ日に 3 本。射撃場 BigArms・灼熱タブ・3 分モード・スペック固定 ON・AUTO 射撃 ON・**オートバースト ON**・操作キャラはミサト（枠 1 の 1 体だけ）。
- 最小構成: 単騎。ミサトのバースト（味方全体の持続回復）と S1 の HP 回復は未対応（C-0180）だが、単騎ではダメージにもゲージにも効かない。バーストの持続回復の tick はチェーンの待ちの中にあり、ゲージが溜まらない間にある。S2（射撃マニュアル状態の間のバリアに与えるダメージ▲・与える HP 回復量▲）は的に効かない。
- 案 B にあった対照のリター単騎は撮らない（2026-10-06 のオーナーの判断）。わけは 2 つ:
  1. オートバースト ON では、リターの S1 のバースト使用時の効果（最大装弾数▲など）が発動する。これらには根拠の結論が無い（[skills.md](../../plan/skills.md) の 82 リター）。V-0188 はオートバースト OFF なので発動しなかった。
  2. モデルでは、リターの 3 回目の満タンまでの窓が遠と中遠の区間にまたがる。中遠は着地点（A と B・C）で弾丸命中率が大きく違う（C-0319・C-0320）。
- 対照を置かなくても見分けられる見込み: 下の判定の指標（当たった数）は、H1 では遠の弾丸命中率の値によらず 500 以下になる。H0 との差（約 60 ヒット）は、遠の表と実測のずれ（V-0215 の 0.777 と表の 0.760）で数ヒットしか動かない。

- **判定の指標**: 録画ごとの h = 2 回目のチェーン切れ（BURST バーが戻ったフレーム）の後の最初のヒットから、3 回目に BURST バーが消えたヒットまでに、的に当たった数（両端を含む）。
  - H1 の値: 500。コンテナに当たった弾（C-0139。1 回で的の半分）があると、その数 c の半分だけ少なくなる。窓の外れの数を m（= 撃った発の数 − h）とすると、500 − m/2 ≤ h ≤ 500。
  - H0 の値: 約 563。予測ファイルの H0 の窓（`far-shots` の 647 発。sustainedHitRateUp: false）の発ごとに、H1 のモデルの弾丸命中率（▲込み。遠は 0.862）を足した当たりの期待値（2026-10-06 に sim の発の列から数えた）。予測ファイルの override は 2 パス目の▲も止めるので、この値はファイルに入らない。コンテナの分（c/2）はこの値からも引かれる。
- **判定の目安**（撮る前に固定する）:
  - 録画ごと: H1 は 500 − m/2 ≤ h ≤ 502（上の 2 は読みの誤差）。H0 は h ≥ 525（563 から、H0 の窓の外れ（647 − 563 = 約 84）の 9 割がコンテナに当たったときの引き算（約 38）を見込んだ下限）。どちらでもなければ、その録画は判定なし。
  - 検証: 3 本とも同じ仮説なら、その仮説。1 本でも判定なしか、仮説が分かれれば、判定なし。
  - h はヒットの数え方で幅が出ることがある（V-0118 と同じ、下限と上限）。幅の全部が同じ側にあるときだけ、その側に入れる。
- **副の指標**（予測ファイルの `far-shots`。判定には使わない）: 同じ窓の撃った発の数。H0 647、H1 581。コンテナの分（C-0139）と遠の表と実測のずれ（V-0215。表より外れが少ない）は、どちらも発の数を少なくする向きに効く。
- **参考**:
  - `near-shots`（1 回目のチェーン切れから 2 回目の満タンまで。近の区間）: 両方 501 発。この窓の当たった数が 500（近は外れがほぼ無い。C-0294）なら、チェーン切れの後に 0 から溜め直す読み方（C-0009）を確かめたことになる。
  - `far-full-frame`（3 回目の満タンのフレーム）: H1 は遠の区間の終わり（3 回目のジャンプ。約 108.3 秒）の前、H0 はジャンプの後。実際の録画は、着地の後に照準が掛かるまで撃たない分（C-0291）だけモデルより遅れる。2 回目の満タン（モデル約 67 秒。2 回目のジャンプの約 1.8 秒前）がジャンプの後にずれると、窓が中遠の区間にかかり、H0 の値が小さくなる。そのときも H1 の値（500 以下）は変わらない。
- 外れたときの影響:
  - H1 なら、C-0265 を確定にする候補（等級は反復実測。3 本）。設計書 [design-sustained-hit-rate-gauge.md](../../plan/design-sustained-hit-rate-gauge.md) の論点 5 を閉じる。
  - H0 なら、C-0265 を棄却し、1 パス目の当たりの窓をゲージに効かせるのを止める（設計書を直す）。2 パス目の弾丸命中率（C-0192）はそのまま。
  - 判定なしで h が 503〜524 なら、▲の一部だけがゲージに効くか、読み方の誤りを疑う。

## 読み方

1. 取り込み: `tools/captures/intake.ts`（録画の id は撮った後に決まる。冒頭の「録画」に足す）。オートバーストと AUTO 射撃のボタンは画で確かめる（guide.md「AUTO 射撃・オートバースト」）。
2. チェーン切れと満タンのフレーム: `tools/captures/gauge.ts --mode series` で、I の発動（BURST バーが読めなくなったフレーム）、チェーン切れ（BURST バーが戻ったフレーム。`077-21` と同じ読み）、満タン（バーが消えたフレーム。満タンのヒットはそのフレームのヒット）を、1〜3 回目について読む。
3. 当たった数: 総ダメージの増分（`hud.ts --mode jumps`。レシピ `hud-jumps`）を、チェーン切れの後の最初のヒットから満タンのヒットまで数える。SMG は 1 フレームに 1 発までなので、前のフレームも読めていた増分は 1 ヒット（V-0200 の `smg-mags` と同じ）。前のフレームが読めていない増分は、下限と上限で数える。
4. 撃った発の数: 照準の横の AMMO の表示（`reticle-ammo.ts`）で、チェーン切れの直後の残弾と満タンの発の直後の残弾を読み、その間のリロード（`reload-segments`）ごとに 120 発を足す。m = 撃った発の数 − h。
5. 1 回目のチェーン切れから 2 回目の満タンまで（参考）も、3・4 と同じに数える。
6. 観測値: 録画ごとに、副の指標 `chainTimeoutToGaugeFullShots`（slot 1・n 1。`setup` は予測ファイルと同じ）と、参考の n 0 を書く。判定の指標 h は、録画ごとの観測値（`count`・`use: record`）に下限・上限・m を添えて書き、3 本の判定を最初の録画の観測値（`use: record`）にまとめる。

## 読み方

1. hud-jumps で増分を読み、1 ヒットの格子でコア・胴体と距離ボーナスに分ける。
2. マガジンの何発目かを 6 つの区切りに分け、帯（近・中近・中遠・遠）ごとにコア命中率を出す。帯の混ざり方の違いは、帯ごとの比べか、帯の配分で重みを付けた期待値との比べで消す。
3. `aim.ts` の `aim_size` で、十字の隙間が撃っている間に段階的に広がり、リロードで戻ることも確かめる。
4. 判定の目安（撮る前に決める）: 何発目かに対するコア命中率の傾きが 0 と 2σ の中で合い、区切りごとの率が帯の配分から出した期待値と 2σ の中で合えば再現。
   - 2026-10-11（読む前に書き足した）: 区切りは Stage 18-B2 と同じ 1〜5・6〜10・11〜20・21〜30・31〜45・46〜60 と、61 以降（装弾数がそれより多いときの残り）。何発目かは、リロードかジャンプの明けの最初の発から発の間隔（5f）で数えた発の番号（外れた発も数える）。
   - 区切りの期待値 = Σ帯（その区切りのその帯のヒットの数 × 3 本を合わせたその帯のコア命中率）÷ その区切りのヒットの数。σ は 2 項分布の √(Σ n p(1 − p)) ÷ n。
   - 傾きは、区切りごとの（実測 − 期待値）を区切りの発の番号の真ん中に対して 1 / σ² の重みで直線に当てはめたもの（1 発あたり）。その σ は当てはめの標準誤差。

## 分かったこと・分からないこと

- **再現した**（読み方 4 の目安の両方に入る）。傾きは 0 と +0.56σ、区切りごとの率はどれも期待値と 2σ の中。十字の隙間はリロードで戻り、撃っている間は広がったままだが、コア命中率は何発目かで変わらない。
- 読み方 3 の「段階的に広がる」は、発の数に応じた広がりではなく、最初の発から 2f の間の 12.5 → 17.5 → 22.5 の段（Stage 18-B2 の 12.5 → 17.6 → 23px と同じ値）だった。撃っている間の 17.5 と 22 の行き来は 5f の発の刻みに合わせた揺れとみる（見立て。5f おきの測定なので刻みとの位相は分けていない）。
- 結論の見込み: C-0042 を確定に戻せる。等級の候補は反復実測（決めるのに使っていない更新の後の 3 本・3,560 ヒット）。`decidedOn` は今の 054・056・057（仮説の出どころ）のまま。
- 録画は更新の後だが、根拠（Stage 18-B2 のクルミ）と同じ形になった。
- 分からないこと: SMG・MG のリングの広がり（Stage 18-B2 で MG 25.7 / 28.2 / 30.4px）とコア命中率の関係は読んでいない（結論の括弧書きは AR だけ）。

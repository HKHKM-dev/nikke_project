# V-0311: ミランダのバーストの攻撃力▲は、I の発動から何フレーム遅れて付くか（単騎）

- 問い: ミランダ（I・宝物あり）の単騎で、バースト使用時の効果（攻撃力▲・クリティカルダメージ▲。候補がいないので自分に付く）は、I の発動から何フレーム遅れて、自分の通常攻撃の 1 発に乗り始めるか。回ごとに揃うか
- 話題: スキル・キャラ固有
- 日付: 2026-10-07
- Stage: plan/design-burst-landing.md 5 節の 2（ほかのキャラの遅れ）。backlog 2-4（バースト使用時の効果の遅れ）
- 状態: 調査中

## 条件

**何を確かめるか**

- ヒットの無いバーストの効果の遅れは、クルミ（C-0138。ほぼ 0）・I-DOLL・サン（C-0364）のほかは測っていない（backlog 2-4。2026-10-07 にオーナーが撮るものを決めた）。ミランダは I のバーストなので単騎で撃て（C-0024 のとおりフルバーストにはならない）、発動に止まりが無く、SMG の約 2.5f ごとの発（V-0216）で効果の付いた最初の発を細かく読める。
- あわせて、単騎（自分を除く候補が 0 機）でもバーストが自分に付くかを見る。C-0322 は 2 人（候補 1 機。録画 `244`）と 3 人（候補 2 機。録画 `245`）の編成で確かめたもので、候補が 0 機の単騎は見ていない（V-0216 の「分からないこと」）。

**編成**

- ミランダ（32。SMG・I・宝物 3 段階・**操作**・AUTO 射撃 ON）の単騎、オートバースト ON。射撃場・灼熱の BigArms・3 分モード・スペック固定 ON。
- **単騎**（AGENTS.md「単騎で観測できる事象は単騎で確かめる」）。S1 の命中率▲（C-0186。仮説）はコア命中率にだけ効き、1 発の値には効かない（V-0216 と同じ）。S2 はフルバーストのきっかけなので単騎では起きない。

**読み方の前提**

- I の発動は、右のバースト欄の六角形が I から II に替わるフレーム（C-0220。満タンで BURST バーが消えた 29f 後）。I・II の発動には止まりが無いので、動画のフレームの差がそのままモデルのフレーム。
- ミランダの 1 発は端数まで読める（`144-05`〜`144-08`・`244-02`〜`244-05`）。攻撃力▲の中の胴体は、外の (1 + 0.5006 + 0.404) ÷ (1 + 0.5006) 倍（宝物版 S1 の攻撃力▲と和。C-0322）。会心はさらにクリティカルダメージ▲の分だけ大きい。
- 指標 `burstEffectFirstShot`（この PR で足した）の `fromShot: true` は、発動の後の最初の発から、効果の発火以後の最初の発までのモデルのフレーム数。効果の遅れが無ければ、発の間隔やリロードの位置によらず 0。

## 予測（撮る前に書く）

撮る前に書いた（2026-10-07）。値は予測ファイル（records/predictions/V-0311.json）。的のジャンプは入れていない（効果の遅れの指標は、発動の時刻とジャンプの重なり方によらず比べたいため。1 発の値は、モデルの 1 回目のバースト（1682f）の前後 60f のフレームで出し、録画では各回のバーストから同じずれの発と比べる）。

| 仮説                                   | 1〜4 回目の「発動の後の最初の発 → ▲の付いた最初の発」 | ▲の中の 1 発（`solo-body-in`・`solo-crit-in`） | 外の 1 発（`solo-body-out`）   |
| -------------------------------------- | ----------------------------------------------------- | ---------------------------------------------- | ------------------------------ |
| H0: いまのモデル（自分に付く・遅れ 0） | `buffed-first-1`〜`buffed-first-4`（0）± 1f           | 予測ファイルの H0                              | 予測ファイル（どの仮説も同じ） |
| E1: 自分に付くが、遅れ d がある        | どの回も 2f 以上（d に揃う）                          | H0 と同じ                                      | 同じ                           |
| H2: 単騎では自分にも付かない           | （▲の付いた発が無い）                                 | 予測ファイルの H2（外と同じ）                  | 同じ                           |

- **H0 を予想する**。ヒットの無いバーストの効果で測った例（クルミ・I-DOLL・サン）はどれも発動のフレームから効いていて、遅れたのはヒットと同じ時刻に効果が出るキャラ（イサベル・ニヒリスター）だけ。単騎で自分に付くことは、説明文の「対象が足りない場合、自分も対象となる」と C-0322 の読み（自分を除く候補が足りなければ自分）から予想する。根拠は推論で弱い。
- 1f の揺れは録画の重複フレームの位置で出るので、± 1f を合うとみる（観測値の許容 `abs: 1`）。SMG の発の間（約 2.5f）より短い遅れは、発動の後の最初の発が▲の外かどうかでしか見えない。
- 当たったときの影響:
  - H0: 遅れの表にミランダの行は要らない（いまのモデルのまま）。単騎で自分に付くことを C-0322 の根拠に足す。
  - E1: 遅れの表にミランダの行（effectFrames d）を足す。▲の窓が d だけ後ろにずれる。
  - H2: 定義の宝物版のバーストの読み（`excludeSelf: unlessShort`）を、候補が 0 機のときの扱いで見直す（C-0322 の言い直し）。
- E1 で値を決めるのがこの録画になったときは、単独実測の仮説にとどまる。値を決めた後に予測を出してから録画 `244`（ミランダ + デルタ。バーストが自分に付く 7 回。V-0216 では付き始めのフレームは読んでいない）を読み直し、再現すれば反復実測にできる。

## 読み方

1. 取り込む: `node tools/captures/intake.ts <元ファイル> --id NNN --name smg_miranda_burst-solo --rid 32 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec on --auto-fire on --auto-burst on`（宝物の段階は `records/recordings/<録画 id>.json` の team の `treasurePhase` に 3 と書く）。台帳を埋めて `npm run records:table`。この検証記録の冒頭に「録画」を足す。
2. 右のバースト欄を 1 フレームずつ並べて、各回の I の発動（六角形が I から II に替わるフレーム）を読む。
3. HUD の増分（`npm run records:read -- <録画 id> --recipe hud-jumps --source V-0311 --write`）から、各回の発動の前後のミランダの発を並べ、格子（胴体・コア × 会心 × 距離ボーナス × 宝物版 S1 の攻撃力▲ × バーストの▲の有無。V-0216 と同じ）で分ける。
4. 各回の「発動の後の最初の発 → ▲の付いた最初の発」を観測値（`burstEffectFirstShot`。`args` は予測ファイルと同じ `slot: 1`・`n`・`fromShot: true`。許容 `abs: 1`）にする。発動がリロードの途中の回は、発動の後の最初の発がリロードの明けになる（指標の起点も同じ）。▲の無い最後の発のフレームも記録する。
5. ▲の中と外の 1 発（`hitDamage`。予測ファイルと同じ `args`・`setup`。`frame` は予測ファイルの値のまま、録画では各回のバーストから同じずれの発を読む）を観測値にする。

# V-0632: イサベルの S2 のヒットは、発動の時点の値で計算するか（読み直し）

- 問い: イサベルの S2 のヒット（発動の約 45f 後）は、発動の後・ヒットの前に付いた（切れた）敵の側のデバフと撃つ側のバフを乗せるか（C-0856）
- 話題: 1 発の式・バフの掛かり方
- 日付: 2026-11-01
- 状態: 完了
- 録画: `0038`、`0891`、`0892`、`0893`
- 結論: `C-0864`
- 派生元: `V-0619`

## 条件

- 型: 読み直し（撮影なし）。2026-11-01 のオーナーの判断で進める。
- 結論の対象: イサベルの S2 の倍率ダメージ（`data/skills/231.json` の skill2 の effects[0]。C-0402・C-0453）が値を決める時点（`damageFormula`）。
  - H-act: S2 の発動の直前の値（撃つ側のバフ・敵の側のデバフ・フルバースト補正）で計算する。発動と同じフレームに付いたものも乗らない。
  - H-act'（読みの途中で足した）: バフとデバフは H-act と同じで、フルバースト補正だけヒットの時点。
  - H-hit: ヒットの時点の値で計算する（読む前のモデル。`frame/plan.ts` の `planSkillHits` は、遅れて出る倍率ダメージをヒットのフレームの値で出していた。plan/design-delayed-skill-hit.md 3.1 節）。
  - 発動の時点（同じフレームを含む）の形は、モデルではたきなの S2 の▲が同じフレームに付いて乗るので、`0890-16`・`0890-17` と合わない（読みの途中でモデルで確かめた）。H-act は「直前」にした。
- 仮説の出どころ（`decidedOn`）:
  - V-0619 の `0890-16`・`0890-17`（C-0856）: たきなの S2 の受けるダメージ▲は、イサベルの S2 と同じ時刻に発動して付くのに、S2 のヒットに乗らなかった。▲が付くのは S2 の発動と同じティックなので、これだけでは「発動の直前の値」と「同じティックに付いたものは乗らない」を見分けられない。
  - V-0619 の 0891 の 3・4 回目のチェーン: イサベルのバーストのヒット（f8019・f10691）で段階 1 の受けるダメージ▲が付いた 15・19f 後に、S2 のヒット（f8034・f10710）が出た。V-0619 の読みで、どの S2 のヒットも▲なしの値だと見ていた。
- H-act は合わせ込みの定数を持たない（値を決めるフレームは発動の 1 フレーム前。発動からヒットまでの 45f は C-0453）ので、出どころの録画も再現に数える（verification-guide.md 2.2 節。結論の `parameterFree`）。
- 最小構成: 0891〜0893 は V-0619 の編成（ラム・イサベル・◎たきな（撃たない））。たきなの使用武器の変更（burst の effects[0]）は、撃たないので効かない（C-0854 の印と同じ）。0038 はラム・デルタ・◎イサベル（V-0270。機構はどれも確定）。

## 予測

なし（読み直し。verification-guide.md 2.2 節）。

## 読み方

1. 候補の録画: イサベルのいる録画のうち、比べる指定を組める `0038`・`0162`・`0163`・`0165`・`0868`・`0869`・`0890`〜`0893`。イサベル単騎（`0008`・`0565`・`0566`）と、アニス：スターと 2 人の `0562`〜`0564` はバーストのチェーンが無く、端が無い。
2. 見分けられる回を、モデルの時刻表で挙げた。録画ごとの比べる指定（既存の観測値と同じ）で、イサベルの S2 のヒットを H-act・H-act'・H-hit の 3 通りに出し、値が分かれる回を拾った（一時的な仮説の切り替えを使った。結論の後にスキル定義の `valueBeforeFire` に置き換えた）。
   - 0162・0163・0165・0868・0869: 分かれる回は無かった（端が発動とヒットの間に入らない）。
   - 0038: 1・6・9 回目。1 回目は、実測の 1 回目のフルバーストの始まり（`0038-22`）がモデルより 39f 早く、実測の窓では 3 仮説で同じ値になる（観測値の 308,564 は会心）ので外した。
   - 0890〜0893: どの回も分かれる（たきなの S2 の▲が、イサベルの S2 の発動と同じティックに付く）。0891 は、イサベルの段階 1 の▲の付き始めが発動の後・ヒットの前に入る 3・4 回目のチェーンの回を拾った。0890 は `0890-16`・`0890-17` が既にある。
3. 拾った回の増分を、HUD の増分のキャッシュ（`hud-jumps`）で読んだ。0038 は Drive の録画からキャッシュを作り直した。0038 の値は V-0270 の探索で読んだ値（`0038-30` の説明）と同じ。0890〜0893 の値は V-0619 の読みで見ていた。
4. 比べる指定は、録画の既存の観測値と同じ（0891〜0893 は V-0619 の `manualBursts`。0892・0893 は 1 回目のチェーンだけを渡す。ほかのチェーンのフルバーストと段階 1 の▲の窓に、どの S2 のヒットも入らず、段階 3 にも届かないので、会心でない値は変わらない）。

## 分かったこと・分からないこと

- **イサベルの S2 のヒットは、発動の直前の値で計算する** → C-0864（C-0856 を置き換えた）: 撃つ側のバフ・敵の側のデバフ・フルバースト補正のどれも、発動の直前の値で決まり、遅れ（約 45f）の間と発動と同じフレームに付いた・切れたものは効かない。
- **分からないこと**:
  - ほかの遅れて出る周期の倍率ダメージ（ラピ・エーテル・ニヒリスターの S2。C-0453）も同じか。今のモデルはヒットの時点のまま（この検証では読んでいない）。クイーン（真）の S1 の追撃（`0823-13` など）は、フルバースト補正を発動の時点で見ると合わない（読みの途中でモデルで確かめた）ので、遅れて出る倍率ダメージのすべてが同じではない。
  - S1 の段階のバフが付くフレーム（III の発動か、バーストのヒットか）。`0891-18` はバーストのヒットから付く形と合うが、S2 の値だけでは決めていない。

# V-0749: B モードを付けない A2 へのユニのチャージ速度▲の効き方

- 問い: B モードを付けない A2 が、ユニの比率のチャージ速度▲（8.97%）を受けたとき、発と発の間はチャージだけが縮むか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-12
- 状態: 調査中
- 派生元: `V-0739`

## 条件

- 型: 撮影（V-0739 の「次に撮るもの」の案 1）。C-1103（仮説。A2 の B モードの間の発と発の間が、チャージだけを縮めるいまのモデルより短い。残差 `1084-11`・`1085-11`）の原因を、「B モードに固有の効き方」か「▲が大きいときだけの効き方」かに分ける手前として、A2 自身が小さな比率の▲（B モードなし）にレイヴン（C-1136）と同じく応じるかを見る。
- いまのモデル（C-0216・C-0217・C-1136）: 射撃姿勢維持型の発と発の間 = 姿勢の長さ ⌈S⌉ + 12f + チャージ C − 1。チャージ速度▲は C だけを縮める（`frame/firing.ts` の `chargeShotIntervalFrames`）。A2 は S = 49.41f → 50・H = 24・C = 59 で 120f、レイヴンは S = 48.82f → 49・H = 16・C = 59 で 119f。
- 編成: リター（I）+ ユニ（II）+ レイヴン（III・AI）+ A2（III・操作）。スペック固定 ON・オートバースト OFF。バーストは リター → ユニ → レイヴン の順に手で押し、A2 のバーストは押さない（B モードを付けない）。
  - ユニの S1（フルバーストの始まりに味方全体へ、チャージ速度 8.97%▲ 10 秒）が、A2 とレイヴンに乗る。窓はフルバーストの窓と同じ。
  - ユニの S2 は味方を回復する。A2 にバーストを使わせると B モード（HP の割合で解除・付き直し。V-0729）が付き直しうるので、A2 のバーストは押さない。
  - レイヴンは同じ録画の中の対照（C-1136 では窓の中 114f・外 119f）。レイヴンのバースト（A.N. モード）は持続ダメージ▲だけで、射撃を変えない。
- 編成はモデルで確かめた（2026-11-12。`noBurstSlots` に A2 の枠を入れた sim）: ユニの▲が A2・レイヴンに乗り、窓の中の間は A2 115f・レイヴン 114f、窓の外は A2 120f・レイヴン 119f。レイヴンのバーストの CT のため、モデルでは 2 サイクルに 1 回だけフルバーストになる（3 分で 5 回）。
- 混ざる要素: A2 の B モードが、バーストなしで付くことはない（B モードは A2 のバーストで付く。V-0729）。射撃場の的のジャンプ（撃てない窓）を跨ぐ間と、窓の端を跨ぐ間は使わない。

## 予測

撮る前（2026-11-12）に手で出した（姿勢の形はモデルの上書きで表せないので予測ファイルにしない）。r はチャージの縮み（チャージ時間の倍率。ユニの▲で 1 ÷ 1.0897 ≒ 0.9103）。整数は C-0217 の切り上げ（⌈⌉）にそろえる。形は V-0739 の表と同じ。

| 形  | 中身                                           | A2・ユニの▲（窓の中） | レイヴン・ユニの▲（窓の中） |
| --- | ---------------------------------------------- | --------------------- | --------------------------- |
| (a) | チャージだけ（いまのモデル）                   | **115**               | **114**                     |
| (b) | 姿勢の長さ S も r 倍（⌈S r⌉）                  | 110                   | 110                         |
| (c) | 満ちてから撃つまで H だけ r 倍（S − H は同じ） | 113                   | 113                         |
| (d) | 発と発の間の全部（12f の待ちも）が r 倍        | 109.2                 | 108.3                       |

- 窓の外の間は、どの形でも A2 120f・レイヴン 119f（C-0216）。
- レイヴンは C-1136 から (a) の 114f を見込む。レイヴンが 114f で A2 が外れれば、A2 に固有の効き方がある。
- (a) と (c) の差は 2f。V-0739 の 0303・0304 では、窓の中の間の最頻値・中央値で 1f の差を見分けられた。

## 読み方

- 取り込みの後、録画を `node tools/captures/fetch.ts` で取り寄せ、`npm run records:read -- <録画> --recipe hud-jumps --source V-0749` で HUD の総ダメージの増分を出す。
- A2・レイヴンの発は、フルチャージの 1 発の値（窓の中はフルバースト補正の乗った値）で拾う。リター・ユニの発と重なった増分は使わない。
- 窓の中か外かは、1 発の値（フルバースト補正の有無）で分ける。続いた 2 発が同じ側の値で、間が 135f 未満のもの（的のジャンプ・窓の端・リロードを挟まない）を数える（V-0739 の `0303-06` などと同じ読み方）。
- 窓の外の間（A2 120f・レイヴン 119f）を先に確かめる。
- 手動のバーストの時刻は、比べる指定に `manualBursts` で渡す。

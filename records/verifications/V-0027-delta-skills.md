# V-0027: デルタのスキルはダメージに関係しないか

- 問い: デルタ（20）のスキルをすべて「ダメージに関係しない」と読んで（効果なしの定義）、モデルは既存の録画のデルタの 1 発と合うか
- 話題: スキル・キャラ固有
- 日付: 2026-09-28
- Stage: キャラの定義（plan/skills-guide.md 2 節。撮影が先に済んでいるとき）
- 録画: `013`、`063`
- 結論: `C-0081`
- 状態: 完了

## 条件

- 説明文（`data/characters/20.json`）を 1 行ずつ分けた（skills-guide.md 1.2 節）。どの行も自分にだけ付き、ダメージに関係しない。
  - S1「フルチャージして攻撃した時、自分に最大HP▲（10 秒）」
  - S2「バーストスキルを使用した時、自分に防御力▲（20 秒）」
  - バースト「自分にデコイ（最終最大HP の一定割合の分身。10 秒）」「敵全体を挑発（10 秒）」
- 定義は全スロットを `unsupported` にして notes だけを書く（V-0026 のラムと同じ形）。
- デルタの 1 発を比べた既存の観測値: `013-01`〜`013-04`（ウンファ：TU + デルタ。フルチャージの 1 発）、`063-07`（フラワー + デルタ + アスカ。フルバースト中のコア + 会心の 1 発）。
- `063` はオートバースト ON（録画の台帳）。モデルでは、デルタのバースト（II）は 1 回目のフルバーストの直前（f550）で、`063-07` の f706 はその後。S1 は AI の射撃もフルチャージ攻撃に数える（Stage 10）ので付いている。S1・S2・バーストの効果がすべて付いている時の 1 発になる。

## 予測（撮る前に書く）

録画は撮ってあり、観測値はどれも前から照合されている（`013-0x` は C-0020、`063-07` は C-0075 の根拠）。デルタの定義はこれまで無く、モデルはスキルなしで計算していた。

| 仮説                                             | `063-07`（フルバースト中のコア + 会心） | `013-0x`（フルチャージの 1 発）  |
| ------------------------------------------------ | --------------------------------------- | -------------------------------- |
| H1: どのスキルもダメージに関係しない（効果なし） | いまのモデルと 1 未満で一致する         | 同じ                             |
| H2: どれかがデルタの与ダメージを上げる           | モデルより大きい値が出る                | S1 の付く前の 1 発なら一致しうる |

- 見分けられるのは `063-07`。デルタ自身のバーストの後で、S1・S2・バーストの効果がすべて付いている。

## 読み方

- 新しく読んだ値は無い。既存の観測値を `npm run records:check` で比べた。

## 結果

- `063-07`・`013-01`〜`013-04` は、デルタの定義（効果なし）を入れた後も、モデルとの差が 1 未満（許容内）。定義を入れる前と数値は変わらない。

## 分かったこと・分からないこと

- **C-0081 は確定（厳密一致）**: デルタのスキルは、デルタ自身の与ダメージを変えない。どれも自分にだけ付くので、味方の与ダメージも変えない。
- `047-03` の戦闘履歴のデルタの与ダメージも、効果なしのモデルと約 0.4% の差で矛盾しない（record のまま。V-0026）。
- **分からないこと**: デコイと挑発が、射撃場の的の攻撃の対象を変えるか（与ダメージには効かない）。

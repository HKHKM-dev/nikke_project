## 読み方

1. 取り込み: `node tools/captures/intake.ts <元ファイル> --name rl+sr+mg_flower+eunhwa-tu+emma-tu_round-explosion --rid 304,95,93 --controlled 3 --target BigArms --element Fire --mode range-3min --fixed-spec on --auto-fire off --auto-burst off`。録画の JSON のエマに `fires: false` を書く（0287 と同じ）。
2. `npm run records:read -- <録画 id> --recipe hud-jumps --source V-0562 --write` で総ダメージの増分を取る。同じフレームに乗った増分は、フラワー・ウンファの系列を引いて分ける。分けられないものは使わない。
3. バーストの時刻（I・II の段の切り替わり）を回ごとに読み、撃ったのがフラワーとウンファか（エマでないか）を右のバースト欄で確かめる。エマが撃った回は使わない。
4. II の後の最初の大きい増分が炸裂弾。その後のウンファの発がカモフラージュの値かで、その回のカモフラージュが着弾の時に付いていたかを分ける。
5. 観測値は、予測ファイルの指標と同じ `metric`・`args`・`setup` で書く（`frame` は予測ファイルの代表の時刻のまま。録画の時刻は `method.note` に書く）。炸裂弾は回ごとの値を記録の観測値にもまとめ、R0・R1・カモフラージュの外れた回の値と合ったかを `method.note` に書く。

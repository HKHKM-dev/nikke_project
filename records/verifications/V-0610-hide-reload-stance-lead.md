# V-0610: 射撃姿勢維持型の、敵のジャンプの間のハイド中のリロードの始まり（A2 単騎）

- 問い: 射撃姿勢維持型のチャージ武器が敵のジャンプの間のハイド中のリロードを始めるのは、前の発の約 19f 後（窓の始まりより前にはしない）か
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-01
- 録画: `0046`、`0055`、`0070`、`0071`、`0123`、`0864`、`0865`、`0805`
- 結論: `C-0840`、`C-0842`、`C-0843`
- 状態: 完了
- 派生元: `V-0606`

## 条件

- 型: 撮る（A2）と読み直し（紅蓮：ブラックシャドウ）。C-0829（仮説）の再現と、V-0606「分かったこと・分からないこと」の 1 つ目。
- 仮説の出どころ: A2 単騎の `0123`（`0123-19`〜`0123-21`。C-0829 の `decidedOn`）と、紅蓮：ブラックシャドウ単騎の `0046-18`（`0046`・`0070`。部分チャージの発とフルチャージの発から RELOADING が出るまで）。
- 武器種: 射撃姿勢維持型（`frame/firing.ts` の `stanceFrames`）は紅蓮：ブラックシャドウ・A2・レイヴンの 3 体で、どれも RL（`packages/core/data/characters/225.json`・`811.json`・`851.json`）。V-0606 が紅蓮：ブラックシャドウを SR と書いたのは誤りで、SR の射撃姿勢維持型は無い。始まりの長さを武器種で撮り分けることはできず、分けうるのはキャラ（姿勢の長さ・チャージ時間）と、前の発の形（部分チャージかフルチャージか）。
- 2 つの値の数え方の違い: `0123-21` は前の発の総ダメージの増分（ヒット）からバーの 0 の点（`reload.ts --mode fit`）まで、`0046-18` は撃ってから RELOADING の文字が出るまで（目で読んだ）。同じ数え方で並べないと、同じ長さかは言えない。モデルの前の発は、照合では総ダメージの増分と比べるフレーム（直進弾の RL には飛ぶ時間の表が無い）。
- 始まりの長さが結果に効くのは A2 だけ: A2（リロード 1.5 秒）は、ハイド中のリロードがリロードの秒 + 約 12f（約 100.2f）で満ちるので、始まりが窓の始まりから約 17f より遅ければ、モデルの窓の中で終えない（録画のハイドの長さ（V-0609）なら約 10f）。紅蓮：ブラックシャドウ・レイヴン（リロード 2 秒）は、始まりによらず終えない。
- 最小構成: A2 単騎・操作・オートバースト OFF（`0123` と同じ）。S1 のチャージダメージ▲（バーストの使用で起きる）とバーストの B モード（未対応）は、バーストを使わないので起きない。S2 のフルチャージの発の追加のダメージは値だけで、発の刻みとリロードに効かない。紅蓮：ブラックシャドウの読み直しの 4 本も単騎・オートバースト OFF。
- 見分けの要: 窓の始まりに A2 がどの段にいたか。モデル（姿勢 50f・発と発の間 120f）では、前の発の後の約 50f は姿勢の中でチャージしていない。
  - (a) チャージの途中で窓に入る（前の発から約 50f より後）: 窓の始まりに部分チャージで撃ち（C-0109）、その発から数える。
  - (b) フルチャージの発の 19f 以内に窓に入る: その発から数える。
  - (c) フルチャージの発の 19〜50f 後（姿勢の中）に窓に入る: 部分チャージの発は無く、前の発から 19f はもう過ぎている。
  - モデルの既定の窓で回すと、1〜4 回目のうちマガジンの途中は 3 回（(a)・(b)・(c) が 1 回ずつ）で、残りの 1 回はマガジンが空。マガジンの途中の回のうち、(a) が約 6 割、(b) が約 1.5 割、(c) が約 2.5 割（姿勢とチャージの長さの比）。

## 読み方

1. A2（撮る）: 総ダメージの増分は `node tools/captures/hud.ts <動画> --mode jumps`、RELOADING のバーは `node tools/captures/reload.ts <動画> --mode fit`（取り消された回は canceled）。発のフレーム（撃った時）は照準の横の残弾（`tools/captures/ammo.ts`。RL は弾が届くまで増分が遅れる。plan/captures/guide.md「画面の読み方」）。
2. ジャンプごとに、窓に入る前後の最後の発（部分チャージかフルチャージか。残弾の減りと増分の両方）、バーの 0 の点と消えたフレーム、満ちたか、明けの後にリロードの前に撃った発の数を読み、(a)〜(c) に分ける。窓の始まりは、(a) は部分チャージの発（C-0109）、(b)・(c) は敵の動き（同じ戦闘時刻の画面を並べる）か、着地の後の 1 発目（C-0549）から決める。
3. 紅蓮：ブラックシャドウ（読み直し。`0046`・`0055`・`0070`・`0071`）: 同じ 1・2 で、マガジンの途中のジャンプの回を読む。
4. モデルとは、録画のジャンプの窓（`setup.jumpWindows`）を入れて比べる。

## 分かったこと・分からないこと

- 分かったこと:
  - A2 の部分チャージの発の回は、撃ってからバーの 0 の点まで約 26f、0 の点から明けまで約 60f で、6 回ともそろう。マガジンの途中のジャンプの間にリロードを終えない（6 回と、窓の前後のフルチャージの発の 3 回）。
  - 紅蓮：ブラックシャドウの部分チャージの発の回は、撃ってから約 12.9f で、A2 と同じ長さではない。どちらも RL で、武器種で撮り分けることはできない。
  - 射撃姿勢維持型のハイド中のリロードは、窓の始まりの約 8f 後（D）と前の発の射撃姿勢の終わり（撃ってから ⌈S⌉ − H）の遅い方から始まる（C-0842。仮説。比べる指標が無い）。部分チャージの発の時刻は C-0840、値は C-0843。
- 分からないこと:
  - S4 は録画を見てから立てた仮説で、再現が要る（V-0615 でレイヴンの既存の録画で再現した）。レイヴン（RL・射撃姿勢維持型・⌈S⌉ 49f・H 16f）なら、S4 は部分チャージの発の回で、撃ってからバーの 0 の点まで約 33f、0 の点から明けまで約 61f、部分チャージの発から明けまで約 94f と、A2・紅蓮：ブラックシャドウと違う値を言う（撮る前に固定できる）。
  - (c)（フルチャージの発の 19〜50f 後に窓に入る回）の A2 が終えるか。
  - 窓の始まりからの約 8f（D）と、V-0609 の 0863 の 4 回目（窓の始まりにフルチャージの発を撃った回はその発から始まる）の関係。

# V-0260: ユニの S2 の最大装弾数▲は、フルチャージの攻撃ごとに味方全体の最大装弾数を 1 発上げ、5 秒で戻すか

- 問い: ユニ（160）の S2 の「フルチャージして攻撃した時、味方全体に最大装弾数 1 発▲（5 秒）」を、C-0017 の形（加算）で味方に付き、付き直しで重ならないと読んで、操作枠の I-DOLL・サン（撃たない）の最大装弾数は 61 になり、ユニの発が 5 秒途切れると 60 に戻るか
- 話題: スキル・キャラ固有
- 日付: 2026-10-07
- 状態: 調査中
- 録画: `288`

## 条件

**なぜ確かめるか**

- backlog 5-2 の残り（[plan/design-skill-claims-5-2.md](../../plan/design-skill-claims-5-2.md) 6 節の案 A）。ユニの S2 の effects[0]（最大装弾数▲）に根拠の結論が無い。

**説明文**（`data/characters/160.json` の skill2）: 「フルチャージして攻撃した時、味方全体に … 最大装弾数 {値 5} 発▲ {値 6} 秒間維持」。Lv10 で 1 発・5 秒。C-0017（確定）: 最大装弾数▲は加算して四捨五入し、切れたら削る。

**編成（最小構成）**

- ユニ（160。AI）+ I-DOLL・サン（308。操作・撃たない。照準は画面の中央）。射撃場・灼熱の BigArms・3 分モード・スペック固定 ON・オートバースト ON。I がいないのでバーストは起きない。
- サンは機構が確定したキャラ（C-0364 ほか）で、スキルの効果はどれも自分にだけ付き（C-0275）、バーストを撃たないので最大装弾数は 60 のまま。未確定の要素はユニの S2 だけ。
- ユニの S2 のほかの効果（防御力▲・吸収回復）は、サンの最大装弾数に効かない。

**順番について（正直に書く）**: 録画は 2026-10-07 にオーナーが撮った（未取り込みの 3 本。撮った順に A・B・C の見込み）。撮影が予測より先になったので、予測ファイルを録画の値を見る前に commit し、その後に取り込みと読み取りをする（[plan/skills-guide.md](../../plan/skills-guide.md) 1.6 節の「読み直しなら読む前に」と同じ扱い）。予測の commit（6a48379・e324f29）の前に録画は開いていない。撮った後、録画の最初と最後のフレーム（出撃画面・戦闘中の 1 フレーム・戦闘履歴のパネル）で編成・枠順・的・モード・スペック固定・AUTO の表示だけを確かめ（guide.md「撮影後は、まず一時停止 / 戦闘履歴のパネルで編成と枠順を確かめ、その編成で予測を出し直す」）、その編成で予測を出し直して commit した（予測ファイルの枠順と、V-0261 の I をラムに直した。値は変わらなかった）。戦闘履歴のパネルの枠ごとの与ダメージの合計は目に入ったが、比べる指標にはしていない。

## 予測（撮る前に書く）

- 予測ファイル: records/predictions/V-0260.json（H1・H0）。

| 仮説                                                           | サンの照準の横の残弾（リロード明けの最大）                                                                                                                                                      |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **H1**: いまの定義。味方全体に 1 発▲、付き直しは窓を延ばすだけ | ユニの最初の発の前は 60（`sun-max-ammo-before`）、後は 61（`sun-max-ammo-in`）。ユニの発が 5 秒（294f。C-0140）途切れると 60 に戻る（モデルでは的のジャンプの前後。`sun-max-ammo-window-ends`） |
| H0: サンには付かない（ユニ自身だけか、効果なし）               | いつも 60                                                                                                                                                                                       |
| H2（手書き）: 付き直しのたびに重なる                           | 61 から 62・63 … と増える                                                                                                                                                                       |

- 見分け方: 撃たないサンの残弾は、最大が増えても増えず、その後のリロードで新しい最大まで込める（V-0236 の録画 196・254〜257 で見た形）。ユニの最初の発の後に、残弾の表示が赤くなってリロードが走り、61 になるかを見る。
- 判定の目安: 読めた区間のどこでも、ユニの発が続いている間が 61、最初の発の前が 60 なら H1（値は説明文と C-0017 から決まるので、一致すれば厳密一致）。60 に戻る時刻は、戻る直前のユニの発から数えて 294f ± 3f なら H1 の 5 秒。
- 外れたときの影響: H0 なら定義の対象を直す（自分だけ）。H2 なら重なりの語彙が要る。

## 読み方

1. 取り込み（skills-guide.md 1.7 節）。戦闘履歴で編成・枠順、左上の表示で AUTO 射撃・オートバーストを確かめる。
2. サンの照準の横の残弾を `reticle-ammo.ts --mode series` で全フレーム読み、値が変わったフレームを並べる（V-0236 と同じ）。
3. ユニの発のフレームを HUD の総ダメージの増分（`hud.ts --mode jumps`）で拾う（サンは撃たないので、増分はどれもユニ）。
4. 61 と 60 の区間を、ユニの発の時刻と並べる。

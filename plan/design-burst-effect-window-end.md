# バーストの効果の遅れと、効果の窓の終わり（モダニア）

- 関連: [design-burst-landing.md](design-burst-landing.md)（遅れの表）、backlog 2-4、V-0310・V-0312、C-0452
- 起案: 2026-10-08
- 状態: 2026-10-08 にオーナーが案 B を承認し、実装した（V-0310・V-0312）

## 0. 要約

- モダニアの殲滅モードの最初の発は、III の発動からモデルのフレームで 7f 遅れる（C-0452。録画 `317`・`044` で再現）。
- 遅れの表（`burst/landing.ts` の `MEASURED_BURST_DELAYS`）にモダニアの行（効果の遅れ 6f。モデルの使用武器変更は効果の発火の次のフレームから撃つ）を足すと、効果の窓は始まりと一緒に**終わりも 6f 後ろにずれる**。実測の窓の終わりは後ろにずれていない（`317-08`）。
- 案: 遅れの表の行に「窓の終わりは発動から数える」印を持てるようにし、モダニアの行にだけ書く（**案 B。推奨**）。

- 説明文は「装弾数無限 15 秒間維持」「殲滅モード 維持時間 15 秒」（`data/characters/260.json` の burst）。モダニアが III のフルバーストは、自分のバーストで 15 秒（C-0274）。

## 2. 案

| 案            | 中身                                                                                                                                                                                   | 長所                                                                                                                                  | 短所                                                                                                                                                                                                                                                                    |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A             | 使用武器変更と、1 パス目で追う射撃の stat（装弾数無限）にも `durationUntil: 'fullBurstEnd'` を書けるようにし、モダニアの定義を「フルバーストの終わりまで」にする                       | 窓の終わりがフルバーストの時刻表に結び付く                                                                                            | 説明文は「15 秒」で、フルバーストの終わりと書いていない。モダニアでは 15 秒とフルバーストの終わりが同じなので、録画で見分けられない。1 パス目の窓の登録（`frame/firstPass.ts` の `register`）と定義の検証（いまは射撃の stat に `fullBurstEnd` を書くと落とす）を変える |
| **B（推奨）** | 遅れの表の行に印 `windowFromActivation: true` を足す。印のある行のキャラは、`burstUse` で発火する効果の維持時間から効果の遅れを引く（窓の始まりは効果の発火、終わりは発動 + 維持時間） | 説明文の「15 秒」を発動から数える読みのまま、実測の「始まりだけが遅れる」形になる。変えるのは遅れの表の行と、効果を解決するところだけ | 印の無い行（イサベル・ニヒリスター・マナ）は今のまま窓ごとずれる。どちらが正しいかはキャラごとに確かめるまで分からない                                                                                                                                                  |
| C             | 行を足し、終わりのずれは未対応の notes に書く                                                                                                                                          | コードを変えない                                                                                                                      | 実測と合わないと分かっているずれをモデルに入れる                                                                                                                                                                                                                        |

- どの案でも、最後の発の 3〜6f の早まり（`317-08`）は残る。発の数の許容（± 15 発）の中で、原因は分からないので合わせ込まない。
- どの案でも、止まりの明けから最初の発まで撃たないこと（モデルは通常の MG の発を撃つ）は、モダニアの burst の未対応の notes に書く（2026-10-08 オーナーの判断）。

## 3. 案 B の実装

1. `burst/landing.ts`: `MeasuredBurstDelayRow` に `windowFromActivation?: true`。モダニアの行 `{ resourceIds: [260], delays: { hitFrames: 0, effectFrames: 6 }, windowFromActivation: true, claim: 'C-0452' }`。
2. 効果の解決: 印のある行のキャラの、トリガーが `burstUse`（`{ count: burstUse }` を含む）の `timed`・`weaponChange` の維持時間（フレーム）から `effectFrames` を引く。置き場所は、行を引くところ（`burstDelaysOf` を使う所）か、編成を組むところ（`applyCompositionToTeam` と同じ層）。sim と calc の両方に効くよう、共通の 1 パス目の前で直す。
3. 退化: 印の無い行と、行の無いキャラは変わらない。モダニアは、窓が [発動 + 7f, 発動 + 882f) になる（いまは [発動 + 1f, 発動 + 882f)）。
4. テスト: `stage11ModerniaTeam.test.ts` の窓とフルバーストの時刻の期待値を直し（経緯をコメントに足す）、印の単体テストを足す。照合: `317-03`〜`317-07`・`044-18`・`044-15`・`044-16` が許容内のまま。

# V-0617: エヌ：ミラクルフェアリーのバーストの回復は防御型の味方（クラウン）に付くか（撮影）

- 問い: エヌ：ミラクルフェアリーのバーストの「火力型の味方全体に、スキル発動者の最終最大HP の X% 回復」は、防御型の味方（撃たない操作のクラウン）には付かず、クラウンの S2（回復効果が適用された時、味方全体に攻撃ダメージ▲）を起こさないか
- 話題: スキル・キャラ固有
- 日付: 2026-11-01
- 状態: 調査中
- 派生元: `V-0480`

## 条件

- 対象は C-0617（仮説・推論）。定義は `data/skills/121.json` の burst の effects[0]（`heal`・`burstUse`・`allies`・`targetClass: "Attacker"`）。仮説は説明文の読みと、同じ行の攻撃力▲の絞り（C-0595）からの類推で、録画からは決めていないので、どの録画も再現に数えられる。回復が満タンの火力型の味方に付いて「回復効果が適用された時」を起こすことと、付くフレームは C-0618（確定）。
- 受け手はクラウン（330・防御型・II）。撃たない操作枠（AUTO 射撃 OFF）にする。撃たない操作枠には的の攻撃が当たらない（`0125-16`。V-0438）ので、クラウンはいつも満タンで、回復が付けば満タンのまま起こす（C-0618 と同じ形）。
- 見るものは 2 つ。
  - **緑の回復の数字（主）**: 操作枠が受けた回復は、満タンでもその枠の上に緑の数字で出る（plan/captures/guide.md「回復の数字（操作枠）」。V-0456）。クラウンの上に、II の替わり目の約 21f 後（C-0618 の付くフレーム）に数字が出るかで、回復がクラウンに付いたかを直接見る。クラウンの S2 の起き方に依らない。
  - **クラウンの S2（従）**: 付けば、味方全体に攻撃ダメージ▲（ゲーム内の 7 秒。C-0271・C-0050）が付き、3 人の顔の下のアイコンと、フラワー・エヌ：ミラクルフェアリーの 1 発の値（攻撃ダメージ▲の乗数）に出る。1 発の値は sim と比べられる（下の「sim と比べる撃ち方」）。
- 受け手の選び方（plan/skill-catalog.md「回復効果が適用された時」の使い手は、アスカ（火力型）・クラウン・ネロ・シラツル（どれも防御型）だけで、支援型はいない）:
  - クラウンは機構が確定したキャラ（plan/skills.md の skill1・skill2・burst の効果がすべて確定の結論に結び付く）で、S2 の効果がダメージに出る。撃たないので、通常攻撃の条件（コア命中率・距離・弾丸命中率）は効かない。
  - ネロ（S1 は受けるダメージ▼）とシラツル（S1 は与えるHP回復量▼のスタック）は、効果がダメージに出ず、定義も無い。緑の数字で読むだけならどの防御型でもよいが、クラウンなら S2 で sim と比べる値も出る。
  - 支援型（自分以外）と自分（エヌ：ミラクルフェアリー）は、この撮影では見ない。H1 に合えば、C-0617 を「防御型には付かない」と「支援型・自分には付かない」に分ける（plan/verification-guide.md 2.2 節）。
- 未確定の要素と分け方:
  - クラウンの S2 が味方からの回復でも起きるか: 確かめたのは自分の回復（C-0271）だけ。緑の数字が出て S2 が起きなければ、回復は付いた（C-0617 の反例）うえで、クラウンの S2 のきっかけを別に問う。S2 の読みは、緑の数字の読みを足すだけで、C-0617 の読みには要らない。
  - エヌ：ミラクルフェアリーの S1 の吸収回復（通常攻撃 3 回ごと）が支援型の味方にだけ付くこと（C-0598。仮説・推論）: 外れて防御型にも付くなら、戦闘の始め（最初の II より前）からクラウンの上に緑の数字が出て、S2 も付き続ける。時刻で分けられる。そのときは C-0598 の反例として記録し、バーストの回の読みは、緑の数字の時刻（替わり目から約 21f 後）と量（発動者の最終最大HP の何 % か）だけで行う。V-0480 では火力型のアスカに S1 の吸収回復は付いていない。
  - エヌ：ミラクルフェアリーの S2 の受けるHP回復量▲（自分の HP が 90% 以上の間・味方全体。間接）: 緑の数字の量を変えうるが、有無と時刻は変えない。
  - フラワー（304）は味方に付く効果が無い（C-0072・C-0178）。クラウンは撃たないので、リラックスが溜まらず、自分の回復（C-0271）は起きない。
- sim と比べる撃ち方: **オートバースト ON**（V-0480 の手で押す撃ち方は `manualBursts` で III を撃たない形を表せなかった）。III がいないのでフルバーストは起きず、II の後 600f でチェーンが切れ、ゲージは 0 に戻る（C-0009）。オートバーストは同じ段の候補のうち左を撃たせ、左が CT なら右を撃たせる（C-0663・C-0664）ので、II はエヌ：ミラクルフェアリー（左・CT 60 秒）が撃てる回はエヌ：ミラクルフェアリー、その CT の回はクラウン（右）になる。クラウンのバーストは攻撃ダメージ▲（C-0393・C-0499。確定）だけで回復は無いので、クラウンの回は H1・H2 で同じ値の対照になる。比べるときは、撃たないクラウンを `holdFire`（戦闘の全体）で入れる。撃たない形のモデル（`holdFire`）では、180 秒の中にエヌ：ミラクルフェアリーの II とクラウンの II が交互に 2 回ずつ起きる（2026-11-01 のモデル）。
- 火力型の対照（アスカ）は入れない。III のアスカがいるとフルバーストが起き、クラウンの S1（フルバースト開始時）とアスカのバーストが混ざる。撃たない操作枠は 1 つしか作れないので、アスカを入れても AI で撃って被弾する。回復が満タンの火力型に付くことは C-0618 で確定しており、エヌ：ミラクルフェアリーがバーストを撃ったことは右のバースト欄で読める。
- 的は BigArms（灼熱タブ）・射撃場 3 分モード・スペック固定 ON。フラワーとエヌ：ミラクルフェアリーは AI で撃つ（AUTO 射撃の ON/OFF は操作のクラウンにだけ効く）。
- 本数は 2 本（反復実測を 1 回の撮影で狙う）。1 本の中にもエヌ：ミラクルフェアリーの II が 2 回ほどあり、回ごとに読む。

## 読み方

1. 取り込みの後、戦闘履歴のパネルで枠順・操作枠（クラウン）・クラウンの与ダメージ 0 と盾の欄 0 を確かめる。盾の欄が 0 でなければ、満タンの読みには使わない（付く・付かないの読みには使える）。
2. 右のバースト欄で、回ごとに I・II の替わり目と、II を撃った枠と、チェーンが切れたことを読む（`npm run records:read -- <録画> --recipe burst-panel`）。
3. クラウンの上の緑の数字を、純緑の画素の数で 1f 単位で拾い（plan/captures/guide.md「回復の数字（操作枠）」）、出たフレームと量を切り出しの画で確かめる。最初の II の前と、クラウンの II の回も読む。
4. 3 人の顔の下のアイコンを、枠ごとの青の画素の割合で読み（plan/captures/guide.md「枠の下のバフのアイコン」。V-0451）、付いた・消えたフレームを確かめる。
5. フラワー・エヌ：ミラクルフェアリーの 1 発を、HUD の総ダメージの増分で、エヌ：ミラクルフェアリーの II の後 7 秒の中と外、クラウンの II の後で読む（V-0457 と同じ読み方。`--recipe hud-jumps`）。
6. 読んだ値は観測値にする（`source` に `V-0617`）。緑の数字・アイコンの時刻は比べる指定なしの記録（`scope` つき）。1 発の値は `hitDamage` で、撃たないクラウンを `holdFire`（戦闘の全体の区間の `use: input` の観測値）で入れて sim と比べる。

## 条件

**5 体の振り分け**

**リバーレリオで何を確かめるか**

- リバーレリオ（262。SR・押下チャージ型・チャージ 1.5 秒・最大装弾数 6・リロード 2 秒・発射レート 200rpm・即着弾）は、チャージ時間がアニス：スター・ネオン：ビジョン・アイ（1 秒）と違う。モデルはアニス：スターの形を当てている（`frame/firing.ts` の `FiringParams.downCharge`。`damage.ts` の注記 `down-charge`）。
- 発射レートの 1 発分はチャージより短いので、発射レートの下限（シンデレラ S1 編の論点 2。C-0603）は効かない。

**編成**（最小構成）

- リバーレリオ単騎・操作・AUTO 射撃 ON・オートバースト OFF。単騎なので、HUD の総ダメージの増分はリバーレリオの発（と S1 の追加ダメージ）だけ。バースト段階 III の単騎はバーストを使えない（フルバーストも起きない）。
- リバーレリオのスキル定義は無い（`data/skills/262.json` が無い）。説明文の効果のうち、発の刻みに効きうるのは S2 だけ:
  - S2 の「フルチャージ攻撃が命中した時、対象がターゲットではないラプチャーなら、緩流: チャージ時間 1 秒で固定」。射撃場の的（BigArms）は「ターゲット」に当たる（C-0410。ネオン：ビジョン・アイの「対象がターゲットなら」の追加ダメージが出る）ので、緩流ではなく激流（攻撃ダメージ▲。刻みに効かない）が付く見込み。緩流が付いたなら、マガジンの中が 1 秒のチャージの間になるので、a で見分けられる（下の表）。
  - S2 の「チャージ速度増加効果無効・チャージ速度減少効果無効」: 単騎で自分にチャージ速度の効果を付けるものは無く、効かない。
  - S1 の「フルバーストタイムが発動した時」の 2 つ（攻撃力▲・味方へのチャージ速度▲）はフルバーストが起きないので出ない。コア命中時の攻撃ダメージ▲と、フルチャージ命中時の追加ダメージは 1 ヒットの値だけに効く。

## 予測（撮る前に書く）

仮説は 2 つの軸に分ける。どれもコードか定義を切り替える仮説なので、予測ファイル（records/predictions/V-0596.json）は、いまのモデル（H1・R1）での戦闘の始まりから 1 回目の的のジャンプの前までの発と発の間だけを持つ。下の表の H0・R2・緩流の値は、チャージ 1.5 秒 = 89f、チャージ 1 秒 = 59f、解放 23f（C-0143）、リロード 2 秒 = 117〜118f（予測ファイルの R1 の値から逆算）で手で出した。

**発と発の間（マガジンの中）**

| 仮説                                                     | 間                           |
| -------------------------------------------------------- | ---------------------------- |
| H1: 押下チャージ型は解放を足さない（いま。予測ファイル） | 89f                          |
| H0: 解放を足す                                           | 112f                         |
| 緩流が付く（H1 のまま、チャージ時間 1 秒の固定）         | 59f（マガジンの 2 発目から） |

**リロードを挟む間隔（最終弾 → 次のマガジンの 1 発目）**

| 仮説                                                                                 | 間        |
| ------------------------------------------------------------------------------------ | --------- |
| R1: リロード + チャージ + 解放 23f（いま。予測ファイル）                             | 229〜230f |
| R2: リロード + チャージ（解放なし）                                                  | 206〜207f |
| 緩流が付く（R1 のまま、チャージ時間 1 秒の固定。緩流は「持続」なのでリロードを跨ぐ） | 199〜200f |

- アニス：スター・ネオン：ビジョン・アイ・シンデレラの b は、どれも R1 より 1〜2f 長かった（C-0222・C-0603）。リバーレリオでも同じ差が出るかを見る（探索。原因は分かっていない）。
- 見分けられるのは、どの仮説の間の差も 20f 以上あり、許容（a ±1f・b ±2f。V-0528 の比べと同じ）より十分大きいから。
- 外れたときの影響: H0 ならリバーレリオの発の数が約 15% 減る（1 マガジンの周期が 5 × 89 + 230 = 675f から 790f に延びる）。緩流が付くなら、射撃場の的の「ターゲット」の読み（C-0410）を見直す。

## 読み方

1. 録画の全体を `npm run records:read -- <録画 id> --recipe hud-jumps` で読む。単騎で即着弾なので、1 つの増分が 1 発（通常攻撃の 1 ヒットと、S1 の追加ダメージ（「5回発動」）が同じフレームに出る見込み）。発の値の組（胴体・コア × 会心）と違う増分は発と数えない（[captures/guide.md](../../plan/captures/guide.md)「画面の読み方」の単騎の射撃の刻み）。増分が拾えないフレームは、照準の横の残弾（`reticle-ammo.ts`）が減ったフレームで補う（同じ節の操作中の SR の射撃）。リロードの完了の時刻も見たくなったら、レシピ `reload-segments` で最終弾 → 完了・完了 → 次の発に分ける（探索。R1 との 1〜2f の差の置き場所の手がかり）。
2. 増分の間が 150f を超える所でマガジンに分け、6 発ずつそろうかを見る。的のジャンプの窓（guide「射撃場の条件」）を挟む間は除く。ジャンプの始まりの直後の部分チャージの発（guide「原則」の SR の注意。入力が UP の SR で起きる）が無いかも見る（押下チャージ型は部分チャージで撃たない。V-0134 の探索。いまのモデルどおり）。
3. 観測値にする（単位 f）:
   - a. マガジンの中の発と発の間: 的のジャンプを挟まないマガジンの間の列（`use: record`）と、戦闘の始まりから 1 回目のジャンプの前までのマガジンの平均（`shotIntervalMean`。`use: compare`。範囲はモデルのそのマガジン）。
   - b. リロードを挟む間隔: ジャンプを挟まない全部の列（`use: record`）と、1 回目のジャンプの前の間（`shotIntervals`。`use: compare`。予測ファイルの指標 `early-intervals` と同じ範囲・setup にして、予測と結び付ける）。
4. 判定: a が 89f・112f・59f のどれにそろうかで H1・H0・緩流、b が 229〜230f・206〜207f・199〜200f のどれかで R1・R2・緩流。

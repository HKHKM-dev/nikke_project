# V-0101: シンデレラ（RL・曲射）単騎 AUTO の区間ごとのコアの外れ

- 問い: シンデレラ単騎 AUTO の通常攻撃（曲射の弾）がコアを外す割合は、区間（距離帯）ごとにいくらか
- 話題: 命中率・距離
- 日付: 2026-10-02
- Stage: plan/backlog.md 2-13（`V-0097` の 1 キャラ）
- 状態: 保留
- 待ち: 撮影（シンデレラ単騎・AUTO・180 秒の 1 本。「次に撮るもの」）
- 派生元: `V-0097`

## 条件

- `V-0097` の弾の種類のうち、曲射（`ProjectileCurve`。弾速 1500・爆発の範囲 50）。曲射の RL はこのキャラだけ。モデルは曲射の弾を扱わない（damage.ts が「曲射型の弾は未対応」で止める）ので、この記録は弾の種類の表を埋める探索。
- シンデレラ（511）は SSR・Defender・電撃・バースト 3 段階。通常攻撃は装弾数 24・連射速度 180・チャージ 1 秒・入力 `DOWN_Charge`（キャラデータの `shot`）。射撃の刻みはこの録画で読む。
- 最小構成は単騎（`V-0097`「条件」）。スキルの見込み（スキル定義は無い）:
  - S1: フルチャージの攻撃でチャージ速度▲（全弾のリロードで解除）。フルチャージ攻撃が命中したとき、対象に追加ダメージ（最終攻撃力の割合）。HUD の増分は 1 ヒット + 追加ダメージになる見込み。バースト 3 段階突入の攻撃力▲は単騎では起きない。
  - S2: 戦闘開始時にデコイ（分身）、デコイがある間は最大 HP▲のスタック。ダメージには効かない見込み（最大 HP は攻撃力に効かない）。
  - バースト: 単騎ではバースト 3 段階のバーストを使えないので起きない（自動バースト OFF）。

## 予測（撮る前に書く）

探索。モデルは曲射の弾で 1 ヒットの値を出せない（未対応）ので、予測ファイルは作らない（予測なし）。`V-0097`「予測」の H1a で弾速だけが効くなら、弾速 1500 は速いのでほぼ 0 になる。曲射の弾の飛ぶ時間（弧を描く道のり）は分からないので、それ以上は予測しない。

## 読み方

1. `tools/captures/intake.ts` で取り込む（`--rid 511 --controlled 1 --target BigArms --element Fire --mode range-3min --fixed-spec on --auto-fire on --auto-burst off`）。台帳を埋めて `npm run records:table`。
2. `npm run records:read -- <録画 id> --recipe hud-jumps` で増分の列を出し、撃ち始めの数発で 1 ヒット（+ S1 の追加ダメージ）の値の組（胴体・コア × 会心）と射撃の刻みを決める。値はキャラデータの `shot.damage`（武器倍率）とスペック固定の攻撃力から手で見積もり、コアと胴体の比（2 倍）で組を確かめる。
3. `V-0097`「読み方」の 1 と 3 のとおり、区間ごとに「撃った発（部分チャージの発を除く）」「コアを外した発」「そのうち着地の後の 1 発目」を観測値（`use: "record"`、`source: V-0101`）にする。区間の切れ目（的のジャンプの窓）はこの録画で読む。
4. 比べと判定は `V-0097` で行う。この記録は、`V-0097` の結論ができたら、その結論を裏付けた記録として閉じる（曲射の弾が仮説の並びに入らないときは、分かったことを書いて打ち切りにする）。

# V-0279: エーテル・ラピの S2 のヒットはバーストゲージを溜めるか（探索）

- 問い: イサベルの S2（C-0404）と同じく、周期で発動するエーテルの S2（C-0405）とラピの S2（C-0403）のヒットも、射手の target_burst_energy_pershot（どちらも 4,000）のゲージを溜めるか。HUD の増分が S2 だけのフレームで BURST バーが伸びるかを見る
- 話題: バーストゲージ
- 日付: 2026-10-07
- 録画: `018`、`073`、`221`
- 結論: `C-0409`
- 状態: 完了

## 条件

- V-0273 で、イサベルの S2 のヒットはゲージを溜める見込みになった（C-0404）。同じく説明文にきっかけが無く周期で発動するエーテル（C-0405）・ラピ（C-0403）の S2 でも同じかを、同じ読み方で見た。どちらも `target_burst_energy_pershot` は 4,000（バー 113px の約 0.5px）。
- 録画: S2 のフレームを読んだ 018（エーテル）・221・073（ラピ）。019 のエーテルの S2 は、どの回もバーが 0 か読めなかった。

## 予測（撮る前に書く）

探索（予測なし）。

## 読み方

- 各録画の S2 のフレーム（`018-22`・`221-09`・`073-19`）の前後 3 フレームを `node tools/captures/gauge.ts <録画> --mode series` で読み、バーが読めて 0 でも 100% でもない回（ラピの 221 の f2093 は 0 から伸びた回）だけを並べた。

## 結果

- エーテル（018）: 4 回のうち 3 回（f2459・4778・9418）で、直前まで平らだったバーが S2 のフレームでちょうど 1px（+0.8〜0.9%）伸び、1 回（f7099）は伸びなかった。
- ラピ: 221 の f2093（0 → 0.9%）と 073 の f2070（85.0 → 85.8%）で、どちらも S2 のフレームで 1px 伸びた。073 は 1 回目の満タンの後、バーが 0 の表示のまま（単騎で III が撃てない）で、残りの 7 回は読めない。
- イサベル（V-0273）の 5 / 8 と合わせて、3 体で 10 / 14。前後のフレームのバーは平らで、S2 のフレームにだけ 1px の伸びが重なる偶然は起きにくい。

## 分かったこと・分からないこと

- 分かったこと（C-0409、仮説・推論）: エーテル・ラピの S2 のヒットもゲージを溜める。量は 1px 未満で、4,000 の形と矛盾しない。
- 分からないこと: 量（px より細かい読みが要る）。

- 判定（読む前に決めた）:
  - 遠 A・遠 B の差は、新しい 2 本（289 の遠 A と 288 の遠 B）の窓の外の発の合計で Fisher の正確検定（両側）。p < 0.05 で、向きが L1 と同じ（遠 A が高い）なら「違う」（L1）。p ≥ 0.05 なら「見分けられない」。仮説の出どころの 4 本（V-0297）は、遠 A の中でも録画どうしで食い違う（164 と 320・321。p = 0.043）ので、合計の検定は参考にとどめ、判定に使わない。
  - 観測値の比べの許容は ±0.25（V-0297 と同じ）。
  - MG は、遠の区間のヒットを距離ボーナス付きと無しの格子に分けた数で決める（どちらかがほぼ全部なら D0・D1。混ざるなら「境目を跨ぐ」として判定なし）。
- 見分けられるか: 遠の区間は約 38 秒で、288・289 は遠の区間にもバーストの窓がある（手で、クールタイムごと）ので、窓の外の発は 1 本あたり 15〜25 発の見込み。差 0.23 だと Fisher の検定で見分けられる見込みは 3 割ほどで、見分けられないことが多い。MG は 1 本の遠の区間で数百ヒットあり、格子が重ならない値で見分けられる。
- 外れたときの影響: L1 なら、表の遠の行を遠 A・遠 B に分ける案（10-06 の判断を変える）をオーナーに諮る。D1 なら、遠 B の距離の範囲を 55 より遠くに直す案（SR・RL・MG など `bonusRange` の上端が 55 の武器種の遠 B の距離ボーナスが外れる）をオーナーに諮る。

## 分かったこと・分からないこと

- 分かったこと: アニス：スターに効く遠の値で、着地点ごとに違うと言えるものは、誘導弾の飛ぶ時間（C-0413。既知）のほかに見つからなかった。コアの割合は遠 A・遠 B で見分けられず（新しい 2 本で向きも逆）、距離ボーナスは RL に無く、弾丸命中率は 1。2026-10-06 の判断の条件（遠 A・遠 B で違う値の表が見つかったら分ける）に当たる値は無いので、**アニス：スターのモデルは 1 か所（帯の値）のまま**にする。
- 分かったこと: 遠 B でも MG に距離ボーナスが乗る（C-0497。仮説）。遠 B の距離は MG の範囲の上端 55 を超えず、モデルの遠 B の距離の範囲 45〜55（C-0477）と矛盾しない。
- 分からないこと: 遠のコアの割合が録画ごとに食い違う原因（遠 A の中でも遠 B の中でも食い違う。V-0297 と同じ）。288・289 の窓の外の数を、表の遠の行（C-0425。2026-10-08 のオーナーの判断で 5 本の合計）に足すかは決めていない（足すと 70/126 = 0.556）。
- 結論: C-0425（仮説）は文のままで正しい（遠 A と遠 B の差も言い切れない）ので変えない。MG の遠 B の距離ボーナスを C-0497 にした。099 に最小構成の警告（ルドミラ：ウィンターオーナーの S1・S2 の未確定の効果）が残り、警告の無い 226 は 1 本なので、仮説にした。
- ID の振り直し: main と重なったため V-0375 → V-0376、C-0496 → C-0497（plan/design-stage20.md 3.6 節）。予測の commit 18b0667 と読んだ後の commit は、振り直す前の ID のまま `claude/anis-star-far-landings-prerename` ブランチに残した。

# V-0648: チャージの無い武器のハイド中のリロードの始まり（AR・SMG・MG・SG の読み直し）

- 問い: 射撃姿勢維持型でない、チャージの無い武器（AR・SMG・MG・SG）のハイド中のリロードは、チャージ武器と同じく窓の始まりの約 8f 後（D）から始まるか（C-0844 のチャージの無い武器への当てはまり）
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-03
- 録画: `0250`、`0251`、`0443`、`0444`、`0305`、`0306`、`0853`、`0854`
- 結論: `C-0844`
- 状態: 完了

## 条件

- 型: 読み直し。課題 2-52（[design-hide-reload-detect.md](../../plan/design-hide-reload-detect.md) 6 節の 3）。C-0844 の D（8f）は、チャージ武器（押下チャージ型を含む）の録画だけで決めて再現した（V-0609・V-0610・V-0615・V-0620）。モデルはチャージの無い武器にも同じ D を掛けている（`frame/shooter.ts` の `beginHide`・`stepHide`）。
- 見分けの要: マガジンの途中に来たジャンプの、ハイド中のリロードの RELOADING のバーの 0 の点（当てはめで長さ 0 に遡った点）から明けまで。
  - D から始まるなら約 110f、窓の始まりから始まるなら約 118f（窓の長さ）。
  - ハイド中のリロードが明けまでに満ちない（取り消される）キャラなら、バーが消えたフレームが明けなので、0 の点 → 明けが 1 つのバーから直に読める。リロードの秒 + 約 12f（C-0841）が約 118f より長いキャラ（リロード約 1.8 秒以上）はどちらの形でも取り消される。
  - リロード 1.67 秒のキャラ（バーの長さ約 110f）は、D から始まれば明けまでに満ちず（取り消し）、窓の始まりから始まれば明けの約 8f 前に満ちる。ジャンプの間に終えるか（明けの後に同じマガジンの残りを撃つか、満タンから撃つか）でも見分けられる。
- 選んだ録画（どれも単騎・操作・オート射撃 ON・オートバースト OFF・射撃場 3 分モード・BigArms（灼熱））: 武器種ごとに、リロード速度に効く効果が単騎で出ないキャラ。
  - AR: マナ（1.67 秒。`0250`・`0251`。スペック固定 OFF。キューブはリロード速度の無いもの（`0251` のタクティカルブーストキューブは最大装弾数）。V-0224 の録画のうち、リロード速度▲のキューブの `0252` は除いた）。
  - MG: エマ（2.5 秒。`0443`・`0444`）。
  - SMG: ルドミラ（2.76 秒。`0305`・`0306`。スペック固定 OFF。`0306` はレリックベアーキューブ Lv15 でリロードが短いが、ハイド中のリロードは明けまでに満ちない）。
  - SG: エーテル（2 秒。分割リロードでない。`0853`・`0854`）。
  - どのキャラも、スキルにリロード速度・装弾の効果が無いか、フルバーストの間だけの効果で、単騎・オートバースト OFF では出ない。
- D（8f）を決めるのに使った録画（C-0844 の `decidedOn`）は入っていない。この 8 本は、D を決めた後に、モデルの D を変えずに読んだ。

なし（読み直し）。

## 読み方

1. 録画は Drive から取り寄せた（`node tools/captures/fetch.ts`）。`node tools/captures/hud.ts <動画> --mode jumps`（増分が撃ったフレーム）と `node tools/captures/reload.ts <動画> --mode fit`（バーの 0 の点・消えたフレーム・満ちるまでの長さ）。
2. ジャンプは、増分が空いた所のうち、マガジンの終わりでない（前のリロードの後の発の長さが 1 本のマガジンより短い）所。取り消されたハイド中のリロードのバー（満ちる前に消えた）の、0 の点 → 消えたフレームを読む。
3. 録画の窓は V-0621 と同じ決め方（ハイド中のリロードのバーが消えたフレームを明けにし、その 2 秒前を始まり）。明けが読めない回（マガジンの終わりのリロードと重なった回など）は、この 8 本で明けが両方読めた間の長さ（1→2・3→4 回目 2140f、4→5 回目 1952f。C-0546）で隣の回から置いた。戦闘開始は最初の増分の 12f 前（C-0114）。窓は `0250-11`・`0251-06`・`0443-03`・`0444-03`・`0305-11`・`0306-11`・`0853-08`・`0854-07`。
4. モデルは録画の窓で回し、窓の中のハイド中のリロードの始まりから窓の終わりまで（`hideReloadToWindowEnd`）と比べる（V-0621 と同じ指標）。

## 分かったこと・分からないこと

- 分かったこと: チャージの無い武器（AR・SMG・MG・SG）のハイド中のリロードも、D から始まる（C-0844 の形）。D を決めるのに使っていない 4 キャラ・8 本の 25 回で再現した。C-0844 の根拠に足した（モデルは変えない）。リロード 1.67 秒のキャラは、マガジンの途中のジャンプの間にリロードを終えない（マナの 8 回）。
- 分かったこと（新しく）: チャージの無い武器は、窓の始まりから D までの間も撃ち続け、最後の発の直後からハイド中のリロードが始まる。モデルは窓の始まりで撃つのを止めるので、ジャンプごとに約 D 分の発が少ない。チャージ武器では、この間はチャージの途中で D の後に部分チャージで撃つ（C-0840）ので、窓の始まりから撃たないことと同じに見えていた。直す案は設計書に起こしてオーナーの承認を得る（モデルは変えていない）。
- 分からないこと: SG（発と発の間が D より長い）で D までに撃つ発があるか。窓の始まりから D までの間の発が的に当たるか（HUD の増分は出ているので当たっている）と、着地点の区間の切れ目（`setup.jumpWindows` の始まり）をどう置くか。

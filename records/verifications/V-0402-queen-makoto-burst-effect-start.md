# V-0402: クイーン（真）のバーストの攻撃力▲と S2 の有利コードの▲は、III のタイマーの 00.00 の何 f 前から発に乗るか（録画 229・230 の読み直し）

- 問い: クイーン（真）（III）のバースト使用時の攻撃力▲（風圧）と S2 の有利コードの攻撃ダメージ▲は、III のタイマーの 00.00 の何 f 前から発に乗るか（HA・HD・HM のどの形か）

- Stage: backlog 2-4（plan/burst-effect-delay-candidates.md の P3。III の自分への効果）

## 条件

**何を確かめるか**

- 遅れの表にクイーン（真）（870）の行は無く、バースト使用時の効果は本当の発動（III のタイマーの 00.00 の 6f 前。C-0516）で付く。見るのは 2 つ:
  - burst の effects[1]: 自分の攻撃力▲（風圧の敵のときだけ。10 秒。C-0308）。
  - skill2 の effects[2]: 有利コードの攻撃ダメージ▲（バースト使用時からフルバースト終了まで。有利の敵にだけ属性の倍率に足す。C-0307）。クイーン（真）は灼熱なので、風圧の的（229）で効き、灼熱の的（230）では効かない。
- III のバースト使用時の効果は、00.00 より前（入りの止まりの前）の発に乗るキャラが多い（C-0510・C-0511・C-0513）。形はキャラごとに違う（V-0399。HA: 00.00 の 5〜6f 前・HD: 1〜2f 前・HM: 00.00 の後）。
- 230（灼熱）では 2 つとも効かないので、00.00 の前の発の値は変わらないはず（対照）。

**編成**

- 録画 `229`（風圧）・`230`（灼熱）: ラム（822。I）+ デルタ（20。II）+ クイーン（真）（870。III・操作・AUTO 射撃 ON）、オートバースト ON。射撃場・BigArms・3 分モード・スペック固定 ON（V-0211・V-0212）。
- **最小構成**: ラム・デルタはダメージに効く効果が無い（C-0252 の根拠と同じ）。クイーン（真）のほかの効果のうち 00.00 の前の発に効くのは、S1 の戦闘開始時・フルバースト終了時の攻撃力▲（C-0270・C-0392。00.00 の前後では付いたまま変わらない）、ペルソナの属性ダメージ▲（常時）、S2 の攻撃ダメージ▲（常時）、S2 のフルバースト III 段の分配ダメージ▲（分配ダメージにだけ効く）。どれも確定で、00.00 の前の数 f で変わらない。

**読み方の前提**

- SG で、1 トリガーに複数のペレットが同じフレームに当たり、HUD の増分は 1 トリガーの和。1 ペレットの単位（倍率グループ 0.5 分）で割った整数で読む（`229-01`〜`229-03` の注記の読み方）。攻撃力▲（風圧）と有利コードの▲で単位が変わるので、00.00 の前のトリガーの単位が、バーストの前の単位か▲の付いた単位かで分ける。
- 00.00 の前は入りの止まりの前で、補正はまだ乗らない（`192-15`・`258-18`）。
- バーストの分配ダメージ（100 万を超える増分）とその 23〜24f 後の追撃（`229-07`）は値で分ける。

## 予測（撮る前に書く）

読む前に書いた（2026-10-10。手計算。予測ファイルは無い）。比べるのは、各回の 00.00 の 8f 前から 1f 前までのクイーン（真）のトリガーに▲があるか。

| 仮説                                                   | 00.00 の 6〜3f 前のトリガー | 2〜1f 前のトリガー | 00.00 の後（止まりの明け） |
| ------------------------------------------------------ | --------------------------- | ------------------ | -------------------------- |
| H0: いまのモデル（本当の発動 = 00.00 の 6f 前。HA 形） | ▲あり                       | ▲あり              | ▲あり                      |
| HD: 00.00 の 1〜2f 前                                  | ▲なし                       | どちらも           | ▲あり                      |
| HM: 00.00 の後                                         | ▲なし                       | ▲なし              | ▲あり                      |

- 予想: **HD**（V-0399 の多くのキャラの形）。攻撃力▲と有利コードの▲は同じ `burstUse` のきっかけなので同じ時刻に付く。
- 230（灼熱）: どの仮説でも 00.00 の前のトリガーの単位はバーストの前と同じ。
- 既に見ていた値: `229-01`〜`229-08`・`230-01`〜`230-05`（窓ごとの単位と、バーストのヒットの値・フレーム）。00.00 の前のトリガーの値は誰も読んでいない。
- 見分けられない場合: SG は発が疎（トリガーの間隔は数十 f）なので、00.00 の 6〜1f 前にトリガーの無い回は数えない。
- 外れたときの影響: 1 回のバーストで、00.00 の前の 0〜1 トリガーの▲の有無。モデルは直さない（plan/burst-effect-delay-candidates.md 2.7 節の案 C）。差は結論の `model` に書く。

## 読み方

1. III のタイマーの 00.00: `timer.ts --mode stalls` の 22〜23f の止まりの位置から候補を出し、III のタイマーの欄を 1 フレームずつ切り出して 00.00 になったフレームを読む（`221-01` と同じ読み方）。
2. HUD の増分（`hud-jumps@2` のキャッシュ）を、各回の 00.00 の 60f 前から止まりの明けの 10f 後まで並べ、クイーン（真）のトリガーを単位の整数に当てる（ラム・デルタの SR の発と重なった増分は分ける）。
3. 00.00 の前で▲の無い最後のトリガーと、▲の付いた最初のトリガーのフレームを記録する。

## 分かったこと・分からないこと

- **C-0522（仮説）**: クイーン（真）のバーストの攻撃力▲は HD の形（00.00 の 1〜5f 前に付く）。S2 の有利コードの攻撃ダメージ▲は 00.00 より後（止まりの明けまで）に付く。モデル（どちらも本当の発動 = 00.00 の 6f 前）とは、1 回のバーストで 00.00 の前の 0〜1 トリガーの▲の有無が違う。
- 分からないこと: 攻撃力▲の付き始めの 5〜2f 前の中の位置。有利コードの▲が 00.00 のフレームか止まりの明けか（S2 のきっかけがバーストのヒットか、フルバーストの始まりか）。
- **最小構成**: C-0522 を burst の effects[1]・skill2 の effects[2] に結んだので、録画 229・259 を根拠にする確定の結論 6 件に警告が出た。比べる値はどれも窓の中の単位か止まりの後のヒットの値で、付き始めに依らない。それぞれの `minimal` に印を書いた（警告の件数は main と同じ）。

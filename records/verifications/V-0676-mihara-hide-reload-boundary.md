# V-0676: リロード 1.67 秒（ミハラ）の、敵のジャンプの間のハイド中のリロードが明けまでに満ちるか（0469・0470・0727・0728 の読み直し）

- 問い: リロード 1.67 秒のミハラの、マガジンの途中に来た敵のジャンプの間のハイド中のリロードは、明けまでに満ちるか。満ちないなら、C-0844 の D と C-0841 の満ちるまでの長さの境目の式から出るのか、値のずれか、窓の長さの違いか
- 話題: 射撃（間隔・リロード・チャージ）
- 日付: 2026-11-06
- 録画: `0469`、`0470`、`0727`、`0728`
- 結論: `C-0959`
- 状態: 完了
- 派生元: `V-0652`

## 条件

- 型: 読み直し。課題 2-54。V-0652 の読みで、ミハラ（161。AR・60 発・リロード 1.67 秒。III・操作）が、マガジンの途中に来た敵のジャンプの間にリロードを終えず、明けの後に残りを撃ってからリロードするのに、モデルは終えていることに気づいた。
  - `0469`・`0470`: ラム・デルタ・ミハラ（V-0432 の撮影）。`0727`・`0728`: アニス：スター・デルタ・ミハラ（V-0533 の撮影）。どれも射撃場 BigArms（風圧）・3 分モード・スペック固定 ON・オート射撃 ON・オートバースト ON。
- 見分けの要: ハイド中のリロードは、窓の始まりの D（8f。C-0844）後から始まり、RELOADING のバーが満ちたとき（リロードの秒 + 約 12f。C-0841）に残弾が満ちる。リロード 1.67 秒は 98.24f で、窓（2 秒 = 117.6f。C-0546）に対して 8 + 98.24 + 12 = 118.24f と、明けとの差が 1f に満たない境目にいる。
  - 満ちるか: 明けの後にマガジンの残りを撃ってからリロードするか（照準の残弾）、バーが満ちて消えるか、満ちる前に消えるか（バーの長さ）。
  - 境目のどの値が効くか: 窓の中のバーの 0 の点 → 明け（窓の長さ − D）と、同じ録画のふだんのリロードのバーの 0 の点 → 満ちて消えるまで（満ちるのに要る長さ）を、同じ道具で直に比べる。
- 最小構成: ミハラのリロードと発の刻みに効く効果は、ミハラにも味方にも無い（どのキャラにもリロード速度・装弾の効果が無い）。アニス：スターのバーストの効果は自分のものとヒットだけで、ミハラのリロードに効かない（C-0959 の `minimal`）。

## 読み方

1. 録画は Drive から取り寄せた（`node tools/captures/fetch.ts`）。
2. `node tools/captures/reticle-ammo.ts <動画> --mode series`（照準の残弾。ミハラは操作キャラ）で、残弾が減ったフレームを発にした。マガジンの途中（残弾が 1 より多い）で 40f より長く空いた所を拾い、HUD の増分（`hud.ts --mode jumps`）で、ジャンプの前の最後の発（0〜1f で合う）と、ほかの止まり（フルバーストの入り・照準の読めないフレーム）でないことを確かめた。
3. `node tools/captures/reload.ts <動画> --mode fit --shots <hud の出力>` で、RELOADING のバーの 0 の点（伸びを長さ 0 に遡った点）・消えたフレーム・見えた最大の長さ・伸びの速さを読んだ。窓の中で消えたバーは、消えたフレームを明けにした（V-0621・V-0648 と同じ）。窓の始まりは明けの 2 秒（117.6f）前。
4. ふだんのリロード（最後の弾の後。窓と重なった回・取り消しの回を除く）のバーの「完了 − 遡った 0 の点」の平均を、満ちるのに要る長さにした（`reload.ts --shots` の集計）。
5. モデルは、V-0652 の比べる設定（`{"enemy":"range-bigarms-wind","events":["range-3min-jump"]}`）で回し、枠 3 の発とハイド中のリロードの始まり（`ShotLog.hideReloadStarts`）を窓ごとに見た。

### 読み

- マガジンの途中に来たジャンプは、4 本で 10 回（`0469` の 1・2・5 回目、`0470` の 1・2・4 回目、`0727`・`0728` の 1・2 回目）。ほかの回は、ジャンプの前にマガジンを撃ち切っていて、弾切れのリロードと重なった（ハイド中のリロードが無い）。`0727`・`0728` にも、マガジンの途中に来たジャンプが 2 回ずつあった。
- 10 回とも、ハイド中のリロードは明けまでに満ちない（`0469-15`・`0470-15`・`0727-21`・`0728-22`）。ジャンプの前の最後の発の後の残弾（10〜49 発）が、明けの後の最初の発で 1 減り、残りを撃ち切ってから弾切れのリロードをした。
- 発のフレームと窓は `0469-14`・`0470-14`・`0727-20`・`0728-21`。ジャンプの前の最後の発は、バーの 0 の点の 0〜3f 前（V-0648 と同じ。窓の始まりから D までも撃ち続ける。C-0912）。
- バーの 0 の点 → 明けは 108.97〜110.97f（`0469-12`・`0470-12`・`0727-18`・`0728-19`。110.97f の 1 回は重複フレームを 1 つ含み、除くと 108.97〜110.13f）。バーは満ちる前（溝 367px のうち 361〜365px）に消えた。伸びの速さはふだんのリロードと同じ（当てはめの「溝の幅 ÷ 伸び」が 109.3〜110.2f で、ふだんの回の約 110f と同じ）。
- 同じ録画のふだんのリロードのバーの 0 の点 → 満ちて消えるまでは、平均 110.62〜110.80f（`0469-13`・`0470-13`・`0727-19`・`0728-20`。22〜24 回ずつ）。ハイド中のリロードは、これより約 0.7f 短い所で明けとともに取り消された。

### 境目の式と比べる

| 値                       | 結論・観測値      | 丸めない値                                                | モデル（いま）                                |
| ------------------------ | ----------------- | --------------------------------------------------------- | --------------------------------------------- |
| 窓の長さ                 | C-0546（2 秒）    | 117.6f                                                    | 117 か 118f（始まりと終わりを別々に四捨五入） |
| D                        | C-0844            | 8f                                                        | 8f                                            |
| リロードの秒             | データ（1.67 秒） | 98.24f                                                    | 98 か 99f（端数を持ち越して切り捨て。C-0145） |
| 満ちるまでに足す長さ     | C-0841（約 12f）  | 12f（ふだんのリロードのバーから 12.4〜12.6f）             | 12f                                           |
| 窓の始まりから満ちるまで | —                 | 8 + 98.24 + 12 = 118.24f（バーからは 8 + 110.7 = 118.7f） | 118 か 119f                                   |
| 満ちるか                 | —                 | 満ちない（明けの 0.6〜1.1f 後）                           | 118f の窓で 98f の回は明けの 1f 前に満ちる    |

- 録画どおり満ちないのは、境目の式（C-0841・C-0844）を丸めずに当てた形から出る。録画で直に測った長さでも、0 の点 → 明け（約 110.0f）が、満ちるのに要る長さ（約 110.7f）より短く、同じ向き。
- D と約 12f の値はずれていない。0 の点 → 明けから D を出すと 117.6 − 110.0 ≈ 7.6f（回によって 7.5〜8.7f）、満ちるのに要る長さから足す長さを出すと 12.4〜12.6f で、どちらも結論の「約」の幅の中。
- 窓の長さは録画ごとに違わない。0 の点 → 明けは 4 本とも約 110f（重複フレームの回を除いて 108.97〜110.13f）で、マナの単騎（`0250`・`0251`。V-0648）の 109.5〜111.1f とも同じ。
- モデルが満ちるのは、整数のフレームに丸めるため。モデルは窓を 117 か 118f、リロードを 98 か 99f に丸め、118f の窓で 98f の回は 8 + 98 + 12 = 118f で明けの 1f 前に満ちる。0469 の比べる設定では、1・4 回目の窓（118f・98f）で満ちて明けの後に 60 発を撃ち、3 回目（117f）は満ちない。
- 同じ 1.67 秒のマナも、録画の窓（`0250-11`）で回したモデルは 1〜3 回目のジャンプの間に満ちる（明けの後に 1 本のマガジンの長さを撃つ）が、録画は 4 回とも満ちていない（`0250-17`。V-0648）。V-0648 では、窓の中のリロードの始まり（`hideReloadToWindowEnd`）を比べ、満ちたかは記録の観測値だったので、モデルとの違いが出ていなかった。

## 分かったこと・分からないこと

- 分かった: リロード 1.67 秒のミハラは、マガジンの途中に来たジャンプの間のハイド中のリロードを終えない（10 回）。マナの 8 回（V-0648）と合わせ、1.67 秒は満ちない側にいる。理由は境目の式を丸めずに当てた形（満ちるのに要る長さが、D から明けまでより約 0.7f 長い）で、D・約 12f・窓の長さのずれではない（C-0959）。
- 分かった（モデル）: いまのモデルは、窓とリロードを整数のフレームに丸めるため、1.67 秒のキャラが窓によって満ちる。直す案は [design-hide-reload.md](../../plan/design-hide-reload.md) 10 節。オーナーの判断（2026-11-06）で案 D（ハイド中のリロードの 1 回分を切り上げる）をモデルに入れ、C-0959 を指標なしで確定にした。入れた後のモデルは、0469 の比べる設定でミハラが明けの後に残りを撃ち、0250 の録画の窓でマナが 4 回とも明けまでに満ちない（録画と同じ）。比べる観測値の状態は変わらない。
- 分からない: 足す長さを 12f と 12.5f のどちらで数えるか（C-0135 の 11.2〜11.6f は最後の発から数えた長さで、バーの 0 の点はその約 1f 前。ふだんのリロードの和は C-0148 の 24f で合わせてあり、ここでは変えない）。境目は 1.67 秒のキャラ（データで 6 体）と、リロード速度▲で実効のリロードが約 97〜99f になる回でだけ効く。

## Context

射撃場の的（`data/enemies.json` の `range-bigarms`）の遠は、着地点が 1 か所（`far`）のまま。近（`nearA`・`nearB`）と中遠（`midFarA`〜`C`）は、着地点ごとの値を配分で混ぜる形になっている（`mixes`。区間の 1 トリガーの値を Σ w_k × T_k で足す。calc と sim で共通）。

- 遠の着地点が 2 か所あること（遠 A・遠 B）は V-0228 で読んだ（C-0333。仮説）。2026-10-06 のオーナーの判断で、遠 A・遠 B で違う値の表が見つかるまで分けないことにしていた。
- V-0328 で、SMG の遠の弾丸命中率が着地点で違うことを、撮る前に固定した目安で見分けた（判定は H2。遠 A 0.8068・遠 B 0.7608）。
- 2026-10-08 のオーナーの判断で、V-0328 の論点 1 は案 1A（目安どおり H2 として結論を作る）、論点 2 は案 2A（遠を 2 か所にする）。この設計書は案 2A の中身を決める。

## 1. 決めてほしいこと

1. **遠の着地点と配分** — 推奨: 遠を `farA`・`farB` の 2 か所にし、配分 `mixes.far` を **0.52 : 0.48** にする。
   - 配分は、遠の足元を V-0228 の規則で読んだ単騎の録画 129 本（V-0228 の 109 本と V-0328 の 20 本）の内訳、遠 A 67・遠 B 62 から（近の 0.4 : 0.6、中遠の 0.3 : 0.3 : 0.4 と同じく 2 桁に丸める）。
   - 3 分モードの並び（`range-3min-jump` の `landings`）の `"far"` は、近の `"near"` と同じく配分の id にする（並びは変えない）。
   - 距離の範囲は 2 か所とも今の遠と同じ 45〜55。遠 B が距離ボーナスの境目（55）を跨ぐかは測っていない（V-0228「分からないこと」）。
2. **的の表の値** — 推奨: SMG の弾丸命中率だけ `farA` 0.8068・`farB` 0.7608（V-0328 の H2。撮る前に固定した値のまま）にし、SMG の帯の値 `far`（0.76）は消す（使われなくなるので）。ほかの武器種の弾丸命中率と、すべての武器種のコア命中率は、帯の値 `far` を 2 か所に共通に使う（表は「着地点の id → 帯 → all」の順で引くので、書き足さなくてよい）。
   - 混ぜた期待値は 0.52 × 0.8068 + 0.48 × 0.7608 = 0.7847 で、今の 0.760 より 3.3% 高い。表を使う SMG の枠の遠の区間の与ダメージと 1 パス目のゲージが、その分上がる。
   - 命中率▲（C-0192）は着地点ごとに当ててから混ぜる（`landingPartsWith`。中遠と同じ）。
   - 誘導弾の飛ぶ時間（`flightFrames`）の遠は、帯の代表値（28・23）のまま（2026-10-05 のオーナーの決定「着地点ごとの値は帯のまま」。C-0413）。
3. **照合での固定** — 推奨: 観測値の `compare.setup` に `farLanding`（A・B の並び。1 回目・2 回目の遠の順。condition が auto のときだけ）を足す。近の `nearLanding` と同じ形で、`enemyLandingsOf` の配分ごとの並びの固定をそのまま使う。sim-run には `--far A,B`。
   - 遠の着地点を読んだ録画（V-0228・V-0328 の位置の観測値で、足元が 540 以上か 536 以下）の、SMG を含む自動の条件の照合の観測値に、読んだ着地点（3 区間目の遠。1 回目）を付ける。6 区間目の遠は読んでいないので配分のまま。足元が間（537〜539）の録画と、読んでいない録画は付けない。
   - V-0328 の判定の指標 `329-06`・`330-06` は、それぞれ遠 A・遠 B に固定する。
4. **結論** — 推奨: 次の 3 つにする。
   - 新しい結論（V-0328）: 「射撃場の SMG 単騎・AUTO の遠の弾丸命中率は、遠の着地点で違う。遠 A 0.8068・遠 B 0.7608」。等級 反復実測（値は V-0200・V-0215 の 40 本、再現は V-0328 の 20 本）。目安の境目に近いこと・着地点ごとにも残る録画ごとの散らばり・差の大きさの揺れを注記に書く。
   - C-0333 を棄却し、配分を 129 本の内訳にした結論に置き換える（状態は仮説のまま。V-0228 の大きさの見込みを外した点は変わらない）。モデル側は「反映」（`farA`・`farB` と配分）。
   - C-0320 を棄却し、SMG の遠の弾丸命中率を除いた結論に置き換える（C-0295 → C-0319・C-0320 のときと同じ）。

# V-0057: 武器の CDN の秒（リロード・チャージ）は 1 秒 = 58.82f で進むか（V-0011 の見直し）

### 読む前に分かっていること（既存の値からの試算）

**(1) 今の録画 4 点の傾き**: V-0055 の最終弾 → 完了の平均（AR 1 秒・SMG 1.5 秒・SR 2 秒・MG 2.5 秒。窓をまたがない回）に、傾きと切片が 1 つずつの直線を当てはめた。

| 当てはめ                                                      | 傾き（f/秒） | SE   | 切片（f） | 残差の最大 |
| ------------------------------------------------------------- | ------------ | ---- | --------- | ---------- |
| 最終弾 → 完了の平均（`073-04`・`054-08`・`075-08`・`072-05`） | 59.01        | 0.15 | 11.0      | 0.19       |
| バーの長さ（`073-06`・`054-10`・`075-09`・`072-07`）          | 58.80        | 0.43 | 11.4      | 0.49       |
| 旧の録画 3 点（`L-AD-07`・`L-AI-04`・`L-AN-05` の平均）       | 59.29        | 0.22 | 11.8      | 0.19       |

- 今の 4 点では、W1 の 58.82 は傾きの 1.3SE、W0 の 60 は 6.5SE 離れている。ただし SE は自由度 2 の粗い値で、4 点は武器種がすべて違う（W0' を外せない）。旧の 3 点は W1 から 2.2SE、W0 から 3.3SE（自由度 1）。
- いちばん離れた 2 点（1 秒と 2.5 秒）の差は、W0 と W1 の予測で 1.8f しか違わない。

**(2) リロード明けの較正値の読み**: 最終弾 → 次の 1 発目から、リロード（切り上げ）を引いた残り。W0 で数えると、リロードが長いほど残りが短い（C-0059 の 22f と C-0002 の 20f の違いはこの形）。W1c で数えると、武器によらず 22〜24f。

| 武器（リロード）         | 観測値   | 最終弾 → 次の 1 発目 | − W0（60f・切り上げ） | − W1c（58.82f・切り上げ） |
| ------------------------ | -------- | -------------------- | --------------------- | ------------------------- |
| AR クルミ（1 秒）        | `004-01` | 82                   | 22                    | 23                        |
| SMG ミサト（1 秒）       | `005-01` | 83・83               | 23                    | 24                        |

| MG エマ（2.5・AI）       | `035-03` | 171 × 3              | 21                    | 23                        |

- 今の録画の AR（`073`）・SMG（`054`）・MG（`072`）も、V-0046 の「最終弾 → 完了 + 完了 → 1 発目」の和で同じ向き（W0 で 22・22・20〜21f、W1c で 23・23・22〜23f）。
- ±1f の幅では、どちらの列も「そろっている」と言えてしまう。向き（W0 の列だけがリロードの長さとともに下がる）は、傾きの判定と同じ情報で、別の判定には数えない。

**(3) 段 A の見分けの強さの見込み**: 設計書 5.1 節の録画を 1 本 1 点とし、武器種ごとに切片を持たせたときの秒の散らばり（武器種の中の偏差の平方和）は 1.37（AR 0.46・SR 0.47・SMG 0.19・SG 0.20・MG 0.06。RL は 2 秒だけで効かない）。点ごとのばらつき σ（平均の読みの誤差とキャラの違い）に対する傾きの SE は、σ = 0.2f で 0.17、0.3f で 0.26、0.4f で 0.34。今の 4 点の残差（最大 0.19f）ほどなら、判定の基準（SE ≤ 0.3）に届く。

## 予測（撮る前に書く）

読み直しの前（2026-09-30）に書いた。W1 の値は切り上げ（W1c）と丸めない（W1x）の両方を書く。

**A-1 リロードの主判定（武器種ごとに切片を持たせた傾き）**

| 仮説 | 傾き  | 武器種ごとの切片（C-0135 の c） |
| ---- | ----- | ------------------------------- |
| W0   | 60    | そろう（武器種によらない）      |
| W0'  | 60    | 武器種ごとに違う                |
| W1   | 58.82 | そろう（今の世代で約 11〜12f）  |

- 武器種の中の 1 組だけでは差が小さい（W0 / W1x / W1c）: AR 1 → 1.67 秒 40.2 / 39.4 / 40（切り上げ 41 / 40）、SMG 1 → 1.5 秒 30 / 29.4 / 30、SR 1.5 → 2 秒 30 / 29.4 / 29、SG 1.5 → 1.86 秒 21.6 / 21.2 / 21（切り上げ 22 / 21）、MG 2.3 → 2.5 秒 12 / 11.8 / 12。どれも 1f 未満で、1 組では見分けられない。まとめた傾きだけが見分けに使える。
- 今の 4 点の試算（条件の (1)）どおりなら、傾きは 58.8〜59.1 の間に出て、W1 が合い W0 は外れる。そのとき W0' を外せるかは、武器種ごとに切片を持たせても傾きが 60 から離れるか（W0' なら 60 に戻る）で決まる。

**A-2 足す長さ c が武器種によらないか（秒が 2 の SR・RL）**

- W0・W1 とも、SR（ラム・ヘルム・アリス）と RL（フラワー・ベロータ）の最終弾 → 完了は ±1f でそろう。そろわなければ W0' の形（武器種ごとの足す長さ）がありうることになり、武器種をまたいだ比較（段 B の別案）は使わない。W0 と W1 はこの値では見分けられない。

**A-3 チャージの主判定（チャージの長さ = 表示の幅 ÷ 1 フレームの伸び）**

| 武器（チャージ）                 | W0   | W1x   | 1 フレームの伸びの例（W0 / W1x）  |
| -------------------------------- | ---- | ----- | --------------------------------- |
| ラム・デルタ・ヘルム（1 秒）     | 60.0 | 58.82 | ラム（100 → 250%）: 2.50 / 2.55 % |
| ベロータ（1.5 秒）               | 90.0 | 88.24 | —                                 |
| 紅蓮BS（0.3 秒。見分けられない） | 18.0 | 17.65 | 100 → 150%: 2.78 / 2.83 %         |

- `075-05` の注記（1 フレーム約 2.6%）は W1 寄りだが、概算の値なので判定に使わない。
- 表示が秒に比例して伸びない（始まりか終わりで止まる）なら、チャージの長さはこの読み方では出せない。そのときは、伸びの一定な区間だけで伸びを出し、全長は表示が 100% を出たフレームと満ちたフレームの差（整数）で補う。

**A-4 補助**

- 分割リロードの段の長さ（段ごとの足す長さが無いとき）: ソーダ：TB・プロダクト23（0.67 秒）は W0 40.2 / W1x 39.4、ノワール（0.23 秒）は 13.8 / 13.5。
- チャージ武器のリロードの分（最終弾 → 次の 1 発目 − 発と発の間）: リロード 2 秒で W0 120 / W1c 118、1.5 秒で 90 / 89。1f 未満の足す長さを含みうる。
- 旧の録画の世代の中の傾き: 条件の (1) の 59.29 から大きく動かない見込み（読み直すのは時計の速さだけ）。

**A-5 旧の録画の時計の速さ（H-old）**

- 旧の録画も 1 秒あたり約 58.82f なら、今との 1〜1.5f の差は時計ではない（ゲームの更新・キャラの違いが残る）。
- 旧の録画の 1 秒あたりのフレームが多く、その値 × リロードの秒を引いた残りが今の c と ±0.5f でそろえば、H-old（旧の録画は時計の進みが違い、リロードはどちらの世代でもゲーム内の時計で進む）。そろうのに要る速さは、AR・SMG・MG の 3 点で 1 秒あたり約 59.5〜60f。

**外れたときの影響**

- W1 に決まれば: 較正値（C-0001・C-0002・C-0014・C-0059）を読み直し（設計書 7 節）、C-0002 と C-0059 は 1 つの値（見込み 23f）にまとまる見込み。単騎の合計の予測は 1% 未満しか動かない（1 周期が 0〜2f）。較正に使っていない長いリロード（2.5 秒を超える武器）の周期が 2〜3f 短くなる。
- W0 のままなら: 今のモデルのまま。C-0135 は「58.82f で数えるとそろう」が偶然か、足す長さが武器種ごとに違う（W0'）ことになる。
- W0' なら: 武器種ごとの足す長さの問いを別に立てる（この検証ではモデルを変えない）。

## 読み方

1. **バー**: 設計書 8 節の `tools/captures/reload.ts`（作るまでは V-0046 の読み方と同じ使い捨てのスクリプト）で、各録画のバーの区間を全部拾う。的のジャンプの窓をまたぐ回（取り消し・満ちきらない回）は除く。まず 073・054・072・075 で `073-04`〜`075-09` の値が再現できることを確かめる。
2. **最終弾**: `hud.ts --mode jumps` の、バーの区間の前の最後の増分。バーの伸びを遡った 0 の点から 3f 以上離れた回は、増分の読み違いとして 1 フレームずつ切り出して画面の残弾で確かめる（V-0055 と同じ）。操作の録画（001〜036）は、照準の横の残弾が 000 になってからのリロードだけを使う（手でリロードした回を除く）。
3. **平均と SE**: 録画ごとに、最終弾 → 完了の平均・標準偏差・回数（10 回以上）を出す。バーの伸びから出したバーの長さも同じように出す。
4. **当てはめ**: 今の世代の点に、傾きが共通で切片が武器種ごとに違う直線を、点ごとの SE の重みで当てはめる。秒をそのまま使ったもの（W1x）と、仮説の丸めでフレームにしたもの（W0・W1c）の両方で判定する（設計書 4 節）。
5. **c の武器種の違い**: 秒が 2 の SR・RL の平均を並べる（A-2）。
6. **チャージ**: 照準の横のチャージの表示を `still.ts` で切り出し、1 回のチャージの 100% を出た直後と満ちる直前の 2 フレームの % を目で読む。伸び = % の差 ÷ フレームの差、チャージの長さ = 表示の幅（フルチャージの % − 100%）÷ 伸び。1 本につき 10 回以上。アリス（`089`）はチャージ速度▲が付いていない発だけ。
7. **旧の録画の時計**: `timer.ts --mode summary` で `L-AD`・`L-AI`・`L-AN` の残り時間 1 秒あたりのフレーム数を出す（C-0048 と同じ読み方）。録画のフレームの刻み（`probe.ts`）も確かめる。
8. **紅蓮BS**: `046`・`055` の発と発の間・最終弾 → 完了 → 次の 1 発目を観測値にする（設計書 7 節の 4。C-0014 の根拠は凍結した記録なので）。判定には使わない。
9. 読んだ値は観測値にする（`source` に `V-0057`）。録画ごとの最終弾 → 完了の各回とバーの長さ、チャージの伸び、旧の録画の時計の速さ。

## 次に撮るもの

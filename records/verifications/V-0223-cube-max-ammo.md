# V-0223: キューブの最大装弾数▲は、マガジンの弾数にどう効くか

- 問い: スペック固定 OFF のマナ単騎で、タクティカルブーストキューブの「最大装弾数▲」は、OL の最大装弾数増加と合わせて、マガジンの弾数にどう効くか

- 状態: 調査中

## 条件

- Stage 13 の残り（[design-stage12.md](../../plan/design-stage12.md) 3.5 節の 6）。
- 録画 2（V-0221「次に撮るもの」）: マナ単騎にタクティカルブーストキューブを付ける。ほかの条件は V-0221 の録画 1 と同じ。
- 最小構成: マガジンの弾数に効くのは、CDN の最大装弾数（60）、OL の 2 行（V-0222 で先に決める）と、問いのキューブだけ。録画 1 を先に撮って読み、OL だけの弾数が V-0222 の H1 で合ったときに、この録画の未確定の要素はキューブの 1 つになる。
- キューブの値は data/masters/cubes.json の段階の値（Lv8 は段階 3）。

## 予測（撮る前に書く）

H1 はいまのモデル（OL の 2 行とキューブの値を足して round(60 × (1 + Σ))）、H0 はキューブが乗らない形（OL だけ）で、値は予測ファイル（records/predictions/V-0223.json）にある。H2（OL で丸めた弾数にキューブの (1 + 値) を掛けて丸める）は式を切り替える仮説なので、ここに手で書いた。どれも V-0222 の H1（OL の 2 行を足す）を前提にする。

| 仮説                          | マガジンの弾数 |
| ----------------------------- | -------------- |
| H1: 足して丸める              | 予測           |
| H0: 乗らない                  | 予測           |
| H2: OL の後にキューブを掛ける | 182            |

- 見分け方: V-0222 と同じ。3 つの仮説は 10 発以上離れる。
- 合えば: H1 ならモデルはそのまま。
- 合わなければ: `effectiveMaxAmmo` の合成（効果層の出どころごとの順）を直す。
